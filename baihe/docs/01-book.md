# 01 · 选书：《鬼谷子》——口者心之门户，关之以捭阖

## 为什么是《鬼谷子》

给「Agent 信息出境治理」找思想源头，先排掉已被本仓占用的书：道德经（zhizhi，其「塞其兑，闭其门」本是最贴合的出处，但一仓不重引一书）、荀子（jiebi）、六祖坛经（zhengnian）、黄帝内经（weibing）、孙子兵法（jiubian）、庄子养生主（youya）、孟子（lunshi）、商君书（dingfen，在途）、周易（licheng，在途——「言行君子之枢机」的地盘在承诺）、论语（buer，在途）。

《鬼谷子》是先秦纵横家的立派之书，后世注家常以道家一脉视之（《隋书·经籍志》列纵横家）。它不只是讲「要保密」——它给**开与闭这对机制**（捭阖即开闭，是一套可操作的机制而非一句告诫）、给**口的本体论地位**（口者心之门户，志意思虑皆由此出入）、给**开口前称量物之轻重的程序**（权衡轻重，乃为之度数）、给**分对象而异的言说规矩**（与阳言依崇高，与阴言依卑小）、还给**对裂缝的分级处置**（可抵而塞）。这五件事恰好是出境治理的五个设计支柱，且《鬼谷子》未被本仓任何项目使用。

需要诚实处理的气质问题：《鬼谷子》常被读作权谋书。本层只取其**开闭之道**——捭阖讲的是「什么该出、什么该闭、出给谁要分寸」，把它用于信息出域的权界，是正用而非术用。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《鬼谷子》原文 | Agent 的病 | 捭阖的机制 |
|---|---|---|
| 捭阖第一：**口者，心之门户也；心者，神之主也。志意、喜欲、思虑、智谋，皆由门户出入，故关之以捭阖，制之以开闭** | 工具参数就是 Agent 的口：内部之物（密钥、内部数据、凭据）全由这扇门出入——但没有任何机制管过这扇门的开闭。装了什么、放走了什么，账上全无 | **境账**：出境调用逐案记账——每次开口（含参数出境的调用）都有案可查 |
| 权篇：**口者，机关也，所以关闭情意也** | 出境即离手：机关一开，物就到了对端，**泄密不可撤回**——这与失诺（可以补救）有本质区别，事后唯一能做的是知道泄了什么、泄到哪 | 泄物以「成功出境」为准（失败出境记**试出**只点名不计分——宁漏勿诬），案案入账、逐件点名 |
| 捭阖第一：**捭之者，开也，言也，阳也；阖之者，闭也，默也，阴也** | 开与闭两态无人记录：出了什么、出给谁、是内域还是外域，无处问起 | 境账逐案记**开闭**（出境/试出）与**域别**（内域/外域） |
| 捭阖第一：**即欲捭之贵周，即欲阖之贵密。周密之贵微，而与道相追** | 该周的没周全（出给谁不明不白），该密的没密住（物原样出境）——病没有量级，一次泄密与零次泄密在报告里看不出区别 | **溃值**分带：**密(0–14) / 疏(15–29) / 溃(≥30)**——堤之于蚁穴，罅在账面见级差 |
| 捭阖第一：**皆见其权衡轻重，乃为之度数** | 出口之前没有人称量过参数里物的轻重：物长什么样、什么是物，连标准都没有 | **阖籍**：物的清单 = 显式登记（声明权在任务方）与默认形表取并集——出境检测对着这份籍逐项称量 |
| 捭阖第一：**捭阖之道，以阴阳试之。故与阳言者依崇高，与阴言者依卑小** | 对内域网关与对外域第三方应当依不同的规矩说话，现在一视同仁：发给自家网关的凭据与发给陌生域名的凭据在审计里毫无区别 | **域别**：内域（白名单 + 回环）出境是本职，记档不计分；外域泄物才计分 |
| 抵巇第四：**巇者，罅也。……巇始有眹，可抵而塞** | 泄密是堤之罅；看不见罅在哪里，就无从抵塞——只能「全部密钥轮换」这种最贵的方式 | **阖门块**逐案点名罅之所在（位次 + host + 形名 + 掩码摘录），CI 门禁可断言——抵而塞，不必决堤 |
| 反应第二：**反以观往，覆以验来** | 出境是瞬时单向的事，事后想复盘「历史会话泄过什么」，连工具都没有 | 契约无关：任何历史会话流可离线验尸，与在线账本逐字对账 |

## 与管理学互证

- **OWASP Top 10 for LLM Applications：LLM06 Sensitive Information Disclosure**——敏感信息泄露是行业公认的 LLM 应用六大风险之一；prompt 注入（LLM01）已有论世看守输入侧，本层看守输出侧，两者合拢才成闭环。
- **最小权限原则（Least Privilege）**：凭据只应流向完成工作所必需的最小范围。域别记账把这个原则变成可审计的事实：内域是「必需」，外域需要显式声明。
- **DLP（Data Loss Prevention）的内容感知出域控制**：企业级 DLP 的成熟做法——先有敏感物登记（内容识别规则），再对出境通道逐件扫描。本层把这套流程做成零依赖、确定性、可进 CI 的 Agent 版。

## 与相邻层的分工

- **论世 lunshi（孟子）是镜子里的对面**：论世审「进来的内容有没有资格发令」（输入权界，防物僭主），捭阖审「出去的参数里有没有不该出的物」（输出权界，防物出境）。一进一出，方向相反，互不引词、互不越界。
- **知止 zhizhi（道德经）拦动作**：出境拦截是行为节制的地盘。捭阖结构性零拦截（插件不存在 pre-execute 监听器），只审计、计分、供给——观察层绝不干扰管道。
- **有涯 youya（庄子）管不忘，本层管不出**：复见复命是「世未变而它忘了」；本层是「物在手而它轻出」。一个看装载的连续性，一个看出境的权界，对象不同。
- 装载不入账：Agent 为了干活读 .env、读密钥文件，是域内的合法行为——**手里有物不罚，物出境才罚**。这是本层与 DLP 的关键边界，也是「宁漏勿诬」的体现。
