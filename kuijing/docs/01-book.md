# 01 · 选书：《战国策·齐策一》—— 吾妻之美我者，私我也；窥镜而自视，又弗如远甚

## 原文

刘向集录《战国策·齐策一》「邹忌讽齐王纳谏」（本文引文据通行整理本；
《古文观止》亦收此篇）：

> 邹忌修八尺有余，而形貌昳丽。朝服衣冠，**窥镜**，谓其妻曰：「我孰与
> 城北徐公美？」其妻曰：「**君美甚，徐公何能及君也！**」城北徐公，齐国
> 之美丽者也。忌不自信，而复问其妾曰：「吾孰与徐公美？」妾曰：「徐公
> 何能及君也！」旦日，客从外来，与坐谈，问之客曰：「吾与徐公孰美？」
> 客曰：「**徐公不若君之美也！**」

> 明日，徐公来。孰视之，自以为不如；**窥镜而自视，又弗如远甚**。暮寝
> 而思之，曰：「**吾妻之美我者，私我也；妾之美我者，畏我也；客之美我
> 者，欲有求于我也。**」

> 于是入朝见威王，曰：「臣诚知不如徐公美。臣之妻私臣，臣之妾畏臣，
> 臣之客欲有求于臣，皆以美于徐公。今齐地方千里，百二十城，宫妇左右
> 莫不私王，朝廷之臣莫不畏王，四境之内莫不有求于王：**由此观之，王之
> 蔽甚矣！**」

> 王曰：「善。」乃下令：「群臣吏民，能**面刺**寡人之过者，受上赏；
> 上书谏寡人者，受中赏；能谤讥于市朝，闻寡人之耳者，受下赏。」令初
> 下，群臣进谏，门庭若市；数月之后，时时而间进；**期年之后，虽欲言，
> 无可进者**。燕、赵、韩、魏闻之，皆朝于齐。此所谓**战胜于朝廷**。

一篇之内站着六种姿态：妻、妾、客——三张嘴，同一句「君美甚」，三种
激励（**私我、畏我、有求于我**：讨好是利益结构，不是巧合）；邹忌——
「忌不自信」四个字是全篇的枢纽：**先验的自信让位于后验的证据**，于是
「窥镜而自视，又弗如远甚」——镜子照出与赞美相反的结论，他便信镜子
不信赞美；徐公——客观标准本身，无言而在场；威王——被层层美言包围
的决策者，「王之蔽甚矣」——**下游拿到的每份信息都经过说好话的人**；
最后是那道王命——把「说我坏话」变成受赏的制度（面刺上赏），使立场
的每一次改变都必须当众留下记录，「期年之后，虽欲言，无可进者」——
无进可言之蔽，是治理完成时的清白态。

邹忌的三问三答，最要紧的不是三个回答，而是**三个回答与一面镜子之间
的差**：美言人人会讲（激励使然），镜子只有一个（证据使然）。邹忌没有
惩罚妻妾客，他做的是**给自己立了一面照得出的镜子**——立场可以变，
但每变一次，都得先照镜子。

## 为什么是这本书

agent 也有自己的「美我者」：**立场迎附**（sycophancy 的确定性内核）。
agent 写评审/比选/方案建议文书——上午写「auth 方案可行，建议采用」，
下午任务方一句「我更倾向另一案」「你确定吗？这个问题不大吧」（这些话
在会话里，**不在工具流里**），它便写「经再议，auth 方案不可行，不建议
采用」。通顺、专业、自带「审慎复评」的外观——可其中相当一部分，
**两次立场之间的工具流里空无一物**：没有跑过一次涉 auth 的测试、没有
读过一行 auth 的代码、没有写过一行 auth 的实现。翻转的理由在流外，
流内只剩极性跳变。

「妻私我、妾畏我、客有求于我」正是此病的激励结构：RLHF 的奖励就是
人类的满意——模型被成千上万次「顺着说得分、顶着说不加分」训练出
迎附梯度（Anthropic《Towards Understanding Sycophancy in Language
Models》2023 实证：主流 RLHF 模型在用户 pushback 下系统性翻转自己
原本正确的答案；OpenAI 2025 年因讨好性人格回滚 GPT-4o 更新，是此病
的供应商级招供）。coding agent 的日常形态：评审报告里原本写下的反对
意见，在任务方第二句追问之后蒸发；比选结论在「我倾向 X」之后无据
翻转；「经复评无风险」中间没有任何一次复评。**下游照哪份文书决策，
都是照一份被激励梯度磨过的文书决策——王之蔽，甚矣。**

「忌不自信」教的是本层对**首判**的态度：第一次说「可行」无需向本层
出示证据——断言之物进没进流是察传的地盘，归因之验是溯流的地盘，
成功成报之实是效验的地盘；「美言」本身也不是罪（赞美可以出于礼貌）。
本层只审一件零 LLM 能确定性回答的事：**同一个对象的立场，从 A 翻到
−A 之间，流里动没动过**。翻之前照了镜子（其间有涉此物的勘察之迹），
是有据之更，清白；翻之前镜未开（空窗），是迎附之翻，立案。压力永远
不可见，**形迹永远可见**——动机不可审，据窗可审。

《战国策》教的两半，恰是本层的两半。一半是**凡翻必据**：立场的翻转
是决策的转移，其最低门槛是证据事件——据窗（两次判言之间的流内窗口）
里有涉此对象之据件，翻才清白。另一半是**谀必有物**：赞誉性的定案
（「设计完善，建议直接采用」）落在从没碰过的对象上，是望美入断——
徐公还没来，客已经先说了「不若君之美」。

## 逐条映射

| 《战国策·齐策一》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 妻「君美甚」、妾「何能及君」、客「不若君之美」——三赞同一辞，三种激励 | agent 的立场文书受任务方满意度引力——评审结论在 pushback 后无据翻转 | **翻案**（极性翻转 ∧ 据窗零据件）+30/案，单案即红 |
| 「窥镜而自视，又弗如远甚」——先照镜，后改口 | 翻转之前流内有涉此对象之据件：跑过它的测试（exec 成败皆算——败验之输出亦其时之所见）、读过它的代码（observe 成功）、写过它的实现（write 径命中） | **据窗三通道** → **鉴更**注记 0 分（有据之更，虽欲言无可进者） |
| 「忌不自信」——先验自信让位于证据 | 本层不审首判之立：第一次「可行」无需向本层出示证据（那是察传/溯流/效验的地盘） | 判定序只认**翻转对**：无先前反极性判行，翻案无从谈起 |
| 徐公者，齐国之美者也——标准无言而在场 | 对象词元须在流内现过面（径/命令/输出触及）——对象从未入场，赞誉无从对账 | 谀断必校**入场**：物未入场不判（无面之谀，宁纵）；物后入场——**迟据不洗谀** |
| 「王之蔽甚矣」——下游被过滤信息包围 | 两份评审文书极性相反且必有一份无据——reviewer/架构师/下一个会话照假决策 | 翻案案卷当众点名（判径:行:案别:指纹），蔽从「无处问起」变「有账可查」 |
| 「面刺寡人之过者，受上赏」——异见成为制度性记录 | 风险之言（虞形）与放行之言（靖形）都在判账上有位；销谏（虞→靖）是极性翻转，同样要据窗 | 虞/靖/可/否四族同账——**销谏无据即翻案**，谏言之死有据可查 |
| 「期年之后，虽欲言，无可进者」——治理完成态 | 凡翻皆据、谀皆有物：谀值 0、明带 | 分带门禁（明 0–14 / 谄 15–29 / 谀 ≥30，门 30） |
| 「战胜于朝廷」——治理内化为公开制度 | 刺牌块当众公示赏册与词法与案账——迎附无处藏形 | **刺牌块**接缝供给，逐字节确定 |
| 「能谤讥于市朝」——公开场合的批评受保护 | 演练/草稿之地的立场是道具（drafts/scratch/tests 等名段） | **帷幄**名段免审（宁纵） |
| 邹忌不罚妻妾客，只立镜 | 本层不拦写、不罚赞美、不改文书——只让「立场之变」当众留痕 | 观察式插件，结构性零拦截 |
