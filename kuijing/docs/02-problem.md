# 02 · 问题：Agent 立场迎附（翻转无据——位随境转，翻不出一据）

## 谁在什么场景下的什么问题

**谁**：任务方与每一个照评审文书决策的人与会话——按 review.md 的
「可行」放行的 reviewer、按「经复评无风险」签收的项目方、用第二份
评估推翻第一份评估的架构师、照交接书最新结论绕开原方案的下一个
会话。

**场景**：agent 写评审/比选/方案建议/决策文书——docs/auth-review.md
上午写「auth 方案可行，建议采用」；下午（任务方说「我更倾向另一案」
「你确定吗？这个问题不大吧」——**这些话在会话里，不在工具流里**）
再写「经再议，auth 方案不可行，不建议采用」。通顺、专业、自带「审慎
复评」的外观，可其中相当一部分，**两次立场之间的工具流里空无一物**：
没有跑过一次涉 auth 的测试、没有读过一行 auth 的代码、没有写过一行
auth 的实现。另一种形态更隐蔽：agent 从没碰过 apollo（全流无一次涉
apollo 的 exec/observe/write），评审书写「apollo 方案设计完善，建议
直接采用」——任务方属意的方案获得了无勘察的赞誉，徐公未至而客先
言美。

**问题**：文书间**立场翻转无据**无账：

- **立场是决策的把手**：一句「可行」与一句「不可行」决定下游放行
  还是返工——两次极性相反的判言必有一份无据，下游照哪份决策都是
  照一份被激励梯度磨过的文书（王之蔽甚矣）；
- **压力不可见而形迹可见**：任务方的 pushback 在会话话语里，工具流
  永远看不见「谁在施压」；但「两个立场之间世界动没动」——有没有
  跑过它的测试、读过它的代码、写过它的实现——流里逐字可查。动机
  不可审，**据窗可审**；
- **翻转与有据之更无从区分**：「照过测试再改口」（窥镜而自视）与
  「没照镜直接改口」（顺着说）在文书上一模一样——事后连「这次翻转
  之间有没有勘察、谀断之言的对象碰没碰过、谏言怎么没的」三问都
  无处问起；
- **首判与更判同纸而居**：第一次「可行」无需证据（断言之物归察传、
  归因之验归溯流、成报之实归效验），翻转的「不可行」却必须有据——
  没有任何一层把「立场之变」单独立案。

相邻层的空白地：完成态声明有 shihu（状词对作工）、话语承诺有
licheng（绳账对兑现）、成功成报有 xiaoyan（效词对输出）、归因断言有
suliu（归因形对验因）、弃责宣告有 zizhao（弃责形对红账）、存在断言有
chachu（指物对流内之物）——**每层都审一句话对世界；没有一层审两句
话对彼此**：同一对象、极性相反、中间空窗。zhixia 审一卷之内的数目
自洽（言列总分——不需要时间），本层审两笔之间的极性账（跨文书、
跨版本、跨时间——必须有时间）。jiebi 审判断的结构失真（锚定/确认
偏误——判之前的蔽），本层审立场的时序跳变（判与判之间的空窗）——
它问「这个判断怎么做的」，本层问「这个立场为什么变了」。

## 问题（治什么病）

一个病根、四档判别，全部真实存在、全部当众可验：

| 档 | 卷面词迹 | 现实对应 |
|------|----------|----------|
| **翻案**（立案档 +30） | 判行（可/否/虞/靖形）+ 对象词元，先前有反极性判行，据窗零据件 | 上午「可行」下午「不可行」，其间没跑过一次 auth 的测试——顺着说，不照镜 |
| **谀断**（黄牌档 +15） | 褒形 ∧ 正极性首形 + 对象词元，先于本笔全流据件零，对象曾在场 | 全流没碰过 apollo，评审书却写「设计完善，建议直接采用」——徐公未至，客先言美 |
| **泛判**（注记档） | 判形命中而对象词元集为空（纯中文泛指） | 「本方案甚完善，建议采用」——判之无物，无从对账（宁纵） |
| **鉴更**（清白档） | 翻转但据窗有据件（败 exec 亦算——看过失败再改口是诚实） | 窥镜而自视，又弗如远甚——有据之更，0 分留痕 |

价值锚点：「这两次立场之间，流里动没动过」是**零 LLM 能确定性回答的
一问**——判形是显式词表、对象词元是 ASCII 切片、据件是流内事件与词
面的对账，逐字节可复算；不需要稿外之物（不读文件系统、不装语料、不
跑模型）。本层不做语义判断（不判哪个立场是对的——auth 到底可不可行，
词法不知道；也不判翻转的动机是迎附还是醒悟——裁决权归人），只做
时序判断（翻必有对象、对象必有先判、先判必反极性、反极性必查据窗、
据窗空才立案）。

## 价值（为什么不是伪需求）

1. **立场迎附是真实且高价的病形**：RLHF 的满意度奖励就是「妻私我、
   妾畏我、客有求于我」的激励结构——Anthropic 2023 年实证主流模型
   在用户 pushback 下系统性翻转正确答案；coding agent 的评审结论在
   任务方第二句追问之后无据蒸发，是 agent 评审可信度的显性抱怨。
   翻转无据正是这一族病的**最小可判定内核**（极性翻转 × 据窗空）；
2. **清白道宽、立案门窄**：鉴更 0 分（败 exec 亦据——看过失败再改口
   是诚实）、泛判注记、否定卫不判、无面之谀不判、帷幄与赏册免案
   ——只有「翻转 ∧ 空窗」才立翻案、只有「褒形 ∧ 正判 ∧ 零据 ∧
   曾在场」才立谀断——不冤照过镜的、不冤判之无物的、不冤如实否
   述的；
3. **记账不禁言**：不拦写（拦是 zhizhi 的地盘）、不改文书、不跑语义
   分析——判形与据件全是公开词法与流内事件比对，观察永不反噬；
4. **与相邻各层谓词正交而非重叠**：shihu/licheng/xiaoyan/suliu/
   zizhao/chachu 各审一句话对世界，本层审两句话对彼此（跨时间极性
   账）；zhixia 审卷内数目自洽（无时间），本层审卷间极性跳变（必有
   时间）——「同径新稿换稿」恰以历史为凭：v1 写「可行」v2 写
   「不可行」，v1 之案随稿撤、v1 之判入历史，翻案案附于 v2 之判行；
5. **谏言之死有账**：虞形（风险之言）与靖形（放行之言）同账同权——
   销谏（虞→靖）是极性翻转，「风险已排除」中间没有一次排除之据，
   即翻案立案——面刺受上赏的制度含义是：**异见可以更，不可以无声
   地没**；
6. **可证伪**：判面形、四族判形、褒形、否定卫、据件三通道、时序
   规则全部锁死于 03；同流重放必得同判词；跨项目历史流可验尸复算
   ——错了改实现，不改标准。

## 产品形态

- **窥镜式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：
  挂 `tools/result` 观察口，判账收全流记判行与据件，刺牌块接缝供给；
- **零依赖审计 CLI**（`kuijing`）：多流离线合审（跨会话判账与据件
  互认），可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的立场协议（凡翻必据、谀必有物、
  鉴而后更、销谏有据）。
