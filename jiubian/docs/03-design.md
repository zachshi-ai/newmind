# 03 · 设计：势账、失机值与变方（语义在本文件锁死，实现与测试不得擅自放宽）

> 本文件是唯一语义权威。所有评分常数、判定次序、豁免条款在这里定死；测试断言的就是这里的数字。

## 1 · 术语

| 术语 | 定义 |
|------|------|
| **势** | 世界的真实状态。九变不直接观测势，只观测势在会话流里留下的信号。 |
| **势变** | 一次 `isError:true` 的工具结果。世界说「不」的时刻，逐条入账。 |
| **途** | Agent 的动作路径：会话流里的调用序列。 |
| **对象键** | 一次调用的作用对象的结构化标识（见 §3）。 |
| **回应 / 变** | 势变之后路径给出的恰当结构回应，逐条记功。 |
| **盲捶** | 失败之后没有任何再察的逐字重试（同工具名+同对象键）。滞的一支。 |
| **悬** | 文件势变之后整条路径再未接触该对象。挂账点名，不计分。 |
| **离** | 命令势变之后再未重试该命令（改途离场）。涂有所不由，正当权利，不计分不挂账。 |
| **游骑** | 悬账未清时，连续 ≥3 个从未见过的新对象上的无凭动作。妄的一支。 |
| **失机值** | 滞分 + 妄分，0–100。滞 = 盲捶，妄 = 游骑。 |

## 2 · 流解析（与 zhizhi / jiebi / zhengnian 同格式）

每行一个 JSON 对象；`#` 与空行为注释；坏行报行号。识别 `tool_call` / `tool_result` / `turn_start` / `turn_end` / `reanchor`。调用归并规则与 zhengnian 的解析器一致：

- 带 id：call 建档（id 首见为准），result 按 id 回填 `isError`；
- 无 id（zhizhi 旧格式）：result 并入紧邻其前的无 id call；
- 孤儿 result 独立建档——不丢任何一次真实执行。

产出：`calls`（时间序：`{ ref, name, args, isError, at }`）。

## 3 · 对象键与工具族（零 NLP，只看显式字段）

**对象键**（按序取第一个命中）：

1. `args.path` / `args.file_path` / `args.notebook_path`（字符串）→ `p:<值>`（文件对象）
2. `args.command`（字符串）→ `c:<trim 后原串>`（命令对象）
3. 其余 → `n:<工具名>`（不透明对象）

**工具族**（先按名字精确集合，再按包含词；大小写不敏感）：

| 族 | 精确名 | 包含词 | 语义 |
|----|--------|--------|------|
| 观察 | `read` `glob` `grep` `ls` `cat` `view` | `read` `grep` `glob` `list` `search` | 再察的合法手段 |
| 写 | `write` `edit` `apply` `create` `move` `remove` | `write` `edit` `patch` `insert` `create` | 改变世界 |
| 执行 | `bash` `exec` `run` `shell` `command` | `bash` `exec` `run` `shell` `command` | 改变世界 |
| 其他 | — | — | 视同「改变世界」参与游骑判定，不参与再察 |

## 4 · 逐势变裁决（first-touch 决定，时序扫描）

对第 i 次调用（isError:true，对象键 o，工具名 t），向后扫描：

**p: 对象（文件）：**

- 首个「观察族且对象=o」的调用 → 裁决 **变**（再察了；若此前已产生过本势变的盲捶裁决，则盲捶照记，再察另记 healed，不 retroactive 撤销）；
- 首个「工具名=t 且对象=o」的调用（逐字重试），且此前无观察 → 裁决 **盲捶**；
- 直至流结束既无观察也无重试 → 裁决 **悬**（挂账）。

**c: 对象（命令）：**

- 失败与首个逐字重试（工具名=t 且对象=o）之间，存在 ≥1 个「族或对象不同」的动作 → 裁决 **变**（路径动过了，重试是有据的复核）；
- 失败后紧邻的逐字重试，中间无任何动作 → 裁决 **盲捶**；
- 直至流结束无重试 → 裁决 **离**（正当改途，不记不挂）。

**n: 对象（不透明）：** 按 c: 规则处理。

每条势变恰有一个裁决（首触决定）：`变` / `盲捶` / `悬` / `离`。重试本身失败会产生**新的**势变，走同样的裁决——链条由此自然生长。

## 5 · 计分（常数锁死）

### 5.1 滞 = 盲捶

- 按流序收集全部盲捶裁决；**相邻且对象键相同**的盲捶连成链；
- 每链首记**免分**（瞬时错误重试合法），链内此后每记 **+12**；
- 滞分 cap **60**。

### 5.2 妄 = 游骑

- 前提：游骑段开始时至段内任一时刻，存在 ≥1 条**未归还的 p: 势变**（裁决尚未定，且对象未再被接触）；
- 游骑段 = 极大连续段，段内每次调用同时满足：(a) 对象键在**全流历史中首次出现**；(b) 工具族**非观察**；
- 段被以下任一情况打断：观察族调用（任何对象）、接触任何未归还势变的对象、流结束；
- 段长 ≥ **3** → 记一次游骑，**+20**；
- 妄分 cap **40**。

### 5.3 失机值

```
失机值 = min(100, 滞分 + 妄分)      滞 ∈ [0,60]，妄 ∈ [0,40]
分带：  0–14 合 ｜ 15–29 钝 ｜ ≥30 胶
门：    默认 30（≥ 门 → fail）
```

「合」：势途相合；「钝」：反应迟滞的苗头；「胶」：胶柱鼓瑟。

## 6 · 变方（接缝处的应变清单，逐字节确定）

```
【九变 · 变方】势账 #<k>
兵无常势，水无常形——下列势变悬而未决，下一动作必须二选一：
  · 回到对象，先行再察（read/grep 原对象）
  · 明改其途：换工具族且换对象，并在动作里留下对势变的可寻址痕迹
悬账（文件势变未归还）：
  <n>. [第<seq>次动作] <工具名> <对象键>
（无悬账时本节显示：悬账：无——势途相合，续行。）
盲捶前科：<b> 记 ｜ 游骑前科：<g> 轮 ｜ 失机值：<s>（<带>）
—— 本块由确定性规则生成；重放同一流必得同一文本。
```

- `<k>` 为渲染序号：CLI 恒为 1；插件内每次调用递增（#1、#2、…）；
- 给定同一份流（或插件同一账本状态），输出逐字节相同——shasum 可证；
- 悬账排序：按势变发生序（seq 升定）。

## 7 · 插件（勘流式，结构性零拦截）

- Cordis 服务 `jiubian`，`inject: ['tools']`，只挂 `ctx.on('tools/result')`，从 `exec.name` / `exec.arguments` / `result.isError` 取数——**源码不存在 pre-execute 监听器**（grep 可证）；
- 观察永不反噬：监听器内任何异常吞掉，管道照常；
- 服务 API（声明合并到 `ctx.jiubian`）：`report()`（观察数/势变数/前科/失机值）、`shi()`（逐条势账与裁决）、`bianfang()`（变方块，`{ text, k, openDebts }`）、`exportStream()`（导出事件流供离线重放）、`gate()`（门禁裁决）；
- 配置：`{ gate?: number }`，其余语义常数不开放配置——放宽门槛就是放宽验收。

## 8 · CLI（零依赖，exit 0/1/2）

```
jiubian audit <stream.jsonl> [--gate <n>] [--json]   势账审计（含失机值与分带）
jiubian bianfang <stream.jsonl> [--json]             变方块（默认纯文本）
jiubian gate --value <n> [--gate <n>]                门禁裁决
jiubian --help | --version
```

- `audit`：失机值 ≥ 门 → exit 1；干净 → exit 0；不可读/坏 JSON → exit 2；
- 无契约参数——九变契约无关，任何历史会话流直接验尸；
- JSON 输出全部可序列化、可离线重放对账。

## 9 · 边界声明（结构性，不是纪律性）

1. 插件源码无 `pre-execute` 监听器——零拦截可 grep 验证（A7）；
2. 不审判断账本（jiebi）、不守本愿契约（zhengnian）、不记跨会话事故账（buer）、不做 t=0 四诊（weibing）；
3. 零 LLM 调用、零网络、零 NLP——对象键是显式字段，不是语义抽取；
4. 悬账、离不计分：分只罚盲捶与游骑两宗结构可证之罪。
