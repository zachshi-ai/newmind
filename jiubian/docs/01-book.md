# 01 · 选书：《孙子兵法》——两千五百年前的「九变」，治的是 2026 年 Agent 最隐蔽的一种浪费：世界已经变了，它还在按开工时的旧图作战

## 一、2026 年，Agent 的第六种昂贵失败：不是停不下来，不是想错了，不是忘了本愿，不是重蹈覆辙，也不是带病开工——而是**世界变了，它没看见**

本实验室已上线的五层治理，各守一个时点与对象：

| 层 | 思想源头 | 治什么 | 工作的时点 |
|---|---|---|---|
| 知止 zhizhi（手） | 《道德经》 | 行为失控：连败死循环、未读先写、无证据宣称完成 | pre-execute 拦截 / 完成时核对 |
| 解蔽 jiebi（眼） | 《荀子·解蔽》 | 判断失真：锚定、确认偏误、不可证伪 | tools/result 审判断账本 |
| 正念 zhengnian（心） | 《六祖坛经》 | 意图漂移：失念、攀缘、代偿完成 | 全程度量 + 接缝供给 |
| 不贰 buer（习） | 《论语》「不贰过」 | 重蹈覆辙：同样的错跨会话再犯 | 事故过账后 |
| 治未病 weibing（工） | 《黄帝内经》 | 带病开工：任务书与环境 t=0 的病灶 | 开工之前 |

六层合起来，手、眼、心、习、工都有了看护。但跑过很多 Agent 任务的人还会遇到第六种下午：**开工时一切正常，中局世界悄悄变了，Agent 还在按开工时的旧图作战**。

这不是假想。任何一个在真实机器上跑过长任务的人都见过：

- 并发会话/并发进程改了文件，Agent 的 edit 撞上 "modified since read"——它**不回头重读**，换个姿势继续写同一个文件；

- `npm test` 连败五次，五次的命令与参数**逐字相同**，中间没有任何一次「先看看为什么失败」；

- 一个文件 edit 失败之后，Agent 全程再没有回到过它——以为什么都没发生，收尾报告里也没提；

- 更隐蔽的一种：悬着的失败没人管，Agent 却**连开三条新战线**——新建这个模块、重构那个脚本、顺手补另一份文档，每一件单看都「像是在干活」，合起来是望风而动：没有任何新证据说这些新战线是当下该做的事。

这些失败有一个共同结构：**「势」（世界的真实状态）与「途」（Agent 的动作路径）脱钩了**。要么势已变而途不变——胶柱鼓瑟；要么途在动而势无凭——望风而动。两种都是**失机**：世界发出信号的时刻，路径没有给出恰当的回应。

《孙子兵法》对这种脱钩有一句两千五百年的诊断：

> **兵无常势，水无常形。能因敌变化而取胜者，谓之神。**（《孙子兵法·虚实篇》）

敌已经变了而我不变，是钝；敌没变而我乱变，是躁。孙子对两种都打了差评，而且给了正面标准：因敌变化。

## 二、为什么是这本书

《孙子兵法》是战略哲学与管理学的共同原典——它对「何时变、何时不变、凭什么变」给出了**成条款**的答案，而不是修辞。条款多到可以直接逐条工程化：

### 2.1 原文条款 → Agent 失败模式逐条对照

| 原典 | 直译 | Agent 的病 |
|---|---|---|
| **兵无常势，水无常形；能因敌变化而取胜者，谓之神**（虚实篇） | 用兵没有刻板的态势，水流没有固定的形状；能随敌情变化而取胜的，才叫用兵如神 | 运行环境是非平稳的：并发会话、依赖漂移、需求更新、命令环境差异。把开工时的环境快照当常量，是全行业 plan-fixation 失败模式的根 |
| **涂有所不由，军有所不击，城有所不攻，地有所不争**（九变篇） | 有的路不走，有的敌不打，有的城不攻，有的地不争 | 路径选择本来就该有舍取——**改途是正当权利**。所以「失败后没回头」本身不是罪；但悬账未清还到处开辟新战线（该不攻的城去攻）是罪，计为「游骑」 |
| **君命有所不受**（九变篇） | 国君的命令，有的因为不符合前线实情而可以不接受 | 开工时定的**路径图**（既定动作序列）必须让位于地面的真实；但注意孙子从未说过「目的地可以变」——变的是途，不是愿。这正是与正念（守愿）的分界线 |
| **非利不动，非得不用，非危不战；主不可以怒而兴师，将不可以愠而致战**（火攻篇） | 无利可图不要行动，无把握不要用兵，不危险不要开战；不能因为愤怒就出兵 | 悬账未清时连开新战线，凭的不是任何新证据，而是「我在干活」的情绪——怒而兴师的机器版，计为「游骑」的另一半依据 |
| **将不通于九变之地利者，虽知地形，不能得地之利**（九变篇） | 将帅不懂九变的属地之利，即使知道地形，也得不到地利 | 静态知道环境（开工时的体检、快照）不够；世界变了之后的**再勘测**才是地利。weibing 治 t=0 的体检，九变治 t>0 的应变——同一战场的两个时点 |
| **智者之虑，必杂于利害**（九变篇） | 聪明人考虑问题，必然同时兼顾利与害两面 | 每次路径变动都该有利害依据：势变（害的信号）之后的动作要么回到害处勘察，要么明改其途——两者都可审计；无凭而动不可审计 |
| **知己知彼，百战不殆**（谋攻篇） | 知己又知彼，百战不危 | 「彼」是环境的**当前**状态。盲捶（失败后逐字重试同款动作）的本质是用过期的彼知作战：世界刚刚说了「不」，下一动作却当它没说过 |

### 2.2 一条主线索：势账

六层的度量对象各不相同：zhizhi 数行为、jiebi 审账本、zhengnian 量锚点、buer 记事故、weibing 诊开工。九变的度量对象是**势变与途的对齐关系**：

- 从会话流里确定性地提取**势变**（世界说「不」的时刻：isError 结果）；
- 逐条势变裁决路径的回应：**变**（回去再察了）、**盲捶**（无再察地逐字重试）、**悬**（文件势变后全程未归）、**离**（改途离场——正当权利，不计分）；
- 反向也审：悬账未清时的**游骑**（连开无凭新战线）；
- 双向合成一个数：**失机值**（0–100），门禁可断言，账本可重放。

## 三、诚实边界（先于实现声明）

1. **v1 是结构层，不是语义层**：势变只取 `isError:true` 的结果；对象键只取显式的 `path` / `command` 字符串。文件内容里说了什么、错误语义是什么，v1 一律不看——零 LLM、零 NLP。
2. **分只罚两宗结构可证之罪**：盲捶（无再察的逐字重试）与游骑（悬账未清时连开无凭新战线）。**悬账挂账不计分**——「失败后没回头」可能是正当的涂有所不由，v1 无权断言它是罪，只把它列进变方提醒归还。这是「不惩罚合法改途」的硬承诺。
3. **首盲免分**：每条盲捶链的第一记免分——瞬时错误的重试是合法战术。罚的是链，不是单次重试。
4. **失机值低不保证成功**：0 分只证明「路径对观察到的世界变化都有结构回应」，不证明方向正确、质量过关。那是 jiebi（判断）与 zhengnian（本愿）的地盘。
5. **势变信号是下限不是上限**：isError 能漏掉「世界变了但没报错」的情形（文件被改但本会话还没撞上）。九变不假装测到了它测不到的势变——变方块只列**确凿入账**的势变，绝不虚构威胁。
