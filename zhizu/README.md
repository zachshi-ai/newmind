# 知足 · Zhizu

> **知足之法，即是富乐安隐之处。知足之人，虽卧地上，犹为安乐；不知足者，虽处天堂，亦不称意。**——《佛遗教经·知足安乐分》

一门两千五百年的知足之学，能不能精确地解决人工智能的一个真实问题？

能。LLM 编码代理有一个最日常也最少被记账的病灶：**变更膨胀**。任务书写「修一下空指针」，Agent 一口气重写整个模块四百五十行；「改个配置项」，它的手伸进八个目录；同一个文件成功写入六次，每一版都覆盖上一版。功能是对的（绿），但 review 面积扩大了五十倍——diff 在变大、返工在变多（GitClear 对 1.53 亿行代码的年度度量：AI 助手主流化以来短期 churn 翻倍 3.3%→7.1%），而这正是 human review 成为瓶颈的时代。佛陀说「多欲之人，多求利故，苦恼亦多」——每一行多余的变更都是新增的风险面。知足把「伸出去的手有多长」变成**可计数、可分带、可门禁、可重放**的结构事实：行少欲者，心则坦然。

## 它是什么

DeepSeek Harness 的**量出式插件**（Cordis）+ 零依赖审计 CLI + Agent Skill——本实验室第二十三个能力类型：判定对象不是事件的性质，而是**事件的数量形**（写了多少、散得多广、翻了几回）。

## 三宗与四道清白

| 案 | 判定 | 分值 | 经证 |
|---|---|---|---|
| **巨写** | 对**既有文件**（此前流内有成功读写）的单次成功写入 > 400 行（默认阈，可配） | +30/案 cap 60 | 「譬如智者，筹量牛力所堪多少，不令过分，以竭其力」 |
| **蔓延** | 全流成功写入的父目录去重 > 6 **或**文件数 ≥ 20 | 单案 +20 | 「譬如大树，众鸟集之，则有枯折之患」 |
| **屡改** | 同径成功写入超出免额 3 笔后，每满 2 笔一案 | +10/案 cap 20 | 「譬如有人，手执蜜器，动转轻躁」 |

四道清白道全部在设计里，不冤枉正当行为：

1. **创笔免记**——新文件（该径此前无成功读写）首写再大也只是脚手架，注记不计分；
2. **免额三笔**——TDD 与渐进实现写三次以内是合法迭代；
3. **豁免在册**——lockfile、生成物，任务方在足册 `.zhizu.json` 里签字即全免出账；
4. **失败不入**——失败之写未落盘，试错之地归九变；exec 是黑盒（重定向写入体流里不可见），宁漏勿诬。

溢值 = min(100, 巨写 + 蔓延 + 屡改)，分带 **俭 0–14 / 盈 15–29 / 溢 ≥30**，门默认 30——单巨写即红；单蔓延 20、单屡改案 10 落点名带不咬门。

## 快速开始

```bash
cd your-repo
zhizu register --exempt package-lock.json   # 开工立足册（生成物签字豁免；阈值可调）
# ……Agent 作业……
zhizu audit session.jsonl                   # 收工审量（exit 码可进 CI；无册照判，默认阈开箱在岗）
zhizu block --file .zhizu.json              # 量牌块（可注入收尾上下文）
```

- **无册照判**：默认阈值（巨写 400 行 / 蔓延 6 目录或 20 文件 / 屡改免 3 笔）开箱在岗，足册只管豁免与调阈；
- **信任模型**：足册是任务方的声明，Agent 无从自我发额度；CLI 旗标（`--huge-lines` 等）是审计方的口径；
- **门禁**：溢值 ≥ 30（默认门）即红；`--gate` 由 CI 自由裁量。

## 验收摘要

97 tests 全绿（core 58 + cli 25 + 真实管道集成 10，0 跳过）；五夹具期望先于实现手算逐字吻合（modest 0 俭 / bloated 60 溢 / sprawling 20 盈 / churny 10 俭 / mixed 50 溢）；量牌块 shasum 双跑逐字节一致；三道 grep 门净（零 IO/网络/子进程、零 pre-execute 监听器、相邻层 80 机制词零撞）；zhizhi/dingfen 历史流跨项目互认零误伤。完整验收表与复现命令见 [docs/04-acceptance.md](docs/04-acceptance.md)。
