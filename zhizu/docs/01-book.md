# 01 · 选书：佛遗教经 × Agent 变更膨胀

## 书

《佛遗教经》，全名《佛垂般涅槃略说教诫经》，一卷，姚秦三藏法师鸠摩罗什译。佛陀临入涅槃之夜，在娑罗双树间为诸弟子的最后嘱托——「是时中夜，寂然无声，为诸弟子略说法要」。全经一卷，从持戒到智慧逐条开示，是汉传佛教流传最广的遗教经典，古来与《四十二章经》《八大人觉经》并称遗教三经。

选它的理由：在全部佛典里，把「少」与「足」讲成一套完整治理哲学的，以此经最为直接——它不是隐约地劝人节制，而是逐条论证「多欲为什么致苦、少欲为什么生功德」，并且把「知量」落在可操作的行为戒条上。对一台「只会多、不会少」的机器，这是一剂对症的药。

## 三条经证，逐条映射

### 其一，知足安乐分——总纲

> 汝等比丘，若欲脱诸苦恼，当观知足。知足之法，即是富乐安隐之处。知足之人，虽卧地上，犹为安乐；不知足者，虽处天堂，亦不称意。不知足者，虽富而贫；知足之人，虽贫而富。不知足者，常为五欲所牵，为知足者之所怜愍。是名知足。

变更的「富」不等于交付的「安」。一次小修出五百行，行数上「虽富」，可维护性上「而贫」；最小可用的 diff「虽卧地上」（朴素），却「犹为安乐」（风险面最小）。Agent 不缺「能写更多」的能力，缺的是「当观知足」的账。

### 其二，少欲分——功德论证

> 汝等比丘，当知多欲之人，多求利故，苦恼亦多；少欲之人，无求无欲，则无此患。……行少欲者，心则坦然，无所忧畏，触事有余，常无不足。

「多求利故，苦恼亦多」：每一行多余的变更都是新增的风险面——review 面积、回归面、理解成本。这不是审美偏好，是功德论：少欲（最小 diff）者「触事有余」——变更越小，余裕越大。

### 其三，知量知足——操作戒条（持戒分）

> 于四供养，知量知足，趣得供事，不应畜积。

佛门对日用之物的要求是「知量」二字：取用要有量、有账。本层的账本因之名为**量账**。这与本实验室 #15 度支（《礼记·王制》「量入以为出」）恰成一对：度支量的是**投入**（调用与时长），知足量的是**产出**（写入规模与广度）——量入为出，量出为安。

## 三条辅喻，分别给三宗定罪

1. **巨写**（对既有文件的单次大改）——饮食分：「譬如智者，筹量牛力所堪多少，不令过分，以竭其力。」智者让牛驮担之前先称牛力——动一个既有文件之前先看它的承受面；一次倾泻四百行进一个既有模块，就是「过分」而「竭其力」。
2. **蔓延**（写域扇出失控）——远离分：「若乐众者，则受众恼；譬如大树，众鸟集之，则有枯折之患。」一个小任务的手伸进八个目录，正如众鸟集于一树——树不是被一只鸟压折的，是被「集」折的。
3. **屡改**（同径反复成功改写）——制心分：「譬如有人，手执蜜器，动转轻躁，但观于蜜，不见深坑。」改了又改、改而不休，是「动转轻躁」——每一版都相信自己这版是对的，账上却留下反复翻动的痕。

蕅益大师《佛遗教经解》：「是知少欲为因，涅槃为果也。」——少欲是因，安隐是果；对 Agent 而言，最小变更是因，可 review、可回滚、可信赖是果。

## 与既有各层书目的关系

- 佛学层已有《六祖坛经》（zhengnian #3，意图守护）——坛经讲「心」的在场，遗教经讲「行」的节度：一书治心、一书治手；
- 《道德经》（zhizhi #1）有「知止不殆」，本经有「知足安乐」——知止与知足，道家与佛家各讲半个节制，#1 与 #22 恰成首尾：知止问「这一步该不该迈」，知足问「已经迈出去的步子有多大」。
