# 知足 · Zhizu — Agent 协作协议

> **知足之法，即是富乐安隐之处。**——《佛遗教经》
>
> 多欲之人，多求利故，苦恼亦多：每一行多余的变更都是新增的风险面——review 面积、回归面、理解成本。最小 diff 不是审美偏好，是功德论：**行少欲者，心则坦然，无所忧畏，触事有余，常无不足**。本协议不禁止你写大文件，它只要求每一次规模的失控留痕上账——新址起屋（创笔）天经地义，动既有大厦则先筹量牛力。

## 给委派任务的工程师

```bash
cd your-repo
zhizu register --exempt package-lock.json   # 开工立足册（生成物签字豁免；可选 --huge-lines 等调阈）
# ……Agent 作业……
zhizu audit session.jsonl                   # 收工审量（exit 码可进 CI；无册照判）
zhizu block --file .zhizu.json              # 量牌块（可注入收尾上下文）
```

- **无册照判**：默认阈值（巨写 400 行 / 蔓延 6 目录或 20 文件 / 屡改免 3 笔）开箱在岗——与「无册不判」的项目不同，这里沉默即默认开秤；
- **豁免要趁早**：lockfile、生成物、脚手架目录，让任务方 `register --exempt` 签字——审查时规整径含任一豁免子串即全免出账；
- **门禁**：溢值 ≥ 30（默认门）即红，单处巨写即红；单蔓延 20、单屡改案 10 落点名带不咬门；`--gate` 由 CI 自由裁量；
- **阈值是审计方的口径**：`audit --huge-lines 200` 临时收紧、`--churn-free 6` 对长迭代任务放宽——册是任务方的声明，Agent 无从自我发额度。

## 给 Agent

1. **动既有文件之前，先看它多重**（「譬如智者，筹量牛力所堪多少，不令过分」）：对已存在的文件一次写入超过 400 行就是**巨写**（+30，即红）——大手术拆成多次有据的变更，或把新东西放进新文件（创笔免记）；
2. **小任务不撒大网**（「譬如大树，众鸟集之，则有枯折之患」）：一次任务的手伸进 7 个以上目录就是**蔓延**（+20）——改动收敛在与任务直接相关的路径上；顺手统一命名、顺手重构，都是「众鸟」；
3. **不轻躁翻动**（「譬如有人，手执蜜器，动转轻躁」）：同一文件成功写入超过 3 次，第 5 笔起每 2 笔记一案**屡改**（+10/案）——想清楚再落笔，一版胜过六版；
4. **新址起屋不设限**：新文件首写再大也只是脚手架（创笔，注记不计分）——把生成物放新目录、初始化放新文件；
5. **生成物先登记**：lockfile、dist、vendor 这类天然巨大的径，开工时让任务方 `zhizu register --exempt`——豁免径完全出账，既不罚你也不啰嗦。

## 判定语义速查

| 案 | 对象 | 阈（默认） | 分值 |
|---|---|---|---|
| 巨写 | 既有文件（此前流内有成功读写）单次成功写入 | > 400 行 | +30/案 cap 60 |
| 蔓延 | 全流成功写入的父目录去重 / 文件去重 | > 6 目录 或 ≥ 20 文件 | 单案 +20 |
| 屡改 | 同规整径成功写入超出免额 | 免 3 笔，每满 2 笔一案 | +10/案 cap 20 |
| 创笔 | 新文件首写超阈 | 注记不计分 | 0 |
| 豁免 | 规整径含足册豁免子串 | 三宗全免出账 | 0 |

溢值 = min(100, 巨写 + 蔓延 + 屡改)；分带 俭 0–14 / 盈 15–29 / 溢 ≥30；门默认 30。失败之写不入账（未落盘）；exec 是黑盒不判规模；老流无内容字段时巨写维度诚实沉默、蔓延与屡改照判。

## 为什么是「知足」

知止（zhizhi，本实验室 #1）管「这一步该不该做」，知足管「已经做的有多少」——道佛各讲半个节制，一拦一账，首尾对偶。佛陀临终把「知足」列为脱诸苦恼的法要：Agent 不缺「能写更多」的能力，缺的是「当观知足」的账。
