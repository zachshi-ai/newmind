# 03 · 设计：考诚 · kaocheng —— DeepSeek Harness 的交付契约层（考诚式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**考诚式插件**（第二十八个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，weibing 证明可以诊，shefa 证明可以审落物之宿，yuanyu 证明可以审入目之禁，
shuitu 证明可以审境变复位——考诚证明插件可以**审交付之契**：契约勒在册上，物对着契约考。

```
tools/result   emit   观察工据与灭据入账（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、零文件系统探测）；
观察永不反噬（监听器异常吞掉，管道照常）；契册持久化归 CLI（register/revoke），插件只吃注入的
book 对象；单会话视图的案与值只采本会话，跨会话归并归离线合并审计。

## 2. 工据与灭据通道（词法锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；observe/write/exec/other 四族）。
径规整同全仓（反斜杠归正、剥 `./` 前缀与尾 `/`），防同文件异写之诬。

**工据（物之生）唯二**：

1. **write 族 p: 径命中契径**——凡 write 族调用（write/edit/patch/create/move/remove…）成功
   且对象键为 `p:<径>`，规整后命中契册之径即记一笔工（写入）；
2. **exec 族生产词法**——命令切段（`&& || ; |`）后逐段，段内非破坏性时：
   `cp`/`mv` 的**末个非旗标词元**规整后命中契径 → 工见（拷贝/挪移落点）；
   `tee`/`touch` 的**任一非旗标词元**命中契径 → 工见；
   重定向目标（`>`/`>>` 后的第一个词元，`2>&1` 天然不中）命中契径 → 工见。

**灭据（物之死）**：段内任一词元（小写化）命中**灭词表**（`rm unlink rmdir del erase trash shred`——
`git rm` 之 `rm` 亦中），且段内任一非旗标词元与契径匹配（规整逐字相等 ∪ 宽 glob：词元含 `*`
时按通配全匹配）→ 灭据一笔。破坏段内的词元不再计工见（rm 不生产）。

**观察不是工**：observe 族（read/glob/grep/ls…）永不生工据——读取只证明「看过」，
不证明「做过」；契约考这单活的交付，不认仓库现状。

**失败不入账**：`isError === true` 一律不入账（失败的写不是工）；isError 未知按已发生入账。
失败之写不豁免幽物——契约考果不考勉：物终不在场，照判幽物。

## 3. 契册（任务方声明，声明权全在任务方）

```json
{
  "version": 1,
  "items": [
    { "name": "报告", "path": "docs/report.md", "form": "text", "minLines": 3, "words": ["结论"] },
    { "name": "结果", "path": "out/result.json", "form": "json", "fields": ["summary", "count"] }
  ]
}
```

- **name**（契名）：必填非空字符串，册内唯一（同名即改契——upsert，register 显式改册）。
- **path**（契径）：必填非空字符串，判定按规整径。
- **form**（结形）：`json` ∪ `text`，缺省 `text`；他值解析报错（exit 2）。
- **fields**（域条）：仅 json 有义——末据可解析后，顶层必含之键。
- **words**（词条）：末据必含之子串（逐字、大小写敏感——与全仓词法同规）。
- **minLines**（卷条）：正整数——末据真实行数下限（按内容真实换行切分，末尾换行不计，同 zhizu 行数口径）。

**无册不判**：audit 无 `--file` 或册缺失 → contractless 报告（0 分、诚带、exit 0），
治理发现注记「无契而工：契册未立，考诚失据（契约声明权在任务方）」——契约是任务方的意图，
引擎无从代拟，宁可沉默不可代言。契约是结构化对象，词旗标载不动，册是唯一入口（故无 audit 词旗标覆盖）。

## 4. 末据与诚实沉默

- **末据**：该契径流内**最后一笔携带 content 的成功写**的内容（`args.content` 为字符串者）。
- **无据之改**：末据之后的内容缺省写（如 edit 族工具只携 old/new，不携全文）不改末据——
  结形条款以末据为准考，gauge 注记「末据后无据之改 N 笔」（改了什么流内不可见，宁漏勿诬）。
- **判据状态机（判定序锁死，逐件恰好一态）**：

| 序 | 条件 | 案别 | 分 |
|----|------|------|----|
| 1 | 全流无工（无成功写 ∧ 无 exec 工见） | **幽物** | +30 |
| 2 | 无成功写 ∧ 有 exec 工见 | **工见未考** | 0（注记：结形黑盒沉默） |
| 3 | 有成功写 ∧ 末笔写（含无据之改）之后有灭据 | **灭物** | +30 |
| 4 | 有成功写 ∧ 全流无一笔带 content 之写 | **账上无末态** | 0（注记：老流诚实沉默） |
| 5 | 末据 trim 后空白 | **壳物** | +20 |
| 6 | form=json 且 JSON.parse 失败 | **畸物** | +30 |
| 7 | 域/词/卷条款有缺 | **疵物** | 缺域 +10/域 · 缺词 +5/词 · 短卷 +10/件 |
| 8 | 全条款过 | **诚物** | 0 |

- 判定序先灭后壳后畸：灭物之物不再考壳畸（物已不存，形无从谈起）；
- 畸物不再考域条（解析不成，域条必全缺——不双罚）；
- 疵物可叠加（缺域两域 + 短卷并计），态仍是疵物一态；
- **灭据夹在两笔写之间不判灭**（w→rm→w：考其末，末笔在即物在）；
- **rm 从未在流内生过之物**：无工（写与工见皆无）→ 判序第 1 仍幽物（流内未见其生）。

## 5. 诚值与门禁

```
you    = min(60, 30 × 幽物件数)
mie    = min(60, 30 × 灭物件数)
ke     = min(40, 20 × 壳物件数)
qi     = min(60, 30 × 畸物件数)
fields = min(30, 10 × 缺域总域数)
words  = min(15,  5 × 缺词总词数)
lines  = min(20, 10 × 短卷件数)
total  = min(100, 七项之和)
```

分带：**诚 0–14 / 欠 15–29 / 欺 ≥30**。门默认 30：

- 单幽物、单灭物、单畸物即红（30 ≥ 门）——物不在场、物终不存、形不成形，都是「工有不当」的死门；
- 单壳物 20 落欠带，黄牌点名不咬门（有其名无其实，罪减三案一等）；
- 缺域三域即红；缺词三词 15 黄牌；短卷两件 20 黄牌；
- 诚物、工见未考、账上无末态恒 0 分。

## 6. 考牌块（接缝供给，逐字节确定）

```
【考诚 · 考牌】
契册：报告<docs/report.md·text>、结果<out/result.json·json>（物 2 件）
物账：诚 2 · 疵 0 · 壳 0 · 畸 0 · 灭 0 · 幽 0 · 工见未考 0 · 无末态 0
（案行：幽/灭/畸/壳逐件点名；疵物逐件带缺什么；工见未考与无末态逐件注记）
```

无册考牌（确定性文本）：`契册：未立（无契而工，考诚失据）`。
块中永不出现末据正文（考牌只载径、契名、条款与判语——掩码是结构性保证）；
同输入两次渲染逐字节相同（shasum 可证）。

## 7. issues 行序（锁死）

幽物 → 灭物 → 畸物 → 壳物 → 疵物 → 工见未考 → 账上无末态 → 全诚（`物皆诚 ×N —— 必功致为上`）；
无册时唯一行：`无契而工：契册未立，考诚失据（契约声明权在任务方）`。

## 8. 插件 API 与 CLI

**插件**（`kaocheng-dsh`，Service 名 `kaocheng`）：`report()` 汇总、`ledger()` 物账全文（逐件）、
`paizi()` 考牌块、`gate()` 门禁裁决、`exportStream()` 导出会话流（call/result 成对、args 原样
——写族的 content 在 args 里随流携带），供 `kaocheng audit` 离线重放对账。

**CLI**（零依赖，`kaocheng`）：

```
kaocheng audit <s1.jsonl> [s2 …] [--file <契册>] [--gate n] [--json]
kaocheng register --name <名> --path <径> [--form json|text] [--fields f1,f2]
                  [--words w1,w2] [--min-lines n] [--file <契册>]
kaocheng revoke --name <名> [--file <契册>]
kaocheng list [--file <契册>]       kaocheng block [--file <契册>]
kaocheng gate --value <n> [--gate n]  kaocheng --help | --version
```

默认册 `./.kaocheng.json`；register 同名 upsert（显式改契）；revoke 无此名 exit 2。
退出码：0 通过 / 1 门禁失败 / 2 用法与输入错误。

## 9. 与既立各层的方向边界（结构性，不是纪律性）

知止拦动作，解蔽审判断，正念守意图，治未病体检开工，九变勘应变，有涯守见闻，
论世审发令资格，定分裁写域，捭阖守出境，法仪护尺，直笔保笔，豫立审备，
度支量入，二柄审柄，终始记程，效验称实，名实核名，立诚结诺，稽疑稽问，
乡校听声，知足量出，审曲审残全，舍筏审落物之宿，渊鱼审入目之禁，不贰记跨会话之训，
水土审境变复位；**考诚审交付之契**：契约（词形与结形）→ 物账 → 诚值（门禁）→ 考牌（供给）。

- **终始**：一程一物。它记众事的**行程**（作工面与终形的流内凭据——走到没走到），本层考物之**末据**
  （该交付的物成没成契）：「有终」的事可以交付幽物——作工的凭据在，物不在；两账并行。
- **效验**：一报一物。它称**成功信号的成色**（`npm test` 输出空不空），本层考**交付物的结形**
  （物对没对上契）：绿而实（有真实测试通过的输出）的会话照样可以交付畸物——报实物畸，它放行本层记账。
- **法仪**：一尺一物。它审**验收器脏净**（尺被改没改），本层审**物对契约**（任务方立的条款过没过）：
  尺直物畸，绿灯架在错的物上——尺归它、物归本层。
- **治未病**：一诊一考。它在 t=0 诊任务书**有没有**终验条款（无验是病灶），诊而不执行；
  本层在收工**执行**任务方立的契约——立契归它劝、考契归本层做。
- **舍筏**：一散一缺。它审落物**归宿**（不该留的清没清），本层审契上物**在场与成形**
  （该在的在不在、对不对）：同一份 `cp` 出的 `.bak`，它账上是筏，本层视而不见——
  契上无此径；同一份交付物，它不管成色，本层逐条考。
- **知足**：一量一果。它量写的**规模**（多少行、多广的手），本层考写的**果**（末态成没成契）：
  巨写可以件件诚（新写交付物按契成形），三行小笔照样可以是畸物。
- **审曲**：一入一契。它称装载证据的**残全**（看见的完不完整），本层考交付物对契约的**成形**
  （做出来的对不对）：读半卷就动刀是它的案，动完刀物不合契是本层的案。
- **立诚**：一诺一契。它追 agent **自己说出口的诺**（话语里的承诺），本层考任务方**册上立的契**
  （结构化的验收条款）：诺在话语里、契在册上——agent 从没承诺过的契约条款，立诚看不见，考诚照考。
- **名实**：一名一物。它核**写下的名**（import 之名在环境里有没有实），本层考**立下的契**
  （物之末据对契约）：幻径之引是它的案，交付物名存实亡（径在物亡/物畸）是本层的案。
- **定分**：一域一物。它裁**写域归属**（这块地归谁），本层考**物之成形**（地里的物成没成契）：
  守分的会话照样可以交付畸物。
- **知止**：账与闸分治。拦动作是它的地盘，本层从不拦——考诚全部发生在接缝之后，观察永不反噬。
- **jiebi/zhengnian/weibing/jiubian/youya/lunshi/baihe/zhibi/yuli/duzhi/erbing/mingshi/jiyi/xiangxiao/
  zhizu/shenqu/shefa/yuanyu/buer/shuitu**：对象键正交（判断/意图/开工体检/势途/见闻/渠道/出境/笔直/
  退路/量入/柄/名/问/声/量出/残全/落物宿/入目禁/跨会话训/境变复位），本层对象是契约条款与物之末据，
  互不引词。

## 11. 既知从宽代价（宁漏方向，逐条登记）

- **exec 无径词面不判**：`npm run build` 静默产出交付物、命令词面不含契径——工见不成立，照判幽物
  （同 shefa「exec 无径词面不判」之既知代价；任务方可改用重定向/`cp` 等词法可见的生产行）；
- **mv 走交付物不判灭**：`mv docs/report.md old.md` 末词元是落点不是源——mv 挪走契上物不在灭词表；
- **rm 目录不判嵌套径**：`rm -rf docs` 与契径 `docs/report.md` 不匹配（词元 ≠ 契径、无 glob）；
- **无据之改的毁损不可见**：edit 族不携全文，末据之后的修改考不到（考其末据，宁漏勿诬）；
- **失败之写不豁免幽物**：试写未遂不是工——契约考果不考勉，物不在场照判（agent 免咎之途是把物写成）；
- **观察在场不作豁免**：读取成功只证明「看过」，不证明「做过」——契约考这单活的交付；
- **词法可欺但骗一次留一次形**：`cp x docs/report.md` 拷来什么，流内不可见——工据成立即免幽物、
  结形黑盒沉默（工见未考是 exec 通道的既知盲区）；write 通道的末据骗不了人——
  写什么考什么，壳与畸都在末据上现形。
