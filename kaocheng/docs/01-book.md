# 01 · 选书：《吕氏春秋·孟冬纪》—— 物勒工名，以考其诚

## 原文

《吕氏春秋·孟冬纪·十月纪》记岁末考工之制：

> 是月也，工师效功。陈祭器，按度程，无或作为淫巧，以荡上心，必功致为上。
> **物勒工名，以考其诚；工有不当，必行其罪，以穷其情。**

《礼记·月令》孟冬之月有平行文本，一字之异而制度全同：

> 是月也，命工师效功，陈祭器，按度程，毋或作为淫巧以荡上心。必功致为上。
> **物勒工名，以考其诚。功有不当，必行其罪，以穷其情。**

孟冬之月，百工呈验一年的成品：工师按度程核验，器物上刻着工匠之名——
哪件器物不合格，顺着名字就能找到那双手，究其罪、穷其情。
**「物勒工名」是先秦成文的交付追责制度：物上带着名，诚与不诚才考得起来。**

## 为什么是这本书

- 戒的不是「做工」，是「交差而无从考」。两千年前的工师就知道：没有勒名之物的考核是空谈——
  器物必须能追溯到「谁、在什么时候、交的什么」。AI Agent 时代的病恰好是它的反面：
  agent 宣布完成时对着自选的证据（某条绿命令、一句「已完成」），
  任务方真正要的**物**——那份报告、那个 JSON、那个文件——从未被对着契约考过。
- 「按度程」给出考核的形态：不是工师临场凭印象打分，是**先有度程、后按度程**——
  契约先于交付、逐条可判。这正是 newmind 全仓的方法论（验收先于实现），而它两千年前就有原文。
- 「工有不当，必行其罪」给出考核的去处：不当不是嘴上说说，是计分、过门、点名——
  罪有所归，情有所穷。契约违反必须落到「哪件物、哪一条、末笔是谁的手」。

## 逐条映射

| 吕氏春秋·孟冬纪 | 考诚层 |
|-----------|--------|
| 工师效功（岁末呈验成品） | 收工审计：会话宣告完成之刻，对着契册逐件考物 |
| 按度程（按标准章程核验） | 契册：任务方显式声明的交付契约——径、结形、域、词、卷五条 |
| 物勒工名（器物刻上工匠之名） | 物账：流内每笔成功写登记会话/凭据/序——物可归工 |
| 以考其诚（验其诚） | 判定序锁死：幽物/灭物/壳物/畸物/疵物/诚物逐件定案 |
| 工有不当，必行其罪（吕氏版本） | 诚值计分与门禁：单幽物、单畸物、单灭物即红 |
| 功有不当，必行其罪（礼记版本） | 同上——两典共通的「不当必究」 |
| 以穷其情（彻查实情） | 考牌块逐件点名：哪件物、哪条不诚、末据是谁的手 |
| 必功致为上（以精致为上) | 诚物 0 分全绿——「功致为上」的现代式 |
| 无或作为淫巧，以荡上心（不许奇巧惑主） | 零 LLM：不装语义判断的淫巧，只按度程词法核验 |

一句话：**《吕氏春秋》说器物勒上工名、按度程考其诚，考诚层让任务方的交付契约勒在册上、
对着会话流里物的末据逐条考过——工有不当，必行其罪，以穷其情。**
