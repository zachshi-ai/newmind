# 02 · 问题：Agent 交付契约失账（功有不当无处考）

## 谁在什么场景下的什么问题

**谁**：任何给 DeepSeek Harness agent 派活的人（工程负责人、任务方、复审的同事与 CI），
以及事后要为「完成」二字负责的会话本身。

**场景一：幽物。** 任务书明言「把审计报告写到 `docs/report.md`，须含结论一节」。agent 修完代码、
测试绿了，对着绿命令宣布完成——`docs/report.md` 从未被任何一笔成功写触碰。完成对着自选的证据
（`npm test` 的退出码）宣布，任务方立的契约条款从头到尾没人考过。

**场景二：壳物与畸物。** 任务书要求「产出 `out/result.json`，JSON 格式，含 summary 与 count 两个域」。
agent 写了——内容是一段包着解释文字的伪 JSON，或者干脆是空壳。绿是真的绿（写命令成功返回），
下游脚本却在读这份交付物的第一行当场炸掉：**炸在交付之后，考在无处**。

**场景三：灭物。** 报告按契写好了，收尾时一个重构顺手把交付物删了或覆盖了——
末态不是交付态。zhongshi 记下「有终」（确实作过工），zhizu 记下笔数，shefa 只管散件不管契上之物——
「物最后还在不在、对不对得上契」没有任何一层看它一眼。

**场景四：复审无处问起。** 跨会话复审或 CI 门禁要回答「当时交付的物是什么样、契约逐条过没过」，
只能人工打开一个个文件逐条核对。会话流里明明带着全部证据（每笔成功写的径与内容），
却没有一张账把「契约 × 物之末据」对起来。

## 问题（治什么病）

**Agent 交付契约失账**：任务方把验收条款立成契约（哪些径、什么结形、必含哪些域与词、至少几行），
agent 收工宣告完成时，没有任何机制把这份契约对着流内物之末据**逐条考过**——

- **终始（zhongshi）**记众事的**行程**（有没走到的流内凭据——作工与终形），不认物：终形被空输出
  撑起的「有终」，它记有终；物本身是幽是畸，它看不见；
- **效验（xiaoyan）**称**成功信号的成色**（命令输出的空实），不认物：绿而实的会话照样可以交付畸物；
- **法仪（fayi）**审**验收器的曲直**（尺被改没改），不认物：尺直物畸，绿灯照样架在错的物上；
- **治未病（weibing）**在 t=0 诊任务书**有没有**终验条款（无验是病灶），诊而不考——
  立了契之后收工时**执行**这份契约，是 t>0 的空档；
- **舍筏（shefa）**审落物的**归宿**（该清的清没清），不审契上之物的**在场与成形**（该在的在不在）。

结构性证据：SWE-bench 一类基准把「测试绿」当完成，业界用结构性手段承认了「完成」需要外部判据；
而真实工程里任务方的完成定义是**交付物清单**——「验收先于实现」是本仓的方法论，
但「验收」本身在会话内无账：契约立了没人考，正是「物勒工名」要治的病——
**器物不勒工名，考核就是空谈；契约不对末据，完成就是自封。**

## 价值（为什么不是伪需求）

自检四问：

1. **问题是真实的吗？**——是。「agent 说做完了但交付物缺失/空壳/格式不对」是 agent 作业最高频的
   失败形态之一：完成宣告对着自选证据，交付物对不上任务方立的条款；后果不可逆地落在下游
   （读这份交付物的下一个会话、脚本、发布流程）。契约（可执行的验收条款）是任务方唯一能精确
   表达完成定义的形态，今天没有任何 harness 机制让它收工时被自动执行。
2. **本仓已定标的二十六层真的没治吗？**——逐行核过方向登记表。最近的四层都只审过程不审物：
   zhongshi 记**程**（作工与终形的流内凭据）、xiaoyan 称**报**（成功信号的成色）、
   fayi 审**尺**（验收器脏净）、weibing 诊**册**（t=0 条款有无）——「契约对物之末据」全仓无账。
   本层与四层两两并行：一程一物、一报一物、一尺一物、一诊一考（边界在 docs/03 §9 逐层锁死）。
3. **确定性可判吗？**——契约条款（径/结形/域/词/卷）与物之末据（流内末笔带内容之成功写）
   全部词法与结构可判：JSON.parse 零依赖原生、词/域/行计数纯字符串运算；
   工据通道（写族成功 ∪ exec 生产词法）与灭据通道（rm 词族 × 词元匹配）都是显式词法。
   零 LLM、零语义判断、零网络、零子进程、零文件系统探测。
4. **判罪会不会冤枉？**——清白道全在设计里：**无册不判**（契约声明权全在任务方，无册只出
   治理发现注记）；**exec 工见从宽**（cp/mv/tee/touch/重定向词法命中即「工见未考」——
   物由命令生成、末态黑盒，结形条款沉默不判）；**老流无 content 诚实沉默**（账上无末态，0 分）；
   **失败之写非工**（isError 不入账，但物不在场照判幽物——契约考果不考勉）；
   **末据考末不考程**（中程烂写后末笔合格即诚物——功考其末）；
   **单疵物 10–20 分黄牌点名不咬门**（宁纵勿诬）；**逐件点名**（每案可对到径与会话）。

## 产品形态

DeepSeek Harness **考诚式插件**（Cordis，结构性零拦截）+ 零依赖审计 CLI + Agent Skill——
与全仓范式一致：可运行、可测量、可证伪、可离线重放验尸。
考诚式是本实验室**第二十八个能力类型**（拦/审/供给/记习/诊/勘流/巡忆/权界/封界/守境/持尺/秉笔/
行前定/计账/审柄/记程/称实/核名/结绳/稽问/谏诤/量出/审材/敛迹/察渊/察土之后）：
判定对象不是动作的节制形（知止）、信号的成色形（效验）或常驻境的复位形（水土），
而是**立下之契对流内物之末据——物在不在、成不成形、对不对得上契约**。
