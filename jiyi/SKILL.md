# 稽疑 · Jiyi — Agent 协作协议

> **汝则有大疑，谋及乃心，谋及卿士，谋及庶人，谋及卜筮。**——《尚书·洪范》
>
> 谋及乃心（猜）只是五谋之一，从不单独定案。面对环境的未知——命令怎么跑、仓库什么规矩、构建怎么触发——本协议不要求你永不猜测，它只要求每个疑条在**首笔动手之前**留下问凭据：要么读过声明文书（成功读取），要么命令文本谋过它（如 `cat package.json`）。

## 给委派任务的工程师

```bash
cd your-repo
jiyi register --ask AGENTS.md --on write --ask package.json --on exec   # 开工立册（疑册=.jiyi.json）
# ……Agent 作业……
jiyi audit session.jsonl --file .jiyi.json                              # 收工稽问（exit 码可进 CI）
jiyi block --file .jiyi.json                                            # 稽块（可注入收尾上下文）
```

- **无册不判**：没立疑册，审计不会冤枉任何一笔动作——默认形表（AGENTS.md/CLAUDE.md/README.md on write）在未登记时也生效，`--no-defaults` 显式可关；
- **登记即作保**：显式疑条意味着你为该源的存在作保——环境里根本没有的文件不要显式登记（默认条的「未见」不罚，显式条的独谋 +15）；
- **触发域要选对**：`--on write` 锁写域（写代码前该读规矩）、`--on exec` 锁执行域（跑命令前该查 scripts）、`--on any` 两者；
- **门禁**：谋值 ≥ 30（默认门）即红，两条显式独谋即红。

## 给 Agent

1. **先谋及卿士，再谋及乃心**（洪范：四谋并列，乃心从不单独定案）：进新仓库，第一笔 write 之前先 `read AGENTS.md` / `CLAUDE.md` / `README.md`；跑构建之前先 `cat package.json` 看 scripts——你的成功读取本身就是问凭据；
2. **不确定文件在不在，先问**：`read` 一次得了 404 不是罪（空疑，疑自解）——不问就猜才是罪（独谋）；
3. **动即问从宽**：`cat package.json` 既查了 scripts 又算了问凭据（命令文本含名）——同一笔动作，谋与动一气呵成，无罪；
4. **先动后问是迟问**：写完代码才补读规矩，+5/条——不红，但账上留痕；纪律是首动之前问；
5. **看见「独谋 ×N」不要狡辩**：那是结构事实（首动之前流内无问凭据），唯一的出路是下个会话先问后动——改审计报告不在任何通道里；
6. **读稽块**：接缝处收到的【稽疑 · 疑册】是逐字节确定的疑册公示与问况，用它对齐「哪些疑条问过、哪些还没问」。

## 案由速查

| 案别 | 分 | 语义 | 出路 |
|---|---|---|---|
| 谋及 | 0 | 首动之前已有问凭据（读取 ∪ 命令含名，动即问同笔同免） | 无需动作 |
| 空疑 | 0 | 问过了，环境答「没有」（读取失败 404）——疑自解 | 确认源确实不存在，无需动作 |
| 迟问 | +5/条（cap 15） | 先动后问：首触发之后才有问凭据 | 下次先问后动 |
| 独谋（显式） | +15/条（cap 45） | 任务方作保的疑条，首动之前全流无问凭据 | 补问 / 补登记豁免 / 下会话先读 |
| 独谋（默认） | +5/条（cap 15） | 默认形表疑条，流内有痕而无问凭据 | 先读再写 |
| 未见 | 0 | 默认形表疑条全流无踪——环境里可能根本没有 | 疑而不罚，无需动作 |
| 无动 | 不判 | 触发域内全流无调用 | 无需动作 |

分带：**谋 0–14 / 疏 15–29 / 独 ≥30**；门默认 30。
