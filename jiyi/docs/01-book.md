# 01 · 选书：《尚书·洪范》——稽疑：大疑面前，谋及乃心从不单独定案

## 为什么是《尚书》

给「动手前稽问治理」找思想源头，候选很多：《论语》有「入太庙，每事问」，但《论语》已留给不贰（buer，在途）；《礼记·曲礼》有「入竟而问禁，入国而问俗，入门而问讳」，但《礼记》已被度支（duzhi，王制篇）占书。《尚书·周书·洪范》的**稽疑**章给出了一个更结构化的东西——它不是一句劝学的格言，它是一套**治理建制**：

1. **疑是常态，稽疑是九畴之一**：洪范九畴第七畴就是「稽疑」，与食货、祭祀、庶征并列——处理「疑而未决」不是修养建议，是治国必须常设的制度（「择建立卜筮人」——卜筮人是开工先立常设的，不是出了事临时抱佛脚）；
2. **四谋并列，乃心只是其一**：「汝则有大疑，谋及乃心，谋及卿士，谋及庶人，谋及卜筮」——自己的判断（乃心）、班子的意见（卿士）、众人的看法（庶民）、制度化的客观程序（卜筮），四条渠道**无一可省**；
3. **乃心从不单独定案**：即使「汝则从」，也必须「龟从，筮从」才成其吉；「龟筮共违于人」则「用静吉，用作凶」——客观程序说不，主观判断再自信也不许动。**只谋乃心就动手，在洪范的账上是违制的**；
4. **三人占，从二人之言**：多数裁决——「问」的结论要有凭据可依，不是问过了就算。

这四件事恰好就是 Agent 稽问治理的四个设计支柱，且《尚书》未被本仓任何项目使用（zhizhi 道德经 / jiebi 荀子 / zhengnian 坛经 / weibing 黄帝内经 / jiubian 孙子 / youya 庄子 / lunshi 孟子 / dingfen 商君书 / baihe 鬼谷子 / fayi 墨子 / zhibi 春秋 / yuli 中庸 / duzhi 礼记王制 / erbing 韩非子 / zhongshi 大学 / xiaoyan 论衡 / mingshi 公孙龙子 / buer 论语〔在途〕/ licheng 周易〔在途〕）。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《尚书·洪范》原文 | Agent 的病 | 稽疑的机制 |
|---|---|---|
| **七、稽疑：择建立卜筮人，乃命卜筮** | 稽问不建制就等于没有：Agent 每轮上下文重生成，连「我有没有查过」都无记忆——查不查全凭当轮自觉，自觉不进任何账本 | **疑册**：任务方开工先立（登记必问清单，声明权在任务方），不是收工补册；问况全流记账，逐笔可查 |
| **汝则有大疑，谋及乃心** | **谋不及物**：Agent 面对环境的一切未知——命令怎么跑、仓库什么规矩、构建怎么触发——用内心猜测代替环境稽问：猜 `npm run build`、猜配置键名、猜「应该有 lint」 | 案名**独谋**：登记疑条在首动之前无任何问凭据——只谋乃心而动，账上现形 |
| **谋及卿士，谋及庶人，谋及卜筮** | 「卿士」在 Agent 环境里有现成的对应物：仓库自立的**声明文书**（AGENTS.md / CLAUDE.md / README.md / package.json / Makefile……）——环境自己立起来的规矩，正是该谋的「卿士」 | **问凭据**只认两种形：成功读取（观察族对象键逐字相等）、成功执行的命令文本含其名（词法相交）——谋及卿士的机器判据 |
| **汝则从，龟从，筮从……是之谓大同**（四从并至才吉） | 猜对了一次不代表谋过了：蒙对的命令、恰好没踩的 lint——侥幸成功把「没问」藏进绿里 | 判定看**流序与凭据**，不看结果成败：首动之前有没有问，与这一动成没成无关 |
| **龟筮共违于人，用静吉，用作凶**（客观程序说不，则不动） | 反向豁免同样要建制：环境已经答过「没有」（读取失败 404），这个疑就自解了，不应再罚 | 案名**空疑**：全流存在对该源的失败读取——问过了，环境答无，免 |
| **三人占，从二人之言**（结论须有凭据） | 「我看过了」不可证——看了没看必须落在流内的调用记录上，声明无凭 | 问凭据是**流内调用词法**，不是任何人的自述；「词法可欺但骗一次留一次形」 |

## 与管理学互证

- **The Checklist Manifesto**（Atul Gawande, 2009）：专家失败的根源多半不是无知（knowing）而是无能（making sure it's applied）——清单把「该做的」变成「必做的，且可核对」。疑册就是开工清单的机器账版本。
- **RTFM 的机制化**：工程文化里「Read The Friendly Manual」喊了几十年，靠的全是纪律；稽疑把纪律变成流内可审的凭据。
- **Due diligence（进场尽调）**：咨询与并购的通行纪律——进入一个环境，先系统稽考其现状文书，再动手。Agent 每一次进入新仓库都是一次 mini-investment，尽调环节至今缺席。
- **SRE runbook**：先查 runbook 再动生产——「动之前问过簿没有」是运维业的成熟纪律，稽疑把它下沉到 Agent 会话流。

## 与相邻思想的分工

- 《论语》「入太庙，每事问」与本层的病形最贴，但《论语》已留 buer（在途）——且「每事问」是无账美德劝喻，洪范给出的是**建制方案**（常设卜筮人 + 四谋渠道 + 定案规则），可机器化程度更高。
- 《礼记·曲礼》「入国而问俗」同病形而撞书（duzhi 已用《礼记》）。
- 《荀子·劝学》「君子博学而日参省乎己」偏内在自省（jiebi 的解蔽已审判断内在），洪范的稽疑是**外在建制**——疑不决于内省，决于「谋及」环境。
