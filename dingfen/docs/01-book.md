# 01 · 选书：《商君书·定分》——一兔走百人逐之，名分定而争止

## 为什么是《商君书》

给「多会话并发争写治理」找思想源头，候选不少：《韩非子》有名法之辨（其"循名责实"审的是**名实对账**——说过的与做到的，属于另一层）；《管子》《慎子》《吕氏春秋》都有"定分"的零星引述；《老子》讲"不争"（其书已被知止占用）。而《商君书·定分第二十六》对"许多人同时想要同一块地怎么办"给出的不是一句劝诫，是一套**完整的制度解剖**：它先给**病案**（一兔走，百人逐之——名分未定，谁都想抢）、再给**反例**（夫卖兔者满市，而盗不敢取——名分已定，行者不顾）、再给**制度化路径**（置官置吏以为天下师——登记与解释的常设机制）、再给**治乱判词**（名分定，势治之道也；名分不定，势乱之道也）。这四件事恰好就是并发写治理的四个设计支柱，且《商君书》未被本仓任何项目使用（知止道德经 / 解蔽荀子 / 正念坛经 / 治未病黄帝内经 / 不贰论语〔在途〕/ 九变孙子 / 立诚周易〔在途〕/ 有涯庄子〔在途〕/ 论世孟子〔在途〕）。

**定分止争，出处即此篇。**"定分"不是比喻，是《商君书》的原生概念：分（fèn）＝名分、权界——谁对何物有资格主张。本项目的层名、账名、命令名全部取自本篇。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《商君书·定分》原文 | Agent 的病 | 定分的机制 |
|---|---|---|
| **一兔走，百人逐之**，非以兔为可分以为百，由名之未定也 | 多会话共写一个工作区：没有领地登记，两只手先后（更危险地：交错）改同一个文件——后者覆盖前者，前者的返工把后者的修复抹掉（**争写**，lost update 的 Agent 版） | **分册**：开工**领分**（显式 glob 声明本会话要写的径），收工**销分**；账是机器可读的地契，不是口头谦让 |
| **夫卖兔者满市，而盗不敢取**，由名分已定也 | 权界不被看见等于没有：A 领了分，B 不知道，照样闯进来写（**侵入**——"不删对方成果"纪律失守的那一刻，纪律本身救不了） | **界碑块**：接缝处逐字节确定地供给分册现状（谁领了什么、哪里在争界），满市公示，行者不顾 |
| **故名分未定，尧、舜、禹、汤且皆如骛焉而逐之；名分已定，贪盗不取** | 争与不争不是道德问题，是结构问题：能力再强的 Agent 在无分之地照样逐鹿——指望"它会小心的"是纪律思维，定分只认结构 | **争值门禁**：把"是否相争"从纪律期望降为可计算的结构事实（争值 0–100，门 30，退出码裁决） |
| **故圣人必为法令置官也，置吏也，为天下师**，所以定名分也 | 定分需要"官吏"：一个无语义、可重放、不收贿（不被说服）的登记与解释机制 | 定分 CLI / 插件就是那个**置吏**：零 LLM、零网络、零子进程（CLI 读流读册），重放同一流必得同一判词 |
| **故夫名分定，势治之道也；名分不定，势乱之道也** | 事故后归因不能：两个会话都改过 `core/auth.js`，谁在何时覆盖了谁、谁闯了谁的地盘，事后连问都无处问起 | **审争**：多流离线重放，三宗逐条对账——**争写**（交错覆盖）、**侵入**（写入他方开放之分）、**越分**（漂出自己声明之界），每条附会话名、时刻、路径 |
| **名分定，则大诈贞信，民皆愿悫，而各自治也** | 好的权界让人自治：不需要拦截器盯着每一笔写 | **结构性零拦截**：定分的插件不存在 pre-execute 监听器——界碑公示 + 事后对账足以自治，诊而不拦 |

> 版本异文说明：「民皆愿悫」一作「巨盗愿悫」；「由名之未定」一作「由名分之未定」。本文引用以 ctext.org 收录本为底，异文不碍义理。

## 与管理学互证

- **产权经济学（科斯定理）**：外部性（互相覆盖）的根源是产权未界定；界定产权（分册）让外部性内部化（你只会覆盖自己的分）。定分止争就是科斯 1960 年那篇论文的法家前置。
- **RACI 责任分配矩阵**：管理学要求每件事恰有一个 Accountable。RACI 是任务级的，定分把它下沉到**路径级**：一条径在同一时刻只该有一只开放的手。
- **版本控制的 lock/branch 语义**：分支就是版本层的"分"（各写各的，合并时对账）；SVN lock 是它的运行时影子。定分把 lock 从"运行时互斥"升级为"可审计的账"——这正是工程界已有直觉的确定性化。

## 与相邻思想的分工

- 《韩非子》"循名责实"审**名实对账**（说到的与做到的）；《商君书》定分审**权界登记**（谁有资格写哪里）。本仓未做前者，勿混。
- 《孟子》"民为贵"的输入信任是**谁有资格发令**（论世〔在途〕审内容渠道的权威）；定分审**谁有资格落笔**——发令权界与写域权界正交。
- 《老子》"知止不殆"的止是**动作节制**（知止〔zhizhi〕拦的是危险动作）；定分的止是**地步之止**——不越界，而非不动作。

## 诚实边界（我们不假装的事）

1. **读不出没登记的心**：没人领分，定分不判越分（声明权在账方）；只对账上有的分负责。
2. **命令是黑盒**：`bash` 里的 `vim foo.js` 是 `c:` 命令对象，定分不解析命令语义——侵入/越分只判显式路径（`p:`）对象。宁可放过，不可错罚。
3. **无时不成案**：争写是流间交错事实，需要时间戳定先后；无 `at` 之流不判争写，只记共写提示。
4. **分界是字面的**：glob 是确定性路径匹配，不是"意图理解"——`src/**` 不会因为"它看起来也该管 tests"而变宽。
