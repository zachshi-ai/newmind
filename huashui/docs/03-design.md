# 03 · 设计：画水 · huashui —— DeepSeek Harness 的落笔之鲜治理（画水式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**画水式插件**（第三十四个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，youya 证明可以审会话见闻之重，jiubian 证明可以勘失败侧的
势变，dingfen 证明可以裁写对写的交错，kaocheng 证明可以考契上物之末据——画水证明
插件可以**审落笔之鲜**：哪一笔写以哪份旧底落了地、其间之变还在不在、重读发生在
写前还是写后。

```
tools/result   emit   观察写面入据账（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、
零文件系统探测——文与变全取自流内）；观察永不反噬（监听器异常吞掉，管道照常）；
水册持久化归 CLI（register/revoke），插件只吃注入的 book 对象；单会话视图的
案与值只采本会话（覆世唯离线合审可见），跨会话归并归离线合并审计。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓（反斜杠归正、循环剥 `./` 前缀
与尾 `/`）。本层**无默认形表**：凡 `p:` 径皆受审——落笔之鲜不挑文件，
挑的是「同径的三序」。

**文据**（同径的带文事件，判定之唯一实体，按序记账）：

- **读据**：observe 族成功（`isError !== true`；未知按已发生）且
  `result.content` 非空 → 该径记读据一笔（行集取 content）；
- **写据**：write 族成功且 `args.content` 非空 → 该径记写据一笔（行集取
  args.content）；
- **无文之写**：write 族成功而 content 为 null/空 → 只在据账记一道**无文
  之痕**（不生文据；它隔断判定，见 §3.4）；
- **入口滤**：`isError === true` 一律不入账（失败的写没落盘、失败的读没看
  见——都不生文据也不生无文之痕，等同未发生）；
- **观察不是写**：读取永不判案，只供旧据；**exec 是黑盒**：命令落盘的文面
  流内不可见，不生文据也不生无文之痕（诚实沉默，同全仓既例）；
- 行集：content 按 `\r?\n` 切行、逐行 trim、弃空行、取集合（去重）。

**合审序（CLI 多流）**：每流一会话（会话名 = 文件 basename，撞名报错）。
若合审各流**全部**调用的 `at` 皆为有限数 → 全局稳定排序键 `(at, 流序, 流内序)`；
否则按参序拼接（审计方须自证流序）。插件运行时只记本会话——**覆世是合审
之案，运行时视图诚实看不见他手**。

## 3. 三序与覆案判定（行集差集，零 LLM）

对每个带文写据（**陈写候选** j，行集 L(j)，会话 s(j)），按且仅按**最近一对**
判定：

### 3.1 变写（其间之变）

m = j 之前**最近的行集不同**的写据（任何会话）。行集相同（等文重写）不取
——世未变。j 之前无异文写据 → 无变写，不判（初据无可覆）。

### 3.2 隔断（陈改不判）

**无文之痕**（无文之写）夹在「最近文据与陈写之间」→ 判定不得，注记
「陈改不判 N 笔」——其间之变不可见，C(j) 对不对得起现状无从证明，
宁漏勿诬。分两形：有变写时看 **m → j** 窗（旧据 → 变写之间的无文之痕
不隔断——变写之文是其时之世的实证，谱系仍有效）；无变写时看
**最后文据 → j** 窗（世可能已变而不可见，只注记）。等文的写据夹在中间
不隔断（世未变，判定仍有效）。

### 3.3 旧据与两线

k = m 之前**最近的行集不同**的文据（读据或写据皆可——上下文里的旧副本
多来自一次读取）。无 k → 不判（变写之前别无他据，无从谓陈）。
行集差集（三集合，元素为行）：

```
陈线 = { l ∈ L(k) \ L(m) : l ∈ L(j) }   旧据独有之行在陈写中重现
新线 = { l ∈ L(m) \ L(k) : l ∉ L(j) }   变写独有之行在陈写中再失
```

### 3.4 案别与注记（判定序锁死，每笔写据至多一案）

对每笔带文写据 j，按序：

1. j 之前无任何文据 → 静默不判（首笔落卷，无世可言）；
2. 变写 m 在（§3.1）且 m → j 间有无文之痕 → **陈改不判**注记；
   无变写而最后文据 → j 间有无文之痕 → **陈改不判**注记；
3. 无变写或变写前无旧据 k（§3.3）→ 静默不判；
4. 陈线 ≥2 ∧ 新线 ≥1：s(m) ≠ s(j) → **覆世** +30/案 cap 60；
   s(m) = s(j) → **覆己** +15/案 cap 40；
5. 陈线 =1 ∧ 新线 ≥1 → **失鲜** 0（注记，点名）；
6. 其余（含新线 =0：保新线不罚——保住变写之行的并集式重写非覆）→ 静默。

- 阈值锁死：陈线 ≥2 且新线 ≥1 成案——双陈线排除单行挪动之噪，新线 ≥1
  排除纯增/纯删之中变（变写纯添行则陈线为空、纯删行则新线为空，两者皆
  不判——净向不罚，同全仓既例；唯混合增删之中变可成覆案）；
- 一径多笔陈写可各成一案（逐笔立案）；同会话合审内 s 取会话名，
  单流审计恒为覆己（无第二会话在场）；
- 读前写后之证：m → j 间（无变写形取最后文据 → j 间）存在读据 → 随案
  注记「案前曾重读」——明覆与盲覆的道德差记入点名，不改分数（宁记不纵，
  登记于 §11）。

## 4. 水册（许复，声明权全在任务方）

```json
{ "version": 1, "excuse": ["legacy/*", "src/generated/**"] }
```

- **excuse（许复）**：glob 串数组——本任务授权凭旧底重写之径。宽 glob：
  词元含 `*` 时按通配全匹配、`*` 跨目录；不含 `*` 时规整逐字相等。命中
  许复的径**不入据账**（豁免在立案前）；
- **无册=全账**：落笔之鲜是仓库公共事实，豁免只能来自册；册缺失自动建册
  （空册 = 全账）；v1 只豁免不扩判；
- git 词面的复古（`git restore`/`git revert`/`git checkout --`）走 exec 族
  不落写账，天然白——正当复古不惊门，许复管的是**手写复古**；
- 册是结构化 JSON、唯一入口（CLI register/revoke），无词旗标覆盖。

## 5. 陈值与门禁

```
shi = min(60, 30 × 覆世案数)
ji  = min(40, 15 × 覆己案数)
total = min(100, shi + ji)
```

分带：**活 0–14 / 滞 15–29 / 腐 ≥30**。门默认 30：

- 单覆世 30 即红（覆他会话之变是丢更新的正面——一釪落水即笑）；
- 两覆己 30 即红；单覆己 15 落滞带，黄牌点名不咬门（自覆己写常在两可——
  或为有意复古，记实为主）；
- 失鲜/陈改不判永不出账，仅点名。

## 6. 水牌块（接缝供给，逐字节确定）

```
【画水 · 水牌】
水册：许复 1 处（vendor/*）
案账：覆世 0 · 覆己 1 · 失鲜 1 · 陈改 1
覆己：src/a.js（seq 3 覆 seq 2——陈线 2 · 新线 1）
失鲜：src/b.js（seq 7——陈线 1 · 新线 2）
陈改：src/c.js（末据后无文之写 1 笔，判定不及）
```

无册水牌（确定性文本）：`水册：未立（凡覆皆记）`。
块中永不出现任何行原文（只载径、seq、行数与案别——掩码是结构性保证；
案行序：覆世 → 覆己 → 失鲜 → 陈改，族内按规整径字典序、seq 升序），
同输入两次渲染逐字节相同（shasum 可证）。

## 7. issues 行序（锁死）

覆世 → 覆己 → 失鲜 → 陈改不判 → 全活（`水皆活 ×N —— 见新乃写，
不作画水之记`，无任何案与注记时出此行，N = 受审径数）。

## 8. 插件 API 与 CLI

**插件**（`huashui-dsh`，Service 名 `huashui`）：`report()` 汇总、
`ledger()` 据账全文（逐径逐案）、`paizi()` 水牌块、`gate()` 门禁裁决、
`exportStream()` 导出会话流（call/result 成对、args 原样——写族 content 在
args 里随流携带），供 `huashui audit` 离线重放对账。

**CLI**（零依赖，`huashui`）：

```
huashui audit <s1.jsonl> [s2 …] [--file <水册>] [--gate n] [--json]
huashui register --path <glob> [--file <水册>]       立许复（重复去重）
huashui revoke --path <glob> [--file <水册>]
huashui list [--file <水册>]                          阅册
huashui block [--file <水册>]                         水牌块（册公示，逐字节确定）
huashui gate --value <n> [--gate n]                   门禁裁决
huashui --help | --version
```

默认册 `./.huashui.json`；register 册缺失自动建册；revoke 无此径 exit 2；
list 缺册 exit 2；block 无册出确定性文本。退出码：0 通过 / 1 门禁失败 /
2 用法与输入错误。

## 9. 与既立各层的方向边界（结构性，不是纪律性）

知止拦动作，解蔽审判断，正念守意图，治未病体检开工，九变勘应变，有涯守见闻，
论世审发令资格，定分裁写域，捭阖守出境，法仪护尺，直笔保笔，豫立审备，
度支量入，二柄审柄，终始记程，效验称实，名实核名，立诚结诺，稽疑稽问，
乡校听声，知足量出，审曲审残全，舍筏审落物之宿，渊鱼审入目之禁，水土审境变
复位，考诚考交付之契，恒法审规矩源之名分，知行审会话之知行断层，防川审交付
代码里的吞错之形，平准审交付籍面上的命脉四案，成事审已遂之施的再施；
**画水审落笔之鲜**：同径三序（旧据 → 变写 → 陈写）→ 行集差集 → 覆案
（陈值）→ 水牌（供给）。

- **有涯**：一重一陈。它审**世未变而重见**之费（复见限「其间无成功写」的
  重装载），本层审**世已变而据未更**之覆——同一笔重读，其间无写它记费、
  其间有写本层视为免案之证（写前重读者行集含新线，谓词自白）；镜像互补
  成一对记忆治理：它让不必要的重读有价，本层让必要的重读有赏。
- **九变**：一败一陈。它勘**失败侧**的势变（盲捶/悬账/游骑，isError 为
  触发），本层审**成功侧**的静默覆写（全绿无败，世变唯据账可见）——
  覆写发生的会话里没有一个失败可供它勘。
- **定分**：一界一陈。它裁**写对写**的交错窗口（争写须两笔写在场、按会话
  分域），本层裁**写对旧据**的行集谱系（凭陈落笔可以无第二笔写——覆己
  单会话即成案；也可以有第二笔写而不争写——顺序写不交错）。
- **shenqu**：一残一陈。它称**读入之残全**（当时看见多少——取窗/显残），
  本层称**据之新陈**（看见的是不是现在——三序对账）；同以读入为据，
  半卷与陈卷正交：读全卷而卷已旧归本层，读半卷而卷尚新归它。
- **zhizu**：一量一陈。它量写之量（行数/写域/屡改），三行的谱系性覆写在
  行数上不可见，本层恰审这三行的**来处**；巨写可以句句新鲜，小笔可以
  行行是陈——量归它、谱系归本层。
- **kaocheng**：一契一陈。它考契上物之末据（收工考物、对契），本层考落笔
  过程之谱系（行中即案、对世变）；末据合契的过程可以覆掉别人的修复，
  谱系干净的落笔可以交畸物——契归它、鲜归本层。
- **mingshi**：一名一陈。它核名之实（写下的名有没有实），本层核据之鲜
  （写下的卷是不是现在）——径同名同而内容已非，正是两层的分界处：
  幻名归它、陈据归本层。
- **chengshi**：一遂一陈。它审已遂之施的再施（外发世界的重复），本层审
  同径之写的覆变（仓库世界的谱系）；外发重施与落笔覆写谓词正交。
- **youya**：见上（一重一陈，镜像互补）。
- **zhizhi**：账与闸分治。拦动作是它的地盘，本层从不拦——画水全部发生在
  接缝之后，观察永不反噬。
- **jiebi/zhengnian/weibing/jiubian/lunshi/baihe/fayi/zhibi/yuli/duzhi/
  erbing/zhongshi/xiaoyan/jiyi/xiangxiao/shenqu/shefa/yuanyu/shuitu/
  hengfa/zhixing/fangchuan/pingzhun/buer**：对象键正交（判断/意图/开工

## 11. 既知从宽代价（宁漏方向，逐条登记）

- **无文之写隔断判定**：edit 族不携全文，其间之变不可见——最常见的中变
  形（str_replace）恰在不可见侧，覆之不判（陈改不判注记）；本层诚实看
  不见，agent 免咎之途是改用带全文之写；
- **exec 落盘黑盒**：`sed -i`、重定向、代码格式化器的改写流内不可见——
  既不生文据也不生无文之痕，隔断与变写皆不知（宁漏）；
- **最近一对判定**：链式覆写（C1→C2→C3→C4 复古自 C1）只按最近一对判，
  远端陈源不入判——中间态可能部分漏记，登记；
- **保新线不罚**：陈线 ≥2 而新线 =0（并集式重写，保住了变写之行、又复古
  了变写删去之行）不判——它可能是正当的合并，也可能是「复古被删代码」
  之病，宁纵登记；
- **窗读为据之诬**：旧据允许取自读据（上下文里的旧副本多来自读取），窗读
  （shenqu 之残见）若为旧据，行集差可能被窗污染——阈值双线（陈线 ≥2 ∧
  新线 ≥1）压噪，残值另账归审曲，本层不重复审残；
- **案前曾重读不改分**：明覆（读后覆）与盲覆（凭记覆）在分数上无别，仅
  注记——有读而覆常为有意复古，许复明言即免案；无册之明覆记实不罚双份；
- **外部之变不可见**：用户手改、另一进程写入不经 harness 流——变写缺席
  则覆案不立（凭据全在流内，本层不探测文件系统）；agent 若曾重读，读得
  之新文即为旧据，其后陈写仍可判（据账自有其序）；
- **等文重写不判**：idempotent 整卷重写（同文覆盖）非覆——但若其前行集
  已陈，等文写恰说明它没看世界，此形从宽放过，登记；
- **词法可欺但骗一次留一次形**：行集 trim/去空行已是归一极限，重排行、
  改注释可移形——骗一次留一次形，三序在账；
- **时序以流序为准**（缺 at 照判；合审序见 §2——无 at 之合审按参序拼接，
  审计方须自证流序）。
