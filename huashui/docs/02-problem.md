# 02 · 问题：Agent 陈据覆新（落笔之鲜无账）

## 谁在什么场景下的什么问题

**谁**：用 agent 写代码的工程师，以及被这单活覆掉的另一个会话（或 agent
自己早先那一步）的主人。

**场景**：长会话里，agent 在第 3 步读入 `src/a.js` 全卷，第 20 步改了一笔
（自己的修复落了盘），第 50 步又要动这个文件——它不再重读，凭上下文里
第 3 步那份旧副本整卷重写：第 20 步的修复被原样抹掉。或者另一只手
（并行的第二个会话、用户的热修）在两次落笔之间改了这个文件，agent 看不见，
整卷旧底覆上去，别人的修复无声蒸发。任务绿了，宣布完成，diff 上库。

**问题**：落笔的**鲜**（写下的内容对不对其时之世）无账：

- **修复静默蒸发**：被覆的那笔变是真实的既成事实——它可能是测试修绿的那行、
  安全补丁、别人的配置；覆写本身是一次完全合法的写入，测试照跑（少的不是
  功能，是修复），diff 照交，**绿得无声**；
- **症状在下游**：覆写发生的会话里一切正常，炸点在下一个会话、下一次构建、
  另一个人的机器——「昨天还在的修复今天没了」，回查 transcript 才能确认，
  而两个月的航程里没人会去查；
- **重读无激励**：动刀前重读一眼即可免病，但重读消耗上下文与调用数
  （duzhi 记费、youya 对「世未变的重读」计复见之费）——**没有一层告诉它
  「这次重读买回的是鲜」**，理性选择反而是不读；
- 就算事后怀疑覆写，也分不清「有意复古」还是「凭陈落笔」——**意图无从考，
  行集可考而无人考**。

相邻层的空白地：youya 审**复见**（世未变而重装载之费——它记的重读恰是
「其间无成功写」的重读，世已变的重读在它账上天然无罪）；jiubian 审**势变**
却以**失败**为触发（盲捶/悬账/游骑全在失败侧，静默的成功侧覆写无败可勘）；
dingfen 裁**写对写**的交错窗口（争写须两笔写在场，凭旧副本覆写可以无第二笔
写、甚至无第二个会话）；zhizu 量**写之量**（三行的谱系性覆写在行数上不可见）；
kaocheng 考**契上物**之末据（收工考物，不管落笔过程对不对得起其间之世）；
shenqu 称**读入之残全**（当时看见多少，不看看见的是不是现在）——
「落笔之鲜」是全仓空白。

## 问题（治什么病）

一个病形，两个案别，全部真实存在、全部有据可查：

| 病形 | 流内词面 | 现实对应 |
|------|----------|----------|
| **覆世** | 径 P：旧据（读/写 C1）→ **他会话**带文写 C2 → 本会话写 C3，C3 重现 C1 所独有之行 ∧ 失 C2 所独有之行 | 跨会话丢更新：别人的修复被凭旧底的一笔覆掉——多 agent 并发作业的正面病 |
| **覆己** | 径 P：旧据 C1 → **本会话**带文写 C2 → 本会话写 C3，同上谱系 | 自我覆写：长会话上下文里的旧副本压掉了自己早先的修复——上下文腐坏的正面病 |
| **失鲜**（注记档） | 同上谱系但陈线仅 1 行 | 疑似覆写而证据单薄——点名留痕不咬门 |
| **陈改不判**（注记档） | 旧据与陈写之间夹无文之写（edit 族不携全文） | 其间之变不可见，判定不得——诚实沉默 |

价值锚点：每一笔覆写都是流内可证的行集事实（带文之写的 `args.content`
与读取的 `result.content` 全在流内——zhixing 已证「知面取文于流」可行）；
工具链侧 IDE 的 local history / git 的 reflog 各守一段，但「**哪一笔写以
哪份旧底覆掉了哪笔变、重读发生在写前还是写后**」的流内账，没有任何一层
在记。本层不做语义判断（不判这次覆写值不值——有意复古与凭陈落笔在行集上
只差一个声明，裁决权归人：水册许复明言即免案），只做行集判断（旧据独有
之行重现了没有、变写独有之行还在不在）——恰是零 LLM 能确定性回答的两问。
**「动刀前重读」由账本结构性地变成唯一免罪之途**：写前重读者，其写之行集
必含变写之新线，谓词自白。

## 价值（为什么不是伪需求）

1. **每一笔都真实落在仓库里**：覆写是交付状态的既成事实，被覆之变是另一个
   真实的既成事实——两者的行集差异全在流内，不是「可能有害」的推断；
2. **意图可豁免而行集须留痕**：复古重写确实是正当工作（任务就是回滚）——
   水册许复明言即免案；git 词面的复古（restore/revert/checkout）走 exec 族
   不落写账、天然白；无册之案也不是罪，是**账**：留痕有价、点名有责、
   门禁有阈；
3. **记账不禁行**（画水的不笑人条款）：不拦写（拦是 zhizhi 的地盘）、不改
   内容、不跑语义分析——判定全部发生在流内行集上，观察永不反噬；
   覆写可以发生，但每一笔都要当众留痕——「尔时众人无不大笑」的透明，
   由账本供给；
4. **可证伪**：三序判定、行集阈值、分数公式全部锁死于 03；同流重放必得
   同判词；跨项目历史流可验尸复算——错了改实现，不改标准。

## 产品形态

- **画水式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：挂
  `tools/result` 观察口，据账入账，水牌块接缝供给；
- **零依赖审计 CLI**（`huashui`）：多流离线合审（时序按 `at` 归并——覆世
  唯合审可见），可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的许复/重读协议。
