# 画水 · Huashui — Agent 协作协议

> **「我今画水作记，舍之而去后当取之。」**
> **「水虽不别，汝昔失时乃在于彼，今在此觅何由可得？」——《百喻经·乘船失釪喻》**
>
> 会话是一条行船：上下文里的文件副本是你在流动水面上作下的记号。径还是
> 那个径，内容早已不之——凭记号整卷重写，覆掉的是你自己的修复或另一个
> 会话的工作。本协议不限制你落笔（拦是知止的地盘），它要求：以旧底覆掉
> 其间之变的每一笔都当众留痕；动刀之前重读一眼，是唯一让账面归白的行为。

## 何时用此 Skill

- 工程师想防住「长会话里 agent 凭上下文旧副本整卷重写、抹掉自己早先的修复」；
- 多会话并行时想防住「A 会话凭陈卷覆掉 B 会话其间落盘的修改」（丢更新）；
- CI 需要一道落笔之鲜门禁（陈值 ≥ 30 即红——单覆世即红、双覆己即红）；
- Agent 需要自查：这一笔写，以哪份底落的？底与现卷之间有几笔变还在不在？

## 给派活的工程师

```bash
cd your-repo
huashui register --path "legacy/*"                  # 允许凭旧底重写的径，先立许复
huashui audit session.jsonl --file .huashui.json    # 收工审鲜（exit 码可进 CI）
huashui audit s1.jsonl s2.jsonl --json              # 多会话合审（覆世唯合审可见）
huashui block --file .huashui.json                  # 水牌块：水册与案账公示
```

- **无册全账**：不立册也审——落笔之鲜是仓库公共事实，许复只能来自册；
- **许复是授权**：任务本身就是凭旧底重写（回滚、重建），开工时把径列进水册；
- **门禁**：陈值 ≥ 30 即红——单覆世即红、双覆己即红、单覆己黄牌点名不咬门。

## 给 Agent 的五条纪律

1. **动刀之前，重读一眼**：写前重读者，其写之行集必含其间之变的行——
   谓词自白；不读而写，覆案的每一笔都记在你名下；
2. **整卷重写是最高危的落法**：你的上下文是水面上的记号，不是水本身——
   径同名同不代表卷同；改一笔用小笔，改全卷先取全卷；
3. **git 复古走 git**：`git restore`/`git revert` 是明言的复古，本层天然白；
   手写复古（凭记忆把旧内容敲回去）与凭陈落笔在账上同形——要有意，就明言；
4. **无文之写是隔断**：edit 族不携全文，其后一笔的谱系判不了——关键文件
   的修改用带全文之写落，让账认得你的底；
5. **词法可欺但骗一次留一次形**：重排行、改注释可移形，三序在账——
   覆掉的每一笔变都在水牌上点名。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 覆世 | 陈写重现旧据独有行 ∧ 失变写独有行，变写出自**他会话** | 覆掉别人的其间之变 | +30/案（单案即红） |
| 覆己 | 同上谱系，变写出自**本会话** | 覆掉自己的中间态 | +15/案（双案即红，单案黄牌） |
| 失鲜 | 同上谱系但陈线仅 1 行 | 疑似覆写证据单薄 | 0（点名） |
| 陈改不判 | 变写位是无文之写（edit 族） | 其间之变不可见 | 0（注记，诚实沉默） |

- 陈值 = min(60,30×覆世) + min(40,15×覆己)，total = min(100)；
- 分带 活 0–14 / 滞 15–29 / 腐 ≥30，门 30；
- 等文重写不判、保新线不罚（并集式重写非覆）、纯增/纯删之中变不判（净向）、
  写前重读则白——账本结构性地奖励重读；
- 全部判定零 LLM：三序是行集差集、许复是 glob——词法可欺但骗一次留一次形。
