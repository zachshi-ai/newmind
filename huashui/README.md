# 画水 · huashui —— DeepSeek Harness 的落笔之鲜治理

> **「我今画水作记，舍之而去后当取之。」**
> **「水虽不别，汝昔失时乃在于彼，今在此觅何由可得？」——《百喻经·乘船失釪喻》**

agent 的上下文里全是「画水作记」：早段读入的文件副本、自己十分钟前写下的
版本——每一笔都是在流动水面上作下的记号。会话是一条行船，几十步工具调用
过去，仓库这块「水」早被自己或别的会话改写过，而它动手时摸向的仍是记号：
凭旧副本整卷重写，覆掉自己早先的修复、或另一个会话其间落盘的工作。这一笔
**全绿、无声、账上无痕**——「昨天还在的修复今天没了」，炸点在下游。

**画水**给 DeepSeek Harness 装上第三十四个能力类型：**画水式插件**（结构性
零拦截）+ 零依赖审计 CLI + Agent Skill。它不拦写（账与闸分治，拦是知止的
地盘）、不做语义判断（不判这次重写是不是有意复古——许复授权归任务方的
水册明言），只做行集可证的两问：**旧据独有之行重现了没有、变写独有之行
还在不在**——同径三序（旧据 → 变写 → 陈写）逐笔对账，写前重读者行集含
新线、谓词自白。

## 快速开始

```bash
cd your-repo
npm install github:zachshi-ai/newmind#huashui-dsh    # 或复制本目录

# 开工（可选）：立水册——任务本就是凭旧底重写的径先许复
huashui register --path "legacy/*"                   # 许复授权（* 跨目录）

# 收工：审鲜
huashui audit session.jsonl --file .huashui.json     # exit 0 通过 / 1 门禁红 / 2 用法错
huashui audit s1.jsonl s2.jsonl --json               # 多会话合审（覆世唯合审可见）
huashui block --file .huashui.json                   # 水牌块：水册与案账公示（逐字节确定）
```

无册照判：不立册也审——无册 = 全账，许复授权只能来自册；git 词面的复古
（restore/revert/checkout）走 exec 族不落写账，天然白。

## 判定语义（docs/03 锁死）

**文据唯二**（无默认形表，凡 `p:` 径皆受审）：observe 族成功 ∧ 正文非空 →
读据；write 族成功 ∧ `args.content` 非空 → 写据；无文之写只留无文之痕
（隔断判定）；`isError=true` 不入账；exec 是黑盒。

**三序判定**（每笔带文写据按且仅按最近一对）：变写 = 陈写前最近异文写据；
旧据 = 变写前最近异文文据（读写皆可）；陈线 = 旧据独有之行在陈写中重现、
新线 = 变写独有之行在陈写中再失。

| 案 | 判定 | 分值 |
|----|------|------|
| **覆世** | 陈线 ≥2 ∧ 新线 ≥1，变写出自他会话 | +30/案，cap 60 |
| **覆己** | 陈线 ≥2 ∧ 新线 ≥1，变写出自本会话 | +15/案，cap 40 |
| **失鲜** | 陈线 =1 ∧ 新线 ≥1 | 0（点名） |
| **陈改不判** | 变写位是无文之痕 | 0（注记，诚实沉默） |

**陈值** = min(60,30×覆世) + min(40,15×覆己)，total = min(100)。分带
**活 0–14 / 滞 15–29 / 腐 ≥30**，门默认 30：单覆世即红、双覆己即红、
单覆己黄牌点名不咬门。

**清白道**：写前重读则白（行集含新线，谓词自白）、等文重写不判、保新线
不罚（并集式重写非覆）、纯增/纯删之中变不判（净向）、git 复古天然白、
许复在册免案。

**水牌块**（接缝供给）：水册公示 + 案账清点 + 逐案点名（径、seq、行数与
案别），永不携带任何行原文——掩码是结构性保证；同输入两次渲染逐字节相同
（shasum 可证）。

## 与既立各层的边界（结构性）

- **有涯**（一重一陈）：它审世未变而重见之费，本层审世已变而据未更之覆——
  同一笔重读，其间无写它记费、其间有写本层视为免案之证，镜像互补；
- **九变**（一败一陈）：它勘失败侧的势变（isError 为触发），本层审成功侧
  的静默覆写（全绿无败，世变唯据账可见）；
- **定分**（一界一陈）：它裁写对写的交错窗口，本层裁写对旧据的行集谱系
  （凭陈落笔可以无第二笔写——覆己单会话即成案）；
- **审曲**（一残一陈）：它称读入之残全（当时看见多少），本层称据之新陈
  （看见的是不是现在）；
- **考诚**（一契一陈）：它考契上物之末据（收工考物），本层考落笔过程之
  谱系（行中即案）。
