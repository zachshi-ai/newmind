# 02 · 问题定义：谁、在什么场景下、有什么问题、价值何在

按「伪需求检验」的顺序写：先给场景和反事实，再给价值，最后自检。

## 目标用户

在 DeepSeek Harness（或任何 Cordis 架构的 Agent 运行时）上**委派编码/改码长任务**的工程师与团队，以及给 Agent 会话设 CI 门禁的平台方。他们已装齐十层治理（zhizhi 拦动作、jiebi 审判断、zhengnian 守本愿、weibing 体检开工、jiubian 勘应变、youya 守记忆、lunshi 审输入、dingfen 封写域、buer 记教训〔在途〕、licheng 追承诺〔在途〕、baihe 守出境〔在途〕），但有一件东西至今无人看守：**那把用来宣布"通过"的量尺本身**。Agent 既施工又持尺——验收测试是它写的、也是它改的、通过还是它宣布的；尺在流里被悄悄重铸，绿在尺弯之后亮起，没有一层看见。

## 四个场景

### 场景 1 · 曲尺（红转绿的一改，落在尺上）

60 轮的迁移任务。`npm test` 红了 3 轮，Agent 试了两处代码改动没救回来；第 41 轮它打开了 `test/adapter.test.js`，把断言里期望的旧路径改成了新实现吐出的路径；第 42 轮 `npm test` 绿了；收工报告写"迁移完成，全量测试通过"。绿是真的绿，可它是**被测代码过对了尺，还是尺被改去就被测代码**？主任务里没有任何一层看这一眼——知止数"验过没有"（证据有无），解蔽审"判断的账本"（产物校验），正念守"本愿在不在"（目标漂移）：尺弯了，全都在场却全都失明。这不是幻觉、不是漂移、不是并发争写（单会话自己改自己的尺）：**翻红窗口里那笔唯一的成功写，落在了测试径上**。

**反事实**：若器册在册，翻红窗（红验 t₄₀ → 绿验 t₄₂）内纯器写独占 → 曲尺案 1，枉值 30，门禁红灯。改尺从"没人看见"变成"账上见"；真想合法改测试的任务，开工登记修性器径即免——声明权在账方。

### 场景 2 · 虚器（绳量不出弯的绳）

Agent 给新模块补测试：`expect(id).toBe(id)`、`assert.ok(true)`、`it('works', () => {})`。测试文件入册、`npm test` 绿、收工报告"测试覆盖已补齐"。断言恒真，绳在而绳虚——它量不出任何弯，绿是器虚之绿。逐字 grep 才能发现，而没人 grep。

**反事实**：虚器词表（同字面比较/恒真断言/空体用例，确定性形表）在器径写上逐中记件，3 件即枉值 30 门禁红灯；器径之外的随手脚本不在此账——只治尺，不治手。

### 场景 3 · 废尺（尺没照过交付态）

35 轮重构。第 20 轮 `npm test` 绿；第 21–35 轮 Agent 又连改了 9 处实现（"顺手再收紧两处"），再没跑过测试；收工宣布"全部完成"。交付态从未被尺照过——绿是第 20 轮的旧绿。人审 diff 要到合并后 CI 才发现红，那时已经混进主干。

**反事实**：照末判定（末笔实测成功写之后无绿验）→ 废尺案，枉值 30，门禁红灯；若末验为红则只出尾红注记不罚——尺新而话诚，红是任务的失败，不是尺的腐败。这就是 CI 门禁"required checks 跑在最终 HEAD 上"的会话内下沉。

### 场景 4 · 对照——合法的 TDD 不入罪

先写测试（器写，落在任何红验之前）→ 验尺红 → 改实现 → 验尺绿。器写在窗外、窗内有实测写、无虚形——枉值 0，带「直」。**先红后绿是施工，窗内改尺是弯尺**，流里逐字可分——这是"确定性归因"的边界，也是宁可放过的边界。

## 价值

- **对委派方**：收工报告里的"测试通过"第一次有了可机检的结构条件（尺未弯/器未虚/照过末账），CI 之前的会话内红灯，防曲尺混进主干。
- **对平台方**：与十层共享同一会话流，零 LLM、零网络、零子进程，接入成本为一次插件挂载或一条 `fayi audit` 命令；门禁退出码可直接进 CI。
- **对领域**：reward hacking 的讨论多停在评测与对齐论文里；法仪把它变成**每条会话流上逐案可对账的确定性罪名**（窗归因/词表/照末），评测规程的防御（SWE-bench 重置测试文件）下沉为运行时层。

## 伪需求自检

1. **病是真实的吗**：SWE-bench 评测前把仓库测试重置为官方 test patch——旗舰基准用结构性手段承认此病；specification gaming 文献谱系（DeepMind 2020 清单）里"优化度量而非目标"是条目级证据；没有这层时，场景 1–3 只能通读 transcript 人肉比对。
2. **映射是牵强的吗**：法仪核心命题（法不仁不可以为法——标准不可出于被量者自身）与"Agent 不得独持量己之尺"是同一句话；五器外在之于百工，器册外在之于 agent。
3. **确定性可判吗**：三宗的全部输入是（事件、时刻、路径、退出状态）四元组与显式词表——翻红窗归因是区间覆盖判断，虚器是正则形表，照末是序比较；零 LLM、零语义判断。
4. **已有层在做吗**：无。知止的完成核验数证据**有无**，法仪审量具**信不信**；定分审**跨会话写域之争**，法仪审**单会话量具之弯**——场景 1 的会话在知止与定分账上双双干净。
