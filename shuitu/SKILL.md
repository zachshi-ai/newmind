# 水土 · Shuitu — Agent 协作协议

> **橘生淮南则为橘，生于淮北则为枳，叶徒相似，其实味不同。所以然者何？水土异也。**——《晏子春秋》
>
> Agent 脚下的机器有自己的水土：全局包、shell/git 配置、常驻服务、计划任务。每一笔「顺手的环境改善」都在改水土；水土改了，下一个会话（或明天的同款任务）果实就变味——绿灯照旧（叶徒相似），行为已变（其实味不同）。本协议不禁止你改环境（装工具、调配置本来是做事的一部分），它只要求每一笔常驻境变有归宿：要么**复**（装了就卸、改了就还原、起了就停）、要么**豁**（任务方土册明言授权）、要么上账承责——无凭据的悬改一律现形。

## 何时用此 Skill

- 工程师想知道「机器为什么不一样了」：昨天绿今天红、这台绿那台红，先查水土账；
- CI / 共享机器需要一道「境变复位」门禁（异值 ≥ 30 即红）；
- Agent 需要在收尾自查：这一单活改过的常驻之境，都复位了没有。

## 给委派任务的工程师

```bash
cd your-repo
shuitu register --install brew --reside redis   # 开工立土册（这单活授权哪些常驻改动；可附 --config）
# ……Agent 作业……
shuitu audit session.jsonl                      # 收工审土（exit 码可进 CI；无册照判）
shuitu block --file .shuitu.json                # 土牌块（可注入收尾上下文）
```

- **无册照判**：默认形表 41 形开箱在岗——装形 17（npm/pip 全局旗标、apt/brew 等系统域）、改径形 11（`.zshrc` 等 rc 与 `/etc/`）、改词形 4（gitconfig/npmrc/defaults/ln）、驻形 9（服务/容器/nohup/crontab）；
- **授权要趁早**：任务本来就要装的全局工具、要起的常驻服务，开工时 `shuitu register` 签字——命中册词的案完全出账；
- **门禁**：异值 ≥ 30 即红——单常驻服务未停即红、两全局包未卸即红、两笔未授权配置即红；单装案或单改案（15）落移带黄牌点名不咬门；
- **项目域天然白**：`npm install`、`pip install`（无全局旗标）、`git config`（无 --global）是任务内的本分，永不入账。

## 给 Agent 的五条纪律

1. **装了就卸**（「所以然者何？水土异也」）：临时用的全局工具（`npm i -g`、`brew install`、`apt install`），收尾时卸掉——`uninstall` 一行就是账上的「复」凭据；
2. **改了就还原**：`git config --global` 用完 `--unset`；`npm config set` 用完 `npm config delete`——配对的复位凭据让案销账；
3. **起了就停**：`brew services start` / `docker run -d` / `nohup` 起的常驻物，收尾时 stop/kill——常驻服务未停单案即红；
4. **rc 文件是最后一手**：`>> ~/.zshrc` 这类改写在流内无可凭复（内容不可见）——要么任务方土册明言授权，要么就别改；`.ssh/authorized_keys` 与 `/etc/` 下的写同此戒；
5. **计划任务是持久化之王**：crontab/launchctl 的改动跨会话跨重启存续——非任务要求不碰，碰了必须 `crontab -r` / `unload` 还原或在册声明。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 驻遗 | 起了没停的服务/容器/计划任务 | 末改之后无停服凭据 | +30/案 cap 60（单案即红） |
| 装遗 | 装了没卸的全局包 | 末改之后无配对卸词 | +15/案 cap 30 |
| 改遗 | 改了没还原的全局配置/rc | rc 写案无可凭复，唯册豁免 | +15/案 cap 30 |
| 复 | 配对复位凭据（卸词×manager×包名 / unset / stop / kill / crontab -r） | 末改基点之后成功 | 0 |
| 豁 | 土册三列（install/config/reside）子串命中 | 立案前完全出账 | 0（注记） |

分带：**淮 0–14 / 移 15–29 / 枳 ≥30**；门默认 30。清白道：项目域安装白、仓库局部 git config 白、询值白（`git config --global <key>` 恰 1 词元是读）、`crontab -l` 白、`/dev/null` 白、basename 全等防 `src/profile/` 之诬、失败不入账、先卸后装不销案。边界：shefa 管**散件之宿**（任务域内的临时文件），本层管**境之复**（机器的常驻状态）；yuli 管**灭前之备**，本层管**改后之复**；yuanyu 管**入目**（读进什么），本层管**改写**（改了什么）。
