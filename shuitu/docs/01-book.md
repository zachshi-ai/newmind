# 01 · 选书：晏子春秋 × Agent 境变不复位

## 书

《晏子春秋》——记齐相晏婴（晏子）言行与政治对话的上古政论文集，内篇外篇八卷、二百一十五章，旧题晏婴撰，实为战国时人纂集成书，「管晏」并称之晏。它不是一人一时论理之作，而是把一位政治家的处世判断编成的**案例库**：每一章一个小故事、一句归因、一条可复用的判断。

选它的理由：在全部政论与管理典籍里，把「**环境差异决定行为差异**」用一个具体、可验证、流传最广的案例说透的，就是橘枳之喻。Agent 不是在真空里作业——它脚下的机器有自己的水土：全局包、shell 配置、常驻服务、计划任务。每一笔「顺手的环境改善」都在改水土，而水土改了，后来的果实就变味。对一台「改完环境就走、从不管复位」的机器，这是一剂对症的药。

## 四条经证，逐条映射

### 其一，橘枳之喻——总纲

> 婴闻之，**橘生淮南则为橘，生于淮北则为枳，叶徒相似，其实味不同。所以然者何？水土异也。**（内篇杂下）

同一粒种子（同一份任务书、同一个 Agent、同一套提示词），种在两片水土上（两台机器、或同一台机器的两个时刻），果实不同。Agent 作业的最痛一类不可复现正是这个结构：昨天绿今天红、这台机器绿那台机器红——仓库 diff 里什么都没变。**为什么？没人记过水土账。**`npm install -g`、`git config --global`、shell rc 里追的一行 export、`brew services start` 起的服务、crontab 里加的任务——每笔都真实发生了，任务宣告完成而水土全数留在了场上。本层的全部职责，就是让每一笔改水土的动作留痕、有价、复位有凭。

### 其二，「所以然者何」——把结果差异回溯为环境之问

晏子的高明不在断言而在**追问的结构**：齐人在齐不盗、入楚则盗，这个行为差异原本无解，晏子把它回溯到环境差异——「得无楚之水土使民善盗耶？」——不可解的行为问题立刻变成可追责的环境问题。本层把这一问做成机制：凡「昨天还好的怎么今天坏了」，先查改账——**谁在哪笔调用里改了什么、复位了没有**——行为差异的第一归因通道不再是玄学。

### 其三，「叶徒相似，其实味不同」——表面一致性的欺骗

橘与枳的叶子看起来一样，果子味道不同。Agent 的输出也一样：绿灯照旧、测试照过（叶徒相似），但行为基线已经被上一笔未复位的环境改动悄悄搬移（其实味不同）——构建顺序变了、默认 shell 变了、注册表源变了。本层让「味」可查：常驻之境的每一笔改动逐案在账， flavor drift 从「说不清」变成「一查便知」。

### 其四，「寡人反取病焉」——治理者不知道自己的水土在作恶

楚王设局羞辱齐使，反被晏子用环境归因反将一军——「圣人非所与熙也，寡人反取病焉」。楚王的失职不在民盗，而在**不知道自己的水土正被指为盗源**。Agent 治理同理：失败会话好处理（有迹可循），悄悄漂移的常驻基线才是暗病——下一个会话（或下一位工程师）踩进的坑，是上一个会话没复位的水土。账的作用就是让坑在踩进去之前现形。

## 与已用诸书的分野

本仓 #15 度支（《礼记·王制》）量的是**投入花销**（量入），#22 知足（《佛遗教经》）量的是**落笔规模**（量出），#24 舍筏（《金刚经》）审的是**散物之宿**（临时之物的归宿），#25 渊鱼（《列子·说符》）禁的是**入目之看**（敏感面的装载），#14 豫立（《中庸》）审的是**灭前之备**（毁掉之前有没有备份），#5 不贰（《论语》）记的是**跨会话之训**（错误教训的账本）——晏子春秋审的是**境之常驻态**：一量一境（度支）、一物一境（舍筏）、一入一改（渊鱼）、一灭一改（豫立）、一训一境（不贰），正交相续。
