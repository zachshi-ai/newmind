# 03 · 设计：揖盗 · yidao —— DeepSeek Harness 的守门开关治理（揖盗式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**揖盗式插件**（第三十七个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，kaocheng/扫屋/约法证明可以审交付卷面的行内之形（吞错之形、
调试残垢、读时之约），fayi 证明可以审**翻红窗**（验收器自弯的时窗归因）——揖盗证明
插件可以**审守门开关与所遇之阻的对见**：哪一处锁被哪笔写拆掉、窗内有没有它正要
绕过的那个错、尾文合没合。

```
tools/result   emit   观察写面入阻账与尾文（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、
零文件系统探测——形与阻全取自流内词面）；观察永不反噬（监听器异常吞掉，
管道照常）；锁册持久化归 CLI（register/revoke），插件只吃注入的 book 对象；
单会话视图的案与值只采本会话，跨会话归并归离线合并审计。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓。

**受审之卷**：write 族 p: 径——**无卷面后缀门**（守门开关不挑语言：
Python/JS/Go/gitconfig/properties 皆可落锁）。唯一豁免在立案前：**校场**
（演武之地不设门禁——名段正则 10 段，径中任一段命中即豁）∪ **锁册
excuse**（glob，声明权全在任务方）。

**阻账（exec 族逐笔全记，不问 isError 旗——败相在文不在旗）**：exec 族
调用之结果正文（含 isError=true 的正文与错误摘要）入阻账，记
`{seq, text}`。exec 落盘的**文面**不可见（黑盒）——拆锁发生在 exec 落点
本层不判，诚实沉默；`cat`/`curl` 之类命令不落卷，永不入尾文。

**尾文（末笔带 content 之成功写）**：write 族成功 ∧ `args.content` 非空 →
该径记尾文（行集取 content，形命中按行号记）；无文之写（edit 族）不改
尾文，记「尾文后无文之改 N 笔」注记。观察不入账——读取不落锁。
**入口滤**：`isError === true` 之写不入账（失败的写没落盘——不生尾文
也不生形）；isError 未知（null，老流）按已发生。

**合审序（CLI 多流）**：全 at 有数 → `(at, 流序, 流内序)` 稳定排序；否则
参序拼接（审计方须自证流序）。单会话运行时视图同法自洽。

## 3. 弱锁形（默认形表 12 形，零 LLM）——无册照判

形为单行正则（大小写敏感，同全仓既例），命中一处=一行=一案，行号按
尾文真实行序：

| # | 形名 | 词面（正则） | 族 |
|---|------|--------------|-----|
| 1 | `verify=False` | `verify\s*=\s*(False\|false\|0)\b` | 验锁 |
| 2 | `ssl_verify=False` | `ssl_verify\s*=\s*(False\|false)` | 验锁 |
| 3 | `CERT_NONE` | `\bCERT_NONE\b` | 验锁 |
| 4 | `check_hostname=False` | `check_hostname\s*=\s*(False\|false)` | 验锁 |
| 5 | `rejectUnauthorized:false` | `rejectUnauthorized['\"]?\s*:\s*(False\|false\|0)\b` | 验锁 |
| 6 | `NODE_TLS_REJECT_UNAUTHORIZED=0` | `NODE_TLS_REJECT_UNAUTHORIZED['\"]?\s*[=:]\s*['\"]?0` | 验锁 |
| 7 | `GIT_SSL_NO_VERIFY` | `\bGIT_SSL_NO_VERIFY\b` | 验锁 |
| 8 | `sslVerify=false` | `sslVerify\s*=\s*(false\|False)` | 验锁 |
| 9 | `InsecureSkipVerify:true` | `InsecureSkipVerify\s*:\s*true` | 验锁 |
| 10 | `--insecure` | `--insecure\b` | 验锁 |
| 11 | `Access-Control-Allow-Origin:*` | `Access-Control-Allow-Origin['\"]?\s*[,:]\s*['\"]?\*` | 网锁 |
| 12 | `origin:'*'` | `origin['\"]?\s*:\s*['\"]\*['\"]` | 网锁 |

**阻词表（10 词，窗归因之据，大小写不敏感、按序取首中）**：

- 验锁族 6：`certificate`、`self-signed`、`ssl`、`tls`、`handshake`、`证书`；
- 网锁族 4：`cors`、`cross-origin`、`access-control`、`跨域`。

## 4. 拆锁窗（败相归因，本层独有的机制）

对尾文命中的每一案（径:行:形，族 f）：**拆锁窗 = 该尾笔入账序之前近 10 笔
入账**（窗宽常量 10）。窗内阻账正文命中 **f 族阻词** → **遇阻案**
（拆锁与所遇之阻对见，+30/处，cap 60）；窗内无同族阻词 → **素拆案**
（+15/处，cap 40）。点名带窗内首中阻词与笔序（阻词原文是公开词表单词，
窗内败笔正文永不入牌——掩码是结构性保证）。

## 5. 锁册与校场（豁免在立案前，声明权全在任务方）

```json
{ "version": 1, "excuse": ["local-dev/*"] }
```

- **excuse（免拆）**：glob 串数组——本任务授权拆锁之径（本地代理、自托管
  环境）。宽 glob：`*` 跨目录；不含 `*` 规整逐字相等。命中者不入账；
- **校场**（默认豁免，常开）：径中任一**名段**（以 `/` 切分的段，径首亦算
  段）命中正则 `^(tests?|specs?|mocks?|fixtures?|debug|examples?|benchmarks?|sandbox|demos?|local)$`
  （10 段）——演武之地本就自签证书，立案前豁免；
- **无册照判**：册缺失自动建册（excuse 空），校场照常豁免；册只管免拆，
  v1 不扩形不扩阻词。

## 6. 判定序（锁死，逐径恰好一态）

对每个曾以 write 落笔之径（豁免前）：

| 序 | 条件 | 案别 | 分 |
|----|------|------|----|
| 1 | 全流无一笔带 content 之写 | —— | 0（诚实沉默） |
| 2 | 尾文命中弱锁形（逐处） | **遇阻**（窗内同族阻词）/ **素拆**（窗内无） | +30/+15，见 §4 |
| 3 | 尾文无命中，而先前任一带文之写命中过 | **复锁** | 0（注记——扶令上马） |
| 4 | 尾文无命中，先前亦无 | —— | 0（静默白） |

- 尾文 = 末笔带 content 之成功写（考其尾文；先前写过形、后来改净的径
  判复锁）；尾文后无文之改不改尾文（注记）；
- 一径多形多行逐处立案，可并存累加；遇阻/素拆按各案逐一归因（同径可
  混案——同窗同族同判，不同行异族各归各窗）。

## 7. 锁值与门禁

```
yu = min(60, 30 × 遇阻处数)
su = min(40, 15 × 素拆处数)
total = min(100, yu + su)
```

分带：**扃 0–14 / 倚 15–29 / 洞 ≥30**。门默认 30：

- 单遇阻 30 即红（败相在窗的拆锁是开门揖盗的正面——绝不让它无声上库）；
- 双素拆 30 即红；单素拆 15 落倚带，黄牌点名不咬门（本地调试与任务授权
  常在两可，记实为主）；
- 复锁/无文之改永不出账，仅注记。

## 8. 锁牌块（接缝供给，逐字节确定）

```
【揖盗 · 锁牌】
锁册：免拆 1 处（local-dev/*）
形表：验锁 10 ∪ 网锁 2（默认 12 形）
案账：遇阻 1 · 素拆 0 · 复锁 0 · 无文之改 0
遇阻：src/client.js:2 verify=False（窗内阻词 certificate @ seq 1）
```

无册锁牌（确定性文本）：`锁册：未立（凡拆皆记）`。
块中永不出现尾文行原文与窗内败笔正文（只载径:行:形名、阻词与笔序——
掩码是结构性保证；案行序：遇阻 → 素拆，族内按规整径字典序、行号升序），
同输入两次渲染逐字节相同（shasum 可证）。

## 9. issues 行序（锁死）

遇阻 → 素拆 → 复锁注记 → 尾文后无文之改注记 → 全扃
（`锁皆扃 ×N —— 常扃不开，盗无从入`，无任何案与注记时出此行，
N = 受审径数）。

## 10. 插件 API 与 CLI

**插件**（`yidao-dsh`，Service 名 `yidao`）：`report()` 汇总、`ledger()`
案账全文、`paizi()` 锁牌块、`gate()` 门禁裁决、`exportStream()` 导出会话流，
供 `yidao audit` 离线重放对账。

**CLI**（零依赖，`yidao`）：

```
yidao audit <s1.jsonl> [s2 …] [--file <锁册>] [--gate n] [--json]
yidao register --path <glob> [--file <锁册>]         立免拆（重复去重）
yidao revoke --path <glob> [--file <锁册>]
yidao list [--file <锁册>]                            阅册
yidao block [--file <锁册>]                           锁牌块（逐字节确定）
yidao gate --value <n> [--gate n]                     门禁裁决
yidao --help | --version
```

默认册 `./.yidao.json`；register 册缺失自动建册；revoke 无此径 exit 2；
list 缺册 exit 2；block 无册出确定性文本。退出码：0 通过 / 1 门禁失败 /
2 用法与输入错误。

度支量入，二柄审柄，终始记程，效验称实，名实核名，立诚结诺，稽疑稽问，

复位，考诚考交付之契，恒法审规矩源之名分，知行审会话之知行断层，防川审交付

守门开关与所遇之阻的对见**：弱锁形（词面）→ 阻账（败相）→ 拆锁窗（归因）→

- **乡校**：一声一锁。它审写进代码一行的**批评通道静音**（@ts-ignore 让

## 13. 既知从宽代价（宁漏方向，逐条登记）

- **exec 落点黑盒**：`git config http.sslVerify false`、`export
  NODE_TLS_REJECT_UNAUTHORIZED=0` 之类命令式拆锁不落卷——文面经命令
  生成不可见，本层不判（宁漏）；阻账只收 exec 的**结果正文**供窗归因；
- **尾文为准**：尾文之后的 edit 族修改考不到（无文之改注记）——若后改
  引入新锁，本层看不见；
- **窗宽固定 10**：败相在 10 笔之外的拆锁降档素拆（远窗旧败不及——宁纵
  方向：素拆 15 < 遇阻 30）；旧拆新卷（形跨多笔写存续）按尾笔窗归因，
  首拆时的败相可能已出窗——降档素拆，登记；
- **异族不归因**：TLS 败相不喂网锁案（族内相交）——`verify=False` 只认
  验锁阻词；族表词面可欺（改注释可移形）——骗一次留一次形；
- **词面误伤面**：`origin: "*"` 在非 CORS 语境（通用配置示例）会被命中
  ——校场与锁册是既定免拆之途；文档后缀不设豁免门（守门开关不挑语言
  亦不挑文体——.md 里的弱锁示例照记，宁纵者自开锁册），登记为既知
  从紧代价的边界选择；
- **case 敏感**：形大小写敏感（`Verify=False` 不中——Python/JS 惯例拼写
  之外从宽），阻词大小写不敏感（败相文体无定式）；
- **时序以流序为准**（缺 at 照判；合审序见 §2——无 at 之合审按参序拼接，
  审计方须自证流序）。
