# 02 · 问题：Agent 遇阻拆锁（守门开关被关无账）

## 谁在什么场景下的什么问题

**谁**：把 agent 产出上库的工程师、审这个 PR 的安全负责人，以及下游每一个
信任这份代码所连服务的人。

**场景**：agent 写一个 API 客户端，`curl` 报 `SSL certificate problem`——
它解围的顺手姿势是在代码里写 `verify=False`；Node 里报 `unable to verify
the first certificate`——`rejectUnauthorized: false` 或
`NODE_TLS_REJECT_UNAUTHORIZED=0`；fetch 被跨域拦下——`origin: "*"`。
证书错误消失了，测试绿了，宣布完成，上库。

**问题**：交付代码的**守门开关**被这单活顺手关掉，而改动无账：

- **拆的不是障碍是防线**：证书报错消失是因为校验不再发生——中间人、
  抢注域、恶意响应畅通无阻；SAST 工具链把这些列为高危（Semgrep/
  bandit/eslint-plugin-security 各有专条——业界对此病的结构性招供），
  但扫描器只对着现状，说不出「**这行锁是哪一笔写、在遇到什么阻之后拆的、
  拆得有没有名分**」——归因只发生在会话流内；
- **人眼漏掉**：一行 diff 混在几百行里，`verify=False` 与 `verify=True`
  在 review 时几乎不可分；
- **症状在门外**：拆锁的会话里一切正常（证书错误本来就该消失），炸点在
  生产与安全审计——「这段代码为什么关着验签」回查时无账可问；
- 就算看见，也分不清「任务授权的本地调试」还是「遇阻解围」——**意图
  无从考，败相可考而无人考**。

相邻层的空白地：乡校审**批评通道**（@ts-ignore/eslint-disable——让组织
的报错闭嘴）却管不到**守门开关**（让验证不发生不是让报错闭嘴）；防川审
**错误之口**（空体 catch——把错误咽下去）而拆锁是**不让错误有机会发生**；
渊鱼审**入目之禁**（读密物）、捭阖审**出境之物**（密物外发）——守门开关
既不入目也不出境，是代码卷面上的第三处门户；恒法审**规矩源**（仓库的
章程文件）、扫屋审**调试残迹**（打印原语与调试语句——开发过程的遗留物），
守门开关是交付代码里被**有意调低的安全与校验机制**，两不相干；yuefa 审
**公共接口面**（导出名）——名之面非锁之面。

## 问题（治什么病）

一个病形、两档案别，全部真实存在、全部有据可查：

| 病形 | 流内词面 | 现实对应 |
|------|----------|----------|
| **遇阻拆锁** | 近十笔内 exec 结果正文命中阻词（certificate/self-signed/ssl/tls/handshake/证书 ∪ cors/cross-origin/access-control/跨域），同族弱锁形落卷 | 经典解围形：TLS 报错 → `verify=False`——拆锁与所遇之阻在同一笔账上对见 |
| **素拆** | 弱锁形落卷而窗内无同族阻词 | 本地调试/任务授权/无端拆锁常在两可——留痕有价，黄牌不咬门 |
| **复锁**（注记档） | 先前写过弱锁形、尾文改净 | 张昭扶令上马——先拆后合的门不算开的门，0 分注记 |
| **尾文后无文之改**（注记档） | edit 族不携全文 | 尾文之后的修改考不到，诚实沉默 |

价值锚点：弱锁形是公开词法（SAST 行业的既成规则表——Semgrep `python.requests.verify-false` 等证明词法可检）；败相与拆锁全在会话流内（exec 结果正文与 write 的 `args.content`）；「哪一处锁被哪笔写拆掉、窗内有没有它正要绕过的那个错」是零 LLM 能确定性回答的三问。本层不做语义判断（不判这次拆锁值不值——本地代理与遇阻解围在词面上只差一个授权声明，裁决权归人：锁册免拆明言即免案），只做词法判断（形落没落、阻在不在窗、尾文合没合）。

## 价值（为什么不是伪需求）

1. **每一笔都真实落在交付代码里**：弱锁形是上库 diff 的既成事实，不是
   「可能有害」的推断；SAST 行业的存在本身证明此病高频且词法可检；
2. **意图可豁免而败相须留痕**：本地调试确实需要关验——锁册免拆明言即
   免案、校场（tests/mocks/fixtures 等名段）默认豁免；无册之案也不是罪，
   是**账**：留痕有价、点名有责、门禁有阈；
3. **记账不禁行**（张昭条款的账面化）：不拦写（拦是 zhizhi 的地盘）、不改
   代码、不跑语义分析——形表与阻词全是公开词法，观察永不反噬；先拆后合
   注记不罚，扶令上马有赏；
4. **可证伪**：形表、阻词表、窗宽、分数公式全部锁死于 03；同流重放必得
   同判词；跨项目历史流可验尸复算——错了改实现，不改标准。

## 产品形态

- **揖盗式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：挂
  `tools/result` 观察口，阻账入账，锁牌块接缝供给；
- **零依赖审计 CLI**（`yidao`）：多流离线合审，可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的免拆/复锁协议。
