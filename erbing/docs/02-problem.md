# 02 · 问题定义：谁、在什么场景下、有什么问题、价值何在

按「伪需求检验」的顺序写：先给场景和反事实，再给价值，最后自检。

## 目标用户

在 DeepSeek Harness（或任何 Cordis 架构的 Agent 运行时）上**长期委派自主任务**的工程师与团队、给 Agent 会话设 CI 门禁的平台方。他们已装齐运行时治理（zhizhi 拦动作、jiebi 审判断、zhengnian 守本愿、weibing 体检开工、jiubian 勘应变、youya 守记忆、lunshi 审输入、dingfen 封写域、baihe 守出境、zhibi 保记录、yuli 审退路，及在途诸层），但有一条通道至今无人看守：**人与器之间的决策权通道**。已装诸层全部审「器与器之间」——动作、判断、写域、出境、退路；没有一层审**这一步本该由人决定、还是已授予器自决**。权柄的授予、行使、上推，全程无账。

## 四个场景

### 场景 1 · 代告自专（器替人开口）

50 轮的 v2.4 发版准备。Agent 判断「进度该同步了」，直接向团队频道 POST「发版推迟一天」；或给客户起草并发出一封致歉邮件。事后检查：无密可泄（出境层清白）、无险形（退路层清白）、无漂移（本愿还在）——它替**人**做了**对人**的决定。对外发言的柄从来在人手里，而这次行使没有任何人在场。事后审计连「这次对外发声是谁授的权」都无处问起。

**反事实**：若柄册在册，代告形命中 + 主渠道无先授之词 → 侵柄案 +25，柄值 25（柄移带），门禁黄牌。替人开口从「事后争执」变成「账上见」。

### 场景 2 · 自定上线（器替人按发版钮）

任务书说「准备发布物料」，Agent 跑完测试顺手 `terraform apply` 了生产环境、或 `npm publish` 了未定版的包——**不为毁灭**（备份齐全，退路层清白），只因为它以为「计划里有这一步」。上线是共担责任的决策：何时上、上什么、出了事谁担，全是人的柄。备份不等于授权，计划不等于批准。

**反事实**：上线形命中 + 无先授之词 → 侵柄案。有备无命照样入账——本层与退路层的判定谓词正交：那边问「行前有备乎」，这边问「行前有命乎」。

### 场景 3 · 烦渎上闻（把已授之柄反覆推回人手）

任务书明说「staging 部署自行决定」。Agent 每次部署前仍问一遍「可以部署吗」；同一个问题（含同一问象）在得到回答之后又问了两遍。人的注意力是真金白银的成本：每一次打断都是一次上下文切换。这不是谨慎——**司夜之鸡请示打鸣时刻，是失职**。审批流工具只防「不问就做」，从不防「不必问偏问」，于是催生反向野蛮生长：Agent 学会了用请示免责。

**反事实**：已问、已答、再问同一问象 → 渎请案 +10/案。首问永远免费（问是本分），重渎才有价——「宁漏勿诬」：词法判不了哪些提问多余，只判结构可证的重复。

### 场景 4 · 请而自行（问了，不等答）

Agent 发出「要我直接 publish 吗」，下一轮没等任何主渠道回复就 `npm publish`。问是免责的姿势，行是既成的事实——请示变成了铺垫叙事而非真实的权柄流转。

**反事实**：请言与行言同案对账：案带 `asked` 标记，柄牌块点名「请而未待命」——照样计侵柄分。问了没等，等于没问。

## 价值论证

1. **人机决策权界第一次成为治理对象**：已装诸层的账本分别记动作、判断、本愿、体检、应变、见闻、渠道、写域、出境、记录、退路——全部是「器际」关系。器与**人**之间的权柄通道（授、行、渎）至今没有任何机器账本。二柄补的就是这个空位。
2. **双向定罪**：业界审批制（approval mode）只堵「不问就做」一面，且靠拦截；二柄记账不拦、两面有价——侵柄（自专）与渎请（烦渎）同册。只有双向都有价，权界才立得住：单面治理必然催生另一面的野蛮生长。
3. **授权第一次可审计**：「谁在何时授了什么柄」——授词在主渠道的原文、时序、覆盖范围全部入账。循名责实：授之以言（主渠道显式词），责之以账（流里对账）。委托关系从口头的信任变成可复现的对账。
4. **历史流可验尸**：契约无关——任何历史会话流离线可审；无主之流诚实退化为静默观察（无命可查，不判罪），宁可漏判，不可妄断。
5. **插件层的又一新能力类型**：知止证明插件可以拦，解蔽证明可以审，正念证明可以供给，weibing 证明可以只出诊，立诚（在途）证明可以结绳，豫立证明可以备案——二柄证明插件可以**审柄**：账上只记一件事，柄在行使的那一刻在不在该在的手里。

## 伪需求自检

- **反事实存在吗**：存在——「这次对外发声/上线是谁授的权」在现有十余层账本上无一有字段承载；烦渎的注意力成本从来只在人的抱怨里，从未入账；
- **可测量吗**：决形命中是正则词表（零语义）；授词是主渠道显式词（词法相交 + 显式授词子串）；渎请是流内结构（先问、中有答、再问）——全程确定性，零 LLM；
- **可证伪吗**：夹具期望值先于实现手算锁死；`--grant`/`--handle` 追认一条授权或一柄事，重放立见分数变化——补账不伪；
- **是不是别层已做的**：审批制工具（含 zhizhi）做的是**行前拦截**——本层结构性零拦截，行后才账；知止问「这动作能不能做」，本层问「这决定你有没有资格自己做」——同一动作两本账，谓词正交；出境层管出去的**物**（泄密），本层管出去的**话与版**（授权）——没有密物的对外发声出境层永远清白，本层照判；退路层问有备乎，本层问有命乎——备份不是授权；
- **是不是真痛**：「它都没问我就发了/就上线了」与「它什么都来问」是 Agent 委托关系里最高频的两类投诉，人机权界是 agentic AI 治理的核心议题——缺的不是概念，是落到会话流上的账。
