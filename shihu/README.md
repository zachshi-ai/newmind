# 市虎 · shihu —— DeepSeek Harness 的状态陈报治理

> **「夫市之无虎明矣，然而三人言而成虎。」——《战国策·魏策二》**

多 agent 编排时代的交接书就是那封文书：会话收工前写下 `HANDOFF.md`——
「- [x] 修复 src/b.js 的空指针」「npm test 全绿」，下一个会话照单全收，
按「已修复」跳过、按「全绿」不再复验。可「市之无虎明矣」的那件事一查
便知：**写这条声明的会话，自己的流里动过手吗？**——声明在文书里，事实
在流里，两处从来没有对过账。

**市虎**给 DeepSeek Harness 装上第三十七个能力类型：**市虎式插件**（结构性
零拦截）+ 零依赖审计 CLI + Agent Skill。它不拦写（账与闸分治，拦是知止的
地盘）、不做语义判断（不判这条声明为什么虚——幻觉与措辞归人裁决），只做
词法可证的一问：**这条完成态声明，你自己的流里动过手没有**——状面唯写 →
状形提取 → 状键对自流作工面对账，单虚功即红。

## 快速开始

```bash
cd your-repo
npm install github:zachshi-ai/newmind#shihu-dsh    # 或复制本目录

# 开工（可选）：立状册——归档类交接书先免对账
shihu register --path "archive/*"                  # 豁免授权（* 跨目录）

# 收工：审状
shihu audit session.jsonl --file .shihu.json       # exit 0 通过 / 1 门禁红 / 2 用法错
shihu audit s1.jsonl s2.jsonl --json               # 多会话合审（声明按会话分账对账）
shihu block --file .shihu.json                     # 状牌块：状册与案账公示（逐字节确定）
```

无册照判：不立册也审——无册 = 全账，交接语境的陈报是公共事实，豁免只能
来自册。

## 判定语义（docs/03 锁死）

**状面唯写**：write 族成功 ∧ 正文非空 ∧ 径命中状面形（默认 5 形：
HANDOFF.md/handoff.md 全等 ∪ 名含 handoff ∪ /handoff/ 段 ∪ 名含「交接」；
册 shapes 增形）→ 状面入账；观察不入账——读来的状态不是写的状态。

**作工面**（对账基准，按会话分账）：本会话 exec 命令原文（**成败皆入**
——试错也是始）∪ 写径 ∪ 读径；不含正文；other 黑盒不入。

**判定序**（每声明行）：径 exempt 免账 → 引用署名 **掠据** 0 → 状键任一
词元命中作工面 **有据** 0 → 全查无 **虚功** +30/条 → 无词元 **无键** 注记。

| 案 | 判定 | 分值 |
|----|------|------|
| **虚功** | 声明对象词元在本会话作工面全部查无 | +30/条 cap 60，**单条即红**（一虎即红） |
| **掠据** | 声明行含引用词（上游/来自/by @…） | 0（点名——署了名的转述不是自己的虎） |
| **无键** | 剥状词后无对象词元 | 0（注记，诚实沉默） |

**虎值** = min(60, 30 × 虚功条)。分带**真 0–14 / 疑 15–29 / 虎 ≥30**，门
默认 30：单虚功条即红——三人言而成虎，一份虚报就足以把假状态立成下游的
事实。

**清白道**：未勾选与将来时不中状形、有据静默（成没成归效验/终始，本层只
问动没动）、掠据署名 0 分、exempt 在册免案。

**状牌块**（接缝供给）：状册公示 + 案账清点 + 逐条点名（径:行号:状键），
永不携带任何行原文——掩码是结构性保证；同输入两次渲染逐字节相同（shasum
可证）。

## 与既立各层的边界（结构性）

- **立诚**（一诺一状）：它审将来时的话语承诺（「我会做 X」），本层审完成
  时的书面陈报（「X 已做完」）——一个是没做的诺、一个是没做过的状；
- **终始**（一册一状）：它审任务方立的事册走到没走到，本层审 agent 自己
  写的状态陈报对没对得上自己的手——交接书不是任务方的事册，「自册自证」
  两面它都不看；
- **效验**（一报一状）：它称绿命令的成色（信号的实），本层对书面状态的
  据（文书与手）——同在「虚与实」，一在信号侧、一在文书侧。
