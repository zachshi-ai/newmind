# 01 · 选书：《战国策》—— 魏策二，三人成虎

## 原文

《战国策》（西汉·刘向集录；本文引文据维基文库《战国策·魏策二》同文，
人物名一作庞恭、一作庞葱，版本异文如实并注）：

> 庞葱与太子质于邯郸，谓魏王曰：**「今一人言市有虎，王信之乎？」**王曰：「否。」
> **「二人言市有虎，王信之乎？」**王曰：「寡人疑之矣。」
> **「三人言市有虎，王信之乎？」**王曰：「**寡人信之矣。**」
> 庞葱曰：**「夫市之无虎明矣，然而三人言而成虎。」**
> 今邯郸去大梁也远于市，而议臣者过于三人矣。

市里明明没有虎——这是**一查便知**的事；可是写在书面上、说得够多次的
话，魏王就信了。庞葱指出的不是魏王蠢，是**陈报的机制缺陷**：等真相要靠
「派人去市里看」，而听信只要看文书——说的人越多、写得越正式，越没有人
再去市里。他自己预见了结局：等他远在邯郸，说他坏话的人「过于三人」，
王将无从查证。

## 为什么是这本书

agent 编排时代的交接书就是那封文书：一个会话收工前写下
`HANDOFF.md`——「- [x] 修复 src/b.js 的空指针」「已完成：文档已迁移」，
下一个会话（或人）**照单全收**，按「已修复」跳过、按「已迁移」继续。
可「市之无虎明矣」的那件事一查便知：**这一笔声明，写它的会话自己的流里
动过手吗？**——交接书说修了 `src/b.js`，全流连一次碰都没碰过它的作工
之迹都没有；说「npm test 全绿」，全流没有一条测试命令。声明在文书里，
事实在流里，两处从来没有对过账。

病的精确形状不是「说谎」（意图无从考），而是**「陈报无据」**：完成态
声明落盘成文（三人言），下游按文书决策（王信之），而「这条声明当时
对没对得上自己的手」在任何一层的账本上都无处问起——等炸点在下游浮现，
邯郸去大梁也远于市。本层把庞葱的问句落成一条治理姿态：**写状有账**
（交接书可以写，每一条完成态声明都过一遍自流对账）、**言必有徵**
（声明行在流内有作工之迹即有据；全查无即虚功——市之无虎，账上点名）；
「动过手才写已完成」不是纪律劝告，是唯一让账面归真的行为。

## 逐条映射

| 《战国策·魏策二》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 一人言市有虎（书面陈报开始） | agent 写盘交接书/状态文件：`- [x] 修复 src/b.js` | **状面唯写**（write 族成功 ∧ 径命中状面形 → 状面入账；观察不入账——读来的状态不是写的状态） |
| 三人言而成虎（成文的假话） | 完成态声明落盘成文：勾选形/✅/已完成 X/done: X | **状形词法**（勾选形 `- [x]` ∪ 状词表 ∪ 里程碑形，行内命中即声明行） |
| 王信之（文书被照单全收） | 下游会话/人按交接书决策——「已修复」就跳过 | **虚功对账**：声明行对象词元全流查无作工之迹 +30/条 cap60 单条即红 |
| 夫市之无虎明矣（真相一查便知） | 流内作工之迹是确定性事实：exec 命令原文 ∪ 写径 ∪ 读径 | **状键对账**（声明行对象词元 × 本会话作工面子串命中即有据——自态自证） |
| 邯郸去大梁远于市（事后无从查证） | 炸点在下游浮现，写状的会话早已收工 | **状牌块**（接缝供给案账清点，逐字节确定，事后验尸有账） |
| 议臣者过于三人（重复陈报压过真相） | 交接书里多条声明逐条落账——每条单独对账，不因条多而从宽 | **逐条立案**（每声明行至多一案，cap 60；两条虚报即满虎带） |
| 曾参杀人同篇语境（慈母不能信也） | 引用上游之功要署名：写明「上游会话已完成」 | **掠据白**（声明行含引用词 → 注记 0 分——转述他人的活不是自己的虎） |
