# 03 · 设计：市虎 · shihu —— DeepSeek Harness 的状态陈报治理（市虎式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**市虎式插件**（第三十七个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，licheng 证明可以追话语之诺，zhongshi 证明可以记任务方之册，
kaocheng 证明可以考契上物之末据，yuefa 证明可以审公面之约——市虎证明插件可以
**审自述之状**：写下的完成态声明，对没对得上自己的手。

```
tools/result   emit   观察写面入状账（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、
零文件系统探测——状与据全取自流内）；观察永不反噬（监听器异常吞掉，管道照
常）；状册持久化归 CLI（register/revoke），插件只吃注入的 book 对象；声明按
其所在会话分账对账（自态自证），合审用于验尸多份交接书。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓。

**状面唯写**（唯一受审通道）：

- write 族成功（`isError !== true`；未知按已发生）∧ `args.content` 非空 ∧
  规整径命中**状面形** → 该径记状面一笔（正文逐行扫声明行）；
- **观察不入账**：读取到的状态不是写下的状态（任务书里的「已完成」是任务方
  的词）；
- **无文之写**：content 为 null/空 → 不入账（无状可扫）；isError === true
  不入账（失败的写没落盘）；
- **作工面**（对账基准，按会话分账）：本会话全部调用的词面——exec 族成功
  **或失败**的命令原文（试错也是始，zhongshi 同款从宽）、write 族规整径、
  observe 族规整径；isError 不滤（失败也动过手——最不可能冤枉的方向，
  代价登记 §11）；other 族黑盒不入作工面；
- exec 命令原文取 `args.command` trim 后全文。

## 3. 状面形（默认形表，开箱在岗）

交接径的词法形态（规整径上判定）：

| 形 | 例 |
|----|----|
| basename 全等 2：`HANDOFF.md`、`handoff.md` | `docs/HANDOFF.md` 命中 |
| 名含 1：basename 小写化后含 `handoff` | `HANDOFF-notes.md`、`handoff-v2.md` 命中 |
| 径段 1：含 `/handoff/` 径段 | `docs/handoff/auth.md` 命中 |
| 中文形 1：basename 含「交接」 | `交接-鉴权.md` 命中 |

- **册增形**（shapes）：册 `shapes` 数组追加 basename 子串（大小写不敏）
  或 glob（含 `*`）；`noDefaults` 可关默认表；
- 状面形之外的径（README/CHANGELOG/普通代码）**不审**——完成态声明只有
  出现在交接语境才是面向下游的陈报；册可以把任何径立进 shapes（声明权
  在任务方）。

## 4. 状形与状键（词法提取，零 LLM）

### 4.1 状形（声明形态，命中即声明行）

正文按 `\r?\n` 切行逐行扫；声明行=命中下列任一状形：

| 族 | 形 |
|----|----|
| 勾选形 | 行首（允许空白与 `-`/`*` 列表符后）`[x]` 或 `[X]`——GitHub task list 语义：勾选即完成态 |
| 状词表（中文 11） | 已完成｜已修复｜已实现｜已添加｜已创建｜已更新｜已删除｜已迁移｜已重构｜已部署｜已解决 |
| 状词表（英文 4） | done:｜completed:｜fixed:｜implemented:（行内子串，大小写不敏） |
| 里程碑形 | `Status:`（或「状态：」）后含 `done`/`complete`/「完成」（大小写不敏） |
| 旗标形 | ✅、☑️、☑（行首或列表符后） |

未勾选的 `- [ ]`、将来时（「将完成」「待办」）不中状形——不是完成态声明。

### 4.2 掠据白（引用署名）

声明行含**引用词**（默认 10：上游｜来自｜转自｜借自｜援自｜承接｜by @｜
from @｜per @｜inherited，大小写不敏）→ **掠据**注记 0 分——转述他人的活
不是自己的虎（宁漏方向：把虚功赦成掠据是放生，代价登记 §11）。

### 4.3 状键（声明对象键）

声明行剥掉：列表符/勾选符/旗标、状词、引用词、**停用词表**（默认 16：
实现｜完成｜修复｜添加｜创建｜更新｜删除｜迁移｜重构｜部署｜解决｜处理｜
支持｜问题｜功能｜模块）后，切词元：

- **径形词元**：正则 `[\w./\\-]+\.[A-Za-z]{1,5}` 抽整段（`src/b.js` 保形
  不碎）；含 `/` 的非径词形（`docs/handoff`）整段抽；
- **普通词元**：其余按 Unicode 字母数字段切（`/[\p{L}\p{N}_-]+/u`），长度
  ≥2 者入状键；对账时大小写归一（两侧 lowercase）子串匹配；
- 状键为空（整行只有状词）→ **无键注记** 0 分（无从对账——诚实沉默）。

## 5. 对账与案别（判定序锁死，每声明行至多一案）

对状面径的每一条声明行，按且仅按：

1. 径命中状册 **exempt glob** → 静默（豁免在立案前）；
2. 行含引用词 → **掠据** 0（注记，点名）；
3. 状键词元**任一**在本会话作工面（任一词面子串命中）→ **有据** 0
   （静默——过得了「你动过手吗」的第一问）；
4. 状键全部词元查无 → **虚功** +30/条 cap 60——市之无虎，账上点名；
5. 状键为空 → **无键** 0（注记，诚实沉默）。

- 声明按其**所在会话**的作工面对账（自态自证）——合审中他会话的作工
  救不了本会话的虚报（把上游的活写成自己的完成，恰是本层要抓的掠据
  之实——署名走引用词）；单流审计即全判；
- 逐条立案：一条声明行至多一案，逐行点名 径:行号:状键。

## 6. 状册（豁免，声明权全在任务方）

```json
{ "version": 1, "exempt": ["archive/*"], "shapes": ["STATUS.md"], "noDefaults": false }
```

- **exempt**：glob 串数组——径命中即免账（豁免在立案前）；宽 glob 同全仓
  （`*` 跨目录，无 `*` 逐字相等）；
- **shapes**：状面增形（basename 子串或 glob）；
- **无册=全账**：交接语境的陈报是公共事实，豁免只能来自册；册缺失自动
  建册（空册=全账）；v1 只豁免与增形不扩判；册是结构化 JSON、唯一入口
  （CLI register/revoke），无词旗标覆盖。

## 7. 虎值与门禁

```
hu = min(60, 30 × 虚功条数)
```

分带：**真 0–14 / 疑 15–29 / 虎 ≥30**。门默认 30：

- 单虚功条 30 即红（三人言而成虎——一份虚报就足以把假状态立成下游的
  事实；一虎即红）；
- 掠据/无键永不出账，仅点名。

## 8. 状牌块（接缝供给，逐字节确定）

```
【市虎 · 状牌】
状册：豁免 1 处（archive/*）
案账：虚功 1 · 掠据 1 · 无键 0
虚功：HANDOFF.md:3（状键 src/b.js——本会话作工面查无）
掠据：HANDOFF.md:5（引用署名——转述上游之功）
```

无册状牌（确定性文本）：`状册：未立（凡状皆对）`。
块中永不出现任何行原文（只载径、行号与状键——掩码是结构性保证；案行序：
虚功 → 掠据 → 无键，族内按规整径字典序、行号升序），同输入两次渲染逐
字节相同（shasum 可证）。

## 9. issues 行序（锁死）

虚功 → 掠据 → 无键 → 全实（`状皆实 ×N —— 言必有徵，不作市虎之谈`，
无任何案与注记时出此行，N = 受审状面数）。

## 10. 插件 API 与 CLI

**插件**（`shihu-dsh`，Service 名 `shihu`）：`report()` 汇总、`ledger()`
状账全文、`paizi()` 状牌块、`gate()` 门禁裁决、`exportStream()` 导出会话
流，供 `shihu audit` 离线重放对账。

**CLI**（零依赖，`shihu`）：

```
shihu audit <s1.jsonl> [s2 …] [--file <状册>] [--gate n] [--json]
shihu register --path <glob> [--file <状册>]       立豁免（重复去重）
shihu revoke --path <glob> [--file <状册>]
shihu list [--file <状册>]                          阅册
shihu block [--file <状册>]                         状牌块（册公示，逐字节确定）
shihu gate --value <n> [--gate n]                   门禁裁决
shihu --help | --version
```

默认册 `./.shihu.json`；register 册缺失自动建册；revoke 无此径 exit 2；
list 缺册 exit 2；block 无册出确定性文本。退出码：0 通过 / 1 门禁失败 /
2 用法与输入错误。

## 11. 与既立各层的方向边界（结构性，不是纪律性）

论世审发令资格，定分裁写域，捭阖守出境，法仪护尺，直笔保笔，豫立审备，
度支量入，二柄审柄，终始记程，效验称实，名实核名，立诚结诺，稽疑稽问，
乡校听声，知足量出，审曲审残全，舍筏审落物之宿，渊鱼审入目之禁，水土审境变
复位，考诚考交付之契，恒法审规矩源之名分，知行审会话之知行断层，防川审交付

**市虎审自述之状**：状面唯写 → 状形提取 → 状键对账 → 虚功（虎值）→
状牌（供给）。

- **licheng**：一诺一状。它审**将来时**的话语承诺（「我会做 X」——绳账

## 13. 既知从宽代价（宁漏方向，逐条登记）

- **只审 write 侧**：agent 在会话消息里说的「已完成」不审（消息文本词法
  不稳）——话语之虚归 licheng/成报之虚归 xiaoyan，本层唯审落盘文书；
- **径限定交接形**：README/CHANGELOG 等的完成态声明不审——只有交接语境
  才是面向下游的陈报；册 shapes 兜底；
- **失败作工算有据**：声明「已完成」而全流只有失败的尝试在本层账上是有
  据（试错也是始——最不可能冤枉的方向），成败归 xiaoyan/zhongshi 两侧
  各自记账；
- **掠据之赦**：引用词同行共现即白——词法认不出「假署名」（把上游没做
  的写成上游做了），宁严一格登记；
- **状键之窄**：对象是词面词元，非径非词的指代（「它」「那个 bug」）切
  不出词元 → 无键注记 0 分诚实沉默；停用词表可能误剔真实对象词（册上
  无法兜底——显式词元走径形）；
- **词元子串之宽**：状键词元任一命中即有据（从宽）——「修复 src/b.js
  的空指针」若流内恰好 `grep 空指针 src/a.js` 过（词元「空指针」命中）
  即有据，尽管 b.js 没碰过——宁纵方向，点名语义在账（有据不等于真做
  完了）；
- **exec 黑盒**：命令改的文件名不在命令原文中（`npm test` 内部写了什么）
  流内不可见——但命令原文本身就在作工面，对账认的是「动过手」不是
  「动过哪个文件」（与 4.3 的径形词元并存，双通道从宽）；
- **状面形之窄**：非英文非中文命名的交接文件（`DER NIKE.md` 类）不中默
  认表——册 shapes 兜底，宁漏；
- **词法可欺但骗一次留一次形**：把虚报写成将来时、藏进非状面径可移形——
  骗一次留一次形，状牌在账；
- **时序以流序为准**（缺 at 照判；合审按 (at, 流序, 流内序) 归并或参序
  拼接——审计方自证流序）。
