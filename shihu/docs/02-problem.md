# 02 · 问题：Agent 状态陈报虚功（交接成报无账）

## 谁在什么场景下的什么问题

**谁**：跑多 agent 编排、会话接力的工程师，以及照着交接书决策的下一个
会话（或下一个人）。

**场景**：会话 A 收工前写 `HANDOFF.md`：「- [x] 修复 src/b.js 的空指针」
「- [x] npm test 全绿」「已完成：文档迁移至 docs/」。其中第一条——A 的
全流没有碰过 `src/b.js`：没有读、没有写、没有一条命令提过它；第二条——
全流没有跑过任何测试。会话 B 开工，读交接书，按「已修复」跳过那个空
指针、按「全绿」不再复验——炸点在 B 的下游、B 的下一次构建浮现。回查
A 的 transcript 才能确认，而没有人会去查：**文书是真的，市里有没有虎
是另一回事**。

**问题**：状态陈报的**据**（写下的完成态对没对得上自己的手）无账：

- **虚报接力**：交接书的作用就是被信——B 不会复验 A 的每一条（复验的
  成本正是交接书要省掉的）；一条虚功声明污染的是 B 的全部决策输入；
- **意图无从考、据可查而无人查**：A 可能是幻觉（它「记得」修过）、可能
  是乐观措辞、可能是上下文串了——本层不判意图，只问流内事实：这条声明
  的对象，写它的会话动过手没有；
- **编排规模放大**：三个会话接力、每个交接五条声明，十五个信任点里只要
  一个虚功，下游整条链都在假地基上——而事后审计连「哪一条当时就没据」
  都无处问起；
- **相邻层的空白地**：licheng 审**话语承诺**（「我会做 X」——将来时的
  诺），反向的「声称已做完」（完成时的状）它无案可记；zhongshi 审**任务
  方事册**的众事行程（册是任务方立的），交接书是 agent 自己立的册——
  「自册自证」两面都不看；kaocheng 考任务方**契册**对交付物之末据（契是
  契），交接书不是契上物；xiaoyan 称**成功信号的成色**（绿命令空不空），
  不审书面状态与作工的对应；huashui 审落笔对**世变**之鲜、yuefa 审公面
  对**读时之约**、mingshi 核**写下的名**有没有实——「写下的**状**有没有
  据」是全仓空白。

## 问题（治什么病）

一个病形，两个案别，全部真实存在、全部有据可查：

| 病形 | 流内词面 | 现实对应 |
|------|----------|----------|
| **虚功** | 交接径的带文之写，声明行状键词元在本会话作工面（exec 命令原文 ∪ 写径 ∪ 读径，失败亦算——试错也是始）全部查无 | 「已修复 src/b.js」而全流没碰过 b.js——下游按假状态决策 |
| **有据** | 状键词元任一命中作工面 | 声明过得了庞葱的第一问：你动过手吗（成没成归效验/终始，本层只问动没动） |
| **掠据**（注记档） | 声明行含引用词（上游/来自/by @） | 转述他人的活——署了名，不算自己的虎 |
| **非状** | 未命中状形（`- [ ]` 未勾选、将来时「将完成」） | 不是完成态声明，不审 |

价值锚点：交接径是显式词法（默认形表 ∪ 册增形）；声明行是显式状形
（勾选/状词/里程碑词表）；状键是词元切分加停用词表；对账基准是本会话
作工面——四件事全是流内可证的确定性事实。本层不做语义判断（不判这条
声明为什么虚——幻觉与措辞归人裁决；引用署名即掠据白），只做词法可证的
一问：**这条完成态，你自己的流里动过手没有**。

## 价值（为什么不是伪需求）

1. **每一笔都真实落在流里**：交接书是 write 落盘的真实文件、下游真的会
   读它决策——虚功声明的据（作工面）与状（声明行）全在流内，不是
   「可能有害」的推断；
2. **意图可豁免而陈报须留痕**：引用上游之功是正当转述——署名（引用词
   同行）即掠据白 0 分；无白之虚功也不是罪，是**账**：留痕有价、点名
   有责、门禁有阈；
3. **记账不禁写**（庞葱不禁人言）：不拦写（拦是 zhizhi 的地盘）、不改
   内容、不跑语义分析——判定全部发生在流内词面上，观察永不反噬；状
   可以写，但每一条都要过自流对账——「市之无虎明矣」的透明，由账本
   供给；
4. **可证伪**：状面形、状词表、词元切分、对账谓词全部锁死于 03；同流
   重放必得同判词；跨项目历史流可验尸复算——错了改实现，不改标准。

## 产品形态

- **市虎式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：挂
  `tools/result` 观察口，状面入账，状牌块接缝供给；
- **零依赖审计 CLI**（`shihu`）：多流离线合审（声明按其所在会话分账
  对账——自态自证），可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的署名/对账协议。
