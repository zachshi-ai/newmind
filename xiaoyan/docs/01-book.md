# 01 · 选书：《论衡》——一千九百年的「疾虚妄」，治的是 2026 年 Agent 最便宜的一种自欺：成功信号空言虚语，验证不算数却层层照单收编

## 一、十七层看护之后，仍有一块公共原料无人称量：**成功的成色**

手、眼、心、习、工、信、记、足、界、分、阖、尺、笔、备、支、柄、终都有了看护。但跑过很多 Agent 任务的人还会遇到下一种下午，而且是最便宜、最常见的一种自欺：

> Agent 跑 `npm test`。命令干干净净——没有 `\|\| true`，没有 `--passWithNoTests`（直笔画「直」）；没有改过任何测试文件（法仪画「尺直」）。退出码 0。**输出是空的**——配置坏了，runner 一个测试都没收集到。然后：知止的证据账记下「1 次成功验证」；jiebi 的判断账本引用它；zhengnian 的终验门对着它放行；zhongshi 的程账记下「有终」。**每一层都问了「验没验」「尺直不直」「笔直不直」，没有一层称过这声「成功」本身有没有做过事。**

这不是假想，这是 Agent 可靠性问题里最小、也最上游的一块空白：

- **静默空转**：runner 配置错、测试目录没被收集、reporter 吞了输出——命令形表完全干净，退出码照常报喜，可观察的「实」是零。直笔的讳形表抓不到它（笔直），法仪的器册抓不到它（尺直），但它就是空言虚语；

- **以令为证**：wrapper 脚本、`bash -x`、CI echo 模式——「验证」的全部输出就是把命令自己复读一遍。Agent 引用这段「输出」当证据，引用的其实是它自己下过的令；

- **静默冤案**：反过来也有——`git diff --quiet`、`tsc --noEmit` 这类**设计上就静默**的检查，exit 0 且无输出是它们的成功语义。一个见空就罚的层会冤枉它，误伤一次用户就永久关掉这个层；

- **事后验尸**：事故复盘的标准问题——「那天它声称的那次验证，输出里到底有没有东西？」——历史会话流里只有成败码，成色**无处问起**。

这些失败有一个共同结构：**环境报了「成功」（言），但从没交出可观察的凭据（验）**。王充对这种脱钩有一千九百年的诊断，而且恰好落在「言」与「验」的关系上：

> **事莫明於有效，论莫定於有证。空言虚语，虽得道心，人犹不信。**（《论衡·薄葬篇》）

对事物最好的证明是它有效果，对论点最好的认定是它有证据。空言虚语，就算把道理讲得再透，人还是不信。**退出码就是那句「得道心」的空言虚语**：它说「成了」，却拿不出半件「效」与「证」。

## 二、为什么是这本书

《论衡》不是泛泛地劝人「重实证」。王充把「疾虚妄」做成了先秦两汉唯一一套**系统的验证方法论**——他批谶纬、批圣人生知、批厚葬祥瑞，凭的不是立场而是一把尺：**凡断言，必引效验**。条款清楚到可以直接逐条工程化：

### 2.1 原文条款 → Agent 失败模式逐条对照

| 原典 | 直译 | Agent 的病 |
|---|---|---|
| **事莫明於有效，论莫定於有证**（薄葬篇） | 对事物最好的证明是有效果，对论点最好的认定是有证据 | 验证类调用报了成功，却拿不出任何可观察之实——**空言**。无「效」无「证」，成功不成其为证据 |
| **空言虚语，虽得道心，人犹不信**（薄葬篇） | 空话虚辞，就算得了道理的神髓，人还是不信 | 退出码 0 说「成了」——道心是有的（命令确实跑完了），效验是零的。下游各层不该信它 |
| **凡论事者，违实不引效验，则虽甘义繁说，众不见信**（知实篇开篇） | 论事的人违背事实而不举出效验，道理再动听、说得再多，众人也不该信 | 「甘义繁说」正是那声 exit 0——形式再体面，不引效验就不该被收编为证据 |
| **事有证验，以效实然**（知实篇开篇） | 事情有证有验，用它来验证真实性 | 证验要**在场**——本层把效账逐件登记，并把**证块**供给到接缝处，让「证」长在上下文里 |
| **《论衡》篇以十数，亦一言也，曰：疾虚妄**（自纪篇） | 《论衡》几十篇，说到底就一句话：痛恨虚妄 | 立场宣言：对空转成功零容忍——但疾的是**虚**，不是**默**（免验词表给设计上静默的检查一条显式生路，不冤枉） |
| **论贵是而不务华**（自纪篇） | 论说贵在正确，不追求华丽 | 本层不解析测试框架输出、不数断言个数（不务华）——只认结构可证的实：有无可观察内容、所答是否为所验 |

### 2.2 一条主线索：效账

十七层的度量对象各不相同。效验的度量对象是**成功信号自身携带的证据含量**——成色：

- 从会话流里确定性登记每一条**成报**（`isError === false` 的工具返回）——环境报「成功」的那一声；
- 只审**效类**成报（显式效词表命中：test / lint / check / build / verify…），非效类的静默成功是合法沉默，永不审——宁可放过，不可错罚；
- 效类成报过**三问**：**有实乎**（有无可观察内容 → 空言）、**所验乎**（所答是否为所验——内容只是命令的回声 → 回令；与所验对象无词相干 → 离效）、**先例乎**（同参复验旧果已陈 → 陈效）；
- 合成一个数：**效值**（0–100，虚分 + 回分），分带 **明 / 疏 / 虚**，门禁可断言，账本可重放；
- **免验**词表给设计上静默的检查一条显式豁免通道——不冤枉，疾虚才立得住。

### 2.3 与尺笔终三层的分野：尺·笔·实三位一体

验证可信性这块，法仪守**尺**（验收器脏没脏——曲尺/虚器/废尺），直笔守**笔**（记录直不直——讳形洗白/空绿），本层守**实**（成功成没成过事——空言/回令）。`npm test` 改了测试文件翻红转绿：法仪记曲尺；`\|\| true` 洗白：直笔记讳笔；**命令干净、尺也没动、输出却是空的**：尺直、笔直、而实空——只有效验称它「空言虚语」。三个对象正交：器（写没写尺）、迹（洗没洗码）、物（有没有效验），缺一即漏。

### 2.4 为什么不是别的书

道（zhizhi）、儒（buer/zhongshi）、兵（jiubian）、医（weibing）、佛（zhengnian）、易（licheng）、庄（youya）、孟（lunshi）、商（dingfen）、鬼谷（baihe）、墨（fayi）、春秋（zhibi）、中庸（yuli）、王制（duzhi）、韩非（erbing）各有其主。「言与验脱钩 + 系统性验证方法论 + 疾虚不疾默」这条链，传世原典里只有《论衡》一次给全：疾虚妄（立场）→ 事莫明于有效（有实乎）→ 论莫定于有证（证验在场）→ 违实不引效验则众不见信（空言不得收编）→ 论贵是而不务华（结构可证，不务华丽）。五个条款，恰好是本层的五个部件。《墨子·非命》的「三表法」曾是候选，但墨家已为法仪所用，且三表重「立仪」的立场宣言，王充给的是更细的**验证程序**（效、证、验三字各有着落）——本仓一书一层，不重开墨家的门。

## 三、诚实边界（先于实现声明）

1. **v1 是结构层，不是语义层**：不解析测试框架输出、不数断言个数、不判断内容好坏——那是框架与语义方案的事。效验只回答一个结构问题：**这声「成功」有没有携带可观察之实、所答是否为所验**。判不了的，效验不假装能判。
2. **只审效类成报**：显式效词表（默认 25 条，ASCII 词界匹配、CJK 子串匹配，可配置追加）命中才入效账。`mkdir`、`touch` 这类天然静默的成功永不审——它们的沉默是合法的。
3. **单件空言不咬门**：一件空言 25 分，落在**疏**带（15–29）——点名、亮黄牌、门禁不咬。设计上静默的检查由**免验词表**显式豁免（默认空表，全靠配置声明——提及不等于授权沉默）。宁可放过，不可错罚。
4. **离效与陈效只点名不计分**：答非所问、旧果已陈都是信息性发现（与有涯「陈账只点名」同一立场）——它们是疑点，不是罪证，v1 不给它们分值。
5. **老流无 content 按「账上无据」记**：不带 content 字段的历史流，效类成报一律记空言嫌疑——这不是判工具的罪，是指出**账本缺口**（流里根本没记证据，无从自证）。单件不咬门，点名可复核。
6. **效值低不等于验证充分**：0 分只证明「显式判据内的空转在这条流里结构可证地没有发生」。断言数为零的测试套、内容真实但断言空洞的输出，不在 v1 的观测范围——尺脏归法仪，码洗归直笔，事没做完归终始。安全层从不假装自己是全部安全。
7. **插件结构性零拦截**：没有任何 pre-execute 监听器（grep 可证）。效验给的是账本与门禁，不是判决书；拦不拦由宿主决定。
