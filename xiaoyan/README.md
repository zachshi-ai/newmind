# 效验 · xiaoyan —— DeepSeek Harness 的成色审计层

> **事莫明於有效，论莫定於有证。空言虚语，虽得道心，人犹不信。**——《论衡·薄葬篇》

一门一千九百年的疾虚妄之学，能不能精确地解决人工智能的一个真实问题？

能。2026 年的 Agent 天天在自我验证：跑测试、跑构建、跑 lint，然后对着退出码宣布完成。而运行时里没有一层称过**这声「成功」本身有没有做过事**——`npm test` 命令干干净净（直笔画「直」）、没动过测试文件（法仪画「尺直」）、退出码 0，输出却是空的：runner 配置坏了，一个测试都没收集到。知止的证据账把它收编为证据，jiebi 的判断账本引用它，zhengnian 的终验门对着它放行，zhongshi 的程账记下「有终」。**空转成功穿过了每一层。** 效验把「绿而不实」变成**可测量、可门禁、可验尸**的结构事实：尺（法仪）·笔（直笔）·实（效验）三位一体，缺一即漏。

## 它是什么

DeepSeek Harness 的**称实式插件**（Cordis）+ 零依赖审计 CLI + Agent Skill。

本实验室第十八层治理，与相邻层的分野：

| 层 | 思想源头 | 治什么 | 工作的对象 |
|---|---|---|---|
| 法仪 fayi（尺） | 《墨子·法仪》 | 验收器自污染 | **器**：尺被改/器本虚/尺没照末 |
| 直笔 zhibi（笔） | 《春秋》 | 失败隐匿洗白 | **迹**：`\|\| true` 等讳形把码洗绿 |
| **效验 xiaoyan（实）** | **《论衡》** | **空转成功（绿而不实）** | **物**：这声「成功」有没有携带可观察之实 |

`npm test \|\| true` 在法仪账上是绿验、在直笔账上是讳笔、在效验账上因失败侧不入账而不可见——三本账互证不互代。效验审的是第四种绿：**命令干净、尺也没动、输出为空**。

## 核心概念

- **成报**：`isError === false` 的工具调用——环境报「成功」的那一声。失败永不入账（九变地盘），成败未知不入账（诚实退化）；
- **效类**：显式效词表（默认 26 条，纯字母数字词界 + 其余子串，零 LLM）命中的成报。非效类的静默成功是合法沉默，永不审；
- **三问判定**（每件至多一项发现）：**有实乎**——content 缺失/空白 → **空言**（虚 +25）；**所验乎**——内容只是命令的回声 → **回令**（回 +20），内容与所验对象无词相干 → **离效**（只点名）；**先例乎**——同参复验旧果已变 → **陈效**（只点名）；
- **效值**（0–100）＝ 虚（cap 50）+ 回（cap 30），分带 **明 0–14 / 疏 15–29 / 虚 ≥30**，门默认 30。单件空言落疏带点名不咬门：偶发嫌疑被看见，合法静默不被冤杀；
- **免验词表**：设计上静默的检查（`git diff --quiet`、静默 reporter）由使用方显式豁免——王充疾的是**虚**，不是**默**；
- **证块**：接缝处供给的成色清单，逐字节确定，重放同流必得同文。

**宁可放过，不可错罚**：类目收敛、单件不咬门、免验显式声明——不冤枉，疾虚才立得住。

## 快速开始

```bash
npm install        # 安装官方 @deepseek-ai/* 包（仅集成验证需要）
npm test           # 74 tests, 74 pass

# 验尸任何历史会话流（契约无关）：
node src/bin/xiaoyan.js audit <stream.jsonl>            # 效值 + 分带 + 门禁（exit 0/1/2）
node src/bin/xiaoyan.js audit <stream.jsonl> --gate 25  # 更严的门
node src/bin/xiaoyan.js zheng <stream.jsonl>            # 证块（成色清单）
```

插件用法（宿主侧）：

```js
import xiaoyan from './src/plugin/xiaoyan.js'
ctx.plugin(xiaoyan, { gate: 30, words: ['deploy'], exempt: ['--quiet'] })

// 运行中任意时刻：
ctx.xiaoyan.exempt(['--reporter=silent'])  // 免验词运行时声明
ctx.xiaoyan.report()   // 观察数 / 空言 / 回令 / 即时效值
ctx.xiaoyan.xiaozhang() // 效账全文（逐件三问判定）
ctx.xiaoyan.zheng()    // 证块（逐字节确定，#k 递增）
ctx.xiaoyan.gate()     // 门禁裁决
```

## 方向边界（与后来者）

只做**成功信号的成色称量**：效账（成报逐件登记）+ 效词表（显式可配，与默认表取并集）+ 三问判定（空言/回令/离效/陈效）+ 效值门禁 + 证块供给，称实式插件结构性零拦截（源码无 pre-execute 监听器）；不拦动作（zhizhi）、不审判断账本（jiebi）、不守本愿（zhengnian）、不做 t=0 体检（weibing）、不管势途（jiubian）、不管记忆衰减（youya）、不审渠道权威（lunshi）、不裁写域（dingfen）、不称量出境（baihe）、不审尺脏（fayi——器与物两本账）、不判笔直（zhibi——迹与物两本账）、不管行前退路（yuli）、不量总量花销（duzhi）、不审须柄授命（erbing）、不记任务项终始（zhongshi——走没走到归它，拿什么证明归本层）、不记跨会话事故（buer）、不追承诺（licheng）；失败事件（isError=true）永不入账；契约无关（可验尸任何历史流）；零 LLM、零网络、零 NLP——不解析测试框架输出、不数断言，只认结构可证之实。
