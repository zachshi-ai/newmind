# 01 · 选书：《墨子》——两千三百年的「言必立仪」，治的是 2026 年 Agent 最便宜的一种自欺：成功信号空而无物，验证不算数却照单收编

## 一、十层看护之后，仍有一维无人看管：**成功的成色**

本实验室已上线的十层治理（八层已提交、两层在途），各守一个对象：

| 层 | 思想源头 | 治什么 | 工作的对象 |
|---|---|---|---|
| [知止 zhizhi](../zhizhi/)（手） | 《道德经》 | 行为失控：连败死循环、未读先写、无证据宣称完成 | **动作** |
| [解蔽 jiebi](../jiebi/)（眼） | 《荀子·解蔽》 | 判断失真：锚定、确认偏误、不可证伪 | **判断的产物** |
| [正念 zhengnian](../zhengnian/)（心） | 《六祖坛经》 | 意图漂移：失念、攀缘、代偿完成 | **意图** |
| 不贰 buer（习） | 《论语》「不贰过」 | 重蹈覆辙：同样的错跨会话再犯 | **事故账本** |
| [治未病 weibing](../weibing/)（工） | 《黄帝内经》 | 带病开工：任务书与环境 t=0 的病灶 | **主渠道（任务书）** |
| 立诚 licheng（信） | 《周易》「修辞立其诚」 | 失诺蒸发：承诺不兑现、无声改诺 | **承诺** |
| [有涯 youya](../youya/)（记） | 《庄子》「吾生也有涯」 | 见闻遗忘：复见、复命——世未变而它忘了 | **记忆** |
| [九变 jiubian](../jiubian/)（足） | 《孙子兵法》 | 势途脱钩：该变不变、没凭乱变 | **势与途的对齐** |
| [论世 lunshi](../lunshi/)（界） | 《孟子》 | 数据渠道的内容冒充主命发令 | **输入渠道的权威** |
| 定分 dingfen | 《商君书·定分》 | 多会话并发争写：名分未定则百人逐兔 | **写权界与争写对账** |

手、眼、心、习、工、信、记、足、界、约都有了看护。但跑过很多 Agent 任务的人还会遇到下一种下午，而且是最便宜、最常见的一种自欺：

> Agent 跑 `npm test`。退出码 0。输出是空的——配置坏了，runner 一个测试都没跑到。它宣布「测试全部通过，修复完成」。知止的证据账把这次「成功的验证命令」记为证据；解蔽的判断账本引用它；正念的终验门对着它放行。**每一层都问了「有没有验证」，没有一层问「这次验证本身算不算数」。**

这不是假想，这是 Agent 可靠性问题的最底层一块板：

- **空转测试**：runner 配置错、测试目录没被收集、`--reporter` 吞了输出、CI 脚本 `|| true` 抹平了失败——退出码照常报喜，可观察的「实」是零。下游每一层（证据账、判断账本、终验门）都把这件事照单收编；

- **以令为证**：wrapper 脚本、`bash -x`、CI echo 模式——「验证」的全部输出就是把命令自己复读一遍。Agent 引用这段「输出」当证据，引用的其实是它自己下过的令；

- **静默冤案**：反过来也有——`git diff --quiet` 这类**设计上就静默**的检查，exit 0 且无输出是它的成功语义。一个见空就罚的层会冤枉它，误伤一次用户就永久关掉这个层；

- **事后验尸**：事故复盘的标准问题——「那天它到底验没验？验证的输出是什么？谁能证明输出里有东西？」——历史会话流里只有成败码，成色**无处问起**。

这些失败有一个共同结构：**环境报了「成功」（言），但从没交出可观察的凭据（仪）**。墨子对这种脱钩有两千三百年的诊断，而且恰好落在「言」与「实」的关系上：

> **言必立仪。言而毋仪，譬犹运钧之上而立朝夕者也。是非利害之辨，不可得而明知也。**（《墨子·非命上》）

说话必须先立仪表。没有仪表的言论，就像在旋转的陶轮上立表测影——影怎么立得住？晨昏怎么判得明？**退出码就是那只旋转的陶轮**：它在转，但不指向任何方向。从 exit 0 断言「事成了」，就是在运钧之上立朝夕。

## 二、为什么是这本书

《墨子》不是泛泛地劝人「重实证」。它对「言凭什么可信」给出了先秦诸子里唯一一套**操作化的验证程序**——三表法——条款清楚到可以直接逐条工程化：

### 2.1 原文条款 → Agent 失败模式逐条对照

| 原典 | 直译 | Agent 的病 |
|---|---|---|
| **言必立仪。言而毋仪，譬犹运钧之上而立朝夕者也**（非命上） | 言论必须立仪表；没有仪表，就像在旋转的陶轮上立表测影，是非利害无从判明 | 退出码是「言」，不是「仪」。成功信号若不携带可观察之实，一切下游判断都立在运钧之上 |
| **故言必有三表……下原察百姓耳目之实**（非命上，第二表） | 言有三表；第二表是察百姓耳目的**实**——直接观察 | 验证类命令报了成功，却拿不出任何可观察的内容——**空报**。耳目无实，成功不成其为证据 |
| **废（发）以为刑政，观其中国家百姓人民之利**（非命上，第三表） | 把言论付之实施，看它是否切合国家百姓之**利**——与所行相干、有用 | 验证的「输出」要么只是把命令复读一遍（以令为证，**回声**），要么与所验对象毫无相干（**掠疑**）——答非所验，何利之有 |
| **上本之于古者圣王之事**（非命上，第一表） | 第一表是**本**之于先例——与既有的经验事实对照 | 同参复验而结果已变，旧数就成了**陈账**——先例变了，引用旧果就是拿着过期的「实」说话（v1 只点名不罚） |
| **言不信者，行不果**（修身） | 说话不可信，做事不会有结果 | 空转成功一旦被下游收编为证据，**整条证据链都是空的**——知止的证据账、jiebi 的账实对账、zhengnian 的终验门，全部立在这声没有成色的「成功」上 |
| **百工为方以矩，为圆以规……放依以从事，犹逾己**（法仪） | 百工画方用矩、画圆用规；巧者能中，不巧者依法而行，还是胜过靠自己 | 词表、门禁是显式的规矩。不依赖模型「这次恰好诚实」——**原则会被违反，触发器不会**，规矩不巧，胜过自评 |

### 2.2 一条主线索：成色账

十层的度量对象各不相同。立仪的度量对象是**成功信号自身携带的证据含量**——成色：

- 从会话流里确定性登记每一条**成报**（`isError === false` 的工具返回）——环境报「成功」的那一声；
- 只审**验类**成报（显式验类词表命中：test / lint / check / build / verify…），非验类的静默成功是合法沉默，永不审——宁可放过，不可错罚；
- 验类成报过**三表**：**原表**（耳目之实：有无可观察内容 → 空报）、**用表**（观其利：所答是否为所验——内容只是命令的回声 → 回声；与所验对象无词相干 → 掠疑）、**本表**（先例之实：同参复验旧果陈账 → 点名）；
- 双向合成一个数：**仪值**（0–100，虚分 + 回分），分带 **明 / 疏 / 无**，门禁可断言，账本可重放；
- **免仪**词表给设计上静默的检查一条显式豁免通道——不冤枉，仪才立得住。

### 2.3 与知止（zhizhi）的互补：数个数与称成色

知止的完成核验把「成功的验证命令」计入证据账——它问的是**这个 turn 有没有验证**（个数）；立仪问的是**这次验证本身算不算数**（成色）。同一个事件，两层各答一问：zhizhi 夹具里那条被记为证据的 `npm test` 成功（流里根本没有内容字段），立仪称出它是空报（25 分·疏带）。九变审**败**账（失败悬而未决），立仪审**成**账（成功空而无物）——一败一成，互为镜面。

### 2.4 为什么不是别的书

道（zhizhi）、儒（buer）、兵（jiubian）、医（weibing）、佛（zhengnian）、易（licheng）、庄（youya）、荀（jiebi）、孟（lunshi）、商（dingfen）各有其主。「言与实脱钩 + 操作化验证程序 + 显式豁免」这条链，先秦原典里只有《墨子·非命》一次给全：言必立仪（成功必须自带仪表）→ 原察耳目之实（可观察之实）→ 观其利（与所验相干）→ 本之于古者圣王之事（先例对照）→ 言不信者行不果（下游危害）→ 法仪规矩（显式词表与门禁）。六个条款，恰好是本层的六个部件。韩非的「循名责实」曾被定分列为候选——它审的是**名实对账**（说过的与做到的），那是 jiebi 的近亲；墨子审的是**言实对账**（宣称的与观察到的），对象不同，且墨家给出了三表这套可直接工程化的程序，而非一句原则。

## 三、诚实边界（先于实现声明）

1. **v1 是结构层，不是语义层**：不解析测试框架输出、不数断言个数、不判断内容好坏——那是框架与语义方案的事。立仪只回答一个结构问题：**这声「成功」有没有携带可观察之实、所答是否为所验**。判不了的，立仪不假装能判。
2. **只审验类成报**：显式验类词表（默认 25 条，ASCII 词界匹配、CJK 子串匹配，可配置追加）命中才入仪账。`mkdir`、`touch` 这类天然静默的成功永不审——它们的沉默是合法的。
3. **单件空报不咬门**：一件空报 25 分，落在**疏**带（15–29）——点名、亮黄牌、门禁不咬。设计上静默的检查由**免仪词表**显式豁免（默认空表，全靠配置声明——提及不等于授权沉默，比论世的「承」更严一格）。宁可放过，不可错罚。
4. **掠疑与陈账只点名不计分**：答非所问、旧果陈账都是信息性发现（与有涯「陈账只点名」同一立场）——它们是疑点，不是罪证，v1 不给它们分值。
5. **老流无 content 按「账上无据」记**：不带 content 字段的历史流，验类成报一律记空报嫌疑——这不是判工具的罪，是指出**账本缺口**（流里根本没记证据，无从自证）。单件不咬门，点名可复核。
6. **仪值低不等于验证充分**：0 分只证明「显式判据内的空转在这条流里结构可证地没有发生」。断言数为零的测试套、内容真实但断言空洞的输出，不在 v1 的观测范围——那是语义层的活。安全层从不假装自己是全部安全。
7. **插件结构性零拦截**：没有任何 pre-execute 监听器（grep 可证）。立仪给的是账本与门禁，不是判决书；拦不拦由宿主决定。
