# 03 · 设计：扫屋 · saowu —— DeepSeek Harness 的调试残迹治理（巡扫式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**巡扫式插件**（第三十六个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，fangchuan 证明可以扫交付码面的吞错之形，shefa 证明可以审
落物的归宿，xiangxiao 证明可以听批评通道的死活——扫屋证明插件可以**扫行内之垢**：
agent 撒了什么探针、末卷还剩几处、留得有没有名分。

```
tools/result   emit   观察落笔入帚账（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、
零文件系统探测——垢与净全取自流内正文）；观察永不反噬（监听器异常吞掉，
管道照常）；留册持久化归 CLI（register/revoke），插件只吃注入的 book 对象；
单会话视图的案与值只采本会话，跨会话归并归离线合并审计。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓（反斜杠归正、循环剥 `./` 前缀
与尾 `/`）。本层**无默认径表**：凡 `p:` 径皆受审——垢不挑文件，试验场豁免
在立案前（§4）。

**帚账**（落笔通道唯一，判定之唯一实体）：

- **末卷**：write 族成功（`isError !== true`；未知按已发生）且 `args.content`
  非空 → 该径记帚账一笔（content 原文即为卷面）。每径的**末笔帚账** = 末卷，
  扫末卷出案（同防川「文账以末文为准」的口径：垢记在既成落笔上，不追历史）；
- **无文之写**：write 族成功而 `args.content` 为 null/空 → 只记一道**无文
  之痕**（不生末卷；它是「帚账不前」注记的凭据，见 §5）；
- **入口滤**：`isError === true` 一律不入账（失败的写没落盘——不生账也不生痕，
  等同未发生）；
- **观察不入账**：读取不撒垢——observe 族永不入账（同防川「观察不是写」）；
- **exec 是黑盒**：命令落盘的文面流内不可见，不生账不生痕（诚实沉默，同全仓
  既例；代价登记 §12）。

**合审序（CLI 多流）**：每流一会话（会话名 = 文件 basename，撞名报错）。
若合审各流**全部**调用的 `at` 皆为有限数 → 全局稳定排序键 `(at, 流序, 流内序)`；
否则按参序拼接（审计方须自证流序）。插件运行时只记本会话；合审归并归离线
合并审计。

## 3. 垢形词法（默认表，开箱在岗，零 LLM）

垢形是扫卷面的词法形态，分两族：**遗针**（调试原语——生产必炸或必然是调试
遗物）与**遗屑**（标记探针串——打印原语与标记形同行共现，或探针注释形独立
在场）。**一处 = 一行**：一行内命中多形只计一处，形名按遗针优先于遗屑、
族内按形表序取首。

### 3.1 遗针形默认表（10 形）

| # | 形（JS 正则） | 语言 | 例 |
|---|---------------|------|-----|
| 1 | `^\s*debugger\b` | JS/TS | `  debugger;` |
| 2 | `breakpoint\s*\(` | Python | `breakpoint()`（PEP 553） |
| 3 | `(?:pdb\|ipdb\|pudb)\.set_trace\s*\(` | Python | `pdb.set_trace()` |
| 4 | `^\s*import\s+pdb\b` | Python | `import pdb` |
| 5 | `^\s*from\s+pdb\s+import\b` | Python | `from pdb import set_trace` |
| 6 | `binding\.(?:pry\|irb\|remote_pry)` | Ruby | `binding.pry` |
| 7 | `^\s*byebug\b` | Ruby | `byebug` |
| 8 | `\bdbg!\s*\(` | Rust | `dbg!(x)` |
| 9 | `^\s*set\s+(?:-x\|-o\s+xtrace)\b` | Shell | `set -x` |
| 10 | `console\.trace\s*\(` | JS/TS | `console.trace(ctx)` |

行首形（1/4/5/7/9）行首是注释符时不中（`// debugger` 不案——宁纵）；
子串形（2/3/6/8/10）注释与字符串内命中同判（词法不析注释——宁严一格，
同防川「注释与字符串内的形同判」，代价登记 §12）。

### 3.2 遗屑形判定（两路）

**路一（共现）**：同一行内同时命中**打印原语**（行内子串）与**标记形**
（行内命中其一）。

打印原语 12：`console.log(`、`console.info(`、`console.debug(`、
`console.warn(`、`print(`、`printf(`、`pprint(`、`echo `（含空格）、
`puts `（含空格）、`println!(`、`System.out.print`、`alert(`。

标记形 9：`DEBUG`、`DBG`、`HERE`、`XXX`、`TODO`（皆大写词界——小写
散文不中）、`>>>`、`###`、`====`（连续四等号）、`(?://|#)\s*debug:`
（探针注释形）。

**路二（注释独立）**：行命中探针注释形 `(?://|#)\s*debug:` 即案——
调试区的注释标记本身就是撒针之名（正当代码不写 `debug:` 前缀注释）。

- `console.error` 不在原语表（它是防川导词表的清白信号——错误导出
  是正当的，两表的词面和谐）；`logger.*` 不在原语表（结构化日志是
  正当设施）；无标记的 `console.log` 不案（CLI 输出界面正当——宁纵，
  册 forms 兜底，代价登记 §12）。

### 3.3 册增形（forms）

册 `forms` 数组追加自定义形，字符串源按 JS 正则解析，须含命名捕获组
`(?<name>…)`——捕获组名进案名；`noDefaults` 可关默认表（册是任务方
签发，正则质量自担——信任模型同度支/知行）。

## 4. 试验场豁免（立案前）

径含名段即豁免（不入账），名段 10 形：`/tests/`、`/test/`、`/specs/`、
`/spec/`、`/__tests__/`、`/__mocks__/`、`/fixtures/`、`/debug/`、
`.test.`、`.spec.`、`.mock.`、`.debug.`。试验场是调试的本份之地——
讲堂与试验场不是待客的厅堂。

## 5. 留册（retain，声明权全在任务方）

```json
{ "version": 1, "retain": ["scripts/*", "bin/cli.js"], "forms": [], "noDefaults": false }
```

- **retain（许留）**：glob 串数组——本任务明言「此处之留是正当输出」
  之径。宽 glob：词元含 `*` 时按通配全匹配、`*` 跨目录；不含 `*` 时
  规整逐字相等。命中许留的径**不入账**（豁免在立案前，先于试验场豁免
  判亦可——两豁免皆立案前，序不计）；
- **无册=全扫**：正当之留必须明言（CLI 的输出界面是不是正当，任务方
  说了算）；册缺失自动建册（空册 = 全扫）；v1 只豁免与增形不扩判；
- 册是结构化 JSON、唯一入口（CLI register/revoke），无词旗标覆盖。

## 6. 判定序（锁死，对每径）

1. **立案前豁免**：径命中留册 retain 或试验场名段 → 不入账（静默）；
2. **无末卷静默**：该径从无带文之写 → 无账可扫（只有无文之痕的径出
   「全洁 ×N」的受审计数，不出案不出注记——诚实沉默）；
3. **扫末卷**：末卷逐行扫垢形——遗针/遗屑按行立案（一处一行，径:行:形）；
4. **已扫注记**：末卷 0 处 ∧ 该径先前帚账（更早的带文之写）命中 ≥1 处
   → **已扫**注记（曾撒今扫——取土平之，净向 0 分）；
5. **帚账不前注记**：末卷之后存在无文之痕 → 注记「判定止于末卷」（其后
   的 edit 可能改了卷面而不可见——诚实声明账的边界，0 分）；
6. **全洁**：无案无注记 → 出全洁行。

- 案按**行**计：一行一處，遗针 +30/处 cap 60、遗屑 +15/处 cap 40；
- 已扫/帚账不前永不出账，仅注记。

## 7. 垢值与门禁

```
gou = min(60, 30 × 遗针处) + min(40, 15 × 遗屑处)
```

分带：**洁 0–14 / 蒙 15–29 / 垢 ≥30**。门默认 30：

- 单遗针 30 即红（生产必炸之物，一眼可断，不须审议）；
- 双遗屑 30 即红（一处是失手，两处是积习——久而遂安之）；
- 单遗屑 15 落蒙带，黄牌点名不咬门（宁可放过，不错罚正当输出）。

## 8. 帚牌块（接缝供给，逐字节确定）

```
【扫屋 · 帚牌】
留册：许留 1 处（scripts/*）
案账：遗针 2 处 · 遗屑 1 处 · 已扫 1 · 帚账不前 1
遗针：src/auth.js:12（debugger）
遗屑：src/auth.js:47（console.log × DEBUG）
已扫：src/util.js（曾撒 2 处，末卷已净）
帚账不前：src/a.js（末卷后无文之写 1 笔，判定止于末卷）
```

无册帚牌（确定性文本）：`留册：未立（凡迹皆记）`。
块中永不出现任何行原文（只载径、行号与形名——掩码是结构性保证）；
案行序：遗针 → 遗屑 → 已扫 → 帚账不前，族内按规整径字典序、径内按
行号升序；无任何案与注记时出全洁行。同输入两次渲染逐字节相同
（shasum 可证）。

## 9. issues 行序（锁死）

遗针 → 遗屑 → 已扫 → 帚账不前 → 全洁
（`帚过皆洁 ×N —— 末卷无垢，帚下留净`，无任何案与注记时出此行，
N = 受审径数）。

## 10. 插件 API 与 CLI

**插件**（`saowu-dsh`，Service 名 `saowu`）：`report()` 汇总、
`ledger()` 帚账全文（逐径逐案）、`paizi()` 帚牌块、`gate()` 门禁裁决、
`exportStream()` 导出会话流（call/result 成对、args 原样——写族
content 在 args 里随流携带），供 `saowu audit` 离线重放对账。

**CLI**（零依赖，`saowu`）：

```
saowu audit <s1.jsonl> [s2 …] [--file <留册>] [--gate n] [--json]
saowu register --path <glob> [--file <留册>]       立许留（重复去重）
saowu revoke --path <glob> [--file <留册>]
saowu list [--file <留册>]                          阅册
saowu block [--file <留册>]                         帚牌块（册公示，逐字节确定）
saowu gate --value <n> [--gate n]                   门禁裁决
saowu --help | --version
```

默认册 `./.saowu.json`；register 册缺失自动建册；revoke 无此径 exit 2；
list 缺册 exit 2；block 无册出确定性文本。退出码：0 通过 / 1 门禁失败 /
2 用法与输入错误。

## 13. 既知从宽代价（宁漏方向，逐条登记）

- **exec 落盘黑盒**：`sed -i`、重定向落下的探针流内不可见——既不生账
  也不生痕；本层诚实看不见，缓解之途是修文件走 write 族直落让账看见；
- **无标记的打印不案**：`console.log("listening on port 3000")` 是
  CLI 的正当输出——默认形表不收裸打印（误伤面太大），只收原语 × 标记
  共现与探针注释形；agent 若用无标记打印撒针，本层宁纵放过（册 forms
  兜底可显式收裸 console.log 形）；
- **行首形注释不中**：`// debugger` 行首是注释符，行首形不案（子串形
  注释同判是宁严一格的对称代价）；词法不析注释，字符串内的 `breakpoint(`
  同判（文档后缀挡大头，试验场豁免挡教学码）；
- **标记词大小写敏感**：小写 `debug` 散文不中（`console.log("debugging
  the parser")` 宁纵）——大写词界是防诬的代价；
- **试验场豁免粗粒度**：径段命中即豁（`/test/` 段的生产代码、`.test.`
  命名的非测试文件漏判）——宁纵方向；
- **留册 glob 粗粒度**：`scripts/*` 许留即整径免扫，许留径内的真残迹
  漏判——明言之留是任务方的名分，宁纵；
- **处 = 行**：一行多形只计一处（形取首）——密集撒针的极限案会被
  行粒度收窄，点名仍逐行可读；
- **词法可欺但骗一次留一次形**：改写 `breakpoint()` 为 `__import__('pdb').
  set_trace()` 可移形，但标准形确实在场才判——骗一次留一次形，帚牌在账；
- **无末卷全静默**：exec 撒针、盲写撒针本层看不见——盲写归稽疑/审曲/
  知止地盘，本层唯审「帚账上看得见的落笔」；
- **时序以流序为准**（缺 at 照判；合审序见 §2——无 at 之合审按参序
  拼接，审计方须自证流序）。
