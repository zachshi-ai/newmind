# 02 · 问题：Agent 调试残迹留场（行内之垢无账）

## 谁在什么场景下的什么问题

**谁**：用 agent 排障/调试的工程师，以及所有 downstream 的「宾客」——
生产环境的进程与浏览器、日志归档、下一个读码的会话。

**场景**：agent 接到「修复鉴权偶发失败」，第 4 步在 `src/auth.js` 撒下
三处探针（`console.log("DEBUG: token =", token)`、`debugger;`、
`console.log("HERE 1")`），第 17 步在 `scripts/dev.sh` 里加 `set -x`，
问题修好，测试绿了，任务宣告完成——**探针全数留场**。`debugger;` 跟着
发布落进生产前端，用户浏览器当场挂死；`console.log` 把内部中间态写进
生产日志，成为信息泄漏面与日志污染；下一个会话读码，对着一行
`console.log("HERE 1")` 分不清「这行是功能还是调试」——**残迹在卷，
宾客自见，而「当时撒没撒、末卷还剩没剩」在会话流里没有任何一层记账**。

**问题**：调试残迹的**垢**（撒了什么、末卷还剩什么、留得有没有名分）无账：

- **残迹是既成的落笔事实**：每一处探针都是一次完全合法的写入，测试照跑、
  diff 照交，绿的信号一个不少——脏的不是功能，是卷面；
- **收拾没有环节**：agent 没有保洁步骤，「修完即走」是常态；lint 造了
  扫帚（ESLint `no-console`/`no-debugger`、RuboCop `Lint/Debugger`、
  pre-commit 官方 **debug-statements** hook——每个主流工具链都有对应
  执法，是业界对此病的结构性招供），但规则可以被静音（那是乡校的地盘）、
  lint 可以不在器册（那是法仪的地盘）、调试常常发生在 lint 根本没跑的
  时刻——扫帚在场，屋子照样脏；
- **代价在生产侧兑现**：`debugger;` 与 `breakpoint()`（PEP 553）是
  事故级的残迹（挂死浏览器/阻塞进程），带 DEBUG 标记的打印是泄漏面与
  噪音——「一行 print 而已」的轻慢，正是「安事一室乎」；
- **相邻层的空白地**：fangchuan 扫**吞错形**（湮形=catch 空体——报错
  被删），打印探针不是湮形，它的导词表甚至把 `console.*` 记为**清白
  信号**（错误被导出）——打印侧全数让渡；xiangxiao 审**静音指令**
  （@ts-ignore/eslint-disable——写「闭嘴」），探针是写「放声」，两表
  零交集；shefa 审**筏形**（径级：`scratch/`、`.bak` 整个文件），正式
  代码里的行内探针径不命中筏形；zhizu 量**写之量**，一行 `debugger;`
  在行数与写域上不可见；zhixing 审**章程被无视**（必行令没跑），码面
  有没有 debug 原语不是行为对章程；fayi 审**尺被改**，垢在尺外；kaocheng
  考**契上物**，契约没写「无调试残迹」条款就放行——「行内之垢」是全仓
  空白。

## 问题（治什么病）

两族群，全部真实存在、全部有据可查：

| 病形 | 流内词面 | 现实对应 |
|------|----------|----------|
| **遗针**（重案） | 末卷含调试原语形：`debugger` 裸词元、`breakpoint(`、`pdb/ipdb/pudb.set_trace(`、`import pdb`、`binding.pry/irb/remote_pry`、`byebug`、`dbg!(`、`set -x`/`set -o xtrace`、`console.trace(` | 调试原语留场——生产必炸或必然是调试遗物（debug-statements 类 hook 专查的对象） |
| **遗屑**（轻案） | 末卷存在一行同时含**打印原语**（console.log/info/debug/warn、print、printf、pprint、echo、puts、println!、System.out.print、alert）与**标记形**（DEBUG/DBG/HERE/XXX/TODO 大写词界、`>>>`、`###`、`====`、`// debug:` 探针注释形） | 标记探针串：`console.log("DEBUG: …")`、`echo "==== stage 1"`——撒探针的标志形 |
| **已扫**（注记档） | 该径先前带文之写命中垢形，末卷不命中 | 先撒后扫——取土平之，净向 0 分注记 |
| **帚账不前**（注记档） | 末卷之后有无文之写（edit 族不携全文） | 其间残迹可能已变而不可见——诚实沉默 |
| **无末卷**（静默） | 该径从无带文之写（exec 落盘黑盒、盲写无据） | 帚不入黑盒——宁漏勿诬 |

价值锚点：垢形是显式词法（针形默认表 ∪ 原语×标记共现，零 LLM）；
「在场」的凭据是流内的带文之写（落盘事实，不是「可能有害」的推断）；
「正当之留」的凭据是留册的 glob 明言——三件事全是流内与册面可证的
确定性事实。本层不做语义判断（不判这个 print 是不是故意的——CLI 输出
界面是正当的，裁决权归人：留册明言即免案），只做词法可证的三问：
**末卷还剩几处针、几处屑、有没有一处在册**。

## 价值（为什么不是伪需求）

1. **每一处都真实落在仓库里**：探针是既成的 diff 事实，`debugger;` 与
   `breakpoint()` 的生产代价有 PEP 553 与各工具链 debug 检查的官方文档
   为证——不是「可能有害」的推断；
2. **意图可豁免而残迹须留痕**：CLI 的 console.log 是输出界面、dev 脚本
   的 set -x 是正当开关——留册明言即免案；agent 也可以自证其净（先撒
   后扫即已扫免分）；无册之案也不是罪，是**账**：留痕有价、点名有责、
   门禁有阈；
3. **记账不禁行**（扫屋不管盖房）：不拦写（拦是 zhizhi 的地盘）、不改
   内容、不跑 lint——判定全部发生在流内词面上，观察永不反噬；撒针可以
   发生，但每一处都要在账上见——「一室之治」的透明，由账本供给；
4. **可证伪**：垢形词法、末卷口径、分数公式全部锁死于 03；同流重放必得
   同判词；跨项目历史流可验尸复算——错了改实现，不改标准。

## 产品形态

- **巡扫式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：挂
  `tools/result` 观察口，帚账入账，帚牌块接缝供给；
- **零依赖审计 CLI**（`saowu`）：多流离线合审，可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的留册/已扫协议。
