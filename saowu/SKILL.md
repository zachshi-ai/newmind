# 扫屋 · Saowu — Agent 协作协议

> **「一室之不治，何以天下家国为？」——清·刘蓉《习惯说》**
> **「大丈夫处世，当埽除天下，安事一室乎！」——《后汉书·陈蕃传》**
>
> 修 bug 时撒下的每一根探针——`console.log("DEBUG: …")`、`debugger;`、
> `breakpoint()`——都是你落在交付卷面上的垢。本协议不限制你调试（拦是
> 知止的地盘），它要求：交付前把屋子扫干净——要么末卷无垢，要么任务方
> 的留册明言此处之留是正当输出，要么先撒后扫（已扫免分）。留场的每一处
> 残迹，都在帚牌上点名。

## 何时用此 Skill

- 工程师想防住「agent 排障撒探针忘收，`debugger` 跟着发布上了生产」；
- 发版前想审「交付卷面还剩几处调试残迹、有没有名分」；
- CI 需要一道码面卫生门禁（垢值 ≥ 30 即红——单针即红、双屑即红）；
- Agent 需要自查：这一单我撒了几根针、末卷还剩几处、留得有没有名分？

## 给派活的工程师

```bash
cd your-repo
saowu register --path "scripts/*"                 # CLI 的输出界面、dev 脚本，先立许留
saowu audit session.jsonl --file .saowu.json      # 收工扫垢（exit 码可进 CI）
saowu audit s1.jsonl s2.jsonl --json              # 多会话合审
saowu block --file .saowu.json                    # 帚牌块：留册与案账公示
```

- **无册全扫**：不立册也审——正当之留必须明言，裁定权在任务方不在 agent；
- **许留是授权**：任务本身就是写 CLI/dev 脚本（打印即功能），开工时把径
  列进留册；
- **门禁**：垢值 ≥ 30 即红——调试原语单处即红（生产必炸之物，一眼可断），
  标记探针串两处即红（一处是失手，两处是积习）。

## 给 Agent 的五条纪律

1. **修完即扫，不留探针过夜**：交付前把调试原语（`debugger;`、
   `breakpoint()`、`binding.pry`、`set -x`）全部清出交付径——它们不是
   「难看」，是生产挂死与日志污染；
2. **撒针当有声**：临时打印要带标记（`DEBUG`/`HERE` 之类）并随手收——
   带标记的打印是遗屑案，无标记的正当输出（CLI 界面）不案；把调试打印
   伪装成正常输出，骗得过词法骗不过帚牌（骗一次留一次形）；
3. **正当之留要有名分**：你的任务真是写 CLI 输出界面？让任务方把径列进
   留册——留册明言之留免案，无册之留记账；
4. **先撒后扫即是白**：同一径先撒探针后收拾，已扫注记 0 分——本协议
   结构性地奖励「收拾」这个动作；
5. **关键文件用带全文之写**：edit 族不携全文，末卷之后的变化帚账看不见
   （帚账不前注记）——修文件的最后一笔走带全文之写，让账认得你的卷面。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 遗针 | 末卷含调试原语形（针形 10：debugger/breakpoint(/set_trace/import pdb/binding/byebug/dbg!/set -x/console.trace 等） | 生产必炸或必脏之物留场 | +30/处 cap60（单针即红） |
| 遗屑 | 打印原语 12 × 标记形 9 同行共现，或探针注释形 `// debug:` 独立在场 | 标记探针串留场 | +15/处 cap40（双屑即红） |
| 已扫 | 先前帚账命中而末卷净 | 取土平之 | 0（注记） |
| 帚账不前 | 末卷之后有无文之写 | 判定止于末卷 | 0（注记） |
| 无末卷 | 该径从无带文之写 | 帚不入黑盒 | 0（静默——盲写/exec 归他层） |

- 垢值 = min(60, 30 × 遗针) + min(40, 15 × 遗屑)；分带 洁 0–14 / 蒙 15–29 /
  垢 ≥30，门 30；
- **试验场豁免**：tests/spec/fixtures/mocks/debug 名段之径在立案前豁免
  （调试的本份之地）；
- **帚牌块**：留册公示 + 案账清点 + 逐处点名（径:行:形），永不携带行原文，
  同输入两次渲染逐字节相同。

## 与相邻层的边界

- **防川**（一删一留）：它审报错之口被堵（catch 空体），本层审调试之声
  留场（探针打印）——`catch (e) { console.log("DEBUG", e) }` 在它账上
  清白、在本层是遗屑案，两账并记；
- **舍筏**（一筏一针）：它审文件级筏形（`scratch/`、`.bak` 整个文件），
  本层审行内垢形（正式代码里的一行探针）；
- **乡校**（一压一撒）：它审批评通道被静音（@ts-ignore），本层审调试
  通道在撒声（console.log）——两默认形表零交集。
