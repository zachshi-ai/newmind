# 知行 · Zhixing — Agent 协作协议

> **「未有知而不行者。知而不行，只是未知。一念发动处，便即是行了。」——《传习录》**
>
> 本协议不限制你怎么干活（拦是知止的地盘），它要求：读进上下文的章程，
> 行为必须对着它结账——戒了的不做、令了的不落，都会被对账点名；
> 「读过」不是知的凭证，「行合」才是（知是行之始，行是知之成）。

## 何时用此 Skill

- 仓库有 AGENTS.md / CLAUDE.md 一类章程，想知道 agent 这一单活有没有照着做；
- CI 需要一道「知行合一」门禁（行值 ≥ 30 即红——单违知即红）；
- Agent 需要自查：装载过的章程，戒条条条守了没有、必行令件件跑了没有。

## 给立章程的工程师

```bash
cd your-repo
zhixing rule --ban "git push --force"          # 亲命戒词（撞 exec/写径/写内容即违知）
zhixing rule --must "npm run lint" --must "npm run build"   # 亲命必行词（全流查无即缺行）
zhixing rule --exempt "--force dry-run"        # 宥词（显式豁免的行不计案）
# ……Agent 作业……
zhixing audit session.jsonl --file .zhixing.json   # 知行对账（exit 码可进 CI）
zhixing block --file .zhixing.json                 # 合牌块：凭册公示 + 知面清单
```

- **亲命直令不问知**：册上戒词/必行词不需要 agent 读过谁——登记之刻即是知入之刻；
- **章程自动生效**：AGENTS.md/CLAUDE.md 等默认知形文件，agent 成功读过即入知面，
  其中「禁止/不要/不得/never/must not」句式自动提取戒形（显式戒词更精确，推荐主道用亲命）；
- **门禁**：行值 ≥ 30 即红——单违知即红，单缺行黄牌点名不咬门。

## 给 Agent 的五条纪律

1. **读了就要照做**（「知而不行，只是未知」）：装载章程不是仪式——
   章程里每一条「禁止/不要」从装载之刻起就是你的行为义务，二十步之后也不许忘；
2. **必行令要落地**：章程写「先跑 lint 再交付」，全流查无这笔执行就是缺行——
   跑过哪怕失败都算行（成败另账），压根没跑才是罪；
3. **别指望失败掩护**：撞戒的失败执行不入行面但计试违注记——试违不罪，罪形可见；
4. **装载之前别抢跑**：装载前的行为不溯既往，但「开工没读章程」本身会被稽问层记账——
   先读章程再动手，两头都干净；
5. **被宥先立宥**：任务方临时授权的行为（如本次允许 force push），让它在册上
   （`--exempt`），否则对账只认词面。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 违知 | 行为撞化知戒形（装载后）或亲命戒词 | 知而不行——「只是未知」 | +30/案（单案即红，cap 60） |
| 缺行 | 必行词全流行面查无 | 令了不做 | +15/条（黄牌不咬默认门，cap 30） |
| 宥 | 撞中处原文含宥词 | 任务方显式豁免 | 0 |
| 试违 | isError 执行撞戒 | 失败之试宁纵（不入行面，罪形可见） | 0 |
| 先悖 | 行为时序不后于装载 | 装载前之行为不溯既往 | 0 |
| 降级 | 装载而流内无文 | 化知道诚实沉默，不凭空捏戒 | 0 |

分带：**合 0–14 / 亏 15–29 / 悔 ≥30 悖**；门默认 30。观察不是行：读取成功不豁免任何戒条；
失败之试非行：isError 执行不生违知；戒形只生自知面：章程没被装载就没有戒形可撞——
不知者无罪，但「没读」自有稽问层的账。
