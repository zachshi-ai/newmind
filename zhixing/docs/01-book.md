# 01 · 选书：《传习录》—— 知而不行，只是未知

## 原文

《传习录·上·徐爱录》记王阳明与弟子论知行：

> **未有知而不行者。知而不行，只是未知。**圣贤教人知行，正是要复那本体。

> **知是行之始，行是知之成。**若会得时，只说一个知，已自有行在；只说一个行，已自有知在。

《传习录·下·黄直录》再申：

> **一念发动处，便即是行了。**发动处有不善，就将这不善的念克倒了，须要彻根彻底。

世人把知行分作两件事：先讲论求知，后从容去行。王阳明说这是一场大患——
知与行本是同一件事的两面：真知必已发动为行，行了才算知之成。
**「知而不行，只是未知」把知的判据从「读过」挪到了「行过」：装载于心的规矩，
唯一可信的凭证是合乎规矩的行为；行为违了，知即未曾有。**

## 为什么是这本书

- 戒的不是「不知」，是「知而不行」。AI Agent 恰好是知行分立的工程实体：
  **上下文装载**与**行为执行**是两个解耦的模块——章程（AGENTS.md 一类治理文书）被成功读入
  上下文，与随后每一步工具调用是否合乎章程，中间没有任何机制对账。
  agent 读过「禁止 git push --force」，二十步之后照样 `git push --force`——
  知入了，行悖了，而账上只有「读过」的记录，没有「行合」的记录。
- 「一念发动处便即是行」给出知与行的绑定点：章程装载之刻，章程里的戒条已发动为行为义务。
  本层把这句话做成结构：**戒形只从已装载的章程文本中提取——戒形存在之处，知必已入；
  其后行为撞戒形，不是「没想起来」，是悖。**知面是戒形的唯一来源，违知案天然蕴含知入。
- 「知是行之始，行是知之成」给出与稽疑层的分工：稽疑（jiyi）审**首动之前问没问**
  ——那是行之始（求知）；知行层审**知入之后行合不合**——这是行之成（行据）。
  问了没读，稽疑记账；读了悖行，知行记账。一始一成，两不越界。
- 「知而不行，只是未知」给出判据的去处：行悖不是道德判断，是**知的账面改写**——
  违知案记下的每一笔，都是「那份章程其实没有被知」的证据，复审者由此知道
  该重读的是章程、该换的是装载方式，而不是徒劳地「再提醒一遍」。

## 逐条映射

| 《传习录》 | 知行层 |
|-----------|--------|
| 知而不行，只是未知 | 违知案：禁了却做——章程装载之后行为撞戒形，「读过」的知当场作废 |
| 知是行之始 | 稽疑的地盘：首动之前问没问（读没读章程，jiyi 审谋） |
| 行是知之成 | 知行的地盘：知入之后行合不合（行为对账章程，本层审行） |
| 一念发动处便即是行 | 知面绑定：章程成功装载之刻，其戒形即成行为义务——戒形内生自知面 |
| 圣贤教人知行，正是要复那本体 | 合牌块供给：接缝处逐字节公示戒形与必行词，让知行复其本体 |
| 发动处有不善，就将这不善的念克倒 | 行值门禁：违知单案即红（+30），复审者在CI就拦下，不必等恶果落地 |
| 知行分作两件事是世人大患 | 本层治的病：装载模块与执行模块解耦，中间无对账——分立的工程实体 |

一句话：**《传习录》说知而不行只是未知，知行层让章程的知以行为结账——
戒形只生自知面（装载之刻即义务发动），行为撞戒形即违知、必行词查无流即缺行，
行值三带过门禁——知是行之始，行是知之成。**
