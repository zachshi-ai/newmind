# 知行 · zhixing —— DeepSeek Harness 的知行断层层

> **「未有知而不行者。知而不行，只是未知。」——《传习录》**
>
> agent 读过「禁止 git push --force」，二十步之后照样 `git push --force`——
> 知入了（上下文里有装载记录），行悖了，而中间没有任何一层把这两件事对起来。
> 稽疑问读没读（行之始），知行问读了之后行合不合（行之成）。
> **知行不拦手（拦是知止的地盘），它让已装之知以行为结账：戒形只生自知面，
> 行为撞戒形即违知，必行词查无流即缺行。**

#29 · newmind 老思想 × 新智能实验室。知行式插件（DeepSeek Harness 插件层的第三十个能力类型）+ 零依赖对账 CLI + Agent Skill。

## 问题：知行断层（知而不行无处对）

章程（AGENTS.md 一类治理文书）被成功装载之刻，其戒条已发动为行为义务（一念发动处便即是行）；
但装载模块与执行模块是解耦的——

- **稽疑（jiyi）**审**首动之前问没问**——问凭据一成立即 0 分，此后行为与所问凭据矛盾它无案别可记；
- **恒法（hengfa）**审**立法之名分**——章程被**改**它记账，章程被**无视**（不改你，但不照你做）它无从看起；
- **知止（zhizhi）**拦**行为失控的形**——它拦的是失控，不审悖知；
- **考诚（kaocheng）**考**契上之物的末据**——契约考的是物，章程约束的是全程的行为；
- **终始（zhongshi）**记**事册之行程**——必行令没被立进事册时，缺行无处可记。

「已装载章程与实际行为的逐条对账」全仓无账，本层补的就是这个空档——
**知而不行，只是未知；装载于心的规矩，唯一可信的凭证是合乎规矩的行为。**

## 机制（全部确定性，零 LLM）

```
知面唯二：    observe 族成功装载 ∧ 凭据径命中（显式 rules ∪ 默认知形 8，noDefaults 可关）
知面取文于流：装载正文取流内 result.content——戒形只生自知面，戒形存在之处知必已入
戒形提取：    11 句式（中文 7 ∪ 英文 4）→ 戒体（至句读或 20 字符）→ 词元过停用词 41 → 戒词元取最长
行面唯三：    exec 族成功切段原文 ∪ write 族成功规整径 ∪ write content（化知戒形不咬 content）
判定序锁死：  宥 > 试违(isError 不入行面) > 先悖(at/流序时序，装载前不溯既往) > 违知(+30/案 cap60)
缺行：        必行词全流行面三处查无 +15/条 cap30（查有认 isError 执行——行了即不缺）
行值门禁：    行值 = min(60,30×违知) + min(30,15×缺行)；合 0–14 / 亏 15–29 / 悔 ≥30 悖；门 30
              ——单违知即红、单缺行黄牌点名不咬门
合牌供给：    凭册公示 + 知面清单（戒形与戒词原文，永不携带装载正文），逐字节确定
```

- **亲命直令不问知**：bans/musts/exempts 是任务方直令，登记之刻即是知入之刻，撞了就是悖；
- **知面取文于流**：全账内生，零文件系统探测——装载记录无 content 则化知道诚实降级（不凭空捏戒）；
- **三道清白**：试违不罪（失败之试宁纵）、先悖不溯（装载前行为不计，且归稽疑审谋）、宥词在册（显式豁免）；
- 结构性零拦截：插件无 pre-execute 监听器，观察永不反噬；零网络、零子进程、零文件系统探测。

## 快速开始（CLI）

```bash
cd your-repo
zhixing rule --ban "git push --force" --must "npm run lint"     # 立亲命（戒词/必行词/宥词/凭据径）
# ……Agent 作业……
zhixing audit session.jsonl --file .zhixing.json   # 知行对账（exit 码可进 CI；无册出默认册）
zhixing audit session.jsonl --file .zhixing.json --json
zhixing block --file .zhixing.json                 # 合牌块：凭册公示 + 知面清单
zhixing gate --value 30 --score 45                 # 门禁裁决（exit 1）
```

无 `--file` 出默认册：知形 8 在岗（AGENTS.md/CLAUDE.md 等 7 单名 + `.cursor/rules/` 前缀）、
亲命空——化知道开箱在岗，读过的章程自动生效。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 违知 | 行为撞化知戒形（装载后）或亲命戒词 | 知而不行——「只是未知」 | +30/案（单案即红，cap 60） |
| 缺行 | 必行词全流行面查无 | 令了不做 | +15/条（黄牌不咬默认门，cap 30） |
| 宥 | 撞中处原文含宥词 | 任务方显式豁免 | 0 |
| 试违 | isError 执行撞戒 | 失败之试宁纵（不入行面，罪形可见） | 0 |
| 先悖 | 行为时序不后于装载 | 装载前之行为不溯既往 | 0 |
| 降级 | 装载而流内无文 | 化知道诚实沉默，不凭空捏戒 | 0 |

分带：**合 0–14 / 亏 15–29 / 悔 ≥30 悖**；门默认 30。
边界：稽疑问始（读没读）、知行考成（行合不合）；恒法审改（法之名分）、知行审悖（法之行据）；
考诚考物（契对末据）、知行考行（程对章程）；一始一成、一改一行、一物一行。
