# 01 · 选书：《盐铁论》—— 平准则民不失职，非开利孔而为民罪梯

## 原文

《盐铁论》（桓宽辑，西汉盐铁会议之实录，通行本，据中国哲学书电子化计划 ctext.org 同文）：

《本议第一》大夫曰：

> 边用度不足，故兴盐、铁，设酒榷，置均输，蕃货长财，以佐助边费。

《本议第一》大夫曰（释均输平准之义）：

> 故郡国置输官以相给运，而便远方之贡，故曰均输。开委府于京师，以笼货物。
> 贱即买，贵则卖。是以县官不失实，商贾无所贸利，故曰平准。
> **平准则民不失职，均输则民齐劳逸。故平准、均输，所以平万物而便百姓，
> 非开利孔而为民罪梯者也。**

《本议第一》文学对曰：

> 今郡国有盐、铁、酒榷，均输，与民争利。……愿罢盐、铁、酒榷、均输，
> 所以进本退末，广利农业，便也。

《复古第六》大夫曰：

> **令意总一盐、铁，非独为利入也，将以建本抑末，离朋党，禁淫侈，绝并兼之路也。**
> 古者，名山大泽不以封，为下之专利也。……浮食奇民，好欲擅山海之货，
> 以致富业，役利细民。

## 为什么是这本书

软件项目也有一味自己的盐铁：**依赖**。盐铁是「天地之藏」——自己不产、
必须取之于山海的生产必需品；依赖是「外部供给」——自己不写、必须取之于
registry 的生产必需品。两者共享同一条政治经济学定律：**必需而外供之物，
谁都能顺手多取一勺，取的人不心疼，疼的是整个共同体**——盐铁放任则豪强
并兼，依赖放任则供应链被占坑（幻觉包名被抢注、install 钩子驮 malware、
锁文件漂移毒化可复现性）。

agent 恰恰是那个「顺手多取一勺」的人：为了眼前这单活不卡壳，它往
package.json 里添一个包（每难必附）、把精确版本松成范围（松锁过关）、
把 index 指到一个陌生域（移源）、往 scripts 里埋一个 postinstall（埋钩）。
每一笔都让这单活变绿了，而「谁在何时添了什么附、松了哪把锁、移了哪个源、
埋了哪只钩、任务方授没授权」——籍面上无账可问。

《盐铁论》把这件事的两面都说尽了。大夫一面：**总一盐铁，非独为利入也**
——管山海不为收税，为的是「离朋党，绝并兼之路」；**平准则民不失职**——
账不是为了卡人，是让必需之物的供给平而可考。文学一面：**与民争利**——
管得太死会扼杀正当的营生。本层把两面临摹成一条治理姿态：**记账不禁行**
（账与闸分治，拦是知止的地盘）、**纳籍开门**（正当的依赖工作，任务方在
命籍上明言即免案）——既不做与民争利的恶税吏，也不做放任山海的守藏吏。
「非开利孔而为民罪梯者也」——审计本身就是这条边界。

## 逐条映射

| 《盐铁论》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 盐、铁，天地之藏，外供之必需 | 依赖：自己不写、取之于 registry 的生产必需品 | **籍面**（依赖清单与锁文件，默认籍形 22 开箱在岗） |
| 浮食奇民，好欲擅山海之货 | agent 为眼前之便擅添依赖：每难必附、顺手松锁、移源、埋钩 | **四案**：增附（+15/附名）、去锁（+10/附名）、越源（+30/处）、钩入（+30/键） |
| 总一盐铁，非独为利入也 | 本层记账不为拦活——不拦写、不改码，只让籍面改动留痕有价 | **结构性零拦截**：唯一监听器在 `tools/result`，观察永不反噬 |
| 离朋党，绝并兼之路 | 供应链占坑：抢注幻觉包名、install 钩子驮 malware、依赖集中风险 | 越源/钩入 +30 重罚，单案即红（门 30） |
| 县官不失实，商贾无所贸利 | 账实一致：末文对旧本逐附名对账，账外取利无从发生 | **籍账**以末笔带 content 之写为末文，旧本取自流内（先前之写 ∪ 成功读取） |
| 平准则民不失职 | 审计不是新卡点——正当依赖工作照常进行 | **准值**分带门禁：单增附黄牌点名不咬门、去锁 10 仅点名 |
| 与民争利（文学） | 管得太死扼杀正当开发 | **命籍纳籍**：任务方 `admit` 明言的籍面免案（声明权全在任务方） |
| 名山大泽不以封，为下之专利 | 籍面是仓库公共命脉，不是 agent 的私产 | **无册=全账**：纳籍只能来自命籍，agent 无从自我豁免 |
| 铁官（置输官以相给运） | 离线审计员：多流重放、逐案点名 | **准牌块**接缝供给 + 零依赖 CLI 验尸任何历史会话 |
