# 平准 · Pingzhun — Agent 协作协议

> **「令意总一盐、铁，非独为利入也，将以建本抑末，离朋党，禁淫侈，绝并兼之路也。」**
> **「平准则民不失职……非开利孔而为民罪梯者也。」——《盐铁论》**
>
> 依赖是项目的盐铁：自己不写、取之于 registry 的生产必需品。本协议不限制你
> 干活（拦是知止的地盘），它要求：交付籍面上的命脉改动逐笔留痕有价——
> 添了附、松了锁、移了源、埋了钩，账上都要见得到；正当的依赖工作，
> 任务方在命籍上纳籍明言即免案。

## 何时用此 Skill

- 工程师想防住「agent 为解眼前之围顺手添包/松版本/改 registry/埋 postinstall」；
- CI 需要一道供应链门禁（准值 ≥ 30 即红——单源单钩即红、两附即红、单附黄牌）；
- Agent 需要自查：这单活我动没动籍面？动的在不在任务方纳籍之列？

## 给派活的工程师

```bash
cd your-repo
pingzhun register --path "third-party/*"            # 允许 agent 动的籍面，先立纳籍
pingzhun audit session.jsonl --file .pingzhun.json  # 收工审籍（exit 码可进 CI）
pingzhun block --file .pingzhun.json                # 准牌块：籍形与命籍公示
```

- **无册全账**：默认籍形 22 开箱在岗——不立册也审，册只管纳籍一侧；
- **纳籍是授权**：正当的依赖升级任务，开工时把允许动的籍面列进命籍；
- **门禁**：准值 ≥ 30 即红——单越源/单钩入即红、两增附即红、单增附黄牌不咬门。

## 给 Agent 的五条纪律

1. **每难必附之前，先谋现仓**：加依赖是扩一条永久供给线（幻名入籍则次次
   必装）——先查仓库既有的轮子，确要添附，向任务方讨纳籍；
2. **锁不许松**：`1.2.3` 改成 `^1.2.3` 过了这一单，毒的是之后每一单的
   可复现性——版本递进走精确对精确；
3. **源不许移**：`-i`/`--index-url`/`publishConfig.registry` 指向非默认域
   是供给线改道，单案即红——企业内网源要任务方纳籍明言；
4. **钩不许埋**：`postinstall` 是装包即执行的代码，新增一只钩就是一道
   后门——husky 之类的既有钩原样保留不判，新增必红；
5. **词法可欺但骗一次留一次形**：整文件重写覆盖不了账——本层对每笔带
   content 之写按当时旧本逐附名对账，改了什么，账上见得到。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 增附 | 旧本四节所无之附名（npm/composer 四节两节 + requirements 行级） | 供给线 +1 | +15/名（两附即红，单附黄牌） |
| 去锁 | 同附名精确 → 范围/脱钉 | 可复现性 −1 | +10/名（仅点名） |
| 越源 | 源词 × 非默认域（新增） | 供给线改道 | +30/处（单案即红） |
| 钩入 | scripts 新增 preinstall/install/postinstall/prepare | 装包即执行 | +30/键（单案即红） |
| 暗籍 | exec 落点命中籍面 | 文面经命令生成 | 0（注记） |
| 素籍 | 只有无 content 之写 | 老流诚实沉默 | 0（注记） |

- 准值 = min(60,30×越源)+min(60,30×钩入)+min(60,15×增附)+min(60,10×去锁)，total=min(100)；
- 分带 平 0–14 / 偏 15–29 / 倾 ≥30，门 30；
- 递案无底本不判（注记「籍无底本」）；删附是净向只注记；精确→精确递进不判；
- 全部判定零 LLM：四案是词法、纳籍是 glob——词法可欺但骗一次留一次形。
