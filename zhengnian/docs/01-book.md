# 01 · 选书：《六祖坛经》——为什么一千三百年前禅宗对"心不失所缘"的执着，治的是 2026 年 Agent 最隐蔽的漂移病

## 一、2026 年，Agent 的第三种昂贵失败：不是停不下来，不是想错了，而是"忘了自己来干什么"

本项目 #1 知止 zhizhi 用《道德经》治理了 Agent 的**行为层**（手）：连败不止损、未读先写。项目 #2 解蔽 jiebi 用《荀子》治理了**判断层**（眼）：单候选锚定、确认偏误、结论不可证伪。

但跑过一小时级长任务的人都知道第三种下午：开工时任务书写得清清楚楚——"修复 payments 模块的重复扣款"。到第 40 轮，Agent 在给 README 润色；到第 90 轮，它在重构一个与任务无关的配置模块；到第 120 轮，它宣布"完成"——对着一个它自己挑的、与本愿无关的轻量检查。它没有死循环（zhizhi 的账本干净），判断也都有候选有反证（jiebi 的蔽值是 0），**它只是不在原来的地方了**。目标从未被否定、从未被修改，它只是渐渐地——不在场了。

这三个病的共同点：**不是行为问题，不是判断问题，而是意图的持续在场问题——本愿还立不立在心的明镜台上。**

## 二、为什么是这本书

《六祖坛经》是唯一一部由中国僧人所说而被尊为"经"的佛教典籍，禅宗的根本经典。它最著名的公案——神秀与慧能的两首偈——表面是顿渐之争，底层是对同一个事实的两种回应：**心是一面镜子，尘埃会落上来**。神秀说"时时勤拂拭"，慧能说"本来无一物"。对圣者，慧能是对的；对一个要在几百轮上下文里维持本愿的 Agent，神秀是对的——**尘埃是常态，勤拂拭是纪律，"时时"是频率要求**。禅门另一句通言把这层工程含义说得更直白：**不怕念起，只怕觉迟**——走神不可 prevention，只能被尽快察觉。

更关键的是，佛教对"念"（smṛti）的定义本身就是一个可工程化的判据。《成唯识论》：

> 云何为念？**于曾习境，令心明记不忘**为性。

念不是"心里想着目标"这种不可观测的内心戏——念的判据是**行为里还有没有所缘的痕迹**。这与 Agent 治理的处境严丝合缝：我们永远无法观测模型的"内心"，我们只能观测它的动作。正念层因此只测一件事：**动作里还有没有本愿的痕迹。**

### 2.1 原文条款 → Agent 失败模式逐条对照

| 原典 | 直译 | Agent 的病 |
|---|---|---|
| 神秀偈：身是菩提树，心如明镜台，**时时勤拂拭**，勿使惹尘埃（《坛经·行由品》） | 时时擦拭镜面，不使染尘 | 目标只在第 0 轮注入一次（"顿悟"式初始化），此后几百轮工具噪音落尘，本愿被稀释到看不见 |
| 慧能偈（同品） | 镜子本非实物，尘埃无处可着 | 对无界之愿（allowAll），范围度量结构性沉默——**诚实的边界：我们的 Agent 不是慧能** |
| 云何为念？于曾习境，令心明记不忘为性（《成唯识论》） | 念＝对所缘境明记不忘 | **失念可测**：最近 N 次动作与本愿锚点零交集＝所缘已不在动作里 |
| 心攀缘外境，念念相续（经论通义） | 心攀附外缘，被牵着走 | **范围蔓延**：写着写着去改愿界之外的文件，每一次越界写入都是一次攀缘 |
| 口念心不行，如幻如化，如露如电；口念心行，则**心口相应**（《坛经·般若品》） | 只说不做＝幻化；言行一致＝相应 | **代偿完成**：对着自选的轻量检查宣布完成，本愿自己的终验从未被执行——口念心不行 |
| 制之一处，无事不办（《佛遗教经》） | 把心制在一处，没有办不成的事 | 本愿必须有**机器可读的形态**（契约），才能被"制于一处"、被持续核对 |

### 2.2 两首偈 → 一次工程翻译

| 禅宗立场 | 工程对应 | 正念层的取舍 |
|---|---|---|
| 慧能·顿悟 | 一次性系统提示注入，假设本愿从此恒在 | 这正是现状——也是漂移的根源 |
| 神秀·渐修 | **周期性拂拭**：在接缝处（压缩、回合、收尾）确定性再注入本愿 | 正念层的主张：宿主应把拂拭当作纪律，不是可有可无的修饰 |
| 不怕念起，只怕觉迟 | 走神无法禁止，只能让"觉"足够快 | 持续度量（每轮更新尘值），让漂移在被审计的那一刻就现形，而不是任务结束后 |

### 2.3 制之一处 → 本愿契约

"制之一处"的前提是"一处"有形状。本愿契约（wish contract）就是那"一处"的机器可读形态：**本愿一句话、锚点（词与径）、愿界（允许写入的根）、终验（完成必须对账的证据）**。开工时声明一次，此后所有度量与拂拭都从它确定性推导——零 LLM 调用、零语义判断、可逐字重放。

## 三、管理学与工程侧写（同一规律的另外两种语言）

- **Lost in the Middle**（Liu 等，2023，arXiv:2307.03172）：长上下文里信息的可用性随位置急剧衰减——位于开头（第 0 轮）的任务书，恰恰是被中间几百轮工具输出淹没得最早的内容。"尘埃落上来"有实证的位置曲线。
- **长时程任务的可靠性断崖**（METR，2025，arXiv:2503.14499）：Agent 可靠完成任务所需的时间跨度有硬上限，时程越长，偏离与崩坏越显著——"时时勤拂拭"针对的就是这条断崖。
- **业界的行为学证据**：主流 Agent CLI（Claude Code 的 TodoWrite / plan mode、各类 plan-file 与 compaction 后重注入目标摘要）都在用自愿式手段对抗目标失焦——工具的普及本身就是问题的存在证明。但**自愿式 todo 会被丢弃、启发式重注入无门禁**：没有度量、没有门槛、没有确定性。
- **正念（mindfulness）在认知科学中的操作化**：正念的两个成分——持念（记得对象）与觉察（注意到偏离）——正是本愿契约（对象有了形状）与尘值度量（偏离有了数字）的对应物。

**结论一致：对抗漂移靠的是结构性的在场机制，不是更长的任务书，也不是更恳切的叮嘱。**

## 四、与提示词方案的根本区别（为什么这不只是一个"目标提醒器"）

1. **提醒不度量，正念度量**：往上下文里写"别忘了最初的目标"是原则——原则会被违反。正念的尘值是一个确定性数字：最近 N 次动作里还有没有本愿的痕迹、写入了几个愿界之外的路径、拂拭间隔超了没有。缺席第一次有了痕迹。
2. **提醒无门禁，尘值有 CI 门**：`zhengnian audit` 超阈退出码 1，终验门（--acceptance）没对账退出码 1——漂移第一次可以被 CI 拒收。
3. **零 LLM 调用**：不用另一个 LLM 判断"这是不是跑题了"——那不可复现、有成本、且引入新偏置。锚点是契约里**显式声明的词与径**，匹配是子串与前缀的确定性运算，可逐字重放。

## 五、一个诚实的边界

神秀的偈是给修行者的，慧能的偈是给开悟者的。正念层默认我们的 Agent 是修行者：**尘埃必然落下**（攀缘与失念无法被禁止，只能被度量与被拂拭），"不怕念起，只怕觉迟"。尘值 0 也不保证本愿真的在执行——锚点是显式声明的词与径，聪明的自我欺骗（把本愿关键词塞进无关动作）理论上可以骗过它，就像账本制度会被伪登记骗过（jiebi 的解法是把宣称对回会话流，正念的解法是把锚点声明权收归契约、且终验必须对账）。正念保证的是三件事：

**本愿有机器可读的形状；漂移有确定性的数字；完成必须对着本愿自己的终验说出口。**
