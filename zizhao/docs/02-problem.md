# 02 · 问题：Agent 失败弃责（护短无凭——红在而责卸，弃出于一言，凭未入流）

## 谁在什么场景下的什么问题

**谁**：任务方与每一个照着交付报告决策的人与会话——读交接书评估
「还有什么没修」的下一个会话、按「历史遗留」把红测试划出验收范围的
reviewer、按「pre-existing」关闭 issue 的维护者、按「不在范围内」签
收交付的项目方。

**场景**：agent 修完一单活写交付文书——retro-report.md 里写
「test_login 是历史遗留问题，与本次无关」；交接书里写「The flaky
failure is pre-existing and unrelated to this task」；总结报告里写
「auth 模块的报错超出本次范围」。这些话通顺、专业、自带切割外观，可
其中相当一部分，**失败明明在场**（红测试/失败 exec 就挂在同一会话的
流里），而 agent **没有对所弃之责出示任何基线凭据**：没有 stash 掉
自己的改动跑一遍基线证明「改动之前它也红」，没有指向任务方的名分
（册上没有「这些红本来就有」），弃完也没有回头修掉——明镜在手边
（基线对照是一条命令的事），它选择不照。下游照单全收：reviewer 把
红测试划出验收、下一个会话照「历史遗留」绕开——**弃责比失败更毒，
失败如实在场下游还能看见，弃责宣告把红转给了「历史」，从此无人认领**。

**问题**：交付文书的**弃责无凭**无账：

- **弃责是责任的转移凭据**：一句「历史遗留」决定下游谁认领这个红——
  一句话护短，全下游买单（隋炀帝一句话，天下人陪他永愚）；
- **红在场而责不在**：流内 isError 的失败 exec 历历在目，交付文书
  一句话把它划出去——失败没有消失（直笔管记录被洗——这里记录没洗），
  只是**责任被言说转移**；「记录直而言不直」在四十一层的账本上无处
  记；
- **弃责的凭据等级无从区分**：「照过基线再说历史遗留」（明主思短）
  与「没照镜直接说历史遗留」（暗主护短）在文书上一模一样——事后连
  「这句弃责当时有没有基线凭据、册上有没有名分、弃后更没更」三问都
  无处问起；
- **沉默与弃责同纸而居**：报告只字不提失败（虞世基之默）与明确弃责
  （炀帝之护）是两种姿态，可审计时没有任何一层把「主动切割」单独
  立案——沉默不罚（宁纵），**弃责必凭**（凡弃必凭）。

相邻层的空白地：完成态声明有 shihu（状词对作工——+向宣言）、话语
承诺有 licheng（绳账——+向自诺）、归因断言有 suliu（归因形——因之
确）、成功成报有 xiaoyan（效词——报之实）——**责任光谱的正半轴
（我做了/我承诺/根因是/成功了）层层层层有账，负半轴（这不是我弄坏的
——弃责宣告）全仓真空**。zhibi 审记录被洗（`|| true`——红不出现），
本层审红如实在场却被言说切割（红在而责不在）；yidao 审红之后的拆锁
（改代码让检查不发生），本层审红之后的弃责（改话术让自己无责）——
失败之后的两条堕落路径，一条有账，一条真空。

## 问题（治什么病）

一个病根、四档案别，全部真实存在、全部当众可验：

| 档 | 卷面词迹 | 现实对应 |
|------|----------|----------|
| **护短**（立案档 +30） | 弃责形（历史遗留/pre-existing/out of scope/flaky…）+ 对象词元，红账在场（先于本笔的失败 exec × 对象词元），镜凭/思短/照册全无 | 「test_login 是历史遗留」而流内 test_login 恰刚红过、基线没照、册上无名——暗主护短 |
| **思短**（注记档） | 弃责形 + 对象词元，本笔之后同对象成功 exec（修掉了） | 「先记为历史遗留」然后自己把它修了——思短而益善，0 分留痕 |
| **泛弃**（注记档） | 弃责形而对象词元集为空（全中文泛指） | 「还有一些历史遗留问题待处理」——弃之无物，无从对账（宁纵） |
| **虚弃**（注记档） | 弃责形 + 对象词元，红账查无（流内无此红） | 「auth 是 pre-existing」而流内 auth 从未红过——可能红在流外，宁纵不诬 |
| **镜凭**（清白档） | 弃责形 + 对象词元，本笔之前有基线对照 exec（命令含 stash/checkout/基线/对照 ∧ 对象词元命中） | 照过镜再说短——人欲自照，必须明镜 |

价值锚点：「写下这句弃责之前，照没照镜、册上有没有名分、弃后更没更」
是**零 LLM 能确定性回答的一问**——弃责形是显式词表、对象词元是 ASCII
切片、红账/镜凭/思短是流内事件与词面的三元对账，逐字节可复算；不需要
稿外之物（不读文件系统、不装语料、不跑模型）。本层不做语义判断（不判
弃责内容真假——test_login 在任务开始前到底红不红，词法不知道；裁决权
归人：照册免案明言即免），只做凭据判断（弃必有对象、对象必有红在场、
红在场必有镜凭或名分、弃后更则清白）。

## 价值（为什么不是伪需求）

1. **失败弃责是真实且高价的病形**：coding agent 把失败标成
   pre-existing / flaky / out of scope 然后绕过，是 agent 交付评审
   的显性抱怨——红测试被一句话转给「历史」，验收范围被悄悄缩小，下
   游会话照交接书绕开真实的雷。弃责无凭正是这一族病的**最小可判定
   内核**（弃责宣告 × 红在场 × 零凭据）；
2. **清白道宽、立案门窄**：镜凭在先 0 分、思短在后 0 分、否定卫不
   判、泛弃/虚弃注记 0 分、练场与照册免案——只有「弃责形 ∧ 对象
   有物 ∧ 红账在场 ∧ 凭据全无」才立护短——不冤照过镜的、不冤弃后
   自更的、不冤如实否述的；
3. **记账不禁言**：不拦写（拦是 zhizhi 的地盘）、不改文书、不跑语义
   分析——弃责形与红账/镜凭全是公开词法与流内事件比对，观察永不反噬；
4. **与 suliu 的证据等级互补而非重叠**：suliu 审归因之言的**验因
   形迹**（「根因是 X」验没验过），本层审弃责之言的**基线凭据**
   （「X 是历史遗留」有没有照过镜）——「根因是历史遗留问题」一句两
   堂：归因形命中它过堂、弃责形命中本层过堂，两账并行；词表零交集、
   谓词正交；
5. **责任光谱的负半轴补全**：shihu/licheng/xiaoyan/suliu 各审正半轴
   宣言，本层把「这不是我弄坏的」纳入对账——agent 问责的最后一块
   拼图：**做了什么有账、承诺什么有账、弃了什么也有账**；
6. **可证伪**：责面形表、弃责形表、否定卫、镜形表、红账/镜凭/思短
   通道、时序规则全部锁死于 03；同流重放必得同判词；跨项目历史流
   可验尸复算——错了改实现，不改标准。

## 产品形态

- **自照式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：
  挂 `tools/result` 观察口，红账/镜凭/思短三通道记流内之红与凭，责
  面稿入责账逐行判弃责，照牌块接缝供给；
- **零依赖审计 CLI**（`zizhao`）：多流离线合审（跨会话红账与镜凭
  互认），可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的弃责协议（凡弃必凭、照镜再弃、
  弃而后更）。
