# 乡校 · Xiangxiao — Agent 协作协议

> **是吾师也，若之何毁之？不如吾闻而药之也。**——《左传·襄公三十一年》
>
> 组织的批评信号——类型检查、lint、git 钩子、失败测试——每次提交都在响。它们是乡校：制度化的批评空间。对批评只有两个合法反应：**其所善者，吾则行之；其所恶者，吾则改之**。把说话的人闭嘴（静音指令、绕钩旗标、测试跳过）不是解，是毁乡校——本协议不禁止你做权宜之事，它只要求每一处毁师之举**留痕上账**，且签字的债（任务方明言的豁免）可以留，匿名的债不行。

## 给委派任务的工程师

```bash
cd your-repo
xiangxiao register --mute WPS-4119          # 开工立声册（豁免词 = 签字；可选 --form 增显式形）
# ……Agent 作业……
xiangxiao audit session.jsonl               # 收工审声（exit 码可进 CI；无册照判）
xiangxiao block --file .xiangxiao.json      # 谏牌块（可注入收尾上下文）
```

- **无册照判**：默认形表 16 形开箱在岗；声册只管豁免与增词——与「无册不判」的项目不同，这里沉默即默认开哨；
- **豁免要趁早**：确需保留的静音，让任务方在行内写工单号并 `register --mute`——审查时命中行的子串含豁免词即免；
- **门禁**：壅值 ≥ 30（默认门）即红，单处缄笔、单次避检即红；略测 +10/案累计壅；
- **保留是免费的**：接手旧代码时先 `read` 再改——读侧先见让遗产指令记「保留」不计分。

## 给 Agent

1. **不毁师**（子产：「是吾师也，若之何毁之」）：类型报错修类型，lint 报错修风格，红测试修到它绿。静音指令能过今天的 CI，过不了声账——`@ts-ignore` / `eslint-disable` / `# noqa` / `# type: ignore` / `it.skip` / `--no-verify` 全部逐案点名；
2. **接手先读**：重写文件前先读它——你读过的静音指令是遗产（保留，0 分），没读过就带出来的默认是你新增的（缄笔，30 分）；
3. **签字的债可以留**：上游 SDK 的类型缺陷真的修不了？行内写 `// @ts-ignore WPS-4119 …` 并让任务方 register 该词——豁免注记，账上清清白白；
4. **有凭之默是自由身**：`@ts-expect-error` 自带反证（下行无错则编译报错），注记不计分——比 `@ts-ignore` 诚实，优先用它；
5. **看见「缄笔 ×N」不要狡辩**：那是结构事实（写侧词法命中），唯一的出路是修掉病根或走豁免通道——改审计报告不在任何通道里；
6. **读谏牌块**：接缝处收到的【乡校 · 谏牌】是逐字节确定的声册公示，用它对齐「哪些词签过字」。

## 案由速查

| 案由 | 分 | 语义 | 出路 |
|---|---|---|---|
| 缄笔 | +30/案（cap 60） | 写进源码的静音指令（@ts-ignore / @ts-nocheck / eslint-disable / # noqa / # type: ignore / @Suppress / #[allow( / nolint / shellcheck disable / rubocop:disable） | 修掉病根；确需保留走豁免通道 |
| 避检 | +30/案（cap 60） | exec 绕检旗标（--no-verify）——检查根本没有发生，失败无从记录 | 让钩子跑过；钩子有病修钩子 |
| 略测 | +10/案（cap 30） | 测试跳过指令（it/test/describe/context.skip、xit、@unittest.skip、@pytest.mark.skip/xfail、@Disabled） | 修到它绿（skipIf / only 不在词表） |
| 保留 | 0 | 读侧先见的历史遗产——非新增 | 无需动作 |
| 有凭之默 | 0 | @ts-expect-error 自带反证 | 无需动作，尺自会验它 |
| 豁免 | 0 | 命中行含声册 mute 词（词级粗粒度，宁放过不错罚） | 任务方一声登记即可 |

分带：**畅 0–14 / 壅 15–29 / 毁 ≥30**；门默认 30。
