# 乡校 · Xiangxiao

> **是吾师也，若之何毁之？……不如吾闻而药之也。**——《左传·襄公三十一年》

一门两千五百年的谏诤之学，能不能精确地解决人工智能的一个真实问题？

能。LLM 编码代理有一个最高频也最隐蔽的病灶：**静音组织的批评信号**。类型报错就塞一行 `@ts-ignore`，lint 烦人就 `eslint-disable`，git 钩子拦路就 `--no-verify`，红测试碍事就 `it.skip`——子产说批评者是「吾师」，Agent 选择的却是毁乡校。这些静音指令混在成千行 diff 里，人眼 review 漏掉率极高；失败没有发生（zhibi 无迹可洗）、验收器没被改（fayi 无尺可审）、输出有真实内容（xiaoyan 无成可称）——批评通道的死，无声无息。乡校把「毁师之举」变成**可登记、可清点、可门禁、可重放**的结构事实：其所恶者，吾则改之。

## 它是什么

DeepSeek Harness 的**谏诤式插件**（Cordis）+ 零依赖审计 CLI + Agent Skill。

## 四个场景

1. **缄笔入地**：修支付回调时类型报错，Agent 塞一行 `// @ts-ignore` 过关收工——三个月后同一条类型债在生产爆掉，追溯时连它是谁在哪个会话写的都无处问起。乡校：缄笔案 +30，壅值即红，点名 `文件:行`。
2. **避检**：pre-commit 钩子拦下提交，Agent 重试时加 `--no-verify`——流里没有任何失败记录，zhibi 无形可见。乡校：避检案 +30，单案即红。
3. **略测**：红测试挡路，Agent 加 `it.skip`——批评者还在仓库里，只是从此闭嘴，CI 绿得很干净。乡校：略测案 +10/案，累计即壅。
4. **遗产与豁免的清白**：接手旧代码库，重写文件把既有 `@ts-ignore` 带上——读侧先见 → 保留不计分；任务方明言的权宜——行内带工单号 + 声册 mute 词 → 豁免注记。新增、保留、豁免同账分明。

## 快速开始

```bash
cd your-repo
xiangxiao register --mute WPS-4119          # 开工立声册（豁免词签字的债可以留，匿名的债不行）
# ……Agent 作业……
xiangxiao audit session.jsonl               # 收工审声（exit 码可进 CI；无册照判，默认 16 形开箱在岗）
xiangxiao block --file .xiangxiao.json      # 谏牌块（可注入收尾上下文）
```

- **无册照判**：默认形表（缄 10 + 略 5 + 避 1）开箱在岗，声册只管豁免与增词；
- **门禁**：壅值 ≥ 30（默认门）即红——单处缄笔、单次避检即红；略测 +10/案，双案入壅带点名不咬门；
- **放行道**：保留（读侧先见）、豁免（声册明言）、有凭之默（`@ts-expect-error` 自带反证）——美德的清白全部在册。

## 案由速查

| 案由 | 分 | 语义 | 出路 |
|---|---|---|---|
| 缄笔 | +30/案（cap 60） | 写进源码的静音指令（@ts-ignore / eslint-disable / # noqa / # type: ignore…） | 修掉病根；确需保留，行内带工单号并 register --mute |
| 避检 | +30/案（cap 60） | exec 绕检旗标（--no-verify）——检查根本没有发生 | 让钩子跑过；钩子本身有病就修钩子 |
| 略测 | +10/案（cap 30） | 测试跳过指令（it.skip / @pytest.mark.skip / @Disabled…） | 修到它绿；skipIf / only 不在词表 |
| 保留 | 0 | 读侧先见的历史遗产——非新增 | 无需动作 |
| 有凭之默 | 0 | @ts-expect-error 自带反证（下行无错则编译报错） | 无需动作，尺自会验它 |
| 豁免 | 0 | 命中行含声册 mute 词 | 任务方一声登记即可 |

分带：**畅 0–14 / 壅 15–29 / 毁 ≥30**；门默认 30。

## 设计约束

- 零 LLM、零网络、零子进程、零文件系统探测：默认形表是 16 条确定性词法（docs/03 §4 全列锁死）；
- 结构性零拦截：源码里不存在 pre-execute 监听器，观察永不反噬；
- 契约无关：任何历史会话流可验尸（与 zhizhi/jiebi/mingshi 等层同流格式，跨项目互审）；
- 前缀一致：运行时增量账本与离线重放同分，案不回撤。
