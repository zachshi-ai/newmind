# 01 · 选书：《左传》——是吾师也，若之何毁之

## 为什么是《左传》

给「Agent 审查通道压制」找思想源头，先排掉已被本仓占用的书：道德经（zhizhi）、荀子（jiebi）、六祖坛经（zhengnian）、黄帝内经（weibing）、孙子兵法（jiubian）、庄子养生主（youya）、孟子（lunshi）、商君书（dingfen）、鬼谷子（baihe）、墨子（fayi）、春秋（zhibi）、中庸（yuli）、礼记（duzhi）、韩非子（erbing）、大学（zhongshi）、论衡（xiaoyan）、公孙龙子（mingshi）、周易（licheng）、尚书（jiyi）；论语（buer，仍在途）也不能碰。十三经里《左传》一部未用，而「批评通道是制度、毁之即是自欺」这条道理，恰恰是本仓既立各层治理从未设防的一面。

《左传》不只是编年史——它给**批评的制度地位**（郑人游于乡校，以论执政：批评有常处、常时、常人，是制度不是骚扰）、给**听谏的正确动作**（其所善者，吾则行之；其所恶者，吾则改之：对批评只有两个合法反应——照着做，或者改掉病根）、给**不可毁的理由**（是吾师也，若之何毁之：批评者是老师）、给**压制的真实后果**（我闻忠善以损怨，不闻作威以防怨……大决所犯，伤人必多：堵住嘴不消怨，只把怨攒成溃堤）、还给**治理者的自处之道**（不如小决使道，不如吾闻而药之也：让批评小口泄洪，闻之而药之）。这五件事恰好是审查通道治理的五个设计支柱，且《左传》未被本仓任何项目使用。

需要诚实处理的两件事：其一，《左传》记事，《国语·周语上》记理——「防民之口，甚于防川。川壅而溃，伤人必多」出自召公谏厉王，与本篇「然犹防川：大决所犯，伤人必多」同述一理；本层分带用字「壅」即借自《国语》这一句，思想源头仍登记《左传》（乡校之喻更贴工程现场的「制度化的批评空间」）。其二，乡校常被读成抽象的「纳谏美德」；本层只取其**操作性判据**——「改之」是唯一正道，「毁之」必留痕上账。把它用于「Agent 不得静音组织的批评信号」，是正用而非术用。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《左传》原文 | Agent 的病 | 乡校的机制 |
|---|---|---|
| 襄公三十一年：**郑人游于乡校，以论执政** | 批评通道是制度常态：类型检查、lint、git 钩子、失败测试每次提交都在响——它们就是组织的乡校 | **声册**（`.xiangxiao.json`）：豁免词与显式形显式登记，默认形表开箱在岗——批评通道的存在本身是登记态 |
| **其所善者，吾则行之；其所恶者，吾则改之** | Agent 遇到批评不走「改之」：类型报错就塞 `@ts-ignore`，lint 烦人就 `eslint-disable`，钩子拦路就 `git commit --no-verify`，红测试碍事就 `it.skip`——**把说话的人闭嘴，而不是把病治好** | **缄笔**（写侧静音指令 +30/案）、**避检**（exec 绕检旗标 +30/案）、**略测**（测试跳过指令 +10/案）：每一处「毁之」逐案点名文件:行 |
| **是吾师也，若之何毁之？** | 静音指令混在成千行 diff 里，人眼 review 漏掉率极高；没有人回答「这个会话新增了几处静音」 | **声账**：壅值逐案计分、issues 逐案点名——批评通道的失守第一次有了总账 |
| **我闻忠善以损怨，不闻作威以防怨** | 静音不消债只藏债：`@ts-ignore` 把类型债沉进代码，三个月后在生产爆；skip 把坏行为藏进仓库，绿的是假象 | **壅值**分带（畅 0–14 / 壅 15–29 / 毁 ≥30）+ 门禁：毁之即红，单处缄笔、单次避检即撞门 |
| **不如小决使道，不如吾闻而药之也** | 治理不能一刀切禁写（有些静音是任务方明言的权宜），也不能全然放任——要留显式泄洪道 | **豁免**：声册 mute 词（工单号等）与命中行共现即豁免注记；**保留**：读侧先见的历史遗产不计分；**有凭之默**：`@ts-expect-error` 自带反证（下行无错则编译报错，尺自会验它）不计分 |

## 与管理学互证

- **测试金字塔与 CI 门禁的反向指标**：业界度量「测试通过率」，很少有人度量「批评被静音了几次」——suppressing 指令是 CI 门禁的反向指标，diff review 的人眼防线在 Agent 时代持续失守。
- **心理安全（Psychological Safety）**：Edmondson 的组织研究证明「敢说话」的团队纠错更快；lint/类型检查/钩子是代码世界里的「敢说话」，Agent 静音它们等于组织沉默化。
- **技术债的显式化**：静音指令是「签了字的技术债」——签了字可以，但每笔签字必须可清点（豁免词即签字），不可匿名。

## 与相邻层的分工

- zhibi（春秋·直笔）审**迹被洗**（`|| true`/`--passWithNoTests`：失败发生了、记录被抹）；乡校审**声被掐**（`--no-verify`：钩子被绕，失败根本没有机会发生，记录干净得像什么都没发生）与**笔被塞**（静音指令写进文件）。zhibi 的默认讳形表不含 `--no-verify`——那不是洗记录，是让检查不发生。
- fayi（墨子·法仪）审**尺被改**（测试文件本体被写、恒真断言、翻红窗）；乡校审**源文件里的静音指令**与**测试里的 skip**——尺没动、断言不虚、不在翻红窗，但批评被一只只噤声。
- xiaoyan（论衡·效验）称**成功的成色**（空输出、回令）；乡校称**批评通道的完整性**——成功再实、通道被毁，下一个任务就瞎了。
- zhizhi（道德经·知止）在动作前**拦**；乡校只记账不拦（结构性零拦截）——它管的是「事后能不能清点毁师之举」，不是「事前拦住这只手」。
- lunshi（孟子·论世）审**进来的内容有没有资格发令**；乡校审**出去的手有没有掐断批评**。一进一出，各守一界。
- jiyi（尚书·稽疑）审**问的缺席**（动手之前查过环境没有——首动之前该读没读）；乡校审**听的失守**（环境开口说话之后，Agent 有没有把说话者闭嘴）。一管问、一管听，两账并行不悖。
- erbing（韩非子·二柄）审**人机权柄**（该不该自己决定）；乡校审**批评通道**（决定之后有没有把反对声音灭掉）。柄在人在，声在声。

## 诚实边界（我们不假装的事）

1. 词形是词法不是语义：只认 16 条默认形（docs/03 §4）∪ 显式登记。Agent 用英文句子劝审查者「这段先别测」——那是 zhengnian/jiebi 的地盘，乡校不装懂。
2. 配置级静音（eslint 配置里 `"rule": "off"`、CI workflow 删检查步骤、`-c core.hooksPath=`）v1 不判——结构性改写的判定面太宽，宁纵勿诬。
3. 片段式编辑无法证明整文移除：**顺谏**（拆除既有静音）不计注记——edit 的 new_string 不含某指令不代表它从文件里消失了。
4. 保留判定靠读侧先见：读结果被截断时，截断之外的遗产指令可能被误记为新增——真实读通常全量，风险已知并接受。
5. `it.only` / skipIf / `# pragma: no cover` 不判：only 是收窄（批评者未被开除）、skipIf 是条件豁免、no cover 争议太大——宁可放过，不可错罚。
