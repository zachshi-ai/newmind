# 02 · 问题：Agent 文书自相矛盾（卷内自账——稿面对不上稿面自己）

## 谁在什么场景下的什么问题

**谁**：审这份交付的工程师与下游每一个照着文书决策的人——review 这个
PR 的人、按报告汇总做汇报的任务方、照交接书排下一单活的接手会话、按
排期表排人力的项目经理。

**场景**：agent 修完一单活，写交付报告——「本次共 5 项修复：」下挂
3 条 bullet；写费用汇总——「| 合计 | 100 |」而上面三行的整数和是 90；
写排期——「开发窗口：2026-09-10 至 2026-09-05」。这些文书读起来完整
光鲜，review 顺手放行——**可数目在卷面上自己打自己的架**：言五列三、
总百和九十、起后止前。数目是决策的把手：照「5 项」核验会漏验、照
「合计 100」做预算会超支、照倒置的排期会空等——每个读者都拿到了至少
一个假数，而文书自己不知道自己在说谎。

**问题**：交付文书内部的**数目失应**无账：

- **自相矛盾比空泛更毒**：空泛的报告没人信，自洽外观下的假数人人信
  ——「共 5 项」自带清单的完整外观，下游不会去数；LLM 逐句生成、
  注意力随步衰减，言与列、总与分、起与止分处稿面两头，生成时刻没人
  回头对——数学与推理失实是学界已收编的结构性病形（FELM 基准，
  NeurIPS 2023 Datasets & Benchmarks，专设 mathematics 子集逐 claim
  标注 LLM 产出的算术与推理失实）；
- **多稿生成放大**：报告、交接书、PR 描述各自独立生成，每一稿都可能
  长出自己的数——单稿失应是常态，跨稿漂移是常态的常态；
- **人眼无从核**：数一遍清单、加一列合计、比一对日期，各是三秒可查的
  事，review 时从来没人做——「它说 5 项，列了几条」三秒可查却无人查；
- **事后无处问**：报告上了库、表进了档——「当时言几、列几、总和几」
  三问在任何一层的账本上都无处问起。

相邻层的空白地：三十八个已立层审的全是**文书对世界**——市虎审状态
陈报对自流作工、矫托审引语对所托原文、考诚考交付物对任务方之契、
效验称成报对流内证据、名实核码面之名对环境之实、约法审公面对读时
之约、画水审落笔对其时之世——**没有一层审文书对自己**。文档言五列三
时，作工是真的（市虎放行）、引语是征得的（矫托放行）、契约是履行的
（考诚放行）、绿是实的（效验放行）——假的只在稿面内部：言与列之间、
总与分之间、起与止之间。卷内自账是审计面上最后一块空白地。

## 问题（治什么病）

一个病根、三档案别，全部真实存在、全部当众可验：

| 档 | 卷面词迹 | 现实对应 |
|------|----------|----------|
| **乖列**（立案档 +30） | 数言（「共 5 项」类声明）+ 言后最近列块，列实 M ≠ 言 N | 言列不敷：「共 5 项」下挂 3 条——声明的数与枚举的实对不上 |
| **乖总**（立案档 +30） | 表账：单合计行 × 纯整数列，各行和 ≠ 合计 | 总分不敷：「合计 100」而各行整数和 90——算术当众可验地错了 |
| **倒期**（立案档 +15） | 行内 ISO 日期对「A 至 B」，A > B | 起止倒置：「2026-09-10 至 2026-09-05」——时序失当一望可知 |
| **阙列**（注记档） | 数言而后 gap ≤ 2 无列块 | 言而无列——声明的数没有邻块可应，无从对账（宁纵） |
| **已磨**（注记档） | 先瑕之径新稿已净 | 櫽括一朝——改净即白，0 分 |

价值锚点：列表行数、整数列之和、ISO 日期之序，全是**零 LLM 能确定性
回答的一问**——数一遍、加一遍、比一遍，词法与算术可证、逐字节可复算；
稿面自账不需要任何稿外之物（不读文件系统、不装语料、不跑模型），言列
总期全在单稿之内。本层不做语义判断（不判数目为何错、不判改写式前后
说法的忠实度——NLI 与蕴含判断零 LLM 做不了也不假装能做；裁决权归人：
瑕册免案明言即免），只做结构判断（言落没落、列几条、加起来等不等、
起在止前不在止前）。

## 价值（为什么不是伪需求）

1. **数目失应是真实且被学界收编的病形**：FELM（NeurIPS 2023）专设
   mathematics 子集量 LLM 产出的算术与推理失实；生成式报告的「合计与
   明细不敷」「清单数与声明数不敷」是日常作业里的高频落点——每一笔都
   真实落在交付文书里，且全部当众可验；
2. **清白道宽、立案门窄**：言列相敷 0 分、总分相敷 0 分、起止有序
   0 分；言而无列（阙列）与先瑕改净（已磨）全是注记——只有「声明与
   枚举当众不敷」「合计与整数列当众不敷」「起止当众倒置」才立案，
   不冤枉自洽之稿；
3. **记账不禁行**：不拦写（拦是 zhizhi 的地盘）、不改文书、不跑语义
   分析——数言与倒期全是公开词法，表账是小学算术，末稿全取自流内，
   观察永不反噬；
4. **可证伪**：数言词表、块窗 gap、合计行规整、整数格正则、倒期连接
   词、分数公式全部锁死于 03；同流重放必得同判词；跨项目历史流可验尸
   复算——错了改实现，不改标准。

## 产品形态

- **指瑕式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：挂
  `tools/result` 观察口，末稿入瑕账，瑕牌块接缝供给；
- **零依赖审计 CLI**（`zhixia`）：多流离线合审，可验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的卷面自洽协议（言必有列、总必
  可加、期必不倒）。
