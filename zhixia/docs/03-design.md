# 03 · 设计：指瑕 · zhixia —— DeepSeek Harness 的文书自洽治理（指瑕式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**指瑕式插件**（第四十个）。shihu 证明插件可以审交接径的
状态陈报，jiaotuo 证明可以审落卷之引对所托之文，kaocheng 证明可以审
任务方之契，fangchuan/saowu 证明可以以末文/末卷为账基扫稿面——指瑕
证明插件可以**审稿面对稿面自己**：哪一句声明的数与它身后的枚举不敷、
哪一张表的合计与它的整数列不敷、哪一对起止日期倒着落卷。

```
tools/result   emit   write 稿面入瑕账并判瑕（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、
零文件系统探测——言列总期全在单稿之内）；观察永不反噬（监听器异常吞掉，
管道照常）；瑕册持久化归 CLI（register/revoke），插件只吃注入的 book 对象；
单会话视图的案与值只采本会话，跨会话归并归离线合并审计。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓。

**瑕账只收写**：write 族 p: 径 ∧ `isError !== true` ∧ `args.content`
非空字符串 → 该 content 成为此径的**末稿**；新稿落地即审（审的正是本笔
content），同径旧稿的案与注记**全数撤换**（以末稿为准）。isError === true
之写不入账（失败的写没落盘）；isError 未知（null，老流）按已发生；
无 content 之写（edit 族等）无稿可审，不入账。

observe 族永不受审（读取不是落卷）；exec 族不受审（命令行无稿面结构
——commit message 里的数没有稿面可对，宁纵，既知代价）；other 族不入。

**豁免（立案前）**：瑕册 `excuse` glob 命中径 ∪ **试场**名段命中径 →
整径不审不记（受审径计数不含）。试场是稿面自洽的本份之地（测试夹具里
的失应文书是演武的道具）：正则形 10——`(tests?|specs?|__tests__|__mocks__|
fixtures|debug)/` 名段（目录段在径首亦算段）∪ `.test.`/`.spec.`/`.mock.`/
`.debug.` 尾形。

**已磨**：同径前稿有案而新稿无案 → 已磨注记（櫽括一朝，0 分）；前稿
无案而新稿有案 → 新案照立；两稿皆有案 → 新案换旧案（不叠加、不双罚）。

**合审序（CLI 多流）**：全 at 有数 → `(at, 流序, 流内序)` 稳定排序；否则
参序拼接（审计方须自证流序）。单会话运行时视图同法自洽。

## 3. 数言（声明数之词法，默认内置，零 LLM）

数言是「声明卷面数目」的词迹，只生于**非列非表行**（行首命中列前缀或
表前缀之行不生言——子弹点内的「共 3 处」类子称数是条目内部的子账，
不是卷面结构声明，宁纵）。一行多言逐言独立判。N ≥ 2 方成言（0 与 1
不判——宁纵）；中文数字不判（既知代价）。

**中文形**：方向词 + 阿拉伯数 1–4 位 + 量词，三段相邻（可夹空白）：

| 方向档 | 方向词 |
|----|----|
| 向上 3 | 以上、上述、前述 |
| 向下 3 | 以下、如下、下述 |
| 无向 6（先下后上） | 共、共计、总共、总计、合计、凡 |

量词 30：个、项、条、点、处、步、名、则、例、类、款、篇、章、节、
条目、事项、任务、问题、风险、需求、建议、要点、步骤、规则、文件、
测试、用例、案例、功能、模块。

**英文形**（大小写不敏感）两式：

| 式 | 形 | 方向 |
|----|----|------|
| 方向形 7 前缀 | `total/all/following/below/above/these/next` + `:`? + N + 量词 | above 向上；following/below/next/these 向下；total/all 先下后上 |
| 冒号形 | N + 量词 + `[:：]` | 先下后上 |

英文量词 27：item(s)、point(s)、step(s)、rule(s)、task(s)、issue(s)、
finding(s)、requirement(s)、risk(s)、note(s)、example(s)、file(s)、
test(s)、case(s)、bug(s)、fix(es)、module(s)、feature(s)、section(s)、
chapter(s)、entries、recommendation(s)、question(s)、option(s)、
candidate(s)。方向形与冒号形跨形去重：两形的「数字起点至量词终点」
区间相交者取方向形。

## 4. 列块与表块（数言之应）

**列前缀**：`/^\s*(?:[-*+]|\d+[.、)])\s/`（无序/有序/任务列表皆中）；
**表前缀**：`/^\s*\|/`。

**方向**：上词只向上、下词只向下、无向先向下找不到再向上。

**块窗**：自数言行起逐行——空行跳过；首个列/表行即块首，块首之前
 encounters 的非空非列非表行数 = gap，**gap ≤ 2 方认块**；gap > 2 或
文档尽头无块 → **阙列**注记（言而无列，留痕 0 分）。

**块**：自块首连续的同类行——块首是列行 → **列块**（连续列行，内部
空行透明，遇非空非列行止）；块首是表行 → **表块**（连续表行，同法）。
表块须有效（行数 ≥ 3 ∧ 第 2 行为分隔行，每格 `/^:?-{2,}:?$/`）方算块，
无效表块按无块论（阙列注记——不拿半张表应言）。

**列实 M**：列块 = 列块行数；表块 = 数据行数（去表头、去分隔行、去
合计行——合计 = 首格规整（trim、去尾冒号、小写）后 ∈ {合计, 总计,
总共, sum, total, grand total, overall}）。

**判**：M ≠ N → **乖列** +30/案；M = N → 清白（不记）。

## 5. 表账（乖总之账，不依赖数言）

每个**有效表块**（同 §4 有效形）独立受审，稿内逐表扫、无声也判：

- **合计行数 ≠ 1 → 整表跳过**（0 或 ≥2 皆跳——分组小计与多汇总表
  不判，宁纵）；
- 各行列数与表头不齐 → 整表跳过（不成谱）；
- **整数格**：剥千分位/空白/尾 `%`/首币符（`,，\s%¥$€£`）后
  `/^[-+]?\d+$/`；小数格不算整数（四舍五入的世界，宁纵）；
- 逐列判：合计格为整数 ∧ 该列全部数据格皆为整数 → Σ ≠ 合计 →
  **乖总** +30/列（案记在合计行行号）；任一格非整数 → 该列跳过。

## 6. 日序（倒期之账）

行内 ISO 日期对（全部行受审——排期常落在列行上）：

```
/(\d{4}-\d{2}-\d{2})\s*(至|到|~|～|–|—|->|→|\bto\b|\bthrough\b)\s*(\d{4}-\d{2}-\d{2})/gi
```

历法门：两侧皆须月 01–12 ∧ 日 01–31（任一出界该处不判）；起 > 止
（零垫串逐字比较）→ **倒期** +15/处，一处 = 一对命中。

## 7. 判定序（每稿锁死）

1. **立案前豁免**：瑕册 excuse ∪ 试场名段 → 整径免审（不审不记）；
2. **乖总**：逐有效表块逐列（§5）；
3. **乖列/阙列**：逐数言（§3/§4）；
4. **倒期**：逐行逐处（§6）；
5. **已磨**：先瑕之径新稿净 → 注记（§2）。

三形**并行扫描、案案独立**——列可乖而期正、总可乖而列敷，一稿可同出
多形多案（与逐行互斥链不同：稿面三形互不吞并）。判词排序锁死：乖列 →
乖总 → 倒期 → 阙列 → 已磨 → 全净行。

## 8. 瑕值门禁

```
xia = min(60, 30 × 乖列) + min(60, 30 × 乖总) + min(40, 15 × 倒期)
total = min(100, xia)
```

分带：**净 0–14 / 瑕 15–29 / 疵 ≥30**；门默认 30——**单乖列即红**
（声明的数与当众可数的实不敷）、**单乖总即红**（算术当众错了）、
**双倒期即红**、**单倒期黄牌点名不咬门**（时序失当伤轻于数谬——黄牌档
正为它留）。

counts：`gl` 乖列 / `gz` 乖总 / `dq` 倒期 / `que` 阙列 / `mo` 已磨。
score：`lie` / `zong` / `dao` / `total`。

## 9. 瑕册

册形 `{ "version": 1, "excuse": ["docs/reports/*"] }`。声明权全在任务
方：免案是「本任务授权之径」的明言；无册照判（凡卷皆审——卷面自洽不
挑文件，豁免授权只能来自册）。register/revoke 归 CLI，插件只吃注入的
book 对象。v1 只豁免不扩形（数言/倒期词表内置固定）。

## 10. 瑕牌块（接缝供给）

逐字节确定，shasum 可证：

- 瑕册公示（无册出确定性文本「瑕册：未立（凡卷皆审）」）；
- 词法公示（数言三形：乖列/乖总/倒期）；
- 案账清点（gl/gz/dq/que/mo）；
- 逐案点名 `径:行:案别:数据:指纹`——乖列载 言 N 实 M、乖总载 列次 言 T
  和 S、倒期载 起 d1 止 d2；指纹为案行的 djb2。**永不携带行原文**（数字
  与日期是案的断言数据不是文面——掩码是结构性保证）。

## 11. 边界（与相邻各层）

- **shihu**：一状一瑕。它审状态陈报对自流作工（文书对世界——「已修复」
  在流里有没有作工），本层审稿面对稿面自己（「共 5 项」对身后的 3 条）
  ——世界无需在场，文档自己对自己；状面限定交接形、本层凡稿皆审。
- **jiaotuo**：一托一瑕。它审落卷之引对所托之文（文书对另一文书——
  引号里的话在原文里吗），本层审稿内之数对稿内之列（声明的数在身后的
  清单里敷不敷）；它锁引形引语、本层锁数言列块，谓词正交。
- **kaocheng**：一契一瑕。它考任务方之契对交付物（无册不判——契上
  写了才考），本层无册照判、凡卷皆审（稿面自洽不是契约是本份）；契考
  「该在的在不在」，本层审「在场的自己打不打架」。
- **xiaoyan**：一报一瑕。它称流内成报之实（绿有没有做过事），本层称
  落卷内部之账（言列总期敷不敷）；报实而稿裂的文书它放行本层立案。
- **mingshi**：一名一瑕。它核码面幻名（写下的名有没有实），本层核卷面
  幻数（声明的数有没有列）——一名一数。
- **fangchuan**：一川一瑕。同以末文为账基，它扫码面湮形（错误通道被
  堵），本层扫稿面数谬（数目通道自相矛盾）；湮是口被堵、瑕是账不合。
- **saowu**：一垢一瑕。同扫卷面，它审调试残迹（探针留场），本层审
  数目失应（言列总分倒期）；垢是行内的声、瑕是稿内的账，两形表零交集。
- **huashui**：一陈一瑕。它审三序覆新（旧副本覆掉其间之变——跨笔的
  时鲜），本层审单稿内部（一稿之内自己打自己——以末稿为准同法不同向）；
  覆要两笔文据、瑕只要一笔稿面。
- **shenqu**：一残一瑕。它称读据残全（看见的完不完整），本层称稿账
  自洽（写下的敷不敷）——一入一稿。
- **zhizu**：一量一瑕。它量写之规模（行数/写域——写了多少），本层审
  写之自洽（写的内容对不对得上自己）；巨写可净、三行可瑕。
- **zhongshi**：一程一瑕。它审任务方事册之终始（无册不判），本层审
  文书自声之数（凡稿皆审）——册是任务方立的、言是稿子自己说的。
- **yuefa**：一约一瑕。它审公面对读时之约（对外承诺的导出名），本层
  审卷面对自身之数（对内声明的枚举）——一对外一对内。
- **zhixing**：一行一瑕。它审章程必行令行没行（行为对章程），本层审
  稿内数言行没敷（稿面对稿面）——一令一数。
- **youya**：一重一瑕。它记重装载之费（读过的再读），本层记自相矛盾
  之瑕（写下的打架）。
- **lunshi/baihe/yuli/duzhi/erbing** 等输入、出境、退路、花销、权柄
  诸层在输入面与行为面，本层只在落卷之稿的**账面**；行为再干净，稿面
  自相矛盾照样立案。
- **buer**：跨会话教训归它，瑕账是流内账，本层不做任何跨会话学习。

## 12. 既知代价（宁漏勿诬的让渡，逐条登记）

- 中文数字不判（「共五项」不是数言——宁纵）；N ∈ {0,1} 不判；
- 列内子数不判（非列非表行才生言——子弹点内的「共 3 处」是条目子账）；
- 小数列不判（四舍五入的世界——任一格非整数该列跳过）；非整数格列
  跳过（千分位/百分号/币符剥后非纯整数）；
- 多合计行/零合计行整表跳过（分组小计不判）；行列数不齐整表跳过
  （不成谱）；表内转义 `\|` 不识（既知代价）；
- 块窗 gap ≤ 2（远处的清单不认——阙列注记留痕）；无效表块按无块论；
- 分片跨笔之稿不重组（每稿独立判——append 式写作的半卷判半卷，宁纵）；
- 日期仅 ISO 横杠形（YYYY/MM/DD、YYYYMMDD、「9 月 5 日」不判）；
  表格分列起止不判（无连接词不成对）；历法门只验月日界不验实存
  （2026-02-30 两界内照判——宁严一格）；
- exec 命令行不审（commit message 之数没有稿面可对——宁纵）；
- 语义一致性不判（改写式前后说法冲突非词法可证——不假装能做）；
- 词法可欺但骗一次留一次形；时序以流序为准（缺 at 照判）；零 LLM。
