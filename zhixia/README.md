# 指瑕 · zhixia —— DeepSeek Harness 的文书自洽治理

> **「古來文才，異世爭驅；或逸才以爽迅，或精思以纖密，而慮動難圓，鮮無瑕病。」**
> **「應劭釋疋，或量首數蹄……辭賦近事，而千里致差。」——《文心雕龙·指瑕第四十一》**

agent 修完一单活写交付报告——「本次共 5 项：」下挂 3 条 bullet；写费用汇总
——「| 合计 | 100 |」而上面三行的整数和是 90；写排期——「2026-09-10 至
2026-09-05」。这些文书读起来完整光鲜，review 顺手放行——**可数目在卷面上
自己打自己的架**。数目是决策的把手：照「5 项」核验会漏验、照「合计 100」
做预算会超支、照倒置的排期会空等。LLM 逐句生成、注意力随步衰减，言与列、
总与分、起与止分处稿面两头，生成时刻没人回头对——数学与推理失实是学界
已收编的结构性病形（FELM，NeurIPS 2023，专设 mathematics 子集）。

**指瑕**给 DeepSeek Harness 装上第四十个能力类型：**指瑕式插件**（结构性
零拦截）+ 零依赖审计 CLI + Agent Skill。它不拦写（账与闸分治，拦是知止的
地盘）、不做语义判断（不判数目为何错——裁决权归人：瑕册免案明言即免），
只做词法与算术可证的一问：**稿面声明的数，与它身后的枚举、它表的合计、
它写的起止，对不对得上**——三十八层审的全是文书对世界，文书对自己只有
本层。

## 快速开始

```bash
cd your-repo
npm install github:zachshi-ai/newmind#zhixia-dsh     # 或复制本目录

# 开工（可选）：立瑕册——模板文书等免审径先列明
zhixia register --path "docs/reports/*"              # 免审授权（* 跨目录）

# 收工：审稿
zhixia audit session.jsonl --file .zhixia.json       # exit 0 通过 / 1 门禁红 / 2 用法错
zhixia audit s1.jsonl s2.jsonl --json                # 多流合审（末稿跨会话归并）
zhixia block --file .zhixia.json                     # 瑕牌块：瑕册与词法公示（逐字节确定）
```

无册照判：数言三形开箱在岗——凡卷皆审；tests/ 等试场名段天然豁免（演武
之地不设门禁），正当之免审必须明言立册。

## 判定语义（docs/03 锁死）

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 乖列 | 数言（「共 5 项」类声明，方向词×量词，N≥2）+ 言后 gap≤2 的列块/表块，列实 M ≠ 言 N | 言列不敷——声明的数与枚举的实对不上 | +30/案（单案即红） |
| 乖总 | 有效表块（≥3 行含分隔行）× 单合计行 × 纯整数列，各行和 ≠ 合计 | 总分不敷——算术当众可验地错了 | +30/案（单案即红） |
| 倒期 | 行内 ISO 日期对「A 至 B」（至/到/~/to/through），起 > 止 | 起止倒置——时序失当 | +15/处（双处即红，单处黄牌） |
| 阙列 | 数言而后 gap ≤ 2 无块 | 言而无列——无从对账 | 注记 0 分 |
| 已磨 | 先瑕之径新稿已净 | 櫽括一朝——改净即白 | 注记 0 分 |

- **以末稿为准**：同径新稿落地即审，旧稿之案全数撤换（两稿皆瑕换案不叠加）；
- **瑕值**：`min(60,30×乖列) + min(60,30×乖总) + min(40,15×倒期)`，分带
  **净 0–14 / 瑕 15–29 / 疵 ≥30**，门默认 30；
- **三形并行、案案独立**：列可乖而期正、总可乖而列敷，一稿可同出多形多案；
- **掩码是结构性保证**：判词与瑕牌只载 径:行:案别:数据:指纹，永不携带行原文。

## 与相邻各层的边界

- **shihu**（一状一瑕）：它审状态陈报对自流作工，本层审稿面对稿面自己；
- **jiaotuo**（一托一瑕）：它审引语对所托原文，本层审稿内之数对稿内之列；
- **kaocheng**（一契一瑕）：它考任务方之契对交付物（无册不判），本层无册照判；
- **xiaoyan**（一报一瑕）：它称流内成报之实，本层称落卷内部之账。
