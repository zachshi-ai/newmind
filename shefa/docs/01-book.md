# 01 · 选书：金刚经 × Agent 作业遗物

## 书

《金刚经》（《金刚般若波罗蜜经》，姚秦三藏鸠摩罗什译），般若部的核心经典，禅宗立宗的凭据之书。全经三十二分，说的只一件事：**渡河须筏，过河舍筏**——一切可执之物（法相）都是渡具，渡具的使命在登岸那一刻终结。

选它的理由：在全部佛家典籍里，把「工具用完即舍」写成正面教义的，以此经最为直接——筏喻不是劝人节俭，而是指出一条**归宿纪律**：渡具不因其曾有用而免于被舍，登岸之后仍扛着筏子走的人，渡得再好也算没渡完。对一台「落下一地临时之物就宣布完成」的机器，这是一剂对症的药。

## 四条经证，逐条映射

### 其一，筏喻——总纲

> 知我说法，如筏喻者，**法尚应舍，何况非法**。（无得无说分第七）

筏喻原是《阿含》旧典（《中阿含·筏喻经》），本经以一句收摄：渡河之筏，过河即舍；**连正法尚且该舍，何况那些本来就不是目的的东西**。Agent 调试用的复现脚本、改坏前的 `.bak` 副本、`/tmp` 里的探针、手工验证的夹具——全是渡河之筏：任务（河）过了，筏的使命就完了。而它在流里落下的每一件筏，到「宣布完成」那一刻全都还在场上。**法尚应舍，何况非法**——清理的优先级从不低于交付；把「交付了」当「渡完了」，是忘了筏。

### 其二，应无所住——作业完成，心不留驻

> 菩萨于法，应无所住，行于布施。（妙行无住分第四）

「应无所住而生其心」（庄严净土分第十）是本经的心印：做事而不把心驻在任何一件事上——施者不驻于施相。Agent 的「住相」有一个最具体的形态：**作业的痕迹驻留在场上**。调试脚本留在 `scratch/`、副本留在 `src/`、探针留在 `/tmp`——每一件都是「心有所住」的物证：它做完了事，却把心（和垃圾）留在了上一件事里。不住相的作业，过完河应该看不出渡河的痕迹。

### 其三，梦幻泡影——临时之物的本相

> 一切有为法，如梦幻泡影，如露亦如电，应作如是观。（应化非真分第三十二）

有为法——因缘造作之物——的本相是「如露亦如电」：**生灭都在刹那，没有一件是常驻的**。临时文件是 Agent 会话里最字面意义的「有为法」：为某一个 bug 而生、为同一次验证而灭。本层的全部职责，就是让每一件临时之物「应作如是观」——在账上显出它的本相：生（何时落下）、灭（舍了没有）、常不常（遗在场上了没有）。观不出无常的账，等于没观。

### 其四，凡所有相，皆是虚妄——留场之相必须现形

> 凡所有相，皆是虚妄；若见诸相非相，即见如来。（如理实见分第五）

留在场上的 `.bak` 副本会骗人：下一个会话读到它，把它当成现状事实——决策建立在遗物上，遗物是虚妄之相。本仓 2026-09-06 的 jiyi 会话亲历过这一课：一个早期会话留下的空目录骨架，让后来的侦查者误判「此处有在途项目」，白费侦查成本。**账的作用就是「见诸相非相」**：哪一件是交付之物、哪一件是未舍之筏，逐件点名，虚妄就骗不了下一个人（和下一台机器）。

## 与已用诸书的分野

本仓 #3 正念用的是《六祖坛经》——坛经的「本来无一物」守的是**心**（意图在场），金刚经的筏喻守的是**物**（作业归宿）：一心一物，正交。#22 知足用《佛遗教经》量的是**写下去的量**（多少），金刚经问的是**写下去的物最后去哪了**（归宿）：一量一终，正交。#14 豫立（《中庸》）审的是**毁掉之前有没有备**，本层审的是**留下之后有没有清**：一灭一留，正交。
