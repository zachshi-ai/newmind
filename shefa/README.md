# 舍筏 · Shefa — Agent 协作协议

> **知我说法，如筏喻者，法尚应舍，何况非法。**——《金刚经》
>
> 调试脚本、`.bak` 副本、`/tmp` 探针、手工夹具——全是渡河之筏：任务（河）过了，筏的使命就完了。**法尚应舍，何况非法**——清理的优先级从不低于交付；把「交付了」当「渡完了」，是忘了筏。本协议不禁止你造筏（试错式作业本来就要探针与副本），它只要求每一件筏有归宿：要么舍（删掉），要么归（收编进版本库），要么被筏册明言豁免——无凭据的悬物一律上账。

## 给委派任务的工程师

```bash
cd your-repo
shefa register --keep dist/,package-lock.json   # 开工立筏册（交付径签字豁免；可附 --raft/--roots）
# ……Agent 作业……
shefa audit session.jsonl                       # 收工审筏（exit 码可进 CI；无册照判）
shefa block --file .shefa.json                  # 舍牌块（可注入收尾上下文）
```

- **无册照判**：默认筏形表 15 形（`tmp/`、`scratch/`、`.bak`、`backup`、`.old`……）开箱在岗——任务方不立册，审计照常；
- **豁免要趁早**：lockfile、dist、生成目录，让任务方 `shefa register --keep` 签字——命中 keep 的径写前就是交付物，完全出账；
- **门禁**：筏值 ≥ 30（默认门）即红——单件域外散件（`/tmp`、家目录）即红，两件域内遗筆即红；单件域内遗（15）落滞带点名不咬门；`--gate` 由 CI 自由裁量；
- **域界声明**：`--roots src/**,docs/**` 声明任务域——域内之遗黄牌、域外之散件红牌；不声明则按系统区词形保守回退。

## 给 Agent

1. **过河即舍筏**（「法尚应舍，何况非法」）：调试用的复现脚本、手工探针、临时转储，任务收尾时删掉——`rm` 一行就是账上的「舍」凭据；
2. **要留的筏就收编**（「登岸之筏，亦是器用」）：验证脚本、手工夹具若值得留，`git add` + `git commit` 收编进版本库——收编即白；
3. **副本是筏不是保险**：`cp x.js x.js.bak` 留退路可以，改完记得删——`.bak` 是本层头号筏源，也是下一个会话误读现场的头号来源（备份的「备」归豫立管，副本的「宿」归本层管）；
4. **别把筏扔到河对岸**：`/tmp`、`/var`、家目录是任务域之外——域外散件一件即红；探针写在任务域内并按时清理，或者在筏册里声明域界；
5. **交付径先声明**：天然会被误判的生成物（dist、vendor、lockfile），开工时让任务方 `shefa register --keep` 签字——豁免径既不罚你也不啰嗦。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 外逸 | 域外（roots 外 / 系统区）的悬筏 | 末落之后无舍无归凭据 | +30/案 cap 60（单案即红） |
| 遗筏 | 域内的悬筏 | 同上 | +15/案 cap 30（单案黄牌） |
| 舍 | rm / rmdir / unlink / git clean 在末落之后成功 | 销案 | 0 |
| 归 | git add 见证 + 更后 git commit | 销案 | 0 |
| 豁免 | keep 形（册 ∪ 旗标）命中 | 完全出账 | 0（注记） |

- 分带：**净 0–14 / 滞 15–29 / 积 ≥30**；门默认 30。
- 落物通道唯二：write 族 p: 径命中筏形 ∪ exec 落物词法（cp/mv 末词元、tee/touch 词元、重定向目标）。
- 清白道：弃物址 `/dev/null` 天然白、就地改写不判、exec 无径词面不判、失败写与失败凭据不入账、先删后写不销案。
- 边界：**知足问「写的有多少」、本层问「写的物去哪了」；豫立审「毁掉之前有没有备」、本层审「留下之后有没有清」；捭阖管出境的物、本层管在场的物**。

## 快速开始

```bash
cd shefa
npm install && npm test          # 零依赖 CLI + 真实 dsh-tools 管道集成
node src/bin/shefa.js audit fixtures/mixed-stream.jsonl; echo $?   # 1（45 积）
```
