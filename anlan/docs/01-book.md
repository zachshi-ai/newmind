# 01 · 选书：W·爱德华兹·戴明《转危为安》（Out of the Crisis）—— 漏斗实验：对稳定系统施治，只会放大变异

## 原文（据通行中译本转述）

戴明在《转危为安》中给出一个亲手设计、人人可重演的确定性实验——**漏斗
实验**：把漏斗悬在靶心上方，让小球从漏斗落下，落点自然散布（任何真实系
统都有散布——这是系统的呼吸）。针对散布，绝大多数人会本能地「纠正」，
戴明把这种本能整理成四条规则并逐一重演：

> **规则一**：把漏斗对准靶心，**保持不动**——落点散布最小，系统最稳；
>
> **规则二**：每落一球，就按「上次落点偏离靶心多少」反向补偿挪动漏斗
> ——散布反而放大；
>
> **规则三**：每落一球，把漏斗挪到上次落点的正上方、不再看靶心——落点
> 随机游走，散布持续放大；
>
> **规则四**：每落一球，把漏斗对准上一落点投出——漂移发散，永无宁日。

戴明的结论（大意）：**若过程处于稳定状态，对它做出响应性调整，只会使变
异越来越大**——把共同原因（系统固有散布）当特殊原因（真信号）去治，每
一次治疗都有「充分的理由」（上一球确实偏了），而序列上净效果为负。全书
另一主线是**红珠实验**：产出波动主要来自系统本身而非操作者——把波动记
到动手的人头上，是管理的失败；以及管理的「经验丛林」诸陷阱——**凭单次
结果行动**位列其中。

一眼看去，四条规则里只有规则一是德，二三四都是病；但落在单帧里，二三四
的每一步都像规则一一样「正确」——**单帧皆有据，序列皆成灾**：这正是任
何单帧审计的结构盲区，也是戴明要用一个确定性实验把它钉死的原因。

## 为什么是这本书

agent 也有自己的靶心与落点：**验证态的波动**。它跑 `npm test -- auth`
红了（可能是真回归，也可能只是环境抖动——flaky、网络、缓存），于是改一
笔代码，复跑绿了；过几步又红，又改一笔，又绿……每一帧都经得起任何一层
单帧审计：上帧确实红了（有据），这一改确实成功了（有绿），交付时确实全
绿（没有红上宣绿）。但拉通序列看：红→改→绿→改→红→改→绿——**叠了三
次、搅了三次，净效果趋零**，而每次搅动注入的都是实打实的新改动、新风险
面。这就是**修复乒乓**（churn）：戴明漏斗规则二/规则三在 agent 身上的
逐帧重演——把随机波动当信号，逐帧响应，越治越荡。

这一病在所有相邻层的账本上都无处立案：zhizhi 数证据之有无（跑过就有据，
对象盲）、jiubian 勘失败后的行为重复（盲捶是「同一失败再捶一次」——振荡
的每一帧都成功绿过，**盲捶结构盲**）、huiji 审痊愈宣称对未决红（本场景
最后是绿的，无红可盖）、zhizu 量单次变更规模（每一次小刀都不巨）——**每
一层都审一帧的成色；没有一层审同一对象验证态的时间序列净效果**。戴明在
四十年前就把这一结构盲区做成了确定性实验：规则一（守准）健康，规则二/三
（响应性施治）成灾——判据不在任何单帧里，只在序列里。

《转危为安》教的本层两半，恰是本层的两半。一半是**波不皆信号**：红绿交
替若无搅动形迹（一次没改），那是环境之波（红珠实验——波动来自系统），
记风浪留痕而不入罪；另一半是**治必对波**：交替之间确有对它的搅动（改了
两次以上），波被搅得翻转三叠，就是荡案——**单帧皆真的施治，序列上叠三
搅二即荡**。

## 逐条映射

| 《转危为安》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 漏斗规则一：对准靶心保持不动 | 单轮修复收敛：红→改→绿，结束 | **叠数 ≤2 静默**（健康的循环不判——守准之德不入罪） |
| 漏斗规则二：按上帧偏差反向补偿 | 抖一次它改一次：红→改→绿→又红→又改 | **波账**逐对象记状态笔序列；**搅笔**记交替间改动形迹 |
| 漏斗规则三：弃靶逐迹、随机游走 | 每次改动都有「充分理由」（上帧确实红）——单帧皆真 | **单帧审计结构盲**：相邻各层全审一帧，本层审序列净效果 |
| 漏斗规则四：漂移发散 | 修复乒乓净效果为零甚至为负，改动面越滚越大 | **荡案** +30/案 单案即红，荡值 min(60, 30×案) |
| 红珠实验：波动来自系统而非操作者 | flaky/网络抖动不是代码之罪 | 叠≥3 而搅窗 <2 → **风浪**注记 0 分（环境之波留痕不入罪） |
| 「对稳定系统施治只会放大变异」（大意） | 每次施治都合理、序列净效果为负 | 判据锁死在序列：**叠 ≥3 ∧ 搅窗 ≥2 → 荡**，与宣称、成色、规模全部正交 |
| 「凭单次结果行动」列经验丛林之陷阱 | 逐帧决策、无序列观 | 荡牌块供给序列全景（翻转史与搅动史当众留痕） |
| 变异之识（profound knowledge 的第一课） | agent 不辨信号与噪声 | 风浪注记即噪声检出器——把 flaky 从乒乓里摘出来还给任务方 |
