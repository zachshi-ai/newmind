# Skill：开工先体检（治未病 · weibing）

## 何时用

你要开工任何**非平凡任务**（预计超过 10 轮工具调用、涉及写入、或被人托付验收的任务）之前。一句话：**第一枚 token 烧掉之前，先让任务书过四诊。**

## 协议（三步，缺一不可）

### 第 1 步 · 立任务书（charter）

把任务写成机器可读的体检对象。最低形态只要三行；条款缺席本身就是症状，别拿"还没想好"当借口——想不清楚恰恰是要报给任务方的病灶：

```json
{
  "version": 1,
  "id": "t-001",
  "brief": "任务原文一句话（体检的闻诊对象）",
  "paths": ["src/v2/"],
  "scope": { "allowRoots": ["src/v2/", "tests/v2/"] },
  "acceptance": [
    { "ref": "a1", "name": "bash", "argsContains": "npm test" },
    { "ref": "a2", "artifact": "reports/repro.txt" }
  ],
  "stop": { "maxSteps": 200, "maxMinutes": 45 },
  "requires": { "files": ["package.json"], "tools": ["node"] }
}
```

骨架用 `weibing template` 生成。

### 第 2 步 · 体检

```console
$ weibing exam t-001.json --cwd <仓库根>
```

读三样东西：

- **病灶**（W1–W6）：无验 / 无界 / 无止 / 相克 / 妄证 / 缺资。每条附医嘱与传变（会烧到下游哪一层）；
- **险兆**：brief 里的无边之词与无度之动词（"所有""优化"）——萌级黄灯，不拦但要点名；
- **病值与分带**：安(0–15) / 萌(16–39) / 病(≥40)。退出码 1 = 病带，CI 会拒收。

### 第 3 步 · 处方，然后才开工

- **病带**：逐条执行医嘱——补终验、立愿界、立止法、收敛矛盾、修证备资——改完重跑体检到退出码 0。医嘱补出来的 `scope` / `acceptance` / `stop` 就是下游治理层（知止 / 正念）的输入：先有体检，契约才立得住。
- **萌带**：可以开工，但把险兆逐条翻译成可数的界（"所有模块"→点名列出；"优化"→改成可对账的终验）再动手。
- **探针 unprobed**：报告里 `probes.unprobed > 0` 说明有些声明没核对过（没给 `--cwd`）——补上再跑，不要带着没核对的证开工。

## 红线

- 体检**诊而不拦**：退出码是建议，不是枷锁；但绕过体检开工的任务，出 mid-run 事故时不得把"没人提醒"当理由——医嘱在案。
- 体检**零 LLM**：别用另一个模型代替 `weibing exam`——不可复现的体检等于没体检。
- 词表可以扩展（`--lexicon`），声明权在任务方；报出来的每一条都可复现、可重放。
