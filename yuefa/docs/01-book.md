# 01 · 选书：《史记》—— 高祖本纪，约法三章

## 原文

《史记》（西汉·司马迁撰；本文引文据维基文库《史记·高祖本纪》同文）：

> 父老苦秦苛法久矣，**诽谤者族，偶语者弃市**。
> 吾与诸侯约，先入关者王之，吾当王关中。
> **与父老约，法三章耳：杀人者死，伤人及盗抵罪。**
> **余悉除去秦法**，吏民皆安堵如故。

刘邦入关，召诸县父老豪桀而约：约是**公开**的（当众与父老立，不是密室之诏）、
**可数**的（三章耳——法多了就背不动，可数才可守）、**削法须明言**（余悉除去
秦法——废掉哪条是当众宣布的，没有一个旧法是「无声失效」的）。此后「吏民皆
安堵如故」：约在，人知道自己倚仗的东西还在。

三章之重的排序也有讲究：**杀人者死**——最重的刑配最重的罪，一眼可断，
不须审议。

## 为什么是这本书

仓库的公共接口面就是一份「与父老之约」：`export` 出去的每个函数、每个类，
都是下游（别的模块、别的仓库、下一个会话）**正在倚仗的条款**。agent 接到
一单重构，读入模块（看见了全部条款），落笔时顺手删掉两个导出——测试没
覆盖它们（死代码测试盲区），编译若放行则全绿上库，**下游 import 当场炸开**：
「昨天还能 import 的函数今天没了」，而这一笔在会话里**全绿、无声、账上无痕**。

病的精确形状不是「改了代码」（改是合法的），而是**「削约无声」**：法三章
被削掉一章，却没有任何「余悉除去」的明言——原案弃置无告、公面收缩无账。
cargo-semver-checks、api-extractor 这些构建时工具能对出两个版本间 API 差了
什么，但它们要构建、要语言服务，而且对不出**那道更细的问题**：这一笔写，
削掉的是**它读时看见的**哪几个名、削得**有没有声**——「知情」只发生在会话
流里的那次读取上，这是任何仓库快照工具都看不见的时刻。

《史记》把这件事的治理姿态说尽了：**约是公开的**（公面可数、约牌公示）、
**削约必须有声**（余悉除去——明削免咎）、**哑削是重罪**（杀人者死——
单名即红）；反过来，**约外不治**（诽谤者族偶语者弃市的秦苛法恰是反面：
法不及私，私有实现随意重构，本层不审）。本层把这四面临摹成一条治理姿态：
**记账不禁行**（削可以发生，拦是 zhizhi 的地盘）、**读时立约**（agent 读取
文件那一刻，公面成为它知情的约定——约据唯读）、**两序可证**（约据 → 落笔，
其间世据折旧）——「削要削在明处」不是纪律劝告，是唯一让账面归白的行为。

## 逐条映射

| 《史记·高祖本纪》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 与父老约，法三章耳（公开、可数的约） | 模块 `export` 出去的公共名——下游正在倚仗的条款 | **公面**（约形词法从流内正文提取的名的集合，可数） |
| 读过卷宗才谈得上知情 | agent 读取文件那一刻，看见了全部条款 | **约据唯读**（observe 族成功 ∧ 正文非空 → 该径立约据；没读过就写，无约可言——静默） |
| 落笔削掉其中一章，无一语声明 | 重构顺手删掉导出函数，测试不覆盖、全绿上库 | **哑削**（公面有名而落笔无、又无弃约之声 +30/名 cap60——单名即红） |
| 余悉除去秦法（削法当众明言） | 弃用注记随削同落：`@deprecated` 与名同在码中 | **明削**（写入正文同行含名 ∧ 弃词——有声之削 0 分注记） |
| 吏民皆安堵如故（约在，下游安稳） | 名还在，下游 import 照常 | **守约/展约**（面无失或只增不减——静默，全活行） |
| 诽谤者族、偶语者弃市（秦苛法之繁） | 把私有实现也管起来——法不及私 | **约外不治**（唯约形命中的公共名入面；私有实现随意重构不审） |
| 诸侯先入关者王之（约变要凭新约） | 其间他人已合法削面，落笔只是保持现状 | **世据折旧**（约据与落笔间最近异文写据之面折旧约面——已在世据里失的名不再记本笔） |
| 杀人者死（重罪重刑一眼可断） | 公共名是离散条款，削一即是 breaking | **门 30**：哑削单名 30 即红——一刀一断，不须审议 |
