# 02 · 问题：Agent 公共接口面收缩（读时之约无账）

## 谁在什么场景下的什么问题

**谁**：用 agent 做重构/清理的工程师，以及所有倚仗这些公共名的下游——
同仓的下一个模块、另一条并行会话、另一个仓库、npm 语义化版本承诺的每一个
使用者。

**场景**：agent 接到「清理 utils 模块」，第 3 步读入 `src/config.js`
全卷（公面：`parseConfig`、`formatDate`、`VERSION` 三个导出），第 20 步
落笔整卷重写——`formatDate` 没了。它「觉得」没人用（死代码）、或顺手
「简化了接口」；仓库内的测试恰不覆盖它（测试盲区），TypeScript 若因
`skipLibCheck`/下游不在本仓而放行，全绿上库。下游 import 当场炸开：
「昨天还能用的函数今天没了」；npm 包场景则是一次无声的 semver 崩坏。
宣布完成时它说的是「重构完成」，不是「我删了 formatDate」——**原案的
弃置没有被告知**。

**问题**：公共接口面的**约**（读时看见的条款在落笔后还在不在、削得
有没有声）无账：

- **breaking 静默发生**：削名本身是一次完全合法的写入，测试照跑、diff
  照交，绿的信号一个不少——少的那个东西在仓库之外（下游的 import 语句），
  本仓任何一层都看不见；
- **意图与授权无从考**：重构单本来就是「可以删东西的活」——但「授权削
  哪些」任务方从没声明过，agent 也从没问过；事后分不清「有意弃用」（会写
  迁移注记）还是「顺手一削」（无声消失）——**声音可考而无人考**；
- **下游信任是慢资产**：一次哑削就够让所有会话学会「不敢信这个仓库的
  公面」；cargo-semver-checks / api-extractor / griffe 都是构建时快照
  工具，要构建、要语言服务，且全都对不出「**这一笔写削的是它读时看见的
  哪几个名**」——知情只发生在流内那次读取上；
- **相邻层的空白地**：mingshi 审**幻名**（写下的名没有实——引用了不
  存在的），反向的「实被削名」（既有的名被删了）它无案可记；huashui 审
  **行集时鲜**（覆：陈线重现 ∧ 新线再失，双线阈值）——纯删一个导出是
  净向，它账上天然无罪；kaocheng 考**契上物**（任务方立契的交付物），
  公面不是契上物；hengfa 审**典面**（章程规矩源凡改即案），`src/*.js`
  不是典；pingzhun 审**籍面**（依赖清单四案），导出面不是籍；fangchuan
  扫**吞错形**（错误之口），削名不是吞形；zhizu 量**写之量**——三行的
  削名 diff 在行数上不可见——「公面之约」是全仓空白。

## 问题（治什么病）

一个病形，两个案别，全部真实存在、全部有据可查：

| 病形 | 流内词面 | 现实对应 |
|------|----------|----------|
| **哑削** | 径 P：约据（读取，公面含名 X）→（其间无异文写据、无无文之写）→ 落笔公面失 X，且写入正文中无「弃词 ×X」同行 | 顺手删公共导出，无注记无声明——下游 import 炸 |
| **明削**（注记档） | 同上，但写入正文存在同行含名 X ∧ 弃词（@deprecated/弃用/移除…） | 有声之削：弃用注记随削同落——0 分点名 |
| **约改不判**（注记档） | 约据与落笔之间夹无文之写（edit 族不携全文） | 其间面可能已变而不可见，判定不得——诚实沉默 |
| **无约静默** | 落笔前该径无成功读取 | 没读过就无约可言——盲写归稽疑/审曲/知止地盘，本层不审 |

价值锚点：公面提取是显式词法（约形默认表 ∪ 册增形，零 LLM）；「知情」
的凭据是流内的成功读取（约据唯读——与 zhixing「知面取文于流」同证可行）；
「有声」的凭据是写入正文同行共现（名 ∧ 弃词）——三件事全是流内可证的
确定性事实。本层不做语义判断（不判这次删值不值——重构正当与否裁决权归
人：约册开门明言即免案），只做词法可证的三问：**读时有哪些名、落笔还剩
几个、削掉的那几个有没有声**。

## 价值（为什么不是伪需求）

1. **每一笔都真实落在仓库里**：被削的名是既成的公共承诺（下游 import
   在别处真实存在），削面是既成的 diff 事实——两者的差集全在流内，不是
   「可能有害」的推断；
2. **意图可豁免而削面须留痕**：重构确实正当（任务就是删废弃 API）——
   约册开门明言即免案；agent 也可以自证其声（弃词随削同落即明削免分）；
   无册之案也不是罪，是**账**：留痕有价、点名有责、门禁有阈；
3. **记账不禁行**（三章之外不治）：不拦写（拦是 zhizhi 的地盘）、不改
   内容、不跑语言服务——判定全部发生在流内词面上，观察永不反噬；削可以
   发生，但每一笔都要当众留痕——「余悉除去」的透明，由账本供给；
4. **可证伪**：约形词法、两序折旧、分数公式全部锁死于 03；同流重放必得
   同判词；跨项目历史流可验尸复算——错了改实现，不改标准。

## 产品形态

- **约法式插件**（DeepSeek Harness 插件层，Cordis，结构性零拦截）：挂
  `tools/result` 观察口，约据入账，约牌块接缝供给；
- **零依赖审计 CLI**（`yuefa`）：多流离线合审（折旧与世据合审归并），可
  验尸任何历史会话；
- **Agent Skill**：给派活方与 agent 的开门/弃用声协议。
