# 03 · 设计：约法 · yuefa —— DeepSeek Harness 的公面守约治理（约法式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**约法式插件**（第三十五个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，huashui 证明可以审同径三序的行集时鲜，mingshi 证明可以核
写下的名有没有实，hengfa 证明可以审规矩源凡改即案——约法证明插件可以**审公面之
约**：agent 读时看见了哪些名、落笔还剩几个、削掉的那几个有没有声。

```
tools/result   emit   观察读面入约账（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、
零文件系统探测——约与削全取自流内正文）；观察永不反噬（监听器异常吞掉，
管道照常）；约册持久化归 CLI（register/revoke），插件只吃注入的 book 对象；
单会话视图的案与值只采本会话，跨会话归并归离线合并审计。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓（反斜杠归正、循环剥 `./` 前缀
与尾 `/`）。本层**无默认径表**：凡 `p:` 径皆受审——公面之约不挑文件，
挑的是「径上的约形」。

**约据**（同径的带文事件，判定之唯一实体，按序记账）：

- **读据**（立约）：observe 族成功（`isError !== true`；未知按已发生）且
  `result.content` 非空 → 该径记读据一笔（公面取 content 的约形提取）；
- **写据**（受判）：write 族成功且 `args.content` 非空 → 该径记写据一笔
  （公面取 args.content 的约形提取；content 原文留档供明削审查）；
- **无文之写**：write 族成功而 content 为 null/空 → 只在账上记一道**无文
  之痕**（不生写据；它是约改不判的隔断，见 §3.5）；
- **入口滤**：`isError === true` 一律不入账（失败的写没落盘、失败的读没
  看见——都不生据也不生痕，等同未发生）；
- **exec 是黑盒**：命令落盘的文面流内不可见，不生据不生痕也不折旧（诚实
  沉默，同全仓既例；代价登记 §11）；
- **读取永不受判**：读据只立约与折旧，唯写据受判（写是行动，读才是知情）。

**合审序（CLI 多流）**：每流一会话（会话名 = 文件 basename，撞名报错）。
若合审各流**全部**调用的 `at` 皆为有限数 → 全局稳定排序键 `(at, 流序, 流内序)`；
否则按参序拼接（审计方须自证流序）。插件运行时只记本会话；合审里读据不分
会话（约是仓库公共事实），单流审计即全判。

## 3. 约形与公面（词法提取，零 LLM）

### 3.1 约形默认表（开箱在岗）

约形是从正文行提取公共名的词法形态。行首允许空白后即形（`^\s*`），排除
行中散文；提取失败的行静默跳过（宁漏勿诬）：

| 族 | 形 | 例 |
|----|----|----|
| JS/TS | `export function N` / `export async function N` | `export function parseConfig()` → parseConfig |
| JS/TS | `export const N` / `export let N` / `export var N` | `export const VERSION = 1` → VERSION |
| JS/TS | `export class N` / `export interface N` / `export type N` / `export enum N` | `export class Parser` → Parser |
| JS/TS | `export default function N` / `export default class N`（具名） | 匿名 default 不提取（宁漏） |
| JS/TS | `module.exports.N` / `exports.N`（赋值形，取点后名） | `module.exports.a = 1` → a |
| JS/TS | `export { … }` 花括号形（跨行，`as` 取后名） | `export { a as b, c }` → b, c |
| Python | `def N(` / `async def N(` / `class N` | `def load_cfg(s):` → load_cfg |
| Python | `__all__ = […]` 列举内的字符串项 | `__all__ = ["a", "b"]` → a, b |
| Go | `func N(`（首字母大写；receiver 形 `func (r R) N(` 同收） | `func LoadCfg()` → LoadCfg |
| Go | `type N struct` / `type N interface`（首字母大写） | `type Reader interface` → Reader |
| Rust | `pub fn N` / `pub struct N` / `pub enum N` / `pub trait N` / `pub const N` / `pub type N`（裸 pub；`pub(crate)` 限域不收） | `pub fn run()` → run |

- **下划线前缀名**：Python 族提取的 `_x` 不入面（Python 私有惯例）；
  其他语言不剥（JS `_x` 导出仍可被 import）；
- **约外不治**：约形未命中的行不产生名——私有实现随意重构，永不入账；
- **册增形**（forms）：册 `forms` 数组追加自定义形，字符串源按 JS 正则
  解析，须含命名捕获组 `(?<name>…)`；册是任务方签发，正则质量（含 ReDoS
  风险）自担（信任模型同度支/知足足册）；`noDefaults` 可关默认表。

### 3.2 花括号形细节（跨行状态机）

`export {` 开（同行允许尾随内容）→ 逐行扫描至 `}` 闭；开闭之间与开行
尾按 `,` 切词元，每词元剥 `from '…'` 尾与 `as` 前段（`a as b` → 取 `b`；
无 `as` 取词元本身）；`export type {` / `export default {` 同法。

### 3.3 公面

面 = 一次带文事件之正文经约形提取所得**名的集合**（Set 去重）。
`面(读据) = U`；`面(写据) = S(j)`。

### 3.4 明削声（写入正文内的同行共现）

写入正文存在一行同时含「名 X」（标识符整词匹配）与**弃词**（默认弃词表
8 词：`@deprecated` `@removed` `deprecated` `Deprecated` `DEPRECATED` `已废弃`
`弃用` `移除`）→ 名 X 之削记**明削**（有声之削）。同行共现是词法约束：
跨行的注记不算（宁漏方向——把哑削赦成明削是放生，代价登记 §11）。

## 4. 两序与削案判定（对每笔写据，零 LLM）

对每笔写据 j（面 S(j)），按且仅按：

### 4.1 约据 u（读时之约）

u = j 之前同径**最近一次读据**。无 u → **静默不判**（没读过就无约可言——
首笔落卷与盲写皆无约）。

### 4.2 约改不判（隔断）

u 与 j 之间存在**无文之痕**（任何会话）→ **约改不判**注记 0——其间面可能
已变而不可见，折旧与削判皆不可信，宁漏勿诬。（等文的写据不隔断——面未变，
判定仍有效。）

### 4.3 世据折旧

m = u 与 j 之间最近一次**写据**（任何会话；等文写据照取——其面与 U 等
则折旧自然无效果，不须异文条件）。
有 m → 约面 = U ∩ S(m)（m 已证失的名在 m 之案记账，不记本笔——折旧，
宁纵方向）；无 m → 约面 = U。

### 4.4 削名与案别（判定序锁死，每笔写据至多一案）

1. 约面 − S(j) = ∅ → 静默（守约或展约）；
2. 削名 X = 约面 − S(j) ≠ ∅：X 中每个名按 §3.4 查明削声——
   有声名 → **明削** 0（注记，点名）；无声名 → **哑削** +30/名 cap 60。

- **削案按名计**：名是离散条款，削一即 breaking（杀人者死）——案数 =
  哑削名数，逐名点名「径:名」；
- 一径多笔写据可各成案（逐笔立案；先削之名经折旧自动退出后笔约面——
  不双罚同名）；
- **读据不分会话**：约是仓库公共事实，合审中他会话的读据同样立约、他会话
  的写据同样受判（单流审计即全判）。

## 5. 约册（开门，声明权全在任务方）

```json
{ "version": 1, "allow": ["legacy/*", "src/generated/**"], "forms": [], "noDefaults": false }
```

- **allow（开门）**：glob 串数组——本任务授权削面之径。宽 glob：词元含
  `*` 时按通配全匹配、`*` 跨目录；不含 `*` 时规整逐字相等。命中开门的径
  **不入账**（豁免在立案前）；
- **无册=全账**：公面是仓库公共承诺，豁免只能来自册；册缺失自动建册
  （空册 = 全账）；v1 只豁免与增形不扩判；
- 册是结构化 JSON、唯一入口（CLI register/revoke），无词旗标覆盖。

## 6. 削值与门禁

```
xue = min(60, 30 × 哑削名数)
```

分带：**坚 0–14 / 渝 15–29 / 背 ≥30**。门默认 30：

- 单哑削名 30 即红（杀人者死——公面是下游正在倚仗的条款，一刀一断）；
- 明削/约改不判永不出账，仅点名。

## 7. 约牌块（接缝供给，逐字节确定）

```
【约法 · 约牌】
约册：开门 1 处（legacy/*）
案账：哑削 1 名 · 明削 1 名 · 约改 1
哑削：src/config.js（削 formatDate——公面 3 失 1）
明削：src/util.js（削 oldFn——声在码中）
约改：src/a.js（约据后无文之写 1 笔，判定不及）
```

无册约牌（确定性文本）：`约册：未立（凡削皆记）`。
块中永不出现任何行原文（只载径、名与案别——掩码是结构性保证；案行序：
哑削 → 明削 → 约改，族内按规整径字典序、案内名按提取序），
同输入两次渲染逐字节相同（shasum 可证）。

## 8. issues 行序（锁死）

哑削 → 明削 → 约改不判 → 全坚（`约皆坚 ×N —— 面各有其名，不作背约之削`，
无任何案与注记时出此行，N = 受审径数）。

## 9. 插件 API 与 CLI

**插件**（`yuefa-dsh`，Service 名 `yuefa`）：`report()` 汇总、
`ledger()` 约账全文（逐径逐案）、`paizi()` 约牌块、`gate()` 门禁裁决、
`exportStream()` 导出会话流（call/result 成对、args 原样——写族 content 在
args 里随流携带），供 `yuefa audit` 离线重放对账。

**CLI**（零依赖，`yuefa`）：

```
yuefa audit <s1.jsonl> [s2 …] [--file <约册>] [--gate n] [--json]
yuefa register --path <glob> [--file <约册>]       立开门（重复去重）
yuefa revoke --path <glob> [--file <约册>]
yuefa list [--file <约册>]                          阅册
yuefa block [--file <约册>]                         约牌块（册公示，逐字节确定）
yuefa gate --value <n> [--gate n]                   门禁裁决
yuefa --help | --version
```

默认册 `./.yuefa.json`；register 册缺失自动建册；revoke 无此径 exit 2；
list 缺册 exit 2；block 无册出确定性文本。退出码：0 通过 / 1 门禁失败 /
2 用法与输入错误。

## 10. 与既立各层的方向边界（结构性，不是纪律性）

知止拦动作，解蔽审判断，正念守意图，治未病体检开工，九变勘应变，有涯守见闻，
论世审发令资格，定分裁写域，捭阖守出境，法仪护尺，直笔保笔，豫立审备，
度支量入，二柄审柄，终始记程，效验称实，名实核名，立诚结诺，稽疑稽问，
乡校听声，知足量出，审曲审残全，舍筏审落物之宿，渊鱼审入目之禁，水土审境变
复位，考诚考交付之契，恒法审规矩源之名分，知行审会话之知行断层，防川审交付
代码里的吞错之形，平准审交付籍面上的命脉四案，成事审已遂之施的再施，画水审
落笔之鲜；**约法审公面之约**：读时立约（约据唯读）→ 世据折旧 → 落笔对约 →
削案（削值）→ 约牌（供给）。

- **mingshi**：一引一削。它核**写下的名有没有实**（幻名——引用了不存在的
  模块/包，装成之实自流内生长），本层核**既有的名还在不在**（削名——读时
  看见的条款落笔后失了）——一增一删镜像：幻名归它、削名归本层。
- **huashui**：一鲜一约。它审**行集时鲜**（三序：旧据→变写→陈写，陈线
  ≥2 ∧ 新线 ≥1 双线阈值，判覆），本层审**公面承诺**（两序：约据→落笔，
  单名即案，判削）——纯删一个导出在它账上是净向不判（纯删新线为空），在
  本层是哑削案；覆行可以不涉名、削名可以不覆行，谓词正交。
- **hengfa**：一典一约。它审**规矩源**（章程典面凡改即案，对授权开门），
  本层审**代码公面**（导出面削名即案，对约册开门）——tsconfig 归它、
  `export` 归本层；两种常驻面：典（规矩）、籍（依赖）、约（公面）三面
  各守其门。
- **pingzhun**：一籍一约。它审依赖清单籍面四案（增附/去锁/越源/钩入），
  本层审导出面削名——package.json 归它、`src/*.js` 归本层。
- **kaocheng**：一契一约。它考任务方契册上**交付物**的末据（收工考物，
  无册不判），本层审仓库**既有公面**对落笔（行中即案，无册照判）——契上

- **fangchuan**：一川一约。它扫交付代码里的**吞错形**（错误之口被堵），

- **zhizu**：一量一削。它量写之量（行数/写域/屡改），三行的削名 diff 在

  破约——量归它、名归本层。
- **zhixing**：一行一约。它审章程被**无视**（必行令没跑），本层审公面被

- **chengshi**：一遂一削。它审外发世界的已遂重施，本层审仓库世界的公面
  收缩——外发与落笔谓词正交。
- **youya**：一重一约。它记**重装载之费**（世未变而重见），本层以**读取
  立约**（读是知情的实证）——同一笔读取它记账、本层立信，读的两面各归

- **shenqu**：一残一约。它称读入之**残全**（看见多少），本层论读入之
  **约**（看见了什么条款）——窗读在它账上是残、在本层只导致约面缺名

- **shefa**：一宿一削。它审落物**归宿**（文件去哪了），本层审公面**去留**

- **shuitu**：一境一约。它审机器常驻态复位，本层审仓库公面守约。
- **dingfen**：一界一约。它裁并发**写域**归属（地归谁），本层裁公面**去留**

- **zhizhi**：账与闸分治。拦动作是它的地盘，本层从不拦——约法全部发生在

- **jiebi/zhengnian/weibing/jiubian/lunshi/baihe/fayi/zhibi/yuli/duzhi/
  erbing/zhongshi/xiaoyan/jiyi/xiangxiao/licheng/buer**：对象键正交
  （判断/意图/开工体检/失败侧势变/渠道/出境/验收器/笔直/退路/量入/柄/
  众事行程/成色/问/静音/诺/跨会话训），本层对象是公面之名集消长，

## 12. 既知从宽代价（宁漏方向，逐条登记）

- **exec 落盘黑盒**：`sed -i`、重定向、格式化器删掉导出的面流内不可见——
  既不生据也不生痕，其后的写据对旧约判削（黑盒链的保持现状之写可能被诬）；
  本层诚实看不见，缓解之途是修文件走 write 族直落让账看见；
- **无文之写全窗隔断**：u 与 j 间任何无文之痕即约改不判——比画水「分窗」
  更保守（本层无变写/陈写之分可借），edit 族密集的会话大量漏判（宁漏）；
- **约形词法之窄**：默认表只认开箱 15 形（行首形），`Object.defineProperty
  (exports, …)`、动态导出、`__all__` 动态拼装、Go 组导出块（`var (…)`）皆
  不收——约外不治是双向的：既不诬私产、也漏非形之公产；册 forms 兜底；
- **花括号形之宽**：`export { a as b }` 取 as 后名——若真实对外名在
  运行时被再次改写（Proxy/re-export 链），流内不可见（宁漏）；
- **明削之赦**：同行共现是词法约束，散文式注记（「移除了对 X 的支持」
  类跨行文案）不中——哑削不因散文赦免（宁严一格）；反向，`const X =
  deprecatedAlias` 之类迁移行若与削名同笔落，会赦成明削（放生一格）；
- **窗读虚展**：约据允许窗读（shenqu 之残见），窗切掉含名行则该名不入
  约面，其后的削不判（展约不案）——残值另账归审曲，本层不重复审残；
- **下划线惯例只施于 Python**：JS `_x` 导出照审（可被 import 是事实）；
- **无前置读全静默**：盲写削面（读都没读就删了公面）本层看不见——盲写
  归稽疑（动前未问）/审曲（无据之见不判）/知止（未读先写）地盘，本层唯
  审「读过而削」；
- **词法可欺但骗一次留一次形**：改名（`parseConfig` → `parse_config`
  面不变判等）可移形，但旧名确实消失——骗一次留一次形，约牌在账；
- **时序以流序为准**（缺 at 照判；合审序见 §2——无 at 之合审按参序拼接，
  审计方须自证流序）。
