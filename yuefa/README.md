# 约法 · yuefa —— DeepSeek Harness 的公面守约治理

> **「与父老约，法三章耳：杀人者死，伤人及盗抵罪。」**
> **「余悉除去秦法」，吏民皆安堵如故。——《史记·高祖本纪》**

仓库的公共接口面就是一份「与父老之约」：`export` 出去的每个函数、每个类，
都是下游（别的模块、并行会话、另一个仓库）**正在倚仗的条款**。agent 接到
一单重构，读入模块（看见了全部条款），落笔时顺手删掉两个导出——测试没
覆盖它们，全绿上库，**下游 import 当场炸开**。这一笔全绿、无声、账上无痕。

**约法**给 DeepSeek Harness 装上第三十五个能力类型：**约法式插件**（结构性
零拦截）+ 零依赖审计 CLI + Agent Skill。它不拦写（账与闸分治，拦是知止的
地盘）、不做语义判断（不判这次删值不值——许削授权归任务方的约册明言），
只做词法可证的三问：**读时有哪些名、落笔还剩几个、削掉的那几个有没有声**
——读时立约（约据唯读）→ 世据折旧 → 落笔对约，单名即案。

## 快速开始

```bash
cd your-repo
npm install github:zachshi-ai/newmind#yuefa-dsh    # 或复制本目录

# 开工（可选）：立约册——任务本就是删废弃 API 的重构单先许削
yuefa register --path "legacy/*"                   # 许削授权（* 跨目录）

# 收工：审削
yuefa audit session.jsonl --file .yuefa.json       # exit 0 通过 / 1 门禁红 / 2 用法错
yuefa audit s1.jsonl s2.jsonl --json               # 多会话合审
yuefa block --file .yuefa.json                     # 约牌块：约册与案账公示（逐字节确定）
```

无册照判：不立册也审——无册 = 全账，公面是仓库公共承诺，许削只能来自册。

## 判定语义（docs/03 锁死）

**约据唯二**（无默认径表，凡 `p:` 径皆受审）：observe 族成功 ∧ 正文非空 →
读据**立约**；write 族成功 ∧ `args.content` 非空 → 写据**受判**；无文之写只
留痕（约改不判的隔断）；`isError=true` 不入账；exec 是黑盒。

**约形词法**（零 LLM）：默认 15 形行首形（JS/TS export 六式 ∪ Python
def/class/`__all__` ∪ Go 大写 func/type ∪ Rust 裸 pub）∪ 花括号跨行形
（`as` 取后名）∪ 册 forms 增形；`_` 前缀名 Python 不入面、`pub(crate)` 限域
不收——约外不治。

**判定序**（每笔写据）：无前置读 → 静默（无约不判）；约据与落笔间有无文之
痕 → **约改不判**注记；世据折旧（m = 约据与落笔间最近写据，约面 = U ∩ S(m)
——他人已削的名不记本笔）；削名 ∅ → 静默（守约/展约）；削名非空 → 查明削
声（写入正文同行含名 ∧ 弃词 8 词 → **明削** 0 分；否则**哑削** +30/名）。

| 案 | 判定 | 分值 |
|----|------|------|
| **哑削** | 公面有名而落笔无、又无弃约之声 | +30/名 cap 60，**单名即红**（杀人者死） |
| **明削** | 弃词与名同行共现（`@deprecated X` 类） | 0（点名——余悉除去，削在明处） |
| **约改不判** | 约据与落笔间有无文之写 | 0（注记，诚实沉默） |

**削值** = min(60, 30 × 哑削名)。分带**坚 0–14 / 渝 15–29 / 背 ≥30**，门默认
30：单哑削名即红。

**清白道**：没读过就写不判（无约）、守约/展约静默、折旧后保持者静默、明削
有声 0 分、许削在册免案。

**约牌块**（接缝供给）：约册公示 + 案账清点 + 逐案点名（径、名与案别），
永不携带任何行原文——掩码是结构性保证；同输入两次渲染逐字节相同（shasum
可证）。

## 与既立各层的边界（结构性）

- **名实**（一引一削）：它核写下的名有没有实（幻名——引用了不存在的），
  本层核既有的名还在不在（削名——读时看见的条款被删了），一增一删镜像；
- **画水**（一鲜一约）：它审行集时鲜（三序覆写，纯删净向不判），本层审公面
  承诺（两序削名，纯删恰是靶点），谓词正交；
- **恒法**（一典一约）：它审章程规矩源凡改即案，本层审代码公面削名即案——
  tsconfig 归它、`export` 归本层；典（规矩）、籍（依赖）、约（公面）三面
  各守其门。
