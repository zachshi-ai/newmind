# 约法 · Yuefa — Agent 协作协议

> **「与父老约，法三章耳：杀人者死，伤人及盗抵罪。」**
> **「余悉除去秦法」，吏民皆安堵如故。——《史记·高祖本纪》**
>
> 你读入模块的那一刻，它的公共导出面就成了你知情的约定：下游正倚仗着那些
> 名字。本协议不限制你落笔（拦是知止的地盘），它要求：削约必须削在明处——
> 要么任务方的约册许削在先，要么弃用注记随削同落；无声消失的每一个名，
> 都在约牌上点名。

## 何时用此 Skill

- 工程师想防住「agent 重构顺手删公共导出、下游 import 炸」；
- 发 npm 包前想审「这一单会话有没有无声破坏语义化版本承诺」；
- CI 需要一道公面门禁（削值 ≥ 30 即红——单哑削名即红）；
- Agent 需要自查：这一笔写，削了读时看见的哪几个名？削得有没有声？

## 给派活的工程师

```bash
cd your-repo
yuefa register --path "legacy/*"                  # 允许削面的径，先立许削
yuefa audit session.jsonl --file .yuefa.json      # 收工审削（exit 码可进 CI）
yuefa audit s1.jsonl s2.jsonl --json              # 多会话合审
yuefa block --file .yuefa.json                    # 约牌块：约册与案账公示
```

- **无册全账**：不立册也审——公面是仓库公共承诺，许削只能来自册；
- **许削是授权**：任务本身就是删废弃 API 的重构单，开工时把径列进约册；
- **门禁**：削值 ≥ 30 即红——单哑削名即红（杀人者死，一刀一断）。

## 给 Agent 的五条纪律

1. **动了公共面，就让世界知道**：删/改名导出时，把弃用注记与名写在**同一
   行**（`// @deprecated formatDate: removed, use calendar`）——同行共现即
   明削免分；跨行的散文注记救不了哑削；
2. **重构单不等于削面授权**：任务说「清理」没说「可以删下游在用的导出」——
   不确定就先问，或让任务方把径列进约册；
3. **保持者不罚**：别人已削的名你照现状保持，经世据折旧不算你的案——
   但你读时的约面与落笔之间的第一刀，账记在落刀者名下；
4. **edit 族是隔断**：不携全文的修改让约改不可见、判定不及——关键文件的
   削面用带全文之写落，让账认得你的刀口；
5. **词法可欺但骗一次留一次形**：改名换行可移形，旧名确实消失——约牌在账，
   削掉的每一个名都点得出名来。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 哑削 | 公面有名而落笔无，正文无弃约之声 | 无声 breaking | +30/名 cap60（单名即红） |
| 明削 | 弃词与名同行共现 | 有声之削 | 0（点名） |
| 约改不判 | 约据与落笔间有无文之写 | 判定不及 | 0（注记） |
| 无约静默 | 落笔前该径无成功读取 | 无约不判 | 0（盲写归他层） |

- 削值 = min(60, 30 × 哑削名)；分带 坚 0–14 / 渝 15–29 / 背 ≥30，门 30；
- 约形是显式词法（JS/TS/Py/Go/Rust 默认 15 形 ∪ 花括号形 ∪ 册增形），
  `_` 前缀名 Py 不入面、`pub(crate)` 不收——约外不治；
- 全部判定零 LLM：读时立约、世据折旧、弃词同行——词法可欺但骗一次留一次形。
