# 01 · 选书：《荀子·解蔽》——为什么两千两百年前的"去蔽"术，治的是 2026 年 Agent 最贵的认知病

## 一、2026 年，Agent 的另一种昂贵失败：不是停不下来，而是"想错了还理直气壮"

本项目（#1 知止 zhizhi）用《道德经》治理了 Agent 的**行为层**：同一动作连败不止损、未读先写、无证据宣称完成——那是"手"的问题。

但跑过长任务的人都知道另一种下午：Agent 在第三轮就锁定了根因假设（"是缓存的问题"），此后它做的一切——检索、读文件、跑测试——都变成了**为这个假设收集辩护词**。它不笨，它甚至很勤奋；它只是从那一刻起再也看不见别的东西。替代方案从未被严肃考虑，反证被解释掉，最后交出一份"结论明确、论证单薄、无从证伪"的报告。

这三个病的共同点：**不是智力问题，不是行为经济学问题，而是认知的几何问题——视角有没有被一个点锁死。**

## 二、为什么是这本书

《荀子》第三十一篇（一说第二十一）《解蔽》，是先秦思想里唯一一篇**把"认知被锁死"当作独立对象来解剖**的文字。它不是泛泛谈"要客观"，而是给了可以直接工程化的三样东西：**蔽的分类学、去蔽的三道门、裁决的程序**。

### 2.1 蔽的分类学 → Agent 失败模式逐条对照

| 《荀子·解蔽》原文 | 直译 | Agent 的病 |
|---|---|---|
| **凡人之患，蔽于一曲，而闇于大理** | 人的祸患：被一个局部遮住，看不见全局 | **单候选锚定**：第一个像答案的假设直奔到底，调试/选型/研究全程只有一个候选 |
| **欲为蔽，恶为蔽** | 喜欢它是一种蔽，讨厌它也是一种蔽 | **自我偏好**：方案是自己写的就更可信；对用户口径的讨好（sycophancy）压过证据 |
| **始为蔽，终为蔽；近为蔽，远为蔽** | 只看开头或只看结局、只看近处或只看远处，都是蔽 | **证据选择性收集**：只检索支持性关键词；只看最近一条日志，不翻最早的报错 |
| **博为蔽，浅为蔽；古为蔽，今为蔽** | 博与浅、旧与新同样能蔽人 | **工具锤子**：手里有某个框架/工具，看什么都是那个框架的钉子；追新框架而无视适用边界 |
| **凡万物异则莫不相为蔽，此心术之公患也** | 万物相异，彼此互为遮蔽——这是心智的通患 | **多 agent 确认级联**：子代理继承同一个引导性提示词，回声变成"共识" |

### 2.2 去蔽三道门：虚、壹、静 → 三条确定性校验

荀子给的解药是**虚壹而静**。妙处在于：他不是劝你"开放心态"，而是给了三条**可判定的条件**：

| 门 | 原文 | 直译 | 工程化翻译（jiebi 的校验项） |
|---|---|---|---|
| **虚** | 不以所已臧害所将受谓之虚 | 不让已经储藏的（旧判断）妨害将要接受的（新证据） | 账本必须登记**至少一条与结论相左的证据**（disconfirming）。零反证 = 第一假设锁死 |
| **壹** | 不以夫一害此一谓之壹 | 不让那一个（别的关切）妨害这一个（当前对象）；兼陈而后能壹 | 账本必须登记**≥2 个被严肃对待的替代方案**，各带最强形式（steelman）与"怎样会杀死它"（kill condition） |
| **静** | 不以梦剧乱知谓之静 | 不让梦幻与骚乱搅乱认知（心如盘水，正错勿动则清明在上） | 每条证据性断言必须**挂可对账的证据引用**；裁决必须带**可证伪条件**——无引用的断言与不可证伪的结论，就是"梦剧乱知" |

### 2.3 裁决程序：兼陈万物而中县衡焉

> 圣人知心术之患，见蔽塞之祸，故无欲无恶，无始无终，无近无远，无博无浅，无古无今。**兼陈万物而中县衡焉。**是故众异不得相蔽以乱其伦也。

把所有候选**并陈**出来（不是心里过一遍，是摆在台面上），在中间**悬一杆秤**（显式的权重与理由），然后裁决。这就是解蔽账本（jiebi ledger）的完整程序：`alternatives[]（兼陈）+ disconfirming[]（去蔽）+ verdict{weights, falsifiable}（县衡）`。

一句"心术之公患"点破了为什么要外置成协议：**蔽不是偶然失误，是心智的结构性通患**——对 Agent 而言更是如此，它的整个"心智"就是一份会话上下文，锁死它的那根锚，就写在上下文的开头几轮里。

## 三、心理学与管理学侧写（同一规律的另外两种语言）

- **Consider the opposite**：Lord、Lepper & Preston（1984, JPSP）的实验证明，"考虑相反面"这一**结构化引导**能显著纠偏，而"要客观"式的空泛叮嘱不能。荀子的"虚"门（强制登记反证）正是 consider-the-opposite 的账本化。
- **事前验尸（Premortem）**：Gary Klein 推广的 premortem 要求在决策前强制写出"它为什么会死"——这就是 kill condition 字段。prospective hindsight 的研究（Mitchell 等，1989）显示强制构造失败解释能显著提高识别真实风险的比例。
- **多 agent 辩论**：Du 等（2023, arXiv:2305.14325）证明**结构化的**多候选辩论提升模型事实性——有效的是结构（并陈+互驳），不是智能本身。这与荀子"兼陈万物而中县衡"在两千两百年后再次汇合。
- **模型的自偏好与讨好**：sycophancy（Sharma 等，2023, arXiv:2310.13548）与 LLM-as-judge 自偏好已被多项研究记录——"欲为蔽，恶为蔽"的现代实证。

**结论一致：对抗偏误靠的是结构性程序，不是更高的智商，也不是更恳切的叮嘱。**

## 四、与提示词方案的根本区别（为什么这不只是一个 ADR 模板）

1. **模板不校验，协议校验**：ADR 模板是给人自觉填写的文档；解蔽账本是**机器可判定的 schema**——缺替代方案、零反证、无证伪条件，`jiebi check` 逐项给出蔽值，CI 可门禁。
2. **模板不对账，协议对账**：账本里的证据引用必须能和会话流里的真实工具调用**逐条对账**（`jiebi reconcile`）——宣称"方案 B 已测试且失败"，流里却没有那次失败调用，就是伪登记。判断第一次变得**可证伪**。
3. **零 LLM 调用**：不用另一个 LLM 当批评家——那会引入新的偏置（且不可复现、有成本）。确定性规则，零调用、零提示词注入、可逐字重放。

## 五、一个诚实的边界

荀子自己就承认账本防不住全部："凡观物有疑，中心不定，则外物不清"——结构不能替代判断，就像秤不能替你决定要买什么。解蔽账本不保证结论正确，它只保证三件事：

**每一个结论都曾在至少两个候选的竞争里存活；至少一条反证被登记并被回应；结论自带可证伪条件。**

蔽值不度量对错，只度量"这个判断在程序上是否还可能被骗"。一个通过了虚壹静三门、蔽值为 0 的判断仍然可能是错的——但它是**可修正的错**；而蔽值为 80 的判断哪怕这次对了，也是**不可审计的运气**。
