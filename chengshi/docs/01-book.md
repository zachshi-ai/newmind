# 01 · 选书：《论语》—— 成事不说，遂事不谏，既往不咎

## 原文

《论语·八佾》（通行本，据中国哲学书电子化计划 ctext.org 同文）：

> 哀公问社于宰我。宰我对曰：「夏后氏以松，殷人以柏，周人以栗，曰使民战栗。」
> 子闻之，曰：**「成事不说，遂事不谏，既往不咎。」**

《论语·学而》：

> **过则勿惮改。**

## 为什么是这本书

agent 对外办事时有一个与「知」无关、与「行」也无关的盲区：**已遂之事的「遂」本身无人记账**。
发布 agent 把公告发了两遍，因为第一遍的超时被记成了失败；巡检 agent 给同一条工单建了两条评论，
因为循环重扫了同一个队列；两个会话各收到一句「把事故报告归个档」，各自归了一份——
世界已经双生，而会话流里没有一张账写着「这件事已经做过了」。

《论语》把这件事的分寸说得最干净。**成事不说，遂事不谏**——已经做成的事不必再叙说，
已经实行的事不必再劝阻；反面读恰是治理的起点：**要让已遂之事不再被翻出来重做，
先得有一本账记着它是遂的**。宰我对哀公说「使民战栗」，话出口就成形；
agent 对世界行使一次，世界就变一次——说错可以更正，施重无法追回，所以「遂」字当先入账。
**既往不咎**给了补过者出路：消了再施是新决，不是重决——咎既往而不咎已改。
**过则勿惮改**要求善后留痕：消据在案，善后才可考。

agent 恰恰是那个「不知道事已做成」的人：它看不见自己的第一笔落在世界上是什么样子
（超时、输出残缺、循环重入、会话恢复），它只看见「这步还没确认完成」。本层把
「确认完成」从一句自我叙述变成一本流内可证的账：命中遂形之施，成功一笔记一笔，
再施之前有账可查（遂牌供给），再施之后有案可考（重决入账）——**成事要记，遂事方不重**。

## 逐条映射

| 《论语》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 成事不说，遂事不谏 | 已遂之施是既成的世界事实；agent 再施一遍，只因「遂」无账可查 | **遂账**：exec 成功 ∧ 命中遂形（默认 15 形开箱在岗）→ 按**遂键**（规整命令串）登记，成功一笔记一笔 |
| 既往不咎 | 消了再施是新决不是重决——补过者不咎 | **已消**：凭消（**成物之柄**×**消词**）之后的再施 0 分注记 |
| 过则勿惮改 | 善后要留痕：对双生之物的消据应在案可考 | **末消**注记：末笔之施后有凭消者点名留痕（善后不销案——世界已双生，凭消只证知悔，不证未发） |
| 宰我对曰「使民战栗」（话出口就成形） | agent 说「已发送」世界不会信——成败只认流内 isError 位与遂形词面，不采信任何叙述 | **遂面**锁死：唯 exec 族成功 ∧ 遂形在场才入账；观察不是施，失败不遂 |
| 哀公问社（君之所问，臣之所对，各有其分） | 再施若是任务方明言的轮询心跳，或主渠道**再命**亲口重发，则不是重决 | **遂册 allow**（声明权在任务方）+ **承施**（同会话主渠道再命：命词在场或对象词元相交——新命开新决，先命之遂不溯既往） |
| 「人而无信，不知其可也」（账是信的底座） | 哪件事做了两次、第二次何以又施、第一次的完成为什么不算数——三问在所有相邻层都无处问起 | **遂牌块**接缝供给遂账清点（逐字节确定）+ **重值**分带门禁 + 零依赖 CLI 验尸任何历史会话 |
