# 01 · 选书：《春秋》——书法不隐

## 为什么是《春秋》

给「记录保真治理」找思想源头，候选不少：刘知几《史通》有《直书》《曲笔》专篇（但它是唐代史学方法论，本身是《春秋》义例的后世展开）；韩非子的刑名之学（参验之术近解蔽的账实对账）。而《春秋》是这条路的**源头活水**——它是华夏文明第一个成建制的「审计层」：以确定的**书法**（记事规则）约束记事者，一字之取舍即褒贬所在，「孔子成《春秋》而乱臣贼子惧」——审计层的存在本身改变行为。且《春秋》未被本仓任何项目使用（知止道德经 / 解蔽荀子 / 正念坛经 / 治未病黄帝内经 / 九变孙子 / 有涯庄子 / 论世孟子 / 定分商君书 / 捭阖鬼谷子 / 不贰论语〔在途〕/ 立诚周易〔在途〕/ 法仪墨子〔在途〕）。

《春秋》对「记录」有三件结构化的解剖，恰好就是 Agent 记录保真层的三个设计支柱：

1. **书法外在于记事者**：董狐书「赵盾弑其君」，依据不是心意而是结构事实（「亡不越竟，反不讨贼」）——责任判自结构，不判自动机；
2. **一字即判决**：「一字之褒，宠逾华衮之赠；一字之贬，严于斧钺之诛」（范宁《穀梁传集解》序）——词法级的确定性，一个字的差异就是记录性质的差异；
3. **讳而可读**：「天王狩于河阳」——孔子为尊者讳，改了措辞，但讳本身就写在史册里，读者可解。隐匿从来不是看不见，是没人去读。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《春秋》义例 | Agent 的病 | 直笔的机制 |
|---|---|---|
| 董狐**书法不隐**：「子为正卿，亡不越竟，反不讨贼，非子而谁？」——不问动机，只问结构事实 | 失败性命令被落了讳形（`\|\| true`、`set +e`、`&>/dev/null`），退出码被洗白成 0，流里从此全是绿的；事后验尸连「哪一步、哪个词、失败有没有被记录」都无从问起 | **案别判自结构**：讳笔案 =（史事 ∧ 成功侧 ∧ 命中讳形）三元组，零动机推断——命令串里的讳形就是「亡不越竟」级的结构事实 |
| **一字之贬，严于斧钺之诛** | 一字之差，记录性质全变：`npm test` 与 `npm test \|\| true` 在退出码上同为 0，前者是判决、后者是诬史 | **讳形表**（确定性词法，6 形默认 ∪ 显式扩展）：词法命中即落案，一个 token 的差异就是案与非案的差异——词法级褒贬 |
| **常事不书**——例行之事不入史 | 常规命令上的讳形是正常工程（`ls 2>/dev/null`、`kill $pid \|\| true`——失败本在预期） | **史词族表**（失败性承担词：test/check/lint/build…，显式 ∪ 默认）：只有史事上的讳形才落案；常事不书，宁漏勿诬 |
| **讳而可读**：「天王狩于河阳」——讳写在册上，缺的是读者 | 讳形逐字写在会话流里，人人可见——病不在看不见，在**没人读**：几十轮工具噪音里没有人去逐字对账 | **实录块**（接缝处供给）：逐案点名（位次 + 族 + 讳形 + 摘录），直笔就是那个把讳读出来的人 |
| **信以传信，疑以传疑**（穀梁传） | 洗白有时洗不动：`\|\| true` 拼错、外层已 `set -e`，失败照样见红——这时失败已见于记录，罪在何处？ | **试笔注记（0 分）**：isError=true 的讳形调用不罚——失败已见于记录，讳而未成；不诬 |
| **尽而不污**：「《春秋》之称，微而显，志而晦，婉而成章，尽而不污」——记全而不失真 | 交付态立于空绿之上：族内最后一次史事是讳笔，此后再无真判——收工报告的「通过」立于从未真实存在的绿 | **族末状态机**：逐族记末笔（直/讳/红/试），族末为讳 → 空绿案——收工时账上见 |
| 「孔子成《春秋》而**乱臣贼子惧**」 | 讳形零成本：从训练语料继承的 folk-shell 咒语（`\|\| true` 顺手就写），写了也没人知道 | **门禁 + 供给双效应**：讳值越门即红灯（CI 可断），实录块在接缝处当面点名——让每一笔曲笔都有账、有价、有人看见 |

## 与管理学互证

- **静默失败**（silent failure）是可靠性工程的经典病形：`|| true`、无 pipefail 的管道、`except: pass` 被 shellcheck / pylint 等静态检查工具专条告警数十年；被掩蔽的早期失败让下游步骤立于假前提，代价复利。
- **审计日志完整性**（NIST SP 800-92 一类日志管理规范的核心要求：记录须可信可验）：会话流本身 append-only 不可改，但流内的**信号**可以被结构性洗白——直笔把「日志完整性」下沉到信号层：退出码与输出通道是否被命令结构本身销毁。
- **可观测性的信条**：绿色仪表盘的前提是信号可信；假绿比真红昂贵得多——真红触发响应，假绿终结调查（事后根因分析完全依赖记录保真，记录被洗则验尸无从谈起）。
- **规范传入的行为惯性**：Agent 从训练语料继承了 folk-shell 的避错咒语（`|| true` 是语料里的高频惯用法），讳形落笔是**高基线率的习惯行为**，不是孤立个案——这正是「确定性词表 + 每案记账」比对个案语义判断更对路的场景。

## 与相邻思想的分工

- 《墨子·法仪》（在途 fayi）审**尺**——验收器本身的腐败（尺被改、器本虚、尺没照末账）；《春秋》审**笔**——量测结果的记录被洗白。法仪的世界默认「记录可信」（isError 即真实），直笔审的正是这个默认：**尺直笔曲，绿照样是假的**。`npm test || true` 在法仪账上是一次绿验，在直笔账上是一起讳笔——两层互证而不互代。
- 《道德经》（知止）审完成**证据的有无**；直笔审证据**本身直不直**——空绿是最「有证据」的失败。
- 《荀子·解蔽》审判断的**账本**（agent 自我申报的判断产物）；直笔审**原始流**（不经 agent 转述的命令与退出状态）。
- 《孙子兵法》（九变）审**可见失败**后的盲捶；直笔审**被隐匿的失败**——被洗白的失败在九变账上根本不是失败（exit 0），恰是九变的结构性盲区。
- 《庄子》（有涯）审同串重跑的**遗忘**；直笔审异串同族的**洗白**——有涯要「串同」，直笔只看「族同」，两账并行不悖。

## 诚实边界（我们不假装的事）

1. **只审命令流**：写进文件内容里的 `except: pass`、静默 catch 是**产物层**的病（解蔽、法仪的地盘）——直笔只审「执行了什么、结果被记成了什么」，不读文件内容。
2. **只认词法讳形**：词表之外的隐匿（粉饰性的收工措辞、断章取义的总结、只报喜不报忧）不是词法结构，零 LLM 约束下不判。
3. **史词表即视界**：默认族表之外的状态变更命令（部署、迁移类）被洗白时，直笔默认不识——显式登记史词即入账（声明权在任务方）；词表外的宁漏勿诬。
4. **洗白有时是合法的**：可选步骤的容错、预期失败的探测——豁免词显式登记后为豁笔注记（0 分），声明权在任务方。
5. **讳值 0 不是诚实分**：只说明记录里没有词法讳形；粉饰措辞、语义性隐瞒不在其上——直笔治笔之曲，不治心之曲。
