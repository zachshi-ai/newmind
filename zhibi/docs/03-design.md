# 03 · 设计：笔册、史事、讳形、族末状态机、讳值与实录块

> 本篇实现**前**定稿；分值、词表、状态机、模板一经定稿不得为实现缺口事后删改。

## §1 总览

```
会话流（tool_call/tool_result，流内序列即时钟——不依赖 at，无时之流全判）
        │ 插件 tools/result 观察（结构性零拦截）
        ▼
   ┌────────────────────────────────────────┐
   │ exec 族 ∧ 命令串命中史词 → 一次史事       │ ← 史词族表（默认 ∪ 显式，只增不删）
   │ 命令串命中讳形 ∧ 成功侧 → 讳笔落账        │ ← 讳形表（默认 6 形 ∪ 显式，只增不删）
   │ 豁免词命中 → 豁笔注记（不计分）           │ ← 豁免词（纯显式，声明权在任务方）
   └───────────────────┬────────────────────┘
                       ▼
        逐族状态机：族末笔 ∈ { 直, 讳, 红, 试 }
                       │
   讳值 = min(30, 10 × 讳笔案) + min(60, 30 × 空绿族)
   分带：素(0–14) / 讳(15–29) / 诬(≥30)      门默认 30
                       │
        宿主在接缝调用 ctx.zhibi.shilu() ──▶ 实录块（逐字节确定）
```

## §2 会话流与调用归并

与 zhizhi / jiebi / zhengnian / jiubian / youya / lunshi / dingfen / baihe 同规（互审前提）：每行一个 JSON；`#` 与空行为注释；坏行报行号；带 id 的 call/result 按 id 首见配对；无 id 旧格式 result 并入紧邻其前的 call；孤儿 result 独立建档；`turn_*` 等非工具事件跳过。`at` 原样保留、不参与任何判定——**排序一律用流内序列**（有涯的「串同」需要时序豁免是它的自由，直笔的族内先后用序列即足够且更严）。

## §3 笔册（register）

```json
{ "version": 1, "words": ["<史词正则>…"], "masks": ["<讳形正则>…"], "excuses": ["<豁免子串>…"], "noDefaults": false }
```

- **words** 显式史词：正则源字符串，与默认族表取并集（只增不删）；
- **masks** 显式讳形：正则源字符串，与默认形表取并集（只增不删）；
- **excuses** 豁免词：**纯显式**（无默认）——命令串含任一子串，该次史事为豁笔注记（0 分、点名）；声明权在任务方；
- `enroll` 与既有册取**并集去重**（只增不删）；`noDefaults: true` 关闭两张默认表（纯显式册）。

## §4 史事判定

- **exec 族**：沿用同仓惯例——工具名（小写）精确属于 `{bash, exec, run, shell, command}` 或含其中任一子串；非 exec 族（写/读/检索）永不为史事。
- **命令串**：`args.command` 为非空字符串时取之；否则将 args 全部字符串值递归拼接（与捭阖 argsText 同法）。
- **史事**：exec 族调用 ∧ 命令串命中史词 ≥1（显式 ∪ 默认，正则搜全文）。一次史事可同属多族（如 `set +e; make; npm run test` 同属 make 族与 test 族）——族成员独立记账。
- **族（family）**：一个史词即一族（默认表 12 词 + 显式登记）。族内先后以**流内序列**定，族末笔 = 该族最后一次史事。
- **成功侧**：`isError !== true`（含 null 孤儿——与捭阖、法仪同口径）；`isError === true` 为失败侧。

## §5 讳形表（默认 6 形，确定性词法）

| 形 id | 名 | 正则源 | 病理 |
|---|---|---|---|
| `t-true` | 吞真形 | `\|\|\s*(true\b\|:)` | 失败吞成真值，退出码归 0 |
| `t-echo` | 吞言形 | `\|\|\s*(echo\|printf)\b` | 失败吞成一句安抚话，退出码归 0 |
| `t-exit` | 吞零形 | `\|\|\s*exit\s+0\b` | 失败吞成显式零 |
| `t-sete` | 弛禁形 | `set\s*\+e\b` | 自此失败不再中断，一族命令整体洗白 |
| `t-devnull` | 塞目形 | `>\s*/dev/null\s+2>&1\|&>\s*/dev/null` | 双通道齐毁，transcript 上无迹可读 |
| `t-notests` | 虚准形 | `--passWithNoTests` | 「没跑任何用例」被洗成「通过」 |

- 一次史事命中多形逐形点名（同一案内全列），分数按案计不按形复利；
- 裸 `2>/dev/null` **不入默认形表**：错误通道弃置而退出码仍真，咎犹可见——这是「讳其咎」与「弃其声」的边界（宁漏勿诬）；
- `--no-verify` 之类的族外绕行属显式扩展场景（`--mask` 登记），默认表不收。

## §6 案别与族末状态机（判定序锁死）

逐次史事按流序结算：

1. **豁免词命中** → **豁笔注记**（0 分，点名）：声明权在任务方，讳形命中也豁；
2. **失败侧**（`isError === true`）→ **试笔注记**（0 分，点名）：讳而未成，失败已见于记录——信以传信；
3. **成功侧 ∧ 命中讳形** → **讳笔落账**：该族末笔置 **讳**；
4. **成功侧 ∧ 无讳形** → 该族末笔置 **直**；失败侧无讳形 → 族末笔置 **红**。

收工（流末）裁决：

- **空绿案**：族末笔为 **讳** 的族，每族 +30（该族末笔那次讳笔**不再计** +10——族末讳笔升级为空绿案，一讳不两罚）；
- **讳笔案**：非族末的成功侧讳笔，每案 +10（其后同族真判已还——**已赎**，但书已曲过）；
- **诚红注记**（族末为红，0 分）：红而不讳，笔直；
- **试笔/豁笔**照注记不罚。

**判定序**：豁免 > 失败侧 > 讳形命中——一史事至多落一案，豁免优先于一切（任务方声明最尊），失败侧优先于讳形（失败已见则无罪）。

## §7 讳值与分带（分值锁死）

```text
讳笔 = min(30, 10 × 讳笔案数)
空绿 = min(60, 30 × 空绿族数)
讳值 total = 讳笔 + 空绿                      （结构上限 90，不设总帽——上限由结构自缚）
分带：素 0–14 ／ 讳 15–29 ／ 诬 ≥30
门禁：默认 30（--gate 可覆盖）；verdict = total ≥ gate ? fail : pass
```

- **一空绿即诬**（30 顶门）：交付态立于空绿之上是最重的记录罪——与「单处争写即红」同一法度；
- **三赎亦讳**（30 顶门）：三案已赎讳笔同样越门——讳虽自直，书已三曲；
- `liveScore`（插件即时值）与离线重放对同流**前缀一致**（逐案结算互不依赖，天然满足）；
- 分带边界逐点可证（14→素、15→讳、29→讳、30→诬）；cap 逐点可证（4 案已赎 40→30、3 空绿族 90→60）。

## §8 实录块（模板锁死，逐字节确定）

```
【直笔 · 实录块 #k】
讳值 n（带），门 g，判 pass|fail
史事 s 笔（族 f：直 a · 讳 b · 红 c · 试 d），讳笔 e 案，空绿 v 族
讳笔点名（按流序）：
  · #seq <tool> <史词label>｜<讳形label>｜<摘录 ≤48 字符>
  （无则「  （无）」）
空绿点名（按族序）：
  · <史词label>｜族末讳笔，此后无真判——交付态勿立其上
  （无则「  （无）」）
族末一览（按族序）：
  · <史词label>：<直|讳|红|试><后缀>（末笔 #seq）
    后缀：直→「」，讳→「（空绿）」，红→「（诚红，0 分）」，试→「（试笔，0 分）」
—— 本块由确定性规则生成；重放同一流必得同一文本。
```

- 无时间戳字段；同状态两次渲染逐字节相同（`#k` 随渲染递增且仅此一处不同，shasum 可证）；
- 摘录自命令串截取讳形命中处前后文 ≤48 字符，并过**掩码自洁**（`sk-`/`Bearer`/私钥头/云钥四形命中即掩码——报告不得成为新的出险面；这不是对出境的审计，出境另有其主）；
- 无流无史事时出确定性空块。

## §9 CLI 契约

```text
zhibi audit  <stream.jsonl> [--register <file>] [--word <正则>…] [--mask <正则>…]
             [--excuse <子串>…] [--no-defaults] [--gate <n>] [--json]
zhibi block  <stream.jsonl> [同上选项]          实录块（默认纯文本，--json 包装）
zhibi list   [--register <file>]               笔册全文
zhibi enroll [--word/--mask/--excuse <项>…] [--file <path>]   并集去重，只增不删
zhibi gate   --value <n> [--gate <n>]          门禁裁决
zhibi --help | --version
```

- `--register` 缺省时若 `./.zhibi.json` 存在则载入，否则纯默认表（契约无关，挂上即审）；
- `audit` 恰取一流（直笔是单会话尺度；跨会话写域之争另有其主，多流 → exit 2）；
- 退出码：0 通过；1 讳值 ≥ 门；2 用法/输入错误（坏文件、坏流、多流、未知命令、缺参数）。

## §10 插件形状（Cordis，秉笔式）

与捭阖/法仪同构：`export const name='zhibi'`、`inject=['tools']`、`apply(ctx, config)`；唯一写入口 `tools/result`（结构性零拦截——源码无 pre-execute 监听，观察异常吞掉，管道照常）。`ZhibiService` 暴露 `report()`（概数 + 讳值 + 分带 + 门）/ `bizhang()`（笔账全目：逐案逐注记）/ `shilu()`（实录块，`#k` 递增）/ `gate()`（门禁裁决）/ `exportStream()`（导出 call/result 成对流，供离线 `audit` 对账）。config：`words` / `masks` / `excuses` / `register`（注入册对象）/ `gate`。

## §11 与十二层的边界（结构性，不是纪律性）

| 层 | 边界 |
|---|---|
| zhizhi 知止 | 拦动作是它的地盘；直笔**结构性零拦截**，只审计、计分、供给；知止数完成证据**有无**，直笔审证据**直不直** |
| jiebi 解蔽 | 不审判断账本；直笔审原始流（不经 agent 转述）；词表是显式词法，零语义 |
| zhengnian 正念 | 不守本愿、无契约字段；契约无关 |
| weibing 治未病 | 不做 t=0 任务书体检；显式登记只是声明权归任务方，不是任务书诊断 |
| jiubian 九变 | 不管势途应变；盲捶审**可见**失败的重复，直笔审**被隐匿**的失败——被洗白的失败在九变账上不是失败（exit 0），恰是九变的盲区 |
| youya 有涯 | 不管见闻连续性；有涯要**串同**（同串重跑才是复命），直笔只看**族同**（异串同族才是洗白与真判的先后）——两账并行不悖 |
| lunshi 论世 | 不审输入渠道权威；史词/讳形审的是**己方出口**的记录，不涉进来内容的话语资格 |
| dingfen 定分 | 不管跨会话写域；单会话内自己洗自己的记录，跨会话之界看不见 |
| buer 不贰 | 不记跨会话教训；直笔的账随流终结，不入跨会话错误账本 |
| licheng 立诚 | 不结承诺之账；「空绿」不是「失诺」——一个对记录，一个对言约 |
| fayi 法仪 | **笔尺分野**：法仪审验收器本身（尺被改/器本虚/尺没照末账），其世界默认记录可信；直笔审记录的洗白（讳形落笔/族末空绿）。`npm test \|\| true` 在法仪账上是一次绿验，在直笔账上是一起讳笔——两层互证不互代；直笔不读文件内容（器径写非其对象），法仪不审退出码的洗白 |
| baihe 捭阖 | 不管出境；实录块的掩码自洁只是报告不成为出险面的卫生措施，不构成对出境的称量 |

## §12 模型无关

核心与插件零 LLM 调用、零网络请求、零子进程：grep `child_process|axios|openai|anthropic|completion(|fetch(` 应无输出——直笔的审计对象是命令串词法与流序状态机，无捭阖式「对象即 http 词法」的例外。
