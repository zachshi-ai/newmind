# 01 · 选书：《大学》——物有本末，事有终始

## 为什么是《大学》

给「任务项行程治理」找思想源头，候选不少：《周易》的「知至至之，知终终之」落在承诺与进退（已为立诚所用）、《诗经》的「靡不有初，鲜克有终」点名了病却没给药方。而《大学》对「众事之账」这件事给的是**最短的完整解剖**——它不劝勉「要有始有终」，它给**终始的存在论地位**（物有本末，事有终始——终与始是事情本身的两个刻度，不是修养的两种美德）、给**先后的可判定性**（知所先后，则近道矣——先后是可知的，且知不知道先后直接决定近道还是歧路），还给**一个完整的次序链条**作范本（欲明明德于天下者，先治其国……物格而后知至，知至而后意诚——八条目就是一张显式的 order 表）。这三件事恰好就是行程治理的三个设计支柱，且《大学》未被本仓任何项目使用（zhizhi 道德经 / jiebi 荀子 / zhengnian 坛经 / weibing 黄帝内经 / jiubian 孙子 / youya 庄子 / lunshi 孟子 / dingfen 商君书 / baihe 鬼谷子 / zhibi 春秋 / yuli 中庸 / duzhi 礼记·王制 / erbing 韩非子；buer 论语〔在途〕/ licheng 周易〔在途〕/ fayi 墨子〔在途〕）。

这一病在文化里的名字来自《诗经·大雅·荡》：**「靡不有初，鲜克有终」**——没有哪件事不开头，罕有哪件事真走完。Agent 的长任务恰恰是这句话的机器版：它开头的效率惊人，收尾的账无人查过。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《大学》原文 | Agent 的病 | 终始的机制 |
|---|---|---|
| **物有本末，事有终始** | 任务书立了众事，Agent 做了几件就宣布完成——每一件事在流里有没有开头、有没有收尾，没有任何一层记过账：没做的事是**幽项**（全流无作工之迹），开了头没下文的事是**半途**（末笔是作工），账上查无可查 | **程账**：事册立事，逐项对流记账——作工之迹为始，显式终形为终，显式弃形为弃；末笔定案别（幽项/半途/有终/有弃），案案有据 |
| **知所先后，则近道矣** | 先后失序无人记账：补索引之终先于回归之始的立序被倒着走（迁移未收先跑回归），事后连「哪一步走早了」都无处问起 | **先后账**：事册显式声明 order 对（A 之终须先于 B 之始），B 之始早于 A 之终即失序案——「先后」从修辞落成可判定的序比较 |
| **八条目之序**（欲明明德于天下者，先治其国……物格而后知至） | 《大学》自己给的就是一张带次序的任务分解表——每一步有名字、每两步有先后；人类组织几千年来最好的任务书都是这个形状 | **事册**：items 逐事登记（名/别名/终形/弃形）∪ order 显式立序——任务方比任何自动分解都懂自己的事，声明权全在册方 |
| **毋自欺也**（诚意章） | **空终**：宣称「迁移完成」之后手还在改迁移代码——对「事已终」的自欺。终言之后继以作工，终被自己的手推翻，而流序里这明明白白，却从未被比对过 | **空终案**：每个「其后复有作工之终言」各计一案——自欺第一次有了账面形状，比无声半途罪加一等 |

## 与管理学互证

- **WBS 工作分解结构**（PMBOK）：任务分解为可验证的工作包，每包有明确的完成判据——事册的 items+terminal 就是工作分解的词面物化；未分解的任务无从对账，正如未分解的项目无从管理。
- **Definition of Done**（敏捷）：「完成」必须事先定义，否则每一件「自认为做完了」都不可反驳——终形不宣则认不了终（无凭之终不认），与 DoD 的纪律同源。
- **清单革命**（Atul Gawande）：航空与医疗的清单纪律不在「列出来」，而在**逐项核销**——跳项是事故的经典成因；agent 的任务清单恰恰只有「列出来」没有「核销」，程账把核销做成机制。
- **燃尽图**（burndown chart）：逐项关闭的可见化是项目健康的第一仪表；程账块是会话内的燃尽表——中断续跑时它就是交接班记录。
- **范围变更控制**（scope change control）：变更合法，无声变更不合法——显式弃形登记的弃不罚（有弃 0 分），与变更单纪律同构。

## 与相邻思想的分工

- 《六祖坛经》守**一愿**（zhengnian：本愿在场、范围不失）；《大学》记**众事**（终始：立了几件事，每件走到哪）。愿是一，事是多——agent 可以毫无漂移而漏掉三件分内事，也可以逐件做完而早已漂走，两层各管一张账。
- 《周易》追**自己说出口的诺**（licheng：绳账咎值）；《大学》记**任务方立下的事**（终始：事册在先，流账在后）。诺在话语里，事在册上——agent 一句没承诺过的任务书之项，立诚看不见，终始照记。
- 《礼记·王制》记**总量**（duzhi：花销多少）；《大学》记**分项**（终始：每事到哪）。总账不分项，分项不计总——214 次调用可以全部在线内而三件事从未开工，两账并行才见全貌。
- 《黄帝内经》看 t=0 任务书的**形状**（weibing：终验条款写没写）；《大学》看 t>0 众事的**行程**（写了白写，只有对账能见——度支同款论证）。
- 《孙子兵法》勘**失败后的改途**（jiubian：势变之地）；《大学》记**事情的走到与否**（行没行至）——改途应不应发是九变的事，走到没走到是终始的事。
- 《庄子·养生主》巡**见闻的重复**（youya：忘不忘）；《大学》记**事情的终始**（完没完）——同一件事读两遍是有涯的复见，做完没做完是有初鲜终。
- 册外之事不入账：Agent 自加的事（攀缘）是正念的地盘；本层只对册上立过的事负责——**无册不判**。

## 诚实边界（我们不假装的事）

1. **审计对象是流与册**：流里没发生的作工看不见，册上没立的事不审——带外通道做的事、任务方没写进册的事，终始无从知晓；这是流审计各层的共同边界。
2. **词面之粗**：项词是大小写归一的子串匹配——无关路径恰含项词会**伪始**（把幽项错记成半途——错在宽侧，宁纵方向）；项词与路径字面全异的真作工会**漏始**（别名可补，宁漏勿诬）。项词之间有字面包含关系（pay/payments）是册方之责。
3. **终形是认终的唯一凭据**：未宣终形之项不得认终——它做了再多也只能记至「行」，程账块点名「未宣终形」。无凭之终不认，这逼的不是 agent，是册方把「怎样算完」说出口。
4. **词法可欺**：把项词故意塞进无关调用可以伪始、把终形词塞进一次无关调用可以伪终——确定性词法的保证是**可审计、可重放、可门禁**，不是不可欺；骗词法的痕迹全在账上，骗一次留一次形。
5. **弃形也是显式的**：没宣弃形，弃就不入账——「无声地不做了」在账上是半途（该罚的罚），想让弃免罚就明说（弃形词可落在提交信息、测试名等任何流中词面里）。
6. **程值 0 不是完成保证**：只说明册上每事账面有终有据；终形本身定得对不对，是任务方与量尺诸层（法仪）的事——账只认凭据，不担保凭据的明智。
