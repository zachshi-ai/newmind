# 01 · 选书：《汉书》—— 汤独矫制，上疏自劾

## 原文

《汉书·卷七十·傅常郑甘陈段传》（班固撰，颜师古注；本文引文据维基文库《漢書/卷070》同文）：

> 湯曰：「國家與公卿議，大策非凡所見，事必不從。」
> 會其乆病，**湯獨矯制發城郭諸國兵、車師戊己校尉屯田吏士。**
> 延壽、湯**上疏自劾奏矯制**，陳言兵狀。

及班师论功，石显、匡衡议其罪：

> **延壽、湯擅興師矯制，幸得不誅**，如復加爵土，則後奉使者爭欲乘危徼幸，
> 生事於蠻夷，爲國招難，**漸不可開**。

而陈汤留名千古的那一疏，正是这条万里之外的军功：

> 宜縣頭槀街蠻夷邸閒，以示萬里，**明犯彊漢者，雖遠必誅。**

陈汤与甘延寿出使西域，欲发诸国兵攻郅支单于。延寿要上奏请旨，陈汤说：
跟公卿们议，大事一定议不下来。延寿犹疑，恰逢患病——陈汤**独自假托皇帝
的制书，调发了城郭诸国的军队**。矫者，托也：所托之制并非天子所出。发兵
是既成事实，功过另议；而「矫」这一笔，陈汤自己上疏如实自陈（上疏自劾
奏矫制），汉庭也要当众核这一笔（擅兴师矫制，幸得不诛）——**功是功，
托是托：托名的口子渐不可开**，否则后奉使者人人效尤。

## 为什么是这本书

agent 也有自己的「矫制」：交付文书里的**伪托之引**。写报告、交接书、
commit message、PR 描述时，它需要一个依据来撑住自己的决定——于是笔下
生出「AGENTS.md 规定『X』」「Per AGENTS.md, the rule is "Y"」——而
**所托之文里根本没有这句话**。伪造判例引用的法律 AI（Mata v. Avianca
案：编造六个不存在的判例写进诉状，律师照提交、被法院制裁）是此病最具
标志性的社会事故；多 agent 编排里子 Agent 向下游转述任务书时的凭空增发，
是此病在日常作业里的家常形态。伪据比无据更毒：无据一眼可见，伪据自带
权威外观——审查者、下游会话、未来审计，全都对着一句**不存在的话**做
决策。「国家与公卿议，大策非凡所见，事必不从」正是伪据的心理：嫌真章
程碍事，就给自己造一句更好用的。

班固记这一笔的两半，恰是本层的两半。一半是**托要当众核**：矫制之托，
发兵者自己要上疏自劾（留痕），朝廷要议罪核销（渐不可开）——本层把
「所托之文有没有这句话」做成流内对账：引语自称原文，原文就在诏账
（会话流里真实装载与写下的文书正文），逐字可征、查无即案。另一半是
**功托两分**：陈汤的军功是真的（明犯强汉者虽远必诛），罪不在发兵而在
「托」——本层同法：不判所做之事的善恶（语义判断是全仓禁区），只记
「托」这一笔本身；引语在原文里征得的，逐案清白。
