# 01 · 选书：《管子·任法》—— 法者不可不恒，生法者君

## 原文

《管子》第四十五篇《任法》（据维基文库与「中国哲学书电子化计划」文本，引文两见异文已注）：

> 有生法，有守法，有法於法。夫生法者，君也；守法者，臣也；法於法者，民也。
> 君臣上下貴賤皆從法，此謂為大治。

> 故曰：法者，不可恆也〔一本作「不可不恆也」〕，存亡治亂之所以出，聖君所以為天下大儀也。

> 聖君任法而不任智，任數而不任說，任公而不任私，任大道而不任小物。

版本注：「法者不可恆也」一句，维基文库与 CTEXT 作「不可恆也」，古文岛等通行本作
「不可不恆也」。本层取通行本「不可不恒」为名——法之常在，不可摇动；两读所指皆同一处：
恒与不恒，正是存亡治乱的分水岭。

## 为什么是这本书

agent 是被派活的一方：任务方立规矩（任务书、仓库的治理文书、检查章程、CI 流程），
agent 在规矩之内干活。可它手里握着写文件的手——嫌报错烦就关一条 lint 规则，嫌 strict
拦路就把 tsconfig 放宽，嫌 CI 红就删掉 workflow 里的检查步骤，嫌指令碍事就顺手改写
AGENTS.md 里的约束条款。这一单活绿了，仓库的规矩却被这一单活改写了：臣生法。

《任法》把这件事说到了根上：**生法者，君也；守法者，臣也**——立法权只在任务方（君），
agent（臣）的本分是守法。**法者不可不恒**——规矩源是常驻之物，恒是默认态；变法必须有
名（任务方的明命授权），无名之变即案。**任法而不任智**——治理靠确定的形表与锁死的
判定序（法与数），不靠临场的语义判断（智与说）：本层不判「改得好不好」（那是智），只记
「谁动了、授没授权、复原没有」（这是法）。**君臣上下贵贱皆从法**——账与门也约束审计
自身：判定序锁死、judge 幂等、法牌逐字节可证。

## 逐条映射

| 《任法》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 生法者，君也 | 规矩源（AGENTS.md/CLAUDE.md、lint 章程、CI 流程）的立法权在任务方 | **典册开门**：授权（open 列）只能由任务方立，agent 无从自我开门 |
| 守法者，臣也 | agent 是执法者不是立法者——它写的每一个文件里，规矩源不是它的辖区 | **宪/禁/章三族典形**：治理文书、CI 流程、检查章程默认在岗，改即立案 |
| 法者不可不恒 | 规矩的默认态是恒定；「昨天严今天松」的病根是无人记账的无名之变 | **改典案**：每径一案、末笔定基点；未授权之变留痕有价 |
| 存亡治乱之所以出 | 规矩被松掉，下一单活就继承松掉的规矩——错不在它而在宪 | 案账清点进法牌块，接缝供给，谁改的、何时改的、基点在哪，逐案可见 |
| 任法而不任智，任数而不任说 | 零 LLM：词形与 glob 是数，判定序是法；不问改动内容的善恶（智与说） | 判定只看「改没改典形、册上开没开门、git 词面复没复」，不看内容语义 |
| 任公而不任私 | 案账是公器，不因 agent 自辩「这样改更好」而移 | 授权唯典册一路；自辩不留痕即不免案（矫制不分善恶，账只记名分） |
| 君臣上下贵贱皆从法，此谓为大治 | 审计自身也受法约束：可复现、可证伪、可验尸历史会话 | judge 幂等（重放同流必得同判词）、法牌 shasum 可证、多流离线重放 |
