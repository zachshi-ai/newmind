# 立诚 · 结绳协议（Agent 侧）

你在长会话里说出口的每一个承诺——"接下来我会补测试""稍后更新文档""提交前跑一遍全量"——都是绳账上的债。每轮上下文重新生成，你对自己说过什么没有机制性记忆；立诚把这笔账从你的记忆里拿出来，放在账本上。

## 四条纪律

### 1. 凡诺必记（出口即入账）

话一出口，立刻入账。**不分大小**——庸言之信，微承诺才是失诺的主战场：

```js
ctx.licheng.make({
  id: 'p-007',
  what: '补齐 payments 模块的边界用例',
  discharge: { tool: 'bash', contains: 'npm test', ok: true },
})
```

### 2. 拟之而后言（出口前先想好凭据）

说"我会 X"之前先回答：**怎样算做到？** 哪个工具、调用里含什么字样、成不成功。想不出凭据的诺，要么别许，要么带着"无凭"的吝分许——结账时账会说话。

凭据语法：`{ "tool": "bash"（可选，工具名精确匹配）, "contains": "npm test"（必需，调用参数 JSON 的子串）, "ok": true（可选：true 要求那次调用未报错，false 要求报错）}`。

### 3. 变卦显式登记（改诺/弃约合法且免费，蒸发不合法）

计划变了不是错——**无咎者，善补过也**。带理由登记，旧结合法关闭，一分不扣：

```js
ctx.licheng.revise({ id: 'p-007r', supersedes: 'p-007', reason: '宿主指示改用方案 B，用例范围收窄', what: '补 smoke 用例' })
ctx.licheng.abandon('p-008', '宿主 mid-run 指示该优化作废')
ctx.licheng.declare('p-009', { tool: 'write', contains: 'README' })  // 立诺时忘了带凭：补宣告，凭据仍要对账
```

不登记的后果：到结账还悬着的结按失诺记咎（+30）——变卦免费，蒸发不免费。

### 4. 收尾过结账门，再宣布完成

宣布完成之前先结账，把结账块亮在收尾报告里：

```js
const r = ctx.licheng.settle()
// r.verdict === 'pass' 才可宣布完成；'fail' 时把悬结逐条处理：
//   能兑现的去兑现，该弃约的带理由弃约——账平了再宣布。
ctx.licheng.block()  // 逐字节确定的结账块，供宿主注入收尾上下文
```

## 离线对账（无宿主时）

```console
$ licheng template > r-001.jsonl            # 绳账骨架
$ licheng ledger r-001.jsonl                # 校验
$ licheng settle r-001.jsonl session.jsonl  # 结账（咎值 ≥ 30 退出码 1）
```

## 账怎么记分

| 爻象 | 判据 | 分 |
|------|------|-----|
| **咎**（失诺） | 结账时凭据无匹配 | +30/条（cap 60） |
| **吝**（轻诺） | 整条链从未有过凭据：无凭失诺叠加、无凭弃约单列 | +10/条（cap 20） |
| **悔**（改诺/弃约） | 带理由显式登记 | 0 |
| **信**（兑现） | 凭据在流中真实命中 | 0 |

分带：无咎(0–14) / 吝(15–29) / 咎(≥30)；结账门默认 30。一笔失诺即过不了门。

## 诚实边界

- 凭据匹配是**字面的**（子串 + 布尔），不是语义理解——写 `contains` 时用调用里真实会出现的字样；
- 账外的话读不到：speech 漏账提示只是词表级 advisory，声明权在使用方；
- **不强迫多许诺**——"古者言之不出"亦是德；立诚只让每一句许出的话都有价。
