# 01 · 选书：《周易》——言出如枢机，诺成而信立

## 为什么是《周易》

给「承诺信用治理」找思想源头，候选很多：《论语》有「人而无信，不知其可也」，孟子有「大人者，言不必信，行不必果，惟义所在」。《论语》留给不贰（buer，在途）；而《周易》对"说过的话如何落地"有一套**更结构化**的解剖——它不只讲"要守信"，它给**言行的本体论地位**（言即枢机，出言即动天地）、给**微承诺的伦理**（庸言之信——日常的每一句话都要信）、给**改过的合法路径**（无咎者，善补过也）、还给一个现成的**三档过错量表**（悔 < 吝 < 咎）。这四件事恰好就是 Agent 承诺治理的四个设计支柱，且《周易》未被本仓任何项目使用（zhizhi 道德经 / jiebi 荀子 / zhengnian 坛经 / weibing 黄帝内经 / buer 论语〔在途〕/ jiubian 孙子〔在途〕）。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《周易》原文 | Agent 的病 | 立诚的机制 |
|---|---|---|
| 系辞上：**言行，君子之枢机**。枢机之发，荣辱之主也；言行，君子之所以动天地也，可不慎乎 | Agent 的话不是"输出"，是**动作**：说出口的"接下来我会 X"会成为下游一切工作的前提与用户的预期，落空即事故 | **绳账**：把口语承诺变成机器可读的**结**（ledger 条目），每一条都必须有下场 |
| 乾·文言 九二：**庸言之信**，庸行之谨 | 失诺的主战场不在大事在**微承诺**：长会话里几十句"我会补测试 / 稍后更新文档"，每一句都局部正确地蒸发 | 微承诺全部入账：**凡诺必记**，不分大小（SKILL 协议的立账规则） |
| 系辞上：**拟之而后言**，议之而后动 | **轻诺**：出口的承诺不带"怎样算兑现"的判据——连它自己都不知道怎么算做到了 | 诺须带**凭**（discharge 判据：哪个工具、含什么字样、成败与否）；无凭之诺计**轻诺**（吝） |
| 乾·文言：**修辞立其诚**，所以居业也 | 承诺的兑现可以伪造——"我跑过了"跑没跑过，账面上无从对证 | **账实对账**：兑现凭据必须在会话流里真实发生过（工具调用逐字匹配） |
| 系辞上：**无咎者，善补过也**；震无咎者存乎**悔** | 计划变了、承诺作废——这本身合法；病在**无声蒸发**：没人在账上看见这次改约 | **改诺 / 弃约**是一等公民：带理由显式登记即免咎（悔）；到结账仍悬着的才是失诺（咎） |
| 系辞上：**悔吝者，言乎其小疵也**；悔 < 吝 < 咎 三档 | 过错没有量级：一句落空的承诺和一场返工同权重，无从门禁 | **咎值**量表：失诺 +30/条（咎，cap 60）＞ 轻诺 +10/条（吝，cap 20）；分带 **无咎(0–14) / 吝(15–29) / 咎(≥30)** |
| 系辞下：上古**结绳而治**，后世圣人易之以书契 | （命名所自）承诺的原始记录形态就是绳上的结：立一诺打一结，诺了则解；结不解，账不平 | 账名**绳账**，引擎动词**结账**（settle）：解开的结（兑现/改诺/弃约）出局，悬着的结记咎 |
| 乾·文言：**庸言之信**→中孚卦：**鸣鹤在阴，其子和之** | （愿景所自）委托关系的地基不是能力是信用：agent 每守一诺，信用复利 | 结账块给宿主一个**逐字节确定**的信用报告，可注入收尾上下文、可进 CI |

## 与管理学互证

- **Promise-Based Management**（Sull & Spinosa，Harvard Business Review 2007）：执行力的本质是承诺链的治理——承诺须公开（public）、须可协商（negotiable）、须主动重谈（renegotiation）。对应立诚的三件事：账是显式的、凭据是协商出来的判据、改诺是一等公民。
- **承诺一致性**（Cialdini, Influence）：人会为自己的话买单——前提是话被**记录**。Agent 的每轮上下文重生成使它天然没有"自己的话"的连续记忆，这正是承诺蒸发比人类更严重的原因。
- **Definition of Done / 退出台账**（工程实践）：完成态需要可判据。立诚把它前移到**承诺态**：不是"做完才定判据"，而是"出口那一刻就带判据"。

## 与相邻思想的分工

- 《论语》"言必信，行必果，硁硁然小人哉"与孟子"惟义所在"提醒：**盲守诺是病**。立诚不强制守诺——改诺/弃约永远合法，只要带理由显式登记。病不是变，是**无声蒸发**。
- 《道德经》"轻诺必寡信"（zhizhi 已用其书）：立诚用《周易》的"拟之而后言"表达同一判断，避免跨项目引书。

## 诚实边界（第五节：我们不假装的事）

1. **读不出没说出口的诺**：插件与 CLI 只对**账上**的诺结账；会话流里的承诺措辞只在带 `speech` 事件时做词表级**提示**（漏账提醒），不计分——声明权在账方，确定性优先于覆盖面。
2. **凭据匹配是字面的**：`contains` 是子串匹配不是语义判断，"跑了全量测试"靠的是 `bash` 调用里真实出现 `npm test` 且未报错，不是理解了那句话。
3. **咎值 0 不是信用满分**：它只说明账上无悬结。从没许过诺的会话咎值也是 0——立诚不强迫多许诺（"古者言之不出"亦是德），它让**每一句许出的话都有价**。
4. **不判诺的内容该不该许**：诺该不该许是意图层的判断（zhengnian 的本愿、jiebi 的账本校验地盘）；立诚只管许出之后**账平不平**。
