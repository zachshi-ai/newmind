# 01 · 选书：《阅微草堂笔记》—— 但知其一，不知其二；可据理臆断欤？

## 原文

纪昀《阅微草堂笔记·卷十六·姑妄听之二》「河中石兽」（本文引文据通行
整理本；「沧州南一寺」一则是中学语文教材名篇）：

> 沧州南一寺临河干，山门圮于河，二石兽并沉焉。阅十余岁，僧募金重修，
> 求石兽于水中，竟不可得。以为顺流下矣，棹数小舟，曳铁钯，寻十余里
> 无迹。

> 一讲学家设帐寺中，闻之笑曰：「尔辈不能究物理。是非木杮，岂能为暴涨
> 携之去？乃石性坚重，沙性松浮，湮于沙下，渐沉渐深耳。沿河求之，不亦
> 颠乎？」**众服为确论。**

> 一老河兵闻之，又笑曰：「**凡河中失石，当求之于上流。**盖石之性坚重，
> 沙之性松浮，水不能冲石，其反激之力，必于石下迎水处啮沙为坎穴，渐激
> 渐深，至石之半，石必倒掷坎穴中。如是再啮，石又再转，转转不已，遂反
> 溯流逆上矣。求之下流，固颠；求之地中，不更颠乎？」**如其言，果得于
> 数里外。**

> **然则天下之事，但知其一，不知其二者多矣，可据理臆断欤？**

一篇之内站着四种姿态：寺僧原地打捞、顺流寻觅（**动而无当**）；讲学家
端坐寺中，以「石性坚重，沙性松浮」之理推出「湮于沙下，渐沉渐深」，
满座叹服「确论」（**看得到现场，推得出结论，唯独没有验过**）；老河兵
「凡河中失石，当求之于上流」——「凡……当……」是从三十年河工里一次
一次真在上游找到石头**归纳**出来的因果律（**动过因、验过果**）；最后
纪昀把问题钉死：**但知其一（石重沙沉之理），不知其二（反激啮沙、转转
不已之机）——天下之事，可据理臆断欤？**

讲学家的推理并没有错——石重沙沉是真的，湮于沙下的推断也合乎物理；
错的不是「理」，是**拿未经干预验证的推理冒充经过验证的结论，还让满座
「服为确论」**。他看过现场（知道石兽沉了河），他的每一步推理单拎出来
都站得住——但他从头到尾没有挖开过一寸沙、没有在上游寻过一寸河。老河
兵与他的差别不在聪明，在**证据的等级**：观察与推理是「望」，干预与验
证才是「溯」。

## 为什么是这本书

agent 也有自己的「据理臆断」：**归因无验**。修完一单活写复盘/排障
报告——「根因是缓存过期导致的数据不一致」「问题在于测试环境与生产的
配置漂移」「The root cause is a race condition in the connection pool」
——这些话通顺、自信、有专业外观，可其中相当一部分，**agent 从头到尾
没有对所断言之因做过一次干预性验证**：没改过那个缓存配置再看错不失、
没复现过一次竞态、没做过一次对照——它是读了几眼日志（看过现场），凭
「一般的系统都是这样坏」的先验之理（石性坚重，沙性松浮），推出了一个
「确论」。下游照根因行动：照「缓存过期」去调 TTL、照「配置漂移」去
对环境——就像满座宾客沿着讲学家的方向沿河挖沙。讲学家没有恶意，讲
学家只是没去验证；假根因也没有恶意，假根因只是**没有人逼它出示验证
的形迹**。

「但知其一，不知其二」正是此病的认识论病根：因果链里总有一环是推理
填的——**推理填环在 agent 手里不是罪，把推理填的环当众写成「根因」
才是罪**。真实世界的 debugging 痛点正在此处：SWE-agent 类系统「plausible
but wrong」的诊断、incident 复盘里 LLM 生成的编造 root cause、人拿到
假根因后照方抓药浪费的整个下游——全是「众服为确论」的现代版。

《阅微草堂笔记》教的两半，恰是本层的两半。一半是**凡因必验**：因果
断言的最低门槛是干预性验证——改过疑因（动因）、其后验过果（验果），
才配写「根因是」三个字；只看过现场（读过日志、跑过一次报错）是「望」，
望而立断，黄牌点名。另一半是**不冤疑而后言者**：「可能是缓存过期」
是诚实的假设——疑而后言者次之，确而不察者下；推测之词（推词）在场
的归因行只留显疑注记，不入罪。本层不装能判因果真假（那是人的裁决权——
词法不知道缓存到底过没过期），只判一件零 LLM 能确定性回答的事：**写下
这句根因之前，流里有没有动过因、验过果的形迹**。

## 逐条映射

| 《阅微草堂笔记·河中石兽》 | AI 现实 | 本层机制 |
|----------|---------|----------|
| 讲学家「众服为确论」——看过现场、合乎物理，唯独零验证 | agent 读了日志（看过现场）推出根因写进复盘——「根因是缓存过期」全流无一次干预验证 | **归因形**（中文 12 ∪ 英文 9）× 诊面径 → 流内无验因形迹 = **臆断** +30/案，单案即红 |
| 老河兵「凡河中失石，当求之上流」——三十年一次一次找过 | 对疑因动过手（改配置/改代码）且其后验过果（成功验证）才配下因果结论 | **拔验**（因面词元命中先前成功 write ∧ 其后成功 exec）→ 清白 |
| 寺僧「棹数小舟，曳铁钯」——动了手，动无当 | 跑过相关命令、看过相关日志——实验过最低限，但没干预过因 | **勘验**（observe 正文/exec 命令含因面词元）∪ **重演**（果词 × 因面同笔 exec ≥2 笔）→ 望断 +15 黄牌（看过≠验过） |
| 「但知其一，不知其二」——推理填环 | 因果链的缺环由先验之理填平——推理不是罪，写成「根因」才是罪 | 词法不判推理，只判**流内形迹**：验因三通道全查无 → 立案 |
| 「可能是 X」式的诚实假设（对照「确论」） | 「根因可能是缓存过期」——疑而后言者 | **推词门**（中文 12 ∪ 英文 12）→ **显疑**注记 0 分，不入罪 |
| 如其言，果得于数里外（验证是可复算的） | 归因验证的形迹全在流内：改没改过、验没验过，重放即见 | 判定序锁死、显式词法，同流重放必得同判词 |
| 寺僧寻十余里无迹（失败之劳不是验） | 404 之读、报错之跑不是勘验——失败之见不是见 | 失败调用不生勘验（isError=true 永不生据；重演之果词除外——败相在文不在旗） |
| 先断言后去验（假如有讲学家事后补挖） | 归因在前、干预验证在后——事后补的验只认干预验证 | **迟验**注记（拔验在后 0 分留痕）；勘验在后不采——望不洗臆 |
| 「尔辈不能究物理」（讲学家讥僧，河兵讥讲学家——谁讥谁？） | 本层不判谁对谁错（因果真伪归人），只逼每个下断言者出示验证形迹 | 语义真伪是全仓禁区；臆册免审明言即免——声明权归任务方 |
