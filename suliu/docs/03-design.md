# 03 · 设计：溯流 · suliu —— DeepSeek Harness 的因果臆断治理（溯流式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**溯流式插件**（第四十二个）。chachu 证明插件可以审断言
所指之**物**进没进流（存在性——看过即据），jiubian 证明失败侧的行为
可勘，shihu 证明文书侧的陈报对自流作工可审，jiaotuo 证明落卷之引对
所托之文可核——溯流证明插件可以**审归因之言验没验**（因果性）：哪
一句「根因是 X」的流里，从未有过动 X 之因、验 X 之果的形迹。

```
tools/result   emit   验因三通道记流内之验；write 诊面稿入断账判归因（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零
子进程、零文件系统探测——因、验、果全取自流内词面与事件）；观察永不
反噬（监听器异常吞掉，管道照常）；臆册持久化归 CLI（register/revoke），
插件只吃注入的 book 对象；单会话视图的案与值只采本会话（跨会话验因
证据互认归离线合并审计）。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:`
不透明；observe/write/exec/other 四族）。径规整同全仓（反斜杠归正斜
杠、剥 `./` 前缀、剥尾 `/`）。

**断账收全流，判言只判诊面之写**：全族调用逐笔记入断账（验因要用
write/observe/exec 三面）；判言只落在 write 族 p: 径 ∧ `isError !== true`
∧ `args.content` 非空字符串 ∧ 规整径**小写化后命中诊面形**（§3）的
稿面上。isError === true 之写不入稿账（失败之写没落盘）；isError 未知
（null，老流）按已发生；无 content 之写不入稿账；**诊面外之稿不审不记**
（归因断言的当众之地是诊断类文书——README 里的「根因是」多为例释，
宁纵，既知代价）。

observe 族结果与 exec 族结果永不判言（数据渠道的话不是 agent 的断言；
命令行无稿面结构——commit message 里的归因没有稿面可对，宁纵，既知
代价）；other 族不入。

**豁免（立案前）**：臆册 `excuse` glob 命中稿径 ∪ **演域**名段命中
稿径 → 整稿不审不记（受审稿计数不含）。演域是归因演练之地：正则形
13——`(tests?|specs?|__tests__|__mocks__|fixtures|scratch|drafts?|wip|
sandbox|demos?|notes?)/` 名段（目录段在径首亦算段）∪ `.test.`/`.spec.`
尾形。

**合审序（CLI 多流）**：全 at 有数 → `(at, 流序, 流内序)` 稳定排序；
否则参序拼接（审计方须自证流序）。单会话运行时视图同法自洽。

## 3. 诊面形（受审径法，默认内置 14 形，零 LLM）

规整径全串**小写化**后子串命中任一形 → 该稿是诊面（诊断类文书）：

postmortem、post-mortem、incident、rca、root-cause、rootcause、
root_cause、diagnosis、diagnostic、debrief、复盘、根因、排查、诊断

（「rca」三字母偶可撞他径——低概率接受，既知代价；诊面形内置固定，
v1 不扩形。）

## 4. 归因形（因果断言之词法，行级）

归因形是「下因果断言」的词迹。判定单位是**行**：归因形命中方成归因
行，一行多形只取首形（行=案，宁纵）。

**中文前向形 12**（子串命中；因面在形**后**）：

根因、原因在于、原因是、原因出在、问题出在、问题在于、问题源于、
症结、归因于、成因、诱因、是因为

**英文前向形 9**（词界，大小写不敏感；因面在形**后**）：

root cause, caused by, due to, because of, the reason is,
resulted from, stemmed from, attributed to, underlying cause

后置形（「X 所致」「X 是罪魁祸首」——因面在形前）v1 不收（既知代价，
宁纵）；纯连接词（因为/由于/导致/造成/引发）不入表（正当叙述保护——
「由于篇幅限制」类不判；代价：口语化归因「就是因为 X」不中——宁纵）。

## 5. 因面与词元（断言之因的词法化）

归因行命中后，**因面** = 行内首个归因形之后的全部内容（剥前导空白与
标点冒号）。因面词元两路提取、并集去重：

- **ASCII 路**：按 `[A-Za-z0-9_\-./@]+` 切词，剥尾部句点；过滤：停词
  26（the a an of and or is was are were be to for in on with that
  this it not when but as at by from，大小写不敏感全等）、纯数字、
  长度 <2——路径形 token（src/config.js）保留；
- **CJK 路**：余文按非汉字字符切段（标点空白皆断——bigram 不跨段），
  段内汉字 bigram 滑窗（段长 ≥2 方出窗）；

**指代判定**：指代形 6——中文 4（见下、如下、下文、上文）∪ 英文 2
（see below、tbd，词界大小写不敏感）——**因面前缀判定**：因面剥前导
标点空白后，以指代形**开头**（中文前缀 ∪ 英文词界前缀）→ **泛因**
注记（因之无物，无从对账，0 分——「根因如下」「根因：见下节」皆归
此档；因面中后段的指代不触发：「根因是缓存过期，详见下文」照判）。
因面词元集为空（纯标点/全停词）同样泛因。

## 6. 推词门（疑而后言不入罪，行级）

归因行命中**推词** → 整行降为**显疑**注记（0 分留痕，不判通道）：

- 中文 12（子串）：可能、或许、也许、大概、疑似、怀疑、猜测、推测、
  估计、待验证、未验证、假设；
- 英文 12（词界，大小写不敏感）：may, might, possibly, perhaps,
  probably, suspect, suspected, guess, speculation, hypothesis,
  unverified, unconfirmed。

立场：**臆断之罪不在断而在确**——疑而后言者次之，确而不察者下。
推词门粒度是行（复合句前确后疑整行降档——降档方向是宽方向，宁纵）。

## 7. 果词（重演通道的果之词迹）

英文 9（词界，大小写不敏感）：error, fail, failed, exception, timeout,
crash, panic, denied, refused ∪ 中文 6（子串）：异常、报错、失败、
错误、超时。

## 8. 验因三通道（流内之验，先于本笔为据）

对稿面某笔（流内序 i）的因面词元集 T，证据只认**流内序 < i** 的调用：

- **拔验**（干预验证，清白）：存在成功 write 族调用 j < i，其对象径
  或 `args.content` 命中 T 中任一词元（**动过因**），且存在成功 exec
  族调用 k，j < k < i，其命令原文或结果 content 命中 T 中任一词元
  （**其后验过果**）；
- **重演**（果之重现，望档证据）：exec 族调用（成败皆算——败相在文
  不在旗）其命令原文或结果 content 同笔共现 T 中任一词元 ∧ 果词，
  ≥ **2 笔**（与疑因相关的错误重现过——可复现是归因的最低实验）；
- **勘验**（现场之望，望档证据）：成功 observe 族调用（isError !==
  true ∧ content 非空）正文命中 T 中任一词元，或成功 exec 族调用
  （isError !== true）其命令原文或结果 content 命中 T 中任一词元
  （看过与因相关之物/跑过相关命令——看过 ≠ 验过）。

判定序（每归因行锁死）：**拔验清白** → **迟验**注记（拔验的 write
与 exec 对全部在 i **之后**——先断言后补的干预验证，0 分留痕；勘验/
重演在后不采不注——望不洗臆，既知代价）→ **重演/勘验**在场 →
**望断** +15（重演勘验同在只立一案，从重不叠）→ 全无 → **臆断** +30。
每行至多一案。

失败之见不是见：isError === true 的 observe/write 永不生勘验与拔验
（404 之读不是看过、失败之写不是动过）；exec 的成败只影响勘验与拔验
通道——重演通道专认败相（成败皆算：果词 × 因面同笔即果之形迹）。

## 9. 判定序（每稿锁死）

1. **立案前豁免**：臆册 excuse ∪ 演域名段 → 整稿免审（不审不记）；
2. **诊面门**：稿径小写化不命中诊面形 → 不入断账（不审不记）；
3. **逐行判定**（行序）：归因形提取（无 → 下一行）→ 推词门（命中 →
   显疑注记，下一行）→ 因面提取与词元化（剥指代后空 → 泛因注记，
   下一行）→ 验因三通道（拔验清白 / 迟验注记 / 望断 / 臆断）；
4. **案排序锁死**：稿径 → 行号 → 案别（臆断 < 望断）；注记排其后
   （显疑 → 迟验 → 泛因）。

行=案单位，案案独立——一行只取首归因形，一稿多行多案（cap 见 §10）。

## 10. 臆值门禁

```
yi   = min(60, 30 × 臆断)
wang = min(40, 15 × 望断)
total = min(100, yi + wang)
```

分带：**澈 0–14 / 望 15–29 / 臆 ≥30**；门默认 30——**单臆断即红**
（确而不察，与讲学家之「确论」同罪）、**双望断即红**、**单望断黄牌
点名不咬门**（寺僧式的动手——动而无当，黄牌档正为它留）。

counts：`yd` 臆断 / `wd` 望断 / `xy` 显疑 / `cy` 迟验 / `fy` 泛因。
score：`yi` / `wang` / `total`。

## 11. 臆册

册形 `{ "version": 1, "excuse": ["docs/drafts/*"] }`。excuse 免审
诊面径，声明权全在任务方：免审是「本文书是推演/草稿性质」的明言；
无册照判（凡因必验——归因之责不挑文件，豁免授权只能来自册）。
register/revoke 归 CLI；插件只吃注入的 book 对象。v1 只豁免，不扩形
（诊面形/归因形/推词/果词表内置固定）；**无基径**——归因验证没有
「不必再验」的正当明言（察传有 grounds，本层不要：物可以「任务方已
知」，因不可以「任务方保真」——因果之验正是写报告的本份）。

## 12. 溯牌块（接缝供给）

逐字节确定，shasum 可证：

- 臆册公示（无册出确定性文本「臆册：未立（凡因必验）」）；
- 词法公示（诊面形 14 · 归因形 12 ∪ 9 · 验因三通道 拔验/重演/勘验 ·
  推词门）；
- 案账清点（yd/wd/xy/cy/fy）；
- 逐案点名 `诊径:行:案别:指纹`——指纹为案行的 djb2。**永不携带行
  原文与因面原文**（因面词元是行内内容切片，比察传的径指物更贴文——
  连词元也不进块，掩码是结构性保证）。

## 13. 边界（与相邻各层）

- **chachu**：一物一因。它审断言之**物**进没进流（存在性——目见即
  清白，看过即据）；本层审归因之**因**验没验（因果性——看过现场只
  算勘验望档，要拔验才清白）。**「看过」是它的清白线，是本层的黄牌
  线**。词面零交集：它的得言形（使用/包含/位于）与本层归因形（根因
  是/caused by）无一重合；它的指物是径形词元，本层因面是归因形后
  内容。复盘报告说「根因是缓存」时 chachu 沉默（归因形不是得言形、
  缓存不是径指物），本层过堂。
- **xiaoyan**：一报一因。它称**成功成报**之实（效词表「完成/成功/
  pass」——绿有没有做过事）；本层称**诊断成报**之验（归因形——因
  有没有被实验过）。效词与归因形零交集；它审收工的完成宣言，本层审
  文中的根因结论。
- **jiubian**：一败一因。它勘**失败后行为**（盲捶——同一失败的重复
  动作）；本层审**失败后之言**（归因——对失败原因的确信断言）。同一
  个失败会话：它记账里捶了几遍，本层查报告里断得有没有据——行为面
  与言面两账并行。
- **shihu**：一状一因。它审**完成态声明**对自流作工（状词「已完成/
  全绿」）；本层审**根因断言**对流内验迹（归因形「根因是/root cause」）。
  词表零交集。
- **jiaotuo**：一托一因。它审**自称原文的引语**对所托文书（需引号与
  引形）；本层审**不引原文的归因**对流内验迹（归因形与因面）。引语
  与归因在词面上互斥。
- **zhixia**：一数一因。它审卷内自洽（言列总分日序——不需要世界在
  场）；本层审归因对流内验证（必须世界在流内在场）。
- **zhixing**：一令一因。它审章程必行令行没行（行为对章程）；本层审
  根因断言验没验（言对流内验迹）。
- **fangchuan**：一川一因。它审代码里的吞错口（catch 空体——报错被
  咽下）；本层审文书里的臆断（根因没验过——结论悬空）。码面与卷面。
- **weibing**：一诊体一因验。t=0 诊任务书与环境（体质体检——触环
  境）；本层 t>0 审归因之言的流内验迹（零环境——证据全在流内事件）。
  「诊」字它在「四诊/病灶」，本层在「诊面」——词面互不包含。
- **jiebi**：它校认知账本（判断去蔽——确认偏误等，账本协议）；本层
  词法流内对账（验因形迹——零认知协议）。归因偏误的认知面归它，形迹
  面归本层。
- **lunshi/huashui/youya/shenqu/mingshi** 诸层各守输入权威、落笔时鲜、
  见闻重复、读据残全、码面名实——与归因之验正交。
- **zhizhi/yuli/duzhi/baihe/erbing** 等行为、退路、花销、出境、权柄
  诸层在动作面，本层只在诊面之稿的**归因言面**；行为再干净，臆断照样
  立案。
- **buer**：跨会话教训归它，验因证据互认只是离线重放不是跨会话学习，
  断账是流内账，本层不做任何跨会话学习。

## 14. 既知代价（宁漏勿诬的让渡，逐条登记）

- 因面词元是词面切片：复合因果链（「网络抖动引发序列化失败引发数据
  丢失」）整面一账不拆链——拆链是语义工作，宁纵；**跨语言词面不可
  对账**（中文因面「缓存过期」与英文证据「cache」词元不相交——翻译
  是语义工作；代价：中文归因 × 英文日志的验迹漏判——宁纵方向，
  同语言词面对照在岗）；
- 后置归因形不判（「X 所致」句式不收——宁纵）；纯连接词（因为/由于/
  导致/造成/引发）不入归因形（「由于篇幅限制」类保护；代价：口语化
  归因「就是因为 X」不中——宁纵）；诊面外文书不审（README 例释的
  「根因是」不判——宁纵）；exec 命令行与会话话语侧的归因不审（无稿
  面——宁纵）；
- 拔验从宽（write 与 exec 各命中因面任一词元即成对——不核改动语义
  是否真针对疑因、不核 exec 是否真在验证）；勘验从宽（词元共现即认
  看过——grep 到过也认）；重演从宽（命令或输出含因面词元与果词即认
  ——不问命令性质）；exec 结果 content 是巨大的日志正文时词元共现
  更宽（cat 到过也认）——三从宽皆宁纵方向（防诬优先）；
- 勘验要求 observe 带 content（老流无正文不可词元比对——宁纵）；
  勘验/重演在后不采不注（望不洗臆——事后看一眼补不了因果；代价：
  断言后紧接着的真实勘验不降档——宁严一格登记）；
- 行级推词门（复合句前确后疑整行降档——显疑是注记不是罚分，降档
  即宽，无诬之险）；行级单归因形（一行两归因只判首形——宁纵）；
- 「rca」三字母偶可撞他径；果词表窄（未及错误形态不中重演——退勘验
  档望）；「估计」等常词在推词表（诊面里「估计需要重启」连带降档——
  宽方向）；
- 词法可欺但骗一次留一次形；时序以流序为准（缺 at 照判）；零 LLM。
