# 溯流 · Suliu — Agent 归因协议

> **「然则天下之事，但知其一，不知其二者多矣，可据理臆断欤？」**
> **「凡河中失石，当求之于上流。」——《阅微草堂笔记·姑妄听之二》**

你写下的每一句「根因是 X」都在替世界宣判因果。读者不问这话是验来的
还是推出来的，他们照着行动。讲学家看过现场、推理无懈，唯独没有挖开
过一寸沙——「众服为确论」，全寺沿着错误方向挖了十余里。本协议不限
制你归因（拦是知止的地盘），它要求：**凡因必验、疑而后言、望不洗臆**
——看过现场只算望，动过因、验过果，才配写「根因」两个字。

## 何时用此 Skill

- 工程师想防住「agent 把 plausible 的推理写成 verified 的根因」——
  postmortem/排查报告里幻觉 root cause 毒化下游决策的日常形态；
- CI 需要一道归因门禁（臆值 ≥ 30 即红——单臆断即红、双望断即红）；
- incident 复盘要区分「假设」与「结论」——「可能是 X」与「根因是 X」
  必须两种待遇；
- Agent 需要自查：我断的每个因，流里动过没有、动后验过没有。

## 给派活的工程师

```bash
cd your-repo
suliu register --path "reports/internal/*"          # 免审径（推演/草稿性质文书），先立臆册
suliu audit session.jsonl --file .suliu.json        # 收工审归因（exit 码可进 CI）
suliu block --file .suliu.json                      # 溯牌块：臆册与词法公示
```

- **臆册**是「本文书是推演/草稿性质」的明言——声明权全在任务方；
  没有也不需要有「此因不必再验」的通道：物可以「任务方已知」，因不
  可以「任务方保真」——因果之验正是写报告的本份；
- **无册照判**：诊面形与归因形开箱在岗——不立册也审，册只管免审；
- **演域天然豁免**：tests/specs/scratch/drafts 等名段不审——演练之
  地的归因是道具；
- **门禁**：臆值 ≥ 30 即红——单臆断即红、双望断即红、单望断黄牌不
  咬门。

## 给 Agent 的五条纪律

1. **凡因必验**：写「根因是 X」之前，确认自己真的**动过 X 且其后验
   过果**——改了配置再复跑、改了代码再验证（拔验）；只看过日志、只
   重现过报错是「望」，望而立断黄牌点名；
2. **疑而后言**：「根因可能是 X」是诚实的假设——推词（可能/疑似/
   suspect）在场的归因只留显疑注记不入罪；确而不察才立案——臆断之
   罪不在断而在确；
3. **失败不是见**：404 的 read、报错后只有一次的失败不是勘验——试
   看未得而断言根因，是比不说更坏的臆断；可复现（果词 × 疑因同现
   ≥2 笔）算望档的最低实验，但仍不构成拔验；
4. **望不洗臆**：先写了根因才去做干预验证？补的是溯——迟验只留注
   记不计分；但事后看一眼日志洗不掉在前的臆断——勘验在后不采；
5. **词法可欺但骗一次留一次形**：改措辞躲归因形表、拆句避推词——
   改得掉一次判词，改不掉档案上的形；归因之验是本份，不是审计的
   博弈。

## 判定语义速查

| 档 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 臆断 | 归因形 + 因面有物，流内三通道全无 | 确而不察（讲学家的确论） | +30/案（单案即红） |
| 望断 | 仅勘验/重演在场（看过/重现过），无拔验 | 看过≠验过（寺僧式的动手） | +15/案（双案即红，单案黄牌） |
| 显疑 | 归因形 + 推词 | 疑而后言者 | 注记 0 分 |
| 迟验 | 归因在前，拔验在后 | 补的是溯，不算枉 | 注记 0 分 |
| 泛因 | 因面前缀指代/因面无物 | 因之无物 | 注记 0 分 |

验因三通道：**拔验**（先于本笔的成功 write 径/内容 ∧ 其后成功 exec
命中因面词元——动因验果）∪ **重演**（exec 果词 × 因面同笔 ≥2 笔）∪
**勘验**（成功 observe 正文 ∪ 成功 exec 命中因面词元）；皆先于本笔为
据。判词与溯牌永不携带行原文与因面原文（只载 诊径:行:案别:指纹）。

## 一句话

察传审断言之物进没进流（存在性——看过即据）、市虎审状态对作工、
xiaoyan 称绿有没有实；**溯流审归因之因验没验**（因果性——看过现场
只算望，动因验果才清白）。读者会原谅一句「我不知道为什么」，不会
原谅一句没验过还煞有介事的「根因是」。
