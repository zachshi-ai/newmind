# 03 · 设计：察传 · chachu —— DeepSeek Harness 的无见立言治理（察传式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**察传式插件**（第四十一个）。youya 证明插件可以记见闻账，
jiyi 证明成功装载与成功执行可以作问凭据，mingshi 证明流内成功读写可以
生实，shihu 证明插件可以审文书对自流作工，jiaotuo 证明可以审落卷之引
对所托之文——察传证明插件可以**审言对所见**：哪一句断言的所指之物从
未进过流。

```
tools/result   emit   见据记流内之见；write 稿面入传账判言（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零
子进程、零文件系统探测——言、物、见全取自流内词面与事件）；观察永不
反噬（监听器异常吞掉，管道照常）；证册持久化归 CLI（register/revoke），
插件只吃注入的 book 对象；单会话视图的案与值只采本会话（跨会话见据
互证归离线合并审计）。

## 2. 对象与通道（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:`
不透明；observe/write/exec/other 四族）。径规整同全仓（反斜杠归正斜
杠、剥 `./` 前缀、剥尾 `/`）。

**传账收全流，判言只判写**：全族调用逐笔记入传账（见据要用目见/书见/
验见三面）；判言只落在 write 族 p: 径 ∧ `isError !== true` ∧
`args.content` 非空字符串的**稿面**上。isError === true 之写不入稿账
（失败之写没落盘）；isError 未知（null，老流）按已发生；无 content 之
写（edit 族等）无稿可判，不入稿账。

observe 族结果与 exec 族结果永不判言（数据渠道的话不是 agent 的断言；
命令行无稿面结构——commit message 里的断言没有稿面可对，宁纵，既知
代价）；other 族不入。

**豁免（立案前）**：证册 `excuse` glob 命中稿径 ∪ **靶场**名段命中
稿径 → 整稿不审不记（受审稿计数不含）。靶场是立言演练之地（测试夹具
里的断言是演武的道具）：正则形 10——`(tests?|specs?|__tests__|__mocks__|
fixtures|debug)/` 名段（目录段在径首亦算段）∪ `.test.`/`.spec.`/
`.mock.`/`.debug.` 尾形。

**合审序（CLI 多流）**：全 at 有数 → `(at, 流序, 流内序)` 稳定排序；
否则参序拼接（审计方须自证流序）。单会话运行时视图同法自洽。

## 3. 得言形（断言之词法，默认内置，零 LLM）

得言形是「自称事状」的词迹——陈述某物如何如何，而非引用某物说了什么
（引语归 jiaotuo）、非宣称任务完成（状词归 shihu）、非指路（详见/参见
不在表内）。判定单位是**行**：得言形与指物同行共现方成言，一行多形
多物逐案独立。

**中文形 30**（子串命中）：

写着 写有 载有 包含 含有 内含 使用 用到 采用 启用 配置了 已配置
设置了 已设置 位于 存于 存放在 存储在 集中在 输出到 输出至 生成于
保存在 定义在 定义于 实现在 声明在 调用 支持 返回

**英文形 23**（词界，大小写不敏感）：

contains, includes, uses, uses the, uses a, lives in, lives at,
located in, located at, stored in, stored at, defined in, defined at,
declared in, implemented in, implements, exports, returns, supports,
written to, generated in, exists in, found in

否定形不设（「不包含」「并未位于」同案——断言缺席与断言在场一样需要
见据；子串命中天然覆盖）。

## 4. 指物（断言之对象的径形词法）

得言形同行提取**指物**——断言指向的那个物。三档：

- **径指物**（档一，立案幻言 +30）：token 含 `/`（URL 域内者见网卫）；
  或 token 命中**专名底表**（大小写敏感全等 10）：README.md、AGENTS.md、
  CLAUDE.md、GEMINI.md、CONTRIBUTING.md、CHANGELOG.md、Makefile、
  Dockerfile、Jenkinsfile、CMakeLists.txt；或 token 以 `.` 开头且余部
  全小写（dotfile：`.env`、`.gitignore`、`.npmrc`）；或 token 命中
  **小写扩展名规则**：`^[a-z][a-z0-9_-]*\.[A-Za-z][A-Za-z0-9]{0,5}$`
  且尾段 ∈ 扩展名白名单 44（js mjs cjs jsx ts tsx mts cts py pyi rb go
  rs java kt kts swift c h cc cpp hpp cs php md markdown txt json jsonc
  json5 yaml yml toml ini cfg conf xml html htm css scss sass less sql
  sh bash zsh fish env lock log csv tsv svg proto properties gradle
  gemspec pl pm lua dart ipynb）——大写词干（Node.js、TypeScript、
  CommonJS）不中，数字词干（v16.17.0）不中，白名单外尾段（example.com
  之 com）不中；
- **自指**（档一，同幻言档）：同行命中自指形——中文 7：本文档、本报告、
  本文件、本方案、本说明、本清单、本篇 ∪ 英文 4：this document、
  this file、this report、this doc——指物即稿径自身（本笔即据，书见
  天然成立）；
- **目录指物**（档二，立案疑言 +15）：token 全等命中**目录底表 18**：
  src lib bin docs tests test config scripts packages app core utils
  tools examples assets public build dist（裸目录名断言——信一半）。

token 词法：行内按 `[A-Za-z0-9_\-./@]+` 切词；**网卫**：行内 URL 跨度
（`https?://\S+`）之内的 token 一律不作指物（`https://example.com/guide/
src/config.js` 里的 config.js 不中）；径指物与目录指物同行并存时逐个
立案；同 token 重复命中只立一案。

## 5. 模态门（将然未然不判，行级）

行内命中模态词 → 整行静默跳过（不是断言，是嘱咐、计划与假设）：

- **中文 24**：将把、将要、将会、即将、将来、应当、应该、需要、务必、
  请、建议、不妨、可以、可能、或许、也许、大概、如果、若、一旦、待、
  计划、打算、考虑；
- **英文 11**（词界，大小写不敏感）：will, shall, should, must, may,
  might, could, would, todo, fixme, tbd。

「将」单字不设门（「该项目将配置集中在 src/config.js」是陈述不是将来
——只认「将把/将要/将会」复合形，既知代价）。

## 6. 见据三通道（流内之见，先于本笔为据）

对稿面某笔（流内序 i）的某指物 P，见据只认**流内序 < i** 的成功事件：

- **目见**：observe 族调用，对象键 `p:` 规整相等 P，`isError !== true`
  （404 之读、失败之见不是见——试看未得不为据；老流无 content 照认，
  成功即见）；
- **书见**：write 族调用，对象键 `p:` 规整相等 P，`isError !== true`，
  流内序 < i（自己写过的物自己知道；P = 稿径即自指，本笔即据）；失败
  之写不是见；
- **验见**：exec 族调用，`isError !== true` ∧ 命令原文含 P 逐字子串
  （jiyi 问凭据同法从宽——命令含名即认；命令性质不问，rm 之罪归他层）。

流内序 **> i** 的见据 = **迟证**注记（先断言后补看，0 分——宁纵，账上
留痕）；全流皆无 = 案（径指物 → 幻言 +30，目录指物 → 疑言 +15）。
证册 `grounds`（**基径**）glob 命中 P → 清白（任务方明言之物，言之有
据——声明权全在任务方）。

## 7. 判定序（每稿锁死）

1. **立案前豁免**：证册 excuse ∪ 靶场名段 → 整稿免审（不审不记）；
2. **逐行判定**（行序）：模态门 → 得言形提取（无 → 下一行）→ 指物
   提取（径指物 ∪ 自指 ∪ 目录指物；全无 → **虚指**注记，一行一记
   0 分）→ 逐指物对账：基径 → 见据三通道（先见清白 / 后见迟证 /
   无见立案：径指物 幻言 +30，目录指物 疑言 +15）；
3. **案排序锁死**：稿径 → 行号 → 案别（幻言 < 疑言）→ 指物；注记排
   其后（迟证 → 虚指）。

行=案单位，案案独立——一行两指物两案、一稿多行多案（cap 见 §8）。

## 8. 幻值门禁

```
huan = min(60, 30 × 幻言)
yi   = min(40, 15 × 疑言)
total = min(100, huan + yi)
```

分带：**彰 0–14 / 疑 15–29 / 诞 ≥30**；门默认 30——**单幻言即红**
（断言之物不在场，与穿井得一人同罪）、**双疑言即红**、**单疑言黄牌
点名不咬门**（裸目录断言信一半——黄牌档正为它留）。

counts：`hy` 幻言 / `yy` 疑言 / `cz` 迟证 / `xz` 虚指。
score：`huan` / `yi` / `total`。

## 9. 证册

册形 `{ "version": 1, "excuse": ["docs/reports/*"], "grounds":
["src/config.js"] }`。excuse 免审稿径、grounds 基径（任务方明言之物），
声明权全在任务方：免审是「本任务授权之稿」的明言，基径是「此物不必
再看」的明言；无册照判（凡言必据——断言之责不挑文件，豁免授权只能
来自册）。register/revoke 归 CLI（管 excuse），grounds 直改册文件；
插件只吃注入的 book 对象。v1 只豁免与基径，不扩形（得言形/指物/模态
词表内置固定）。

## 10. 证牌块（接缝供给）

逐字节确定，shasum 可证：

- 证册公示（无册出确定性文本「证册：未立（凡言必据）」）；
- 词法公示（得言形 30 ∪ 23 · 指物三档 · 见据三通道 目见/书见/验见）；
- 案账清点（hy/yy/cz/xz）；
- 逐案点名 `稿径:行:案别:指物:指纹`——指纹为案行的 djb2。**永不携带
  行原文**（指物与案别是案的断言数据不是文面——掩码是结构性保证）。

## 11. 边界（与相邻各层）

- **jiaotuo**：一托一证。它审引语对所托原文（「文里有没有这句」——
  需引号与引形），本层审断言之物对流内之见（「这本进过流没有」——
  需得言形与指物）。**引语不避**：带引号的断言行照判——所托之本在
  流内时它账上有诏本、本层有目见，两清；所托之本不在流内时它给阙据
  注记（0 分），本层给幻言（+30）——**本的缺席只有本层计分**。
- **shihu**：一状一证。它审交接径的完成态声明对自流作工（状面形 +
  状词），本层审任意稿面的平铺断言对流内见据（得言形 + 指物）——
  「已修复」归它、「使用 CommonJS」归本层，词表零交集。
- **kaocheng**：一契一证。它考任务方立契的交付物（无册不判），本层
  无册照判、凡稿皆审（立言之据不是契约是本份）。
- **xiaoyan**：一报一证。它称流内成报之实（绿有没有做过事——信号
  侧），本层称落卷断言之据（言有没有所指之见——文书侧）。
- **mingshi**：一名一证。它核码面幻名（import 之名有没有实——包与
  模块），本层核卷面所指（断言之物进没进流——文件与目录）；幻包
  归它、幻言归本层。
- **jiyi**：一问一证。它审动前问没问（疑册登记之疑的问凭据），本层
  审笔下言有没据（断言的见据）；借同一批成功事件作凭据，一在行前、
  一在言侧。
- **weibing**：一诊一证。t=0 诊任务书引用在环境里在不在（触环境），
  本层 t>0 审断言之物在流里进过没有（零环境——证据全在流内事件）。
- **youya**：一重一证。它记重装载之费（读过的再读），本层借装载作
  见据（读过的能说）——同一笔目见它记账、本层作据，两账并行不悖。
- **shenqu**：一残一证。它称读据残全（看见的完不完整），本层称断言
  有没有见（言对物在场）；残而能断是它的案、无见而断是本层的案。
- **huashui**：一鲜一证。它审陈据覆新（时鲜——见据过期），本层只审
  在场（见据存不存在）——物进过流之后变没变归它，进没进过归本层。
- **zhixing**：一令一证。它审章程必行令行没行（行为对章程），本层审
  断言所指进没进流（言对所见）。
- **zhixia**：一数一证。它审稿面对稿面自己（言列总分），本层审言对
  流内世界——它不需要世界在场，本层断的就是世界在没在场。
- **lunshi**：一世一证。它审数据渠道有没有冒充主命发令（入面的资格），
  本层审笔下断言有没有流内之见（出面的根据）。
- **zhizhi/erbing/yuli/duzhi/baihe** 等行为、权柄、退路、花销、出境
  诸层在动作面，本层只在落卷之稿的**言面**；行为再干净，无见立言
  照样立案。
- **buer**：跨会话教训归它，见据互证只是离线重放不是跨会话学习，
  传账是流内账，本层不做任何跨会话学习。

## 12. 既知代价（宁漏勿诬的让渡，逐条登记）

- 指物是 ASCII 词面（中文路径、「测试目录」式中文指称不判——宁纵）；
  裸目录名只认底表 18（自建目录名不中——证册 grounds 兜底）；大写
  词干专名不判（Node.js/TypeScript 之断言不可见——宁纵）；
- 得言形未及的句式不判（「由 … 组成」「定义了三个超时」类——词表
  可增但 v1 固定）；指路词（详见/参见/见）不是得言形；「共 N 个」
  的数目声明归 zhixia；
- 夔一足不判（所言与所指之义的偏差是语义失真——NLI 零 LLM 做不了，
  不假装能做；本层只断在场不断真伪——物在场而言伪，是「审」的更深
  一层，归人与下游语义工具）；
- 验见从宽（命令含名即认，不问命令性质——rm 掉之后声称它存在，本层
  看不见；罪归他层）；目见不问 content 有无（老流成功装载即据）；
- 引语不避（带引号断言行照判——与 jiaotuo 并行，阙据在它账上是注记
  在本层是幻言）；「将」单字不设门（「该项目将配置集中在 …」照判，
  将然侧既知误伤由复合形收窄）；
- exec 命令行的断言不审（commit message 无稿面——宁纵）；会话话语侧
  的口头断言不审（归 licheng/xiaoyan——文书之外无稿面）；
- 时鲜不判（见据过期归 huashui——物进过流后世界变了，本层照清白）；
- 词法可欺但骗一次留一次形；时序以流序为准（缺 at 照判）；零 LLM。
