# 矫托 · Jiaotuo — Agent 协作协议

> **「国家与公卿议，大策非凡所见，事必不从。」**
> **「会其久病，汤独矫制发城郭诸国兵、车师戊己校尉屯田吏士。」**
> **「延寿、汤上疏自劾奏矫制，陈言兵状。」——《汉书·卷七十·傅常郑甘陈段传》**
>
> 矫者，托也：所托之制并非天子所出。agent 写报告、交接书、commit message
> 时也需要一个依据撑住自己的决定——于是笔下生出「AGENTS.md 规定『X』」，
> 而所托之文里根本没有这句话。伪据比无据更毒：无据一眼可见，伪据自带
> 权威外观。本协议不限制你落笔（拦是知止的地盘），它要求：引的哪句话、
> 原文里有没有、有没有人核过，账上都要见得到——引必有据，托必有本。

## 何时用此 Skill

- 工程师想防住「agent 在报告/交接/commit message 里伪造依据」——法律 AI
  判例幻觉（Mata v. Avianca）的日常作业形态；
- CI 需要一道伪据门禁（矫值 ≥ 30 即红——单矫引即红、双佚据即红）；
- 多 agent 编排里，主会话要防子 Agent 转述任务书时凭空增发「规定」；
- Agent 需要自查：我写下的每句「按规定」，原文里真的有吗？

## 给派活的工程师

```bash
cd your-repo
jiaotuo register --path "docs/reports/*"            # 免案径（模板报告等），先立诏册
jiaotuo audit session.jsonl --file .jiaotuo.json    # 收工审托（exit 码可进 CI）
jiaotuo block --file .jiaotuo.json                  # 矫牌块：诏册与引形公示
```

- **无册照判**：引形 25 开箱在岗——不立册也审，册只管免案一侧；
- **免案是授权**：模板文书、示例报告确需自由落笔，开工时把径列进诏册；
- **门禁**：矫值 ≥ 30 即红——单矫引即红、双佚据即红、单佚据黄牌不咬门。

## 给 Agent 的五条纪律

1. **引必有据**：写「AGENTS.md 规定『X』」之前，打开 AGENTS.md 找到 X——
   引号是「原文引用」的记号，引号里的每一句都要在原文里逐字征得；
2. **托必有本**：引哪份文书就把名字写明——「AGENTS.md 规定」远强于
   「有关规定」；未指名的改写式转述进泛引注记，指名查无的原文引用
   单案即红；
3. **托主之引留凭**：引用户的话（「用户要求『删掉测试』」）是托主注记
   不判分——但用户的原话要有处可查，导出流里没有主渠道正文，线下终裁；
4. **功是功，托是托**：活干得再对，托名一句不存在的「规定」也是伪据
   （陈汤军功千古，矫制之罪照议）——需要新规矩，向任务方讨诏册增补，
   不要笔下立法；
5. **词法可欺但骗一次留一次形**：去掉引号变转述、换份文书名——改写式
   词元过半查无是佚据黄牌，档案上留痕。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 矫引 | 引形 + 引号引语，引语在诏本查无（指名查指名、未指名全库查） | 伪托原文——自称原文而原文无此语 | +30/案（单案即红） |
| 佚据 | 指名托径 + 无引号改写式，词元过半在诏本查无 | 转述大半无据——黄牌点名 | +15/案（双案即红，单案黄牌） |
| 征引 / 征据 | 引语诏本命中 / 词元过半命中 | 真引用 | 0（清白） |
| 托主 | 引形 + 托主词（用户/任务方/you said…） | 引的是主渠道——导出流无主文 | 0（注记，线下终裁） |
| 阙据 | 指名托径而流内无该文书诏本 | 所托之文没装载过——无从对账 | 0（注记，诚实沉默） |
| 泛引 | 有引形无引号未指名 | 泛泛转述——不必然自称原文 | 0（注记） |

- 引形 25（文书型 16：规定/章程/任务书/写明/明言/明确指出/条例/守则/依据/
  per/according to/as stated/as defined in/as noted in/as documented in/as
  specified；泛型 9：要求/明确要求/遵照/约定/as required/as mandated/
  required by/mandated by/as per）——英文词界、大小写不敏感；
- 引语三式：中文「」『』 ∪ 英文双引 ∪ 英文单引（撇号防御）；原文 ≥4 字符；
  嵌套取内（`-m "per X: require '…'"` 只判内层）；
- 诏账：observe 的 `result.content` ∪ write 的 `args.content` 皆生诏本
  （末据覆盖），write 先判后录；托面 = write 按行 ∪ exec 按笔（皆非失败）；
- 矫值 = min(60,30×矫引) + min(40,15×佚据)，total = min(100)；
- 分带 信 0–14 / 疑 15–29 / 矫 ≥30，门 30；
- 全部判定零 LLM：引形与引语是公开词法、诏账全取自流内——引必有据，
  托必有本。
