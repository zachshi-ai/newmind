# 矫托 · jiaotuo —— DeepSeek Harness 的伪据虚引治理

> **「国家与公卿议，大策非凡所见，事必不从。」**
> **「会其久病，汤独矫制发城郭诸国兵、车师戊己校尉屯田吏士。」**
> **「延寿、汤上疏自劾奏矫制，陈言兵状。」——《汉书·卷七十·傅常郑甘陈段传》**

agent 写报告、交接书、commit message、PR 描述时需要一个依据撑住自己的
决定——于是笔下生出「AGENTS.md 规定『X』」「Per AGENTS.md, the rule is
"Y"」，而**所托之文里根本没有这句话**。伪据比无据更毒：无据一眼可见，
伪据自带权威外观——审查者、下游会话、未来审计全都对着一句不存在的话
做决策。编造判例引用的法律 AI（Mata v. Avianca，律师被法院制裁）是此病
的社会级事故样本；多 agent 编排里子 Agent 转述任务书时凭空增发「任务
要求 X」，是此病在日常作业里的家常形态。

**矫托**给 DeepSeek Harness 装上第三十九个能力类型：**矫托式插件**（结构性
零拦截）+ 零依赖审计 CLI + Agent Skill。矫者，托也。它不拦写（账与闸分治，
拦是知止的地盘）、不做语义判断（不判这次引用的动机善恶——裁决权归人：
诏册免案明言即免），只做词法可证的一问：**这句自称原文的引语，在所托
文书的原文里有没有**——引形 25 开箱在岗，引语三式（嵌套取内）自称原文
即核，诏账（流内装载与写下的文书正文）逐字对账，征得即清白、查无即案。

## 快速开始

```bash
cd your-repo
npm install github:zachshi-ai/newmind#jiaotuo-dsh     # 或复制本目录

# 开工（可选）：立诏册——模板文书等免案径先列明
jiaotuo register --path "docs/reports/*"              # 免案授权（* 跨目录）

# 收工：审托
jiaotuo audit session.jsonl --file .jiaotuo.json      # exit 0 通过 / 1 门禁红 / 2 用法错
jiaotuo audit s1.jsonl s2.jsonl --json                # 多流合审（诏账跨会话归并）
jiaotuo block --file .jiaotuo.json                    # 矫牌块：诏册与引形公示（逐字节确定）
```

无册照判：引形 25 开箱在岗——凡托皆记；伪据自带权威外观，免案授权只能
来自册。

## 判定语义（docs/03 锁死）

**托面唯二**：write 族按行 ∪ exec 族按笔（`git commit -m`、`gh pr create
--body` 是伪据重灾区），皆非失败之笔；isError===true 不入账。**诏账**：
observe 的 `result.content` ∪ write 的 `args.content` 皆生诏本（末据覆盖）；
write 先判后录——判时不用本笔自证。

**引形 25**（自称依据的引导词，文书型先于泛型）：

| 档 | 形 |
|----|-----|
| 文书型 16 | 规定 · 章程 · 任务书 · 写明 · 明言 · 明确指出 · 条例 · 守则 · 依据 ∪ per · according to · as stated · as defined in · as noted in · as documented in · as specified |
| 泛型 9 | 要求 · 明确要求 · 遵照 · 约定 ∪ as required · as mandated · required by · mandated by · as per |

**引语三式**（自称原文之文，原文 ≥4 字符，嵌套取内）：中文「」『』 ∪
英文双引 ∪ 英文单引（撇号防御：`don't` 不成对）。

**判定序**（逐行锁死）：

| 案 | 条件 | 分值 |
|----|------|------|
| 矫引 | 引语在诏本查无（指名查指名、未指名全库查） | +30/案（单案即红） |
| 佚据 | 指名改写式词元过半查无（CJK bigram ∪ 英文词元，命中比 <0.5） | +15/案（黄牌不咬门） |
| 征引 / 征据 | 引语命中 / 词元过半命中 | 0（清白） |
| 托主 | 引形 + 托主词同行（用户/任务方/you said…） | 0（注记——主渠道无文，线下终裁） |
| 阙据 | 指名托径而流内无诏本 | 0（注记——诚实沉默） |
| 泛引 | 有引形无引号未指名 | 0（注记） |

**矫值** = min(60, 30×矫引) + min(40, 15×佚据)，total = min(100)；分带
**信 0–14 / 疑 15–29 / 矫 ≥30**，门 30——单矫引即红、双佚据即红、单佚据
黄牌不咬门。

## 与相邻各层的边界

- **论世 lunshi**：一进一出——它审输入侧冒充（数据冒充主命发给 agent），
  本层审输出侧冒充（agent 冒充文书给世界立据）；
- **知行 zhixing**：一行一引——它审真章程不被遵守（读了不照做），本层审
  假章程被发明（章程没说的话说成它说的）；
- **市虎 shihu**：一状一引——它审状态虚报（「已修复」对自流作工），本层
  审依据虚托（「按规定」对所托原文）；
- **名实 mingshi**：一名一引——它审码面幻名（import 不存在的模块），本层
  审文面幻引（引文书里不存在的话）；
- **画水 huashui**：时鲜与存无——它审落笔对不对其时之世，本层审引语在
  不在原文里；
- **考诚 kaocheng**：一契一托——它考任务方之契对交付物，本层考落卷之引
  对所托文。
