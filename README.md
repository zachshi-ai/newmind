# newmind · 老思想 × 新智能 实验室

> 一门老思想，能不能精确地解决人工智能的一个真实问题？
>
> 每个项目走同一条完整生命周期：**明确谁在什么场景下的什么问题 → 定价值 → 设计 → 定验收标准 → 落地 → 自动化验证 → 文档**。每个点子都是可运行、可测试的成品，不是 PPT。

## 方向登记

为避免撞车，每个新项目开工前先对照此表：**方向不得与已有项目重复**。

| 项目 | 方向 | 与后来者的边界 |
|------|------|----------------|
| zhizhi | Agent 运行时行为治理（插件层，代码强制） | 只做"动作节制"的确定性约束，不做行为分析之外的治理；不改 harness 源码 |
| [newidea](https://github.com/zachshi-ai/newidea) | 软件工程工作分析（决策债务/文档漂移/过劳信号……） | 面向人的 git 仓库考古，不触碰 Agent 运行时 |
| [harness-fields](https://github.com/zachshi-ai/harness-fields) | AI 协作约束的文档方法论（字段记忆系统） | 方法论与文档层约束；zhizhi 是它的运行时下沉——"原则会被违反，触发器不会"的代码版 |

## 选书标准

1. 思想层面：哲学 / 管理学 / 佛学 / 道家等经典；
2. 能**逐条映射**到 AI 领域的某个真实失败模式，映射不牵强；
3. 产出的产品可运行、可测量、可证伪。
