# 01 · 选书：《列子·说符》—— 察见渊鱼者不祥

## 原文

《列子·说符》记赵襄子之事，引周谚：

> 周谚有言：「察见渊鱼者不祥，智料隐匿者有殃。」

深渊里有鱼，看见了，不是眼力好，是祸端开了头：藏在水底的东西本与人无涉，
一眼望进去，看的人从此与那点「藏」结了缘——知道了不该知道的，就背上了不该背的。
故古谚以「不祥」「有殃」断之：**窥探隐匿这件事本身，就是祸的起点。**

《列子》（《冲虚真经》）为道家四大经典之一，此谚是先秦对「看」这件事最直白的一句戒律：
眼有边界，看有代价，看见了藏起来的东西，殃就从看见那一刻开始记。

## 为什么是这本书

- 戒的不是「拿」，是「看」。业内的秘密治理都在管「拿走」（防出境、防落盘），
  而 agent 时代的新病恰好是「只是看了一眼」：会话里 `cat .env`，
  密物进了上下文窗口与 transcript——什么都没偷，什么都已经发生。
- 「不祥」记账在**看见**这一刻，不在使用那一刻。渊鱼层同样：装载即入账，
  至于这密物后来用没用、传没传，是下游各层的账；本层只回答「你看了不该看的没有」。
- 「智料隐匿者有殃」给出加重档：不光看了，还把所料所见的**拿出来用**——
  密值从视野流进命令参数与写入内容（转运），殃从「入目」升级为「入物」。

## 逐条映射

| 列子·说符 | 渊鱼层 |
|-----------|--------|
| 渊（深渊） | 敏感面：`.env`、`*.pem`、`~/.ssh/`、`.npmrc`……藏起来的东西所在之处 |
| 鱼（渊中之鱼） | 密物本身：密钥、令牌、凭据——本与人无涉之物 |
| 察见（看见了） | 装载：read 族读入 ∪ exec 窥词法（cat/less/grep/……）——密物进入会话视野 |
| 不祥 | 涉视案：未登记的敏感装载即入账计分（看见这一刻就记账，不等出事） |
| 智料隐匿（把所见的拿出来料用） | 转运：装载所得密值在更后的写入内容与命令词面中逐字重现 |
| 有殃 | 转运案（+30，即红）：殃从入目升级为入物，近泄露的确定性证据链 |
| 「看」的边界由谁定 | 礼册：本职径由任务方显式登记（改鉴权就该看 `.env`——册上明言即清白） |
| 周谚（众人共守的老话） | 默认秘形表：开箱在岗，不靠事后追认 |

一句话：**《列子》说看见深渊之鱼本身就是不祥，渊鱼层让每一眼「看进隐匿」都留痕、有价、过门。**
