# 渊鱼 · Yuanyu — Agent 协作协议

> **「察见渊鱼者不祥，智料隐匿者有殃。」——《列子·说符》**
>
> 深渊里有鱼，看见了，祸端就开了头。本协议不禁止你看（调试本来就要看配置），
> 它要求：不该看的暗处别用眼睛去趟——要看，先让任务方在礼册上明言这是本职；
> 看进来的密物，绝不能流转进写入与命令——那一步叫转运，殃从入目升级为入物。

## 何时用此 Skill

- 工程师想在收工时审计 Agent 会话的敏感面装载（transcript 可不可以放心归档/外发）；
- 合规需要一道「入目无禁区」门禁（渊值 ≥ 30 即红）；
- Agent 需要自查：这一单活，我看了哪些不该看的。

## 给委派任务的工程师

```bash
cd your-repo
yuanyu register --duty .env              # 开工立礼册：本职要看什么，明言即清白
# ……Agent 作业……
yuanyu audit session.jsonl               # 收工审目（exit 码可进 CI；无册照判）
yuanyu block --file .yuanyu.json         # 鉴牌块：礼册公示 + 视账清点（指纹掩码）
```

- **无册照判**：默认秘形 20 形开箱在岗（`.env`、`*.pem`、`.aws/`、`.ssh/`、`id_rsa`、`.npmrc`……）；
- **豁免要趁早**：本职径让任务方 `--duty` 签字——改鉴权的活就该看 `.env`，册上明言 0 分；
- **门禁**：渊值 ≥ 30 即红——单转运即红，两案涉视即红；单案涉视（15）黄牌点名不咬门。

## 给 Agent 的五条纪律

1. **眼有边界**（「察见渊鱼者不祥」）：`.env`、`*.pem`、`~/.ssh`、`.npmrc` 这类暗处，任务没点名就别看——看一眼，账上一笔；
2. **要看先立册**：确实需要看（任务本职），开工时向任务方申请登记 `--duty`——礼册明言即清白，事后追册只对后案生效；
3. **密物不过手**（「智料隐匿者有殃」）：装载所得的密值绝不抄进代码、测试、文档或 curl 命令——转运单案即红，这是本层唯一的死门；
4. **模板无罪，真值有账**：`.env.example` 这类模板随便看；把真值当模板看，白形救不了你；
5. **别把指纹当密文**：鉴牌块里的 `fp:…(len N)` 是对账用的指纹，不是脱敏——真值从来不该出现在你的输出里。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 涉视 | 未登记的敏感装载（observe 径秘形 ∪ exec 窥词法） | 命中默认/显式秘形、无 duty | +15/案 cap 45（单案黄牌） |
| 转运 | 密值流入后续写入/命令 | 装载后 write 内容/exec 命令原文逐字含值且写目标≠源径 | +30/案（单案即红，每源一案） |
| 本职 | 礼册 duty 命中的装载 | 声明权在任务方 | 0（注记） |
| 白形 | `.env.example/.env.sample/.env.template` | 模板无罪 | 0（静默出账） |
| 未得 | 失败之读 | isError=true | 不入账 |

分带：**澄 0–14 / 浊 15–29 / 渍 ≥30**；门默认 30。边界：捭阖管出境的物、本层管入目的物（一出一入）；有涯管装载的重、本层管装载的禁（一重一禁）；审曲称看见的全不全、本层称看见的该不该（一残一秘）；知足量写的量、本层审看的禁（一写一看）。礼册赦的是看，不是传——本职之值照样转运立案。
