# 审曲 · Shenqu — Agent 协作协议

> **审曲面势，以饬五材，以辨民器，谓之百工。**——《考工记·总叙》
>
> **凡斩毂之道，必矩其阴阳。**——轮人斩毂之前，必先标记毂木的向阳面与背阴面：动手之前，材的两面必须先登记在案。

本协议不禁止你动刀，它只要求你**看全了再动**：残卷之上落刀，每一刀都留痕上账——盲写不生据，残见必有名。

## 给 Agent 的三条审材戒律

1. **限窗必到底。** 带 `limit` 读取而回程行数恰等于窗值，说明窗后面多半还有——你没有看全。要么去掉窗参数读到卷尾，要么明确声明只动了窗内区域。**自证其全唯有一途：读到比窗小的回程。**
2. **残记必回头。** 读到的内容尾部挂着 `[truncated]` 一类的截断标记时，你手里是半卷。半卷上只做两件事合法：补一次完整读取，或者声明「我只依据了已见部分」。把半卷当全卷去推断结构、改写引用，是本协议第一罪（盲动 +30/案）。
3. **拼窗不成卷。** 对同一个文件连开三扇小窗（`limit=20`、`offset=10`、再 `limit=5`）而不做一次完整读取，你的结构认知是一张拼图——拼图上动刀之前先读全卷（碎览 +10/径）。

## 清白道（不会冤枉的行为）

- **取窗认全**：回程行数**小于**窗值 = 卷短于窗，你见到底了，这是全览；
- **补览赦免**：残见之后、动刀之前补了完整读取，从全览起清白（已立之案不销——时序以流序为准）；
- **自书为览**：你自己写过的径视同有据——create → 取窗 → patch 的 TDD 链条清白；但注意：**盲写不生据**，残见上落的第一刀不记自书，同径次刀照样立案；
- **豁免在册**：生成物、vendor、日志，任务方在 `.shenqu.json` 的 `exempt` 里签了字即全免出账。

## 对任务方

- 开工立册：`shenqu register --exempt <生成物子串>`；无册照判——默认残记 10 形、窗字段 18 名、碎览阈 3 窗开箱在岗；
- 收工审计：`shenqu audit <session.jsonl>`，残值分带 **全 0–14 / 昧 15–29 / 盲 ≥30**，门默认 30（`--gate` 由 CI 裁量）；
- 接缝供给：材牌块逐字节确定，盲动/碎览点名到径——「哪些文件是在没看全的情况下改的」从 mystery 变成一张复读工作清单。

## 分野（本协议不做什么）

知止问「写前读过没有」（读之有无），本协议问「读到的是全貌还是残卷」（读之残全）；有涯管读的重复，本协议管读的缺省；效验称报之空实（验的输出），本协议称据之残全（读的输入）；定分裁跨会话写域归属，本协议按会话分账读据成色——甲会话读全救不了乙会话的盲。
