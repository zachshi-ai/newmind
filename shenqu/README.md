# 审曲 · Shenqu

> **审曲面势，以饬五材，以辨民器，谓之百工。**——《考工记·总叙》
>
> **天有时，地有气，材有美，工有巧。合此四者，然后可以为良。**

一门两千三百年的审材之学，能不能精确地解决人工智能的一个真实问题？

能。LLM 编码代理有一个最隐蔽也最少被记账的病灶：**残卷盲动**。两千行的配置模块，它带着 `limit: 40` 取一扇窗，就推断出全部结构并在从未见过的第 380 行区域落刀；工具输出超限，harness 在尾部接一行 `[truncated]`，它把这半卷当全卷用，重构改断了被截掉的那半卷里的引用；同一个日志文件被取了三次窗，它对着不足全卷三成的拼图就开始改日志解析器。「它当时看见了什么」全部留在会话流里——只是从没有一层去称这份证据的残全。《考工记》说工匠的本分是先「审曲面势」再「饬五材」：看不全就动刀，不配谓之百工。

## 它是什么

DeepSeek Harness 的**审材式插件**（Cordis）+ 零依赖审计 CLI + Agent Skill——本实验室第二十四个能力类型：判定对象不是事件的性质，不是事件的数量形，而是**证据的成色形——看见的那一份完不完整**。

## 两通道、两宗与八道清白

残见的两通道全部是流内结构信号（零 LLM）：

| 通道 | 判定 | 经证 |
|---|---|---|
| **取窗** | 读调用参数命中窗字段表（限形 11 名存在即窗；偏形 7 名存在且 >0 即窗——跳卷首） | 「凡斩毂之道，必矩其阴阳」——动手前先登记材的两面 |
| **显残** | 读结果内容卷尾命中残记形表（默认 10 形认尾；册显式词认全文） | 「材美工巧，然而不良」——半卷上的工巧，不良只在后头 |

两宗：

| 案 | 判定 | 分值 |
|---|---|---|
| **盲动** | 残见之径上动刀（残见 ≥1 ∧ 全览 =0 ∧ 自书 =0；立案之笔不记自书——盲写不生据，逐笔立案） | +30/案 cap 60 |
| **碎览** | 只窥不作：残见 ≥3 窗而无全览无自书无盲动案（不双罚） | +10/径 cap 20 |

八道清白道不冤枉正当行为：**取窗认全**（回程行数 < 窗值 = 卷短于窗，见到底了）、**补览赦免**（残见后全览再动刀清白，已立之案不销——时序以流序为准）、**自书为览**（作者知道自己写过什么：create → 取窗 → patch 的 TDD 链条清白）、**豁免在册**（材册 `.shenqu.json` 签字全免出账）、**失败见不入账**（isError=true 什么也没看见）、**执行黑盒**（命令式读取不可寻径，宁漏勿诬）、**无据之见不判**（老流无 content——不证其残亦不证其全）、**点名不咬门**（单碎览 10 分落全带）。

残值 = min(100, 盲动 + 碎览)，分带 **全 0–14 / 昧 15–29 / 盲 ≥30**，门默认 30——单盲动即红；单碎览 10、双碎览 20 落点名带不咬门。**据证链按会话分账**：盲动的对象是「一个动刀者的见闻」，甲会话读全救不了乙会话的盲。

## 快速开始

```bash
cd your-repo
shenqu register --exempt vendor/            # 开工立材册（生成物签字豁免；残记/窗字段可增补）
# ……Agent 作业……
shenqu audit session.jsonl                  # 收工审材（exit 码可进 CI；无册照判，默认表开箱在岗）
shenqu block --file .shenqu.json            # 材牌块（可注入收尾上下文）
```

- **无册照判**：默认残记 10 形、窗字段 18 名、碎览阈 3 窗，开箱在岗；材册只管豁免、增词与调阈；
- **信任模型**：材册是任务方的声明，Agent 无从自我豁免；CLI 旗标（`--markers`、`--window-fields`、`--frag-windows` 等）是审计方的口径；
- **门禁**：残值 ≥ 30（默认门）即红；`--gate` 由 CI 自由裁量。
