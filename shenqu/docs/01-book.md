# 01 · 选书：考工记 × Agent 残卷盲动

## 书

《考工记》，先齐国官书，西汉补入《周礼》为《冬官》——一部记载百工之制的工艺典籍，也是中国最早把「质量」拆成可核查要素的管理学文献。开篇总叙把「良」字立在四个条件上，随即点出工匠的本分：**先审材，后动刀**。

选它的理由：在全部先秦典籍里，把「看全了材再下手」写成职业第一戒律的，以此书最为直接——它不是泛泛地劝人谨慎，而是把「审」落在具体的工序上：斩毂之前先矩其阴阳，制弓之前先辨六材。对一台「看半卷就敢动刀」的机器，这是一剂对症的药。

## 四条经证，逐条映射

### 其一，审曲面势——总纲

> 审曲面埶（势），以饬五材，以辨民器，谓之百工。

「百工」的定义本身就是一个动作序列：**先「审曲面势」**——审视材料表面的曲直、纹理的走向——**然后才「饬五材」**——动手整治。看不全就动刀，不配谓之百工。Agent 读一个两千行的文件只见了前四十行（工具输出截断），就推断出全部结构并落笔修改——这正是「不审曲面而饬材」：刀是快的，材是没看过的。

### 其二，材有美，工有巧——四合为良

> 天有时，地有气，材有美，工有巧。合此四者，然后可以为良。材美工巧，然而不良，则不时，不得地气也。

「良」不取决于「巧」一项。Agent 的产物可以处处显出「工巧」——代码通顺、测试通过——但只要它是建在**残材**（没看全的证据）之上的，「合此四者」就缺了一角，不良只在后头等着：CI 深处炸出一个它从没见过的模块引用，运行时踩进它没读到的那半张配置表。**工巧可见，材之残全不可见**——本层的职责就是让后者现形上账。

### 其三，斩毂之道，必矩其阴阳——工序即登记

> 凡斩毂之道，必矩其阴阳。阳也者，稹理而坚；阴也者，疏理而柔。

轮人斩毂之前，必先用矩标记毂木的向阳面与背阴面——两面纹理一坚一柔，下刀的方向全然不同。**动手之前，材的两面必须先登记在案。**本层的材账因之得名：每一次装载证据（读文件）都按其残全登记在案——全览入清白册，残见（取窗/显残）入待勘册；后续每一次动刀都先查这本账。

### 其四，取六材必以其时——残全有时序

> 弓人为弓，取六材必以其时。六材既聚，巧者和之。

六材必须**按其时**取用——早了未成，晚了已老。材的判断有时序，账的判断也有时序：补览救得了后续的刀，救不了已落的刀。残见之上动过刀（盲动立案），之后再读全（补览）也只是从下一笔起清白——时序以流序为准，案不因补览而销。

## 与既有各层书目的关系

- 《庄子·养生主》（youya #8）讲「生也有涯」——有涯管读的**重复**（世未变而重装载），考工记管读的**残全**（残卷上动工）：一书防遗忘之费，一书防盲动之灾；
- 《道德经》（zhizhi #1）「知止不殆」拦的是动作该不该发生——写前读过没有；考工记审的是读到的东西完不完整——**读过且读全，两戒相续才构成完整的先审后动**；
- 《黄帝内经》（weibing #4）望闻问切是对**人**的四诊——开工前体检任务书与环境；考工记审曲面势是对**材**的审察——动刀前勘验证据的残全：一诊体、一审材，皆先审而后动。
