# 02 · 问题：Agent 残卷盲动

## 场景（谁在什么场景下）

**谁**：DeepSeek Harness 上跑的编码 Agent（以及一切「会话流可重放」的 LLM 编码代理）的**任务方与审计方**——需要验收 Agent 交付的工程师、需要给 Agent 交付立门禁的 CI。

**场景一：取窗之后动刀。** 两千行的配置模块，Agent 发起的读取带着 `limit: 40`——工具只回前 40 行。它推断出「这个文件就是个简单映射表」，在从未见过的第 380 行区域插了一个引用同模块常量的补丁：CI 深处炸出 `undefined`，因为它不知道第 380 行附近有一个同名局部变量。事后连「这次修改所依据的视野有多少行、文件有没有看全」都无处问起。

**场景二：截断标记下的自信。** 工具输出超限，harness 在尾部接一行 `[truncated]` 返回。Agent 把这半卷当全卷用：总结文档说「该模块只有两个导出」，重构把「第三个导出」（在被截掉的那半卷里）的引用全部改断。失败证据要到运行时才出现，而「它看见的是被截断的那一份」这件事，在流里明明留了痕——只是没有一层去读。

**场景三：只窥不读的爬窗。** 同一个日志文件被 `limit=20` 取了三次窗（第一页、跳 10 行再取、再取 5 行），始终没有一个完整读取；随后对着这三次窗的拼图就开始改日志解析器。三个窗加起来不足全卷的三成，「拼窗当全卷」的手术在流里有迹可循，却无人记账。

## 问题（治什么病）

**Agent 残卷盲动**：会话流里每一次装载证据都真实发生了，但**没有任何一层审计读据的残全**——

- 本仓 #1–#22 已交付的二十二层层层核过登记表：知止拦「写前读过没有」（读之有无），有涯管「读过的重复装载」（读之重复），稽疑审「动前问没问」（问之有无），效验称「成功输出的成色」（报之空实），知足量「写入的规模」（写之多少）——**「读到的是全貌还是残卷」全仓无账**。
- 业界结构性证据：上下文窗口有限，**截断是所有 Agent 运行时的结构性常态而非偶发故障**——主流编码代理的读文件工具普遍带行数上限并在结果尾部标注截断（如 Claude Code 的 Read 在 2000 行处截断并留提示行）；语言模型对长上下文中部的利用衰减有专门的实验文献（Liu et al.《Lost in the Middle》，2023）。「读半卷而作」是 harness 结构与模型局限的叠加处，却只靠「希望你自觉多读几次」这一条纪律——**没有账**。

## 价值（为什么不是伪需求）

自检四问：

1. **问题是真实的吗？**——是。三个场景都是 agent 编码的日常；截断是结构性机制（窗口有限 + 输出上限），不是偶发 bug；「改坏了没看见的地方」是 review Agent 交付时最常见的定责难题——而「它当时看见了什么」其实全部留在会话流里，只是从没被称过残全。
2. **本仓二十二层真的没治吗？**——逐行核过方向登记表。最近似的几层：知止治**读之有无**（写前拦未读），本层治**读之残全**（残见上动刀）；有涯治**读之重复**（世未变而重装载），本层治**读之缺省**（一卷未见其全）；稽疑治**问之缺席**（该问的没问），本层治**看之残缺**（看了但没看全）；效验称**报之空实**（验的输出），本层称**据之残全**（读的输入）——一输出一输入，谓词正交。边界在 docs/03 §11 逐层锁死。
3. **确定性可判吗？**——残见的两通道全部是流内结构信号：**取窗**=读取调用参数里出现的窗口字段（`limit`/`offset>0` 等，字段名显式表）；**显残**=装载结果内容尾部的截断标记（默认形表认尾、显式形认全文）。零 LLM、零语义判断、零网络、零子进程、零文件系统探测。
4. **判罪会不会冤枉？**——清白道全在设计里：**取窗认全**（限窗内回程行数不足窗值=卷小于窗，见全了，全览）、**补览赦免**（残见之后、动刀之前有全览，从全览起清白）、**自书为览**（该径此前被本会话成功写过——自己写的自己知道）、**豁免在册**（材册签字的径全免出账）、**失败见不入账**（isError=true 的读取什么也没看见）、**执行黑盒不判**（exec 的输出不可寻径，宁漏勿诬）、**无据之见不判**（老流无 content 也不见窗字段——不证其残亦不证其全，静默放过）、**单碎览十分不咬门**（点名不门禁）。

## 产品形态

DeepSeek Harness **审材式插件**（Cordis，结构性零拦截）+ 零依赖审计 CLI + Agent Skill——与全仓范式一致：可运行、可测量、可证伪、可离线重放验尸。审材式是本实验室**第二十四个能力类型**（拦/审/供给/记习/诊/勘流/巡忆/守权界/封界/权界/秉笔/行前定/计账/审柄/记程/称实/核名/稽问/结绳/谏诤/量出之后）：判定对象不是事件的性质，也不是事件的数量形，而是**证据的成色形——看见的那一份完不完整**。
