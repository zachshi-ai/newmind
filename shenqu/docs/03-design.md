# 03 · 设计：语义锁死

> 本文锁死全部判定语义：名词、判定序、分值、门与带、材册形状、夹具期望。实现与本文冲突时只能改实现，不得改本文（A 表同理）。

## 1 · 流与会话（按会话分账）

- 每行一个 JSON 对象；`#` 与空行为注释；坏行报行号并退出（exit 2）。格式与 zhizhi/jiebi/zhengnian/jiubian/dingfen/mingshi/xiangxiao 同规（`tool_call` / `tool_result`，id 配对回填，无 id 时 result 并入紧邻其前的 call，孤儿 result 独立建档）。
- **result 的 `content` 字段（字符串）随 result 事件到达，回填到对应调用上**——这是显残通道的证据源（乡校/知足同款字段）。content 为块数组时防御式提取 text 拼接（插件侧）。
- 本层判定只用**流内序列**，不依赖时间戳（时序无关，缺 at 之流全判）。
- 每个流文件是一个会话，会话名 = 文件 basename。**据证链按会话分账**：残见/全览/自书的登记与盲动/碎览的判定都以 (session, path) 为键——盲动的对象是「一个动刀者的见闻」，甲会话读全救不了乙会话的盲（与知足的全流归并不同：那是量的归并，这是知的归属）。报告的案与注记带 session 字段，issues 行按径聚合展示。

## 2 · 对象键与工具族（与 jiubian/dingfen/mingshi/xiangxiao/zhizu 同规，零 NLP）

- 对象键三级回退：`args.path | args.file_path | args.notebook_path` → `p:`；`args.command` → `c:`；其余 → `n:`。
- 工具族词表同知足：observe（read/grep/glob/…） / write（write/edit/patch/create/…） / exec（bash/exec/run/…） / other。
- **径规整**（normalizePath 同 mingshi/jiyi/zhizu）：反斜杠归正斜杠、循环剥前缀 `./`、剥尾 `/`。残见/全览/自书的同径判定一律用规整径。
- **执行族黑盒**：`c:` 对象的命令式读取（cat/head）输出残否不可判、对象不可寻径——两通道都不判（宁漏勿诬）。

## 3 · 材册（`.shenqu.json`）——残记与豁免之册

```json
{
  "version": 1,
  "exempt": ["vendor/"],
  "markers": ["END-OF-EXCERPT"],
  "windowFields": ["maxLines"],
  "fragWindows": 3,
  "noDefaults": false
}
```

- 全部字段可选；缺省即默认值。字段校验失败（类型不对、fragWindows 非 ≥1 整数）exit 2。
- `exempt`：豁免子串表——规整径**包含**任一子串 → 该径一切阶段出账（见不登记、写不判），豁免注记每径一记。声明权在任务方。
- `markers`：显式残记词——**认全文**（内容任意位置含该词即显残）。默认残记形**认尾**（内容去尾空白后以该形结尾才算——截断标记的物理位置在尾部，正文里引用「truncated」字样的文档不误伤）。
- `windowFields`：增补窗字段名（与默认表取并集；`noDefaults: true` 时只有显式表）。
- `fragWindows`（默认 3）：碎览的窗数阈。
- `noDefaults`（默认 false）：关闭两张默认表（残记形/窗字段）——审计方口径的开关。
- **无册照判**：audit 不带 `--file` 或册缺失时，默认表照常在岗。坏册 exit 2。
- **信任模型**（同知足足册/度支制册）：材册是任务方的声明，Agent 无从自我豁免；Agent 若自改册文件，残见本身在流里留痕，审计方应以任务方签发的册为准。CLI 旗标是**审计方**的口径，优先级：旗标 > 册 > 默认。

### 3.1 默认残记形表（10 形，认尾）

`[truncated]`、`[truncated…]`、`[...truncated]`、`[output truncated]`、`[content truncated]`、`<truncated>`、`(truncated)`、`[Clipped]`、`[...clipped]`、`[cut off]`

### 3.2 默认窗字段表（18 名）

- **限形**（字段存在即窗，11 名）：`limit`、`max_lines`、`maxLines`、`num_lines`、`numLines`、`line_limit`、`lineLimit`、`head_limit`、`headLimit`、`tail_limit`、`tailLimit`
- **偏形**（字段存在且为 >0 数值即窗——跳过了卷首，7 名）：`offset`、`start_line`、`startLine`、`begin_line`、`beginLine`、`skip_lines`、`skipLines`

## 4 · 判定序（锁死，零 LLM）

引擎唯一写入口 `recordCall`，逐调用处理。**入口滤（先于一切）**：`isError === true` 一律不入账——失败之见非见（什么也没看见），失败之写未落盘；`isError` 未知（null，老流）按已发生入账。

### 4.1 残见两通道（observe + p: + 成功）

判定序：

1. **豁免**：规整径含豁免子串 → 豁免注记（每径一记），见不入账，止。
2. **窗字段命中**？限形=字段存在且值为数值；偏形=字段存在且值为 >0 数值。
   - 偏形命中 → **残见（取窗·跳卷首）**——跳过了卷首，无论回程多少行都是残卷，止。
   - 限形命中 ∧ content 缺 → **无据之见**（窗已开而回程不可见——不证其残亦不证其全），止。
   - 限形命中 ∧ content 在 ∧ 内容行数 < 限值 → **全览（取窗认全）**——回程短于窗，卷短于窗，见到底了，止。
   - 限形命中 ∧ content 在 ∧ 内容行数 ≥ 限值 → **残见（取窗）**——窗满而未证到底。见没见全的举证责任在动刀者：自证其全唯有一途，读到比窗小的回程。
3. 无窗字段：
   - content 在 ∧ 无显残 → **全览**（卷在眼前而无所缺）。
   - content 在 ∧ 显残 → **残见（显残）**——卷尾自带残记。
   - content 缺 → **无据之见**（老流诚实沉默）。

残见事件登记 {kind: 'window'|'marker', path, session}；全览登记 {path, session}。内容行数按真实换行切分、末尾换行不计（编辑器常识行数）。

### 4.2 盲动（write + p: + 成功）

判定序：

1. **豁免**：同上，写不入账，止。
2. **写前查账**（该 (session, 规整径) 的见闻史，**先查后记**——本次写不算自己的凭据）：残见 ≥ 1 ∧ 全览 = 0 ∧ 自书 = 0 → **盲动立案 +30/案，cap 60**。
3. **自书登记（只记无案之写）**：写时立案（盲动）则该笔不记自书——**盲写不生据**，同径次刀仍可立案（逐笔立案，cap 60 才可达）；写时清白（有全览、有自书、或该径无残见）才记自书。无见闻之写（不归本层）亦记自书——作者知道自己写过什么：create → 取窗 → patch 的 TDD 链条清白。
4. 写前**无任何入账见闻也无自书** → 不归本层（写前读过没有是知止的地盘），静默但记自书；全是无据之见 → 同静默（宁纵）。

同一径先后多笔写皆在残见之后：逐笔立案（每笔动刀各是一案），cap 60 封顶。残见之后、动刀之前的**补览**（全览）救得了后续的刀，救不了已立的案——时序以流序为准。

### 4.3 碎览（judge 收尾现算，幂等）

- 对象：(session, 规整径)，非豁免径。
- 判定：残见数 ≥ fragWindows（默认 3） ∧ 全览 = 0 ∧ 自书 = 0 ∧ **该径无盲动案**（有刀之径已由盲动定罪，不双罚——只窥不作之径归碎览）→ 单径一案 +10，cap 20。
- 三窗而始终不读全卷：拼窗当全卷的手术前奏，单看每窗都小，合起来是结构性的「不审曲面」。

### 4.4 执行族与其他（exec / n:）

黑盒不判：命令式读取的输出残否与寻径都不可得——不登记、不立案（宁可放过，不可错罚）。

## 5 · 清白道（汇总）

| 清白道 | 条件 | 结果 |
|---|---|---|
| 取窗认全 | 限窗命中而回程行数 < 窗值 | 全览（卷短于窗，见到底了） |
| 补览赦免 | 残见之后、动刀之前有全览 | 从全览起清白（已立之案不销） |
| 自书为览 | 该径此前被本会话**无案**成功写过（盲写不生据） | 视同有据 |
| 豁免在册 | 规整径含材册 exempt 子串 | 见写全免出账，注记每径一记 |
| 失败见不入账 | isError === true | 全程不入账 |
| 执行黑盒 | exec 族 | 不判（宁漏勿诬） |
| 无据之见 | content 缺（含限窗开而回程缺） | 不证残全，静默（老流诚实沉默） |
| 只窥不作 | 有残见案之径不再入碎览 | 不双罚 |
| 点名不咬门 | 单碎览 10 分 | 落全带（0–14），exit 0 |

## 6 · 分值与分带门（锁死）

```
blind = min(60, 30 × 盲动案)
crawl = min(20, 10 × 碎览径)
残值 total = min(100, blind + crawl)
分带：全 0–14 / 昧 15–29 / 盲 ≥30
门：默认 30（--gate 可调）——单盲动即红；单碎览 10 全带点名不咬门；双碎览 20 昧带点名不咬门
```

中带可达性校验：双碎览 20——昧带（15–29）非空。

## 7 · issues 行序（锁死）

盲动 → 碎览 → 豁免 → 净鉴（无任何案时一行「净鉴」收尾；豁免注记不挡净鉴）。

- 盲动：`盲动 ×N（+30/案）：径 残见 K 笔（窗 a · 显 b）、径2 … —— 审曲面势，以饬五材`（按径聚合，K 为该径残见总数；a/b 为取窗/显残计数，零者省略；径按首次立案序）
- 碎览：`碎览 ×N（+10/径）：径 窗 K、径2 窗 K2 —— 斩毂之道，必矩其阴阳`（残见数降序，同数按径字典序）
- 豁免：`豁免 ×N（不计分）：径 —— 材册明言`
- 净鉴：`净鉴：材账无案——材美工巧，合之为良`

## 8 · 报告形状（CLI 与插件共用，锁定）

```json
{
  "sessions": 1, "calls": 4, "views": 2, "writes": 2, "cases": 1,
  "score": { "total": 30, "blind": 30, "crawl": 0 },
  "band": "盲", "gate": 30, "verdict": "fail", "ok": false,
  "counts": { "blindActs": 1, "crawls": 0, "partialViews": 1, "fullViews": 1, "exempted": 0 },
  "gauge": { "viewedPaths": 1, "windowReads": 1, "markerHits": 0, "fragTop": [{ "path": "src/api.js", "partials": 1 }] },
  "issues": ["…"]
}
```

- `views` = 残见 + 全览（入账见闻数）；`writes` = 入账成功写数。
- `counts`：盲动案数 / 碎览径案数 / 残见数 / 全览数 / 豁免注记数。
- `gauge`（材况）：入账见闻的规整径去重数、取窗命中调用数（含认全）、显残命中数、fragTop（残见 ≥1 的径按残见数降序取前 3，同数按径字典序）。
- CLI 只吐判词（本形状），不吐引擎内部账。

## 9 · 材牌块（接缝供给，逐字节确定）

- 材册公示 + 材账计数，两次渲染必得同一文本（shasum 可证）；全缺省册输出确定性文本。
- 文案模板（行序锁死）：

```
【审曲 · 材牌】
材册：残记 10 形 · 窗字段 18 名 · 碎览阈 3 窗
豁免径 N 条
  · <子串>
材账：盲动 x · 碎览 y · 残见 a · 全览 b
审曲面势，以饬五材——合此四者，然后可以为良
本块由确定性规则生成；重放同一材册必得同一文本。
```

（残记/窗字段计数为**生效表**大小——默认 ∪ 显式，noDefaults 时仅显式；豁免 0 条时省略条目行；带账版在材账行用引擎 counts。）

## 11 · 与相邻层的边界（结构性，不是纪律性）

| jiyi（#20） | 稽疑审**问的缺席**（首动之前问没问环境），审曲审**看的残缺**（看了但没看全就动刀）：一问一看；该问的问了、看到的那份却是半卷，稽疑看不见、审曲看得见 |

## 12 · 诚实边界

- **执行族黑盒**：`cat`/`head` 式命令读取的输出残否与对象寻径都不可得——不登记不立案（宁漏勿诬）。本层两通道都长在专用读工具的结构上（参数窗字段 + 结果尾部残记），这是能力边界不是漏判。
- **老流退化**：result 无 content 且调用无窗字段 → 无据之见，不证其残亦不证其全，静默（与知足「老流巨写维度沉默」同款的诚实）。
- **默认形认尾**：残记默认形只认内容**尾部**（截断标记的物理位置）；正文里讨论「truncated」字样的文档（比如本仓自己的设计文档）不会误伤。显式形认全文——显式声明权在任务方，签了字就按全文找。
- **窗满未到底即残**：回程行数 ≥ 窗值时无法分辨「恰好在卷尾截到等行数」与「后面还有」——判残见的依据不是断言后面必有，而是**动刀者未证其全**：自证其全唯有一途（读到比窗小的回程）。举证责任在动刀者，这不是错罚。
- **词法可欺**：Agent 可以不用窗口参数、让 harness 静默截断而无标记——流里无痕，本层诚实沉默。凡留痕之残必上账；词法可欺但骗一次留一次形，是全仓同款取舍。
- **模型无关**：零 LLM 调用、零提示词注入、零网络、零子进程、零文件系统探测（core/plugin 不触 fs，bin 才读文件）。
