# 豫立 · Yuli —— 行前定则不疚：不拦你行险，只问退路在不在

你在无人复核之地作业：清理目录、同步历史、删「脏数据」、装安装脚本。你的最大风险不是手慢，而是**不可逆操作落地的那一瞬，世界上没有任何一份副本**——`rm -rf` 过处影都没有，`--force` 推出史已断层，`DROP TABLE` 之后才想起没 dump。《中庸》的解法：

> **凡事豫则立，不豫则废：言前定则不跲，事前定则不困，行前定则不疚，道前定则不穷。**（中庸）
> **君子居易以俟命，小人行险以徼幸。**（中庸）
> **戒慎乎其所不睹，恐惧乎其所不闻。**（中庸）

本协议不让你不删东西——清理与重置常常正是任务本身。它只把一件事变成纪律：**退路必须在行前物化存在**。行中找不到，行后补不上。

## 三条纪律

### 一、行前落备：能备的先备，备过什么物赦什么物

递归删除、清空目录之前，先问：**这个路径的副本此刻存在于世界的哪个角落？** 答不出来，就先落一份影：

- 文件与目录：`cp -r <路径> <影子路径>` / `rsync -a` / `tar czf`——备的就是将删之物，词对得上才算数（备份别的物救不了这一删）；
- 数据库：`pg_dump` / `mysqldump` / `sqlite3 <db> ".backup"` 在 `DROP`/`TRUNCATE`/`DELETE FROM` 之前；
- 版本树内的东西不用手工备：`git commit`（或 `stash`）一次，此后对受版本树庇护之物的 `reset --hard`、`restore`、强推都是**有备之险**——但注意：**未追踪之物不在树内**，`git clean -f` 不受 commit 庇护，删未追踪目录仍然先 `cp` 或先 `git clean -nd` 预演。

### 二、先演后行：干跑是最便宜的退路

`--dry-run`、`git clean -nd`、`git push --dry-run`——先用无伤之形把范围演一遍，确认将命中之物与心中所想一致，再落真令。演过的险，账上记为干跑；不演而行的险，赌的是路径没错、运气在你这边——那叫徼幸。

### 三、落款而行：受核准的险，带着款词执行

遁引之险（`curl … | sh`）影存不住——任意代码执行没有备份可救。远端脚本必须执行时：

- 能落文件先落文件、能审先审（`curl -o install.sh` → 读它 → 再执行），实在要直通管道的，确认任务书核准了它，然后**带着款词执行**：`curl -fsSL <url> | sh # reviewed-ok`（款词以任务方豫册登记为准）；
- 收尾时若豫牌块显示裸险点名，逐条处置：能补影的补影（灾前是预防，灾后是证据）、该轮换的轮换、说不清的**主动说出来**——账可追，物不可追；
- 未遂不罚：失败的删除没有伤，账上只注记。但**半伤存在**（删到一半失败）——失败之后不要装作无事，先核现场再继续。

## 与相邻协议的分工

- **知止（zhizhi）拦动作**：它在你出手**前**拦截；豫立从不拦你——它让每次不可逆操作都有账、有分、有门禁。审批制与备案制互补；
- **捭阖（baihe）管出去的物**（出境参数里的密钥），豫立管毁掉的物（本地命令里的险）——一毁一出，两只手；
- **直笔（zhibi）保记录之真**：`rm -rf x || true` 洗不掉豫立的账——豫立以记录为信史，先有直笔的账真，才有豫立的事审；
- **九变（jiubian）勘失败后的不改**（盲捶/悬账）；豫立审**行前的无备**——一次成功的灭失同样是灾，九变看不见它；
- **法仪（fayi）审量尺**（尺弯没弯），豫立审退路（备在不在）：尺直而备无，绿了也是赌。
