# 01 · 选书：《中庸》——凡事豫则立，不豫则废

## 为什么是《中庸》

给「险行退路治理」找思想源头，候选不少：老子的「慎终如始」（已为知止所用，且重在节制不在退路）、《周易》的「思患预防」（已为立诚所用）。而《中庸》对「行险」这件事有一套**更结构化**的解剖——它不只讲"要谨慎"，它给**行前定**的操作定义（言前定则不跲，事前定则不困，行前定则不疚，道前定则不穷——退路是行前物化出来的，不是行中临时找的）、给**险与备的对照画像**（君子居易以俟命，小人行险以徼幸——无备而行的本质是把存亡押给运气）、还给**无人在场时的戒慎**（戒慎乎其所不睹，恐惧乎其所不闻——Agent 恰恰全程无人在场）。这三件事恰好就是险备治理的三个设计支柱，且《中庸》未被本仓任何项目使用（zhizhi 道德经 / jiebi 荀子 / zhengnian 坛经 / weibing 黄帝内经 / jiubian 孙子 / youya 庄子 / lunshi 孟子 / dingfen 商君书 / baihe 鬼谷子 / zhibi 春秋〔在途〕/ buer 论语〔在途〕/ licheng 周易〔在途〕/ fayi 墨子〔在途〕）。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《中庸》原文 | Agent 的病 | 豫立的机制 |
|---|---|---|
| **凡事豫则立，不豫则废**：言前定则不跲，事前定则不困，**行前定则不疚**，道前定则不穷 | 险行的「备」必须**在行之前**落成——行中找不到、行后补不上：`rm -rf` 过后，影子来不及存；`--force` 推出，旧史追不回。备不是心态，是**行前存在于流里的物证** | **备形对账**：备 = 流中先于险行的成功事件（影写/存史/干跑逐族有形）；行前无备形而险行遂，即裸险入账——「疚」被逐案落成账面上的确定词条 |
| **小人行险以徼幸**（君子居易以俟命） | 无备而行险，本质是**押运气的赌博**：赌路径没错、赌没人恢复、赌输出可逆。徼幸者不是不知道险，是认为险轮不到自己 | **裸险案**：险形命中 ∧ 成功 ∧ 无备 → +30/案（默认族）；点名不裁动机——它是不是「故意的徼幸」账上不问，账上只问**退路在不在** |
| **戒慎乎其所不睹，恐惧乎其所不闻** | Agent 全程在「所不睹、所不闻」之地作业：无人在场、无人复核，危险命令落在深夜的 transcript 第 4317 行——**无人在场恰是行险的高发地**，人却只能在灾后通读全流 | **险账**：每条 exec 族调用过四族险形词表，命中即逐案入账（裸险/虚险/落款/有备考案）——「所不睹」之地从此有账可查 |
| **言前定则不跲**（跲：绊倒） | 干跑即「言前定」的物化：`git clean -nd`、`git push --dry-run --force`——先以无伤之形把范围演一遍，再行真令 | **干跑**：险形命中 ∧ 带 `--dry-run` 词 → 改判干跑事件（0 分），并为其族登记在先之备——先演后行是合法行险的正路 |
| **君子而时中**——中庸之道在「不过不及」：**不禁止行险（发强刚毅皆有之），也不纵容无备** | 治理的两极都是病：一律拦截（Agent 干不了活）与一律放行（灾后无账）。中道是**不拦行险、只问有备**：有备者行天下之至险而不疚，无备者删一个目录也是赌 | **结构性零拦截**：插件无 pre-execute 监听器——险行皆入账、无备才计分；审批制（拦下等人批）之外开**备案制**（行前留备即放行），治理不与效率为敌 |
| **博学之，审问之，慎思之，明辨之，笃行之** | 落款协议：任务方明知某险可受（构建产物可再生、安装脚本已审），须**明说**——显式落款，而非默认放任 | **款词**：`.yuli.json` 登记 `exempt` 词；命令串含款词 → 落款案 0 分。声明权在任务方——豁免不是关闸，是落款 |

## 与管理学互证

- **RPO / 备份窗口**（灾难恢复的两基准量）：RPO 问「能忍受丢多久之前的数据」——答案由**最近一次成功备份**决定，不由意愿决定；影写/布影对账的正是「最近一次成功备份是否先于灭失」这一 RPO 的会话内形式。
- **Terraform plan/apply 二段式**：业界对不可变基础设施的标准纪律——先 plan（无伤预演）后 apply（真令）；干跑是它的词表级下沉。
- **变更管理（CAB / rollback plan）**：ITIL 对高风险变更的硬性要求是**回滚方案先于变更存在**，无回滚方案的变更不得上会——豫立把「回滚方案」物化为流中可验的备形。
- **git 分支保护 + required checks**：业界旗舰平台对 force-push 的默认防禁；豫立不禁 force-push，只让「无存史而强推」在账上现形。
- **3-2-1 备份律**：三副本、两种介质、一份离站——备的多寡是量的问题，豫立只治**备的有无**（零语义约束下可判定的一端）。

## 与相邻思想的分工

- 《道德经》「知止」落在**行为节制**（zhizhi：动作前拦截——数复与未读先写）；豫立落在**行前退路**（不拦行险，审退路之有无）：知止是闸，豫立是账。
- 《商君书·定分》治**横向之争**（地归谁，dingfen）；豫立治**纵向之险**（行之前备在不在）——并发之争在别人之手，灭失之险在自己之手。
- 《墨子·法仪》审**量具之弯**（fayi：尺信不信）；豫立审**退路之在**（备在不在）。尺直而备无，绿了也是赌——法仪管不了 `rm -rf` 的直与弯，它管测试。
- 《春秋》直笔治**记录之讳**（zhibi：`|| true` 洗白退出码）；豫立以记录为**信史**——直笔保证账是真的，豫立在真账上问退路。互为基座：笔讳则险账皆伪，此为两层的公共边界（流审计）。
- 出境之险（baihe：物出境不可追）与灭失之险（yuli：物灭失不可追）是**两只手**：一只把物送出去，一只把物毁在本地——捭阖审参数里的物，豫立审命令里的险。

## 诚实边界（我们不假装的事）

1. **审计对象是流**：流里没发生的破坏，账上看不见——经带外通道（别的终端、别的进程）删的文件，豫立无从知晓；这是流审计各层的共同边界，不是豫立的缺陷。
2. **词表级险形**：只认可证之险形（四族默认形 ∪ 显式登记）；词表之外的险（新形态的破坏命令）不入账——宁可漏判，不可妄断。
3. **备形只问有无，不问对不对得上**：影写以**词法相交**定关系（备过什么物、赦什么物之险——`cp` 命令与险行命令共享词元即算影随其物），`git` 存史全族全局（受版本树庇护之物一荣俱荣）；「备份内容是否完整可恢复」是语义判断，零 LLM 约束下不做。
4. **未遂不罚**：`isError=true` 的险行只记虚险 0 分——半伤（删到一半失败）不可辨，宁纵勿诬；红是真的，伤可能也是真的，账上只能承认辨不了。
5. **险值 0 不是安全分**：只说明**账上无裸险**；词表外的世界管不着——豫立治已形之裸险，不测未形之险。
