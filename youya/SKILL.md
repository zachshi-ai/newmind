# 有涯 · Youya —— 世未变而它忘了，账上见

你在长会话里干活：窗口是硬预算，而会话流每轮都在变厚。你最大的隐性风险不是笨，是**你早先见过的东西已经无声地落出了工作记忆**——于是你重读没改过的文件（复见）、空跑没变化的命令（复命）、或者凭走样的记忆动手。《庄子·养生主》的解法：

> **吾生也有涯，而知也无涯。以有涯随无涯，殆已。**
> **缘督以为经。**（以一线要籍为常，不逐万物）
> **官知止而神欲行。**（感官该停的地方：已见未变之物，不必再拿一遍）

本协议不让你更聪明，只让「不忘」变成三条可执行的纪律。

## 三条纪律

### 一、不复见：装载之前，先问「我手里是不是已经有了」

打开 read/cat/view 之前，回想该路径是否已在本会话装载过、其间是否被（你或任何人）写入过。**其间无写 ⇒ 内容未变 ⇒ 手里那份就是最新的**，直接用；要更新位置感，看要籍块里的陈账行（末见闻第几调用、隔了多远），而不是重新整文件装载。写后重读是正当刷新（那是「鲜」），不在此列。

### 二、不复命：执行之前，先问「世界变了吗」

重跑一条跑过的命令之前，检查上次运行之后有没有**成功的写入**（你改过任何文件）。有 ⇒ 重跑有据；没有 ⇒ 重跑在信息上是空转（复命）。例外：上次运行**失败**了——那是势变之地（失败后的应对归九变纪律），不属遗忘。

### 三、看要籍：动手前先看账内地图

宿主在接缝处递给你**要籍块**时：读陈账清单（隔久未顾的路径——复见之诱的高危区）→ 对每个要动的路径先判断「手里这份是否仍然有效」（其间无写即有效）→ 再决定用记忆还是真需要装载。要籍是确定性生成的，它列的每笔账都在流里真实发生；它没提的路径只代表流里没有证据。

## 操作流程

```bash
youya audit <本会话流.jsonl>           # 途中/收尾审计殆值（新硎/割/折）
youya yaoji <本会话流.jsonl>           # 拿到要籍：陈账清单 + 工作集地图
youya audit <stream.jsonl> --gate 20   # 关键任务用更严的门
```

殆值进「折」带（≥30）说明遗忘已经在账上成案——回到纪律一、二逐案核对，而不是继续按走样的记忆干活。

## 何时必须自查

1. 拿起 read/cat/view 之前（纪律一：其间无写就不必复见）；
2. 重跑一条历史命令之前（纪律二：账内有成功写入才重跑）；
3. 会话过半、早期文件要再动手时（纪律三：先看要籍/跑一次 yaoji）；
4. 任务收尾前跑一次 `youya audit`——殆值是「折」带就还有没对账的遗忘。

## 边界

- 殆值 0 不保证判断正确、方向对头——判断校准归解蔽，目标在场归正念，失败后的重试归九变（有失败介入的重复不是遗忘，是势变）；
- 外部世界的变化（时间、远端、他人进程）流里看不见：等外部事件的轮询可能被误计为复命——若你在等一个账外的变化，注明即可，账会替你声明这个局限；
- 要籍块只列确凿入账的见闻，绝不虚构威胁——它没提的路径不代表不重要，只代表流里没有证据。
