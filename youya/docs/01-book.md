# 01 · 选书：《庄子·养生主》——以有涯御无涯，官知止而神欲行

## 为什么是《庄子》

给「会话中上下文记忆治理」找思想源头，候选不少：《道德经》"多则惑"（其书已被知止占用）、佛家"念起即觉"（禅宗已被正念占用）、《大学》"知止而后有定"（知止之名亦已被占用）。而《庄子·养生主》对"有限容量如何对付无限信息"给出的不是一句劝诫，是一套**完整的解剖**：它先点破**容量的本体论事实**（吾生也有涯，而知也无涯——窗口有限、流无涯，这不是缺陷是结构）、再给**病名**（以有涯随无涯，殆已——追着无限装，就是殆）、再给**解法**（缘督以为经——以一线要籍为常，不逐万物）、再给**方法的合法性证明**（庖丁之刀十九年若新发于硎——只载要物的刀，千轮仍利；良庖岁更刀、族庖月更刀——装得太满的窗口月月要换）。这四件事恰好就是上下文记忆治理的四个设计支柱，且《庄子》未被本仓任何项目使用（知止 道德经 / 解蔽 荀子 / 正念 坛经 / 治未病 黄帝内经 / 不贰 论语〔在途〕/ 九变 孙子〔已上线〕/ 立诚 周易〔在途〕）。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《庄子·养生主》原文 | Agent 的病 | 有涯的机制 |
|---|---|---|
| **吾生也有涯，而知也无涯** | 上下文窗口是硬预算（token 上限），而会话流无限增长——每次工具结果都在变厚，早期的见闻被稀释、被压缩、被挤出窗口 | 层的存在前提：不扩窗（做不到）、不读心（零 LLM），只对**见闻的账**负责 |
| **以有涯随无涯，殆已；已而为知者，殆而已矣** | 世未变而它忘了：第 3 轮读过的文件第 40 轮原样再读一遍（**复见**）、跑过的命令账内无任何写入又原样重跑（**复命**）——每一次都是"用有限窗口去装它已经装过的东西"，正是庄子点名的殆 | **见闻账**：复见/复命两宗病形逐条入账，合成 **殆值** 0–100——把 context rot 从"感觉变笨了"变成有数可查 |
| **缘督以为经** | 窗口里没有一张"我自己见过什么"的地图：要么凭走样的记忆瞎写，要么付出一整轮装载去重读 | **要籍块**：接缝处供给账内工作集地图（哪些路径、末次见闻在第几调用、隔了多远），以一线要籍为常 |
| **依乎天理，因其固然** | 任何"理解文件重要性"的语义判断都会引入幻觉 | 账本只从流自己的显式结构取义（args.path / args.command 逐字），因其固然——零语义、零 NLP |
| **官知止而神欲行** | 感官该停的地方：已经拿到的东西不必再拿一遍 | 要籍块的指令行：已见未变之物，官知止——把省下的窗口留给神欲行 |
| **良庖岁更刀，割也；族庖月更刀，折也** | 过错没有量级：偶一复读与全程失忆同权重，无从门禁 | **殆值分带**：新硎(0–14，庖丁之刀) / 割(15–29，良庖之刀) / 折(≥30，族庖之刀)，门默认 30 |
| **刀刃若新发于硎**（十九年而刀刃若新） | 正面判准：只载要物的窗口不会钝 | 要籍块让"只载要物"有了可执行的抓手——陈账点名，新物不复见 |
| **指穷于薪，火传也，不知其尽也** | （相邻分工所自）薪烬火传是**跨会话**的事 | 火传归不贰（跨会话错误账本）；**薪**——会内窗内这一把火烧得旺不旺——归有涯 |
| **善刀而藏之** | 流终要收刀 | finalize：流终闭合全部账目、定谳殆值（收刀） |

## 与实证研究互证

- **Lost in the Middle**（Liu et al., TACL 2023）：长上下文模型的可用信息随其在窗口中的位置显著衰减——中段的见闻近乎不可用。这是"陈账"的实证基础：不是内容不在窗口里，是位置决定了它还在不在**工作记忆**里。
- **Context Engineering 实践**（2025 年以来各家运行时的 compaction / context editing / memory tool）：工程界已承认"窗口必须主动管理"；有涯给这件事一个**确定性、可审计、零模型**的下账层——压缩发生了什么、什么被丢了，不再只是运行时的内部行为。
- **复读即症状**：一次完整装载的成本（整文件 token + 一轮延迟）是可核算的；复见率是 context rot 的**行为学指标**——不需要读懂任何语义就能测出"它开始忘了"。

## 与相邻思想的分工

- **有失败介入的重复是势变，归九变**：失败之后原样重试，世界（至少是失败信号）已经变了，它还在按旧图作战——那是盲捶。有涯只罚**世未变的重复**：两次成功装载/执行之间，账内无任何写入——世界没变，它忘了。判定边界在流里逐字可证（有无 `isError:true` 介入）。
- **本愿不失是正念的事，见闻不忘是有涯的事**：正念供给的是开工契约里**声明过**的锚点；有涯供给的是运行中**发现**的工作集（实际读过的路径、跑过的命令）。一个守愿，一个守见闻。
- **火传是 buer 的事，薪是有涯的事**：跨会话的教训传递归不贰；本会话这一把火烧得旺不旺（窗口里的见闻还活着吗）归有涯。
- 《道德经》"轻诺必寡信""多则惑"（知止已用其书）：有涯不引道德经——复见复命是行为学事实，不是节制劝诫；有涯不拦任何动作（知止地盘），只在账上见。

## 诚实边界（我们不假装的事）

1. **只记账内之变**：外部世界的变化（时间流逝、远端状态、他人进程）流里看不见。复命以「账内无成功写入」判——轮询类会话（等待外部事件反复 `git status`）可能被误计。声明权在流：这是确定性换覆盖面的明码标价（治未病闻诊同款诚实）。
2. **复见限装载类工具**（read/cat/view）：检索类（grep/glob/search/ls）每次参数各异、所问不同，同路径再检索是**合法的再问**不是遗忘——不同的问题不是失忆。
3. **路径不做归一化**：`./a.js` 与 `a.js` 是两个对象（零语义；宁漏勿诬）。
4. **同会话"盲写"不可判，故不设此罪名**：单会话流里唯一的写者就是它自己，写后不重读不构成失忆（自己写的自己知道）；流外有人才可能造成"建立在旧记忆上的写"，但那在流里无从对证——有涯不判看不见的罪。
5. **殆值 0 不是记性满分**：它只说明账内无复见复命之案。从没读过任何东西的会话殆值也是 0——有涯不强迫多读（庖丁解牛数千牛，刀仍有余），它让**每一次遗忘都有价**。
6. **要籍块只列账内确凿的见闻**，绝不虚构威胁：它没提的路径不代表不重要，只代表流里没有装载或写入的证据。
