# 03 · 设计：度支 · duzhi —— DeepSeek Harness 的量纲治理层

## 0 · 一句话

**制册立线（冢宰制国用），用账对总量（量入以为出），余量块供蓄支（三年之蓄有刻度），制值分带门禁（越界曰非）。**

## 1 · 四件套总览

| 件 | 是什么 | 谁供给 | 何时 |
|---|---|---|---|
| **制册** | 预算声明：`{version:1, id, budget:{maxCalls?, maxMinutes?}}`——至少一条线 | 任务方（`.duzhi.json` 或 CLI 旗标） | 开工前（追认验尸时=审计时补立） |
| **用账** | 总量对账：出 = 每次工具调用（含失败）∧ 时程 = 末 `at` − 首 `at`；逐调用判逾案 | 度支引擎（tools/result 观察结算） | t>0 全程 |
| **制值** | `(无制?40:0) + min(60, 6×逾案)`；分带 足/急/非，门 30 | 度支引擎 | 观察 / 审计 |
| **余量块** | 接缝处逐字节确定的蓄支图（入/出/蓄/带/逾点名，shasum 可证） | `ctx.duzhi.yuliang()` / `duzhi block` | 宿主决定注入时 |

## 2 · 制册（预算声明）

```json
{
  "version": 1,
  "id": "fix-login-bug",
  "budget": { "maxCalls": 120, "maxMinutes": 45 }
}
```

- **schema**：`version` 必为 1；`id` 非空字符串；`budget` 对象且 `maxCalls / maxMinutes` **至少其一**（无量纲之册非法）；两者存在时必为 **≥1 的整数**；多余字段宽容忽略。
- **两条线互相独立**：只设 `maxCalls` → 时长维度不判；只设 `maxMinutes` → 调用维度不判。
- **声明权在冢宰（任务方）**：Agent 无从自我发额度；CLI 旗标 `--max-calls / --max-minutes` 与制册同构，可与册并用（缺键互补、同键 CLI 覆盖）。
- **追认合法**：对历史流补线即重判——线是新的，越线是硬数字（声明权仍在任务方一侧的审计者）。
- 缺省载入 `./.duzhi.json`（存在时）；`duzhi declare` 写册（补丁语义：给的键更新、未给的键保留、未给 `--id` 时保留旧 id）。

## 3 · 用账（总量对账）

- **出·调用**：流内**每一次**工具调用计 1——**含 isError 的失败调用**（失败也花了钱）；非工具事件（turn_start/turn_end）不计。
- **出·时程**：`spanMs = 末个带 at 调用的 at − 首个带 at 调用的 at`（毫秒）；`at` 为 Unix 毫秒（与全仓插件 `Date.now()` 惯例一致）。
- **无时不判**：全流无 `at` → `spanMs = null`，时程维度诚实退化；个别调用缺 `at` → 该调用的时程逾判跳过（调用维度照判），`firstAt` 取**首个带 at 调用**的 at。
- **逾案判定**（每调用至多一案，逐案记 `{seq, ref, at, via}`）：
  - 调用过线（via `calls`）：`seq > maxCalls`——**第 maxCalls 次合法，第 maxCalls+1 次起逾**（线内合法，过线即逾）；
  - 时程过线（via `time`）：`at − firstAt > maxMinutes × 60000`——**严格大于**（恰在线上合法）；
  - 两线同越（via `both`）：一案计一次，不双重计分。
- **判定与 isError 无关**、与工具名无关——量纲面前调用平等（读一次文件也是一次出）。

## 4 · 三宗案别

| 案别 | 条件 | 分 |
|---|---|---|
| **无制** | 制册与旗标皆无（一条线都没有） | 40，一次性（冢宰不制国用——无制则量入无从谈起，出已无界） |
| **逾制** | 越线调用，逐案 | +6/案，cap 60 |
| **守界** | 有制未逾 | 0——不冤枉线内的花销 |

## 5 · 制值与分带

```
制值 = (无制 ? 40 : 0) + min(60, 6 × 逾案数)
```

| 带 | 区间 | 王制刻度 | 门禁 |
|---|---|---|---|
| **足** | 0–14 | 蓄厚（有九年之蓄） | 绿 |
| **急** | 15–29 | 蓄薄（无六年之蓄） | 黄——点名不门禁 |
| **非** | ≥30 | 国非其国（越界或从未有界） | 红——门默认 30，`--gate` 可覆盖 |

边界逐点可证：14→足、15→急、29→急、30→非。无制单独即 40 → 非：**无制之任，非其任也**——不是任务不该跑，是它从未被当作「量入为出」的一任来治理。

## 6 · 余量块（接缝处供给件）

逐字节确定（无时间戳；`#k` 随渲染递增且仅首行不同；同状态两跑 shasum 同值）。模板锁死：

```
【度支 · 余量块 #1】
任：fix-login-bug
入：调用 ≤120 · 时长 ≤45 分钟
出：调用 87 · 时程 39.2 分钟
蓄：调用 33 · 时程 5.8 分钟
带：急
逾：无
—— 本块由确定性规则生成；重放同一流必得同一文本。
```

变体锁死：
- **无制**：`任：（未立制册）`／`入：未制——量入无从谈起，出已无界`／`蓄：——`／`带：非`／`逾：未制，逾无从判`；
- **未设某线**：该线写作 `调用 ——（未设）` 或 `时长 ——（未设）`；
- **无时不判**：时程与时长两处写 `——（无时不判）`；
- **透支**：蓄为负写作 `调用 −5（已透支）`；
- **逾点名**：`第 4 次调用（调用过线）、第 5 次调用（时程过线）、第 6 次调用（调用·时程过线）`……按流序列出；
- 分钟一律 `toFixed(1)`（spanMs/60000）。

## 7 · 插件（Cordis，结构性零拦截）

```
tools/result   emit    观察结算，用账步进一格（唯一写入口）
（无 pre-execute）      —— 零拦截是结构性的；动作之闸是知止的地盘
```

- `inject = ['tools']`：观察口挂在真实工具管道上；
- 服务 `ctx.duzhi`：`report()`（概数+制值+带）、`ledger()`（逐案全目）、`yuliang()`（余量块，`#k` 递增）、`gate()`（门禁裁决）、`exportStream()`（导出流供离线重放对账）、`setBudget(register)`（立/换册，换册=新账）；
- 配置：`{ register: {id, maxCalls, maxMinutes} }` 或直配 `{ maxCalls, maxMinutes, id, gate }`（直配覆盖 register 同键）；
- 观察永不反噬：监听器内异常吞掉，管道照常；
- **前缀一致性**：逐案结算互不依赖——运行中即时制值与离线重放同流天然一致（observe×audit 账实对账的前提）。

## 8 · CLI

```
duzhi audit   <stream.jsonl> [--register f | --max-calls n --max-minutes m] [--id s] [--gate n] [--json]
duzhi block   <stream.jsonl> [同上]                余量块（接缝处供给件）
duzhi declare --max-calls n [--max-minutes m] [--id s] [--file f]     写册（补丁语义）
duzhi list    [--register f | --max-calls n --max-minutes m]           生效之线（JSON）
duzhi gate    --value <n> [--gate n]                门禁裁决
duzhi --help | --version
```

退出码：**0** 守界（制值 < 门）；**1** 门禁失败（≥30 默认门）；**2** 用法/输入错误（坏流带行号、制册非法、未知命令）。

## 9 · 流格式

兼容全仓共享会话流格式（zhizhi/jiebi/zhengnian/…同构）：`#` 与空行为注释；坏行报行号；带 id 的 call/result 按 id 归并（首见为准）；无 id 旧格式 result 并入紧邻其前 call；孤儿 result 独立建档；非工具事件跳过——解析器与其余各层逐字同源，跨项目互审的前提。

## 10 · 与前各层的边界（结构性，不是纪律性）

| 层 | 它的地盘 | 度支不碰 |
|---|---|---|
| zhizhi | 动作发生**前**拦（总闸） | 度支零拦截——只在 result 结账，闸与账分治 |
| jiebi | 判断产物的账实对账 | 不判「花得值不值」——值不值是判断 |
| zhengnian | 本愿在场与目标漂移 | 不问「干的是不是愿内之事」——只问花了多少 |
| weibing | t=0 任务书体检（条款**在场性**） | 不看任务书写没写线——只对账**实际有没有越**（写了白写只有对账能见） |
| jiubian | 单案应变性质（盲捶/悬账/游骑） | 不问这一笔该不该发——只记它在线内还是线外 |
| youya | 单案记忆连续性（复见/复命） | 不问是不是忘了——重复的花销照样是一笔出 |
| lunshi | 输入渠道权威 | 不看参数里的话是谁说的 |
| dingfen | 跨会话写域归属 | 分了地不分钱包——总量是度支的事 |
| baihe | 信息出境 | 不看参数里有没有物 |
| zhibi | 记录保真（失败不被洗白） | 用账以真账为前提——笔讳则用账皆伪 |
| buer/licheng/fayi/yuli | 教训/承诺/量尺/退路 | 各不越界；yuli 管灭失之险，度支管烧穿之费 |

## 11 · 结构性声明与 grep 门

- 零拦截：源码无 pre-execute 监听（grep `tools/pre-execute` 精确模式）+ 行为学测试（探针无条件到达工具本体）；
- 模型无关：grep `child_process|axios|openai|anthropic|completion\(|fetch\(` 无输出；
- 他层机制词表（A10）：`alternatives|disconfirming|anchors|wish|charter|盲捶|悬账|游骑|失机|复见|复命|殆值|要籍|越词|涉命|僭行|争界|侵入|越分|争写|贰过|省身|绳账|咎值|结账|溃值|泄物|尘值|拂拭|病灶|医嘱|验尺|曲尺|虚器|照末|废尺|尾红|枉值|翻红窗|绳墨|绿验|器册|险形|裸险|虚险|落款|影写|存史|布影|豫牌|险值|款词|行前定`——源码应无输出（写注释时避开这些字面量，含英文键）。
