# 01 · 选书：《礼记·王制》——量入以为出

## 为什么是《礼记·王制》

给「Agent 资源无账」找思想源头，候选不少：《大学》的「生财有大道」（生之者众，食之者寡）讲的是**财富的生成结构**，不是**单笔工程的支出边界**；《管子·轻重》讲的是国家操盘市场之术，离治理一个作业单元太远；德鲁克《卓有成效的管理者》的时间账（记录→诊断→整块）方法同构，但它是**管理科学**，本仓要的是能逐条落到机制上的**经典条款**。而《礼记·王制》的「制国用」一节，是汉语世界**预算制度的源头文本**，它给的三样东西恰好就是预算治理的三个设计支柱——且《礼记》未被本仓任何项目使用（zhizhi 道德经 / jiebi 荀子 / zhengnian 坛经 / weibing 黄帝内经 / jiubian 孙子 / youya 庄子 / lunshi 孟子 / dingfen 商君书 / baihe 鬼谷子 / zhibi 春秋〔在途〕/ buer 论语〔在途〕/ licheng 周易〔在途〕/ fayi 墨子〔在途〕/ yuli 中庸〔在途〕）。

## 原典条款 → Agent 病 → 机制：逐条映射

| 《礼记·王制》原文 | Agent 的病 | 度支的机制 |
|---|---|---|
| **冢宰制国用，必于岁之杪，五谷皆入，然后制国用** | 预算必须由**冢宰**（主事者）**在用之前**编成——不是干活的人边干边随意。Agent 任务几乎从不在开工时领一条线：这单活值多少次调用、多少时长，无人声明，量纲从未立过 | **制册**：`.duzhi.json`（或 CLI 显式旗标）声明 `budget.maxCalls / maxMinutes`——线由任务方先立，Agent 无从自我发额度；声明权在冢宰，不在臣工 |
| **量入以为出** | 支出以申报的「入」为度——入了多少，才许出多少。Agent 的「出」（工具调用、时程）从不与任何「入」对账：500 次调用的任务和 5 次的看起来一样，灾后连「花了多少、该花多少、何时越的线」三问都无处问起 | **用账**：出 = 流内每一次工具调用（含失败——失败也花了钱）∧ 时程 = 末调用 `at` − 首调用 `at`（毫秒）；入 = 制册所声明的两条线；逐调用对账，过线即记**逾案** |
| **国无九年之蓄曰不足，无六年之蓄曰急，无三年之蓄曰国非其国也** | 蓄备有**分级刻度**：蓄薄到什么程度算告急、薄到什么程度算「已经不是国了」——界限本身成文。Agent 花销没有任何分带：贴着线跑和穿透线跑，在所有账本上长得一模一样 | **制值分带**：足（0–14，蓄厚）/ 急（15–29，蓄浅）/ 非（≥30，越界或从未有界）；门 30——非者支出已出国用之界，门禁红灯 |
| **三年耕，必有一年之食；九年耕，必有三年之食** | 蓄是**可以核算的余量**，不是感觉。Agent 运行中没有任何东西告诉它「还剩多少」——它不知道自己在贴线，更不知道自己已经穿线 | **余量块**：接缝处逐字节确定地供给蓄支图（入 / 出 / 蓄 / 带 / 逾案点名，shasum 可证）——运行中的 Agent 第一次能看见自己的余量 |
| 「量入以为出」的**追认面**：冢宰岁杪造册，用的是**已成之年的实入** | 审计常常是**事后**的：一条历史会话流，当时没人立线——验尸者仍可追认一条线，重放即见越线几案。声明权在任务方，事后补线不伪：线是新的，越线是硬数字 | **追认验尸**：`duzhi audit 历史流.jsonl --max-calls 30`——对任何无册之流补线即判；不补则诚实报「无制 40」（从未被量纲约束，是事实陈述，不是诬告） |

## 与管理学互证

- **FinOps / 云成本治理**：业界对云支出的标准三件——预算声明（budget）、越线告警（alert）、异常检测（anomaly）。Agent 运行时的调用数与时长是同一性质的支出，却几乎没有等价物落到会话流上；度支是它的流级下沉。
- **max_steps 与 step 预算**：Agent 研究里「步数」是标准努力量纲（基准测试普遍以 step 计费计分）；harness 侧的 max_steps 是**执行前的总闸**（知止式的拦），度支是**执行中的账**（对账、分带、点名）——闸与账互补，正如直笔与知止。
- **chargeback / showback**：IT 财务把成本记回业务单元；多会话并行的今天（dingfen 分了写域，没分钱包），每任务一份用账是 showback 的前提。
- **工时单（timesheet）**：德鲁克说有效的管理者从记录时间的实况开始、不从记忆开始——用账就是会话流的工时单，逐案留痕，不靠回忆。

## 与相邻思想的分工

- 《黄帝内经》治未病是 **t=0 的体检**：望诊看任务书**有没有**止法条款（在场性）；度支是 **t>0 的对账**：实际花销**有没有越过**所声明之线（数值性）。体检说「写了没写」，用账说「超了没超」——写了白写是另一种病，只有度支能见。
- 《孙子兵法》九变审**单案性质**（败而再捶是盲捶）、《庄子》有涯审**单案遗忘**（原样重读是复见）——两层的分都是**性质分**；度支只记**总量**：同一笔调用，九变问它应不应再发、有涯问它是不是忘了、度支问它花的是线内还是线外——三账并行不悖。
- 《春秋》直笔保证**账是真的**（退出码没被洗白）；度支在真账上问**花销在不在界内**——笔讳则用账皆伪，此为两层共用的基座（流审计）。
- 《中庸》豫立（在途）审**行险的退路**（备在不在）；度支审**常行的用量**（线在不在）：一个是灭失之险，一个是烧穿之费。
- 《商君书》定分裁**谁有资格写哪块地**；《礼记》王制裁**这一任花的是不是授权之内的量**——名分之争在横向，量入之度在纵向。

## 诚实边界（我们不假装的事）

1. **量纲只有两个**：调用数与时程——token 与货币成本不在会话流里，度支不假装能算钱；调用数是 Agent 研究的标准努力单位（step），时程由流内 `at` 确定性导出。想要钱，拿这两条量纲去乘单价，是审计者的事，不是本层的事。
2. **无制 40 是治理发现，不是诬告**：无册之流判「无制」说的是「此流从未被量纲约束」——事实陈述；要验越线，请追认一条线（声明权在任务方，事后补线合法）。
3. **线内花完也是 0 分**：度支只问「在不在界内」，不问「花得值不值」——值不值是判断，判断另有其主（jiebi 地盘）；一条线内烧满 100 次调用的任务与本层无涉。
4. **无时不判**：`at` 不在流里（或调用缺 `at`）时，时长维度诚实退化（spanMs 为 null、时程逾案不判），调用数照判——宁可漏判，不可妄断。
5. **审计对象是流**：带外通道（别的终端、别的进程）的花销，账上看不见——这是流审计各层的共同边界，不是度支的缺陷。
