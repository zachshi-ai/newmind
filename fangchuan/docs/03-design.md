# 03 · 设计：防川 · fangchuan —— DeepSeek Harness 的吞错形治理（防川式插件）

> 本文锁死全部判定语义；实现与本文冲突时改实现，不改本文与 04 的手算期望。

## 1. 能力类型与接缝

新能力类型：**防川式插件**（第三十一个）。zhizhi 证明插件可以拦，jiebi 证明可以审，
zhengnian 证明可以供给，weibing 证明可以诊，xiangxiao 证明可以听开发期批评之默，
kaocheng 证明可以考契上物之末据，hengfa 证明可以审规矩源之名分——防川证明插件可以
**审交付代码里的吞错之形**：运行期的报错之口被堵在哪里、几处、哪一行、改净了没有。

```
tools/result   emit   观察写面入文账（唯一写入口）
（无 pre-execute）     —— 零拦截是结构性的
```

设计约束（与全仓同规）：模型无关（零 LLM、零提示词注入、零网络、零子进程、零文件系统探测）；
观察永不反噬（监听器异常吞掉，管道照常）；川册持久化归 CLI（register/revoke），插件只吃注入的
book 对象；单会话视图的案与值只采本会话，跨会话归并归离线合并审计。

## 2. 写面与文账（通道锁死）

对象键与工具族同全仓（object.js 同规：`p:` 文件 / `c:` 命令 / `n:` 不透明；
observe/write/exec/other 四族）。径规整同全仓（反斜杠归正、剥 `./` 前缀与尾 `/`）。

**码面**（受扫之径）：不命中豁免形的径。豁免形（防诬卫生设施，开箱在岗）：

- 后缀豁免 10：`.md` `.mdx` `.txt` `.rst` `.adoc` `.json` `.yml` `.yaml` `.svg` `.csv`
  ——文档与数据里的吞形是示例不是行为（「宣之使言」的讲堂）；
- 名形豁免 2：basename 含 `.min.`（压缩产物）；径含 `__snapshots__/` 段（快照）。

**文账（写面唯一）**：write 族 p: 径命中码面且成功 → 该径记一笔写
（content 取 `args.content`，可为 null——无文之写）。
**编辑族不携全文**（old/new 形）：不改末文——判定以末笔带 content 之写为准，
gauge 注记「末文后无文之改 N 笔」（改了什么流内不可见，宁漏勿诬）。

**沙川（exec 落点）**：exec 族生产词法——cp/mv 末个非旗标词元 ∪ tee/touch 任一非旗标词元
∪ 重定向目标（`2>&1` 天然不中）——落点命中码面 → 该径记沙川一笔（文面经命令生成，
扫描不得，诚实沉默）。破坏段（rm 词族）内不计生产（rm 不生产）。

**观察不是写**：observe 族永不入文账。**失败不入账**：`isError === true` 一律不入账。

## 3. 湮形（默认形表，三语族 6 形）——无册照判

对每径的**末文**（末笔带 content 之写）逐行扫描；命中即湮案（一处一案，载径、1-based 行号、形名）。

| # | 形名 | 语族 | 词法 |
|---|------|------|------|
| 1 | **空捕** | JS/TS/Java/C# | `catch` 后可选 `(…)`，花括号体剥空白后为空（`catch (e) { }`、`catch { }`） |
| 2 | **空还** | 同上 | 花括号体剥空白后恰为 `return;`（空还吞——`return null` 等降级不判，宁纵） |
| 3 | **空接** | JS/TS promise | `.catch(…)` 内实参为：空体箭头 `() => { }`、`() => null`、`() => undefined`、空体 `function () { }` |
| 4 | **单行空捕** | Python | `except …: pass` / `except: pass`（行尾可带注释） |
| 5 | **多行空捕** | Python | `except …:` 行后、更大缩进的体全部为 pass / `...` / 注释 / 空行 |
| 6 | **空救** | Ruby | `rescue` 行后到同缩进 `end` 之间体全部为注释 / 空行 |

**导词表**（决之使导——体内有之即清白）：`throw` `raise` `rethrow` `console.` `logger`
`log.` `print(` `sys.stderr` `process.exit` `reject(` `emit(` `alert(`——空接的表达式部分
含导词即不判（`.catch(() => console.error(e))` 是导不是湮）；其余表达式（`false`、`0`、
变量名等）宁纵不判。空捕/空还/空救体为空，导词天然无从在场。

## 4. 川册（纵列授权，声明权全在任务方）

```json
{ "version": 1, "indulge": ["src/best-effort/*"] }
```

- **indulge（纵列）**：glob 串数组——本任务**豁免受扫**的码面（best-effort 清理、
  垫层等「本该静默」之径）。宽 glob：词元含 `*` 时按通配全匹配、`*` 跨目录；
  不含 `*` 时规整逐字相等。命中纵列的径**不入文账**（豁免在立案前，与豁免后缀同层）；
- **无册照判**：湮形开箱在岗，册只管纵列，v1 不扩形、不豁免别的；
- 册是结构化 JSON、唯一入口（CLI register/revoke），无词旗标覆盖；
- 册缺失自动建册（纵列是授权，空册 = 全扫）。

## 5. 判定序（锁死，逐径恰好一态）

对每个曾以任一方式被「落笔」（文账 ∪ 沙川）之径：

| 序 | 条件 | 案别 | 分 |
|----|------|------|----|
| 1 | 仅沙川、文账无写 | **沙川** | 0（注记：文面经命令生成，扫描不得） |
| 2 | 有写、全流无一笔带 content | **无文** | 0（注记：老流诚实沉默） |
| 3 | 有末文 → 扫末文命中湮形 N 处 | **湮案** | +15/处（逐处点名：径:行:形） |
| 4 | 末文净，先前某笔之文曾有形 | **已浚** | 0（注记：改了就净——考其末文） |
| 5 | 末文净且历来净 | **净川** | 0 |

- **考末文**：湮案只看末笔带 content 之写——先前写过吞形、后来改净的径是已浚不是湮
  （交付的是末文，历史在已浚注记里可见）；沙川与无文之后的带 content 之写照常入文账；
- 末文后无文之改不改末文（gauge 注记，同 kaocheng 末据之例）。

## 6. 塞值与门禁

```
sai = min(60, 15 × 湮案总数)
total = min(100, sai)
```

分带：**宣 0–14 / 淤 15–29 / 塞 ≥30**。门默认 30：

## 9. 插件 API 与 CLI

**插件**（`fangchuan-dsh`，Service 名 `fangchuan`）：`report()` 汇总、`ledger()` 文账全文
（逐径逐案）、`paizi()` 导牌块、`gate()` 门禁裁决、`exportStream()` 导出会话流
（call/result 成对、args 原样——写族 content 在 args 里随流携带），
供 `fangchuan audit` 离线重放对账。

**CLI**（零依赖，`fangchuan`）：

```
fangchuan audit <s1.jsonl> [s2 …] [--file <川册>] [--gate n] [--json]
fangchuan register --path <glob> [--file <川册>]    立纵（纵列授权，重复去重）
fangchuan revoke --path <glob> [--file <川册>]      销纵
fangchuan list [--file <川册>]                      阅册
fangchuan block [--file <川册>]                     导牌块（湮形与川册公示，逐字节确定）
fangchuan gate --value <n> [--gate n]               门禁裁决
fangchuan --help | --version
```

默认册 `./.fangchuan.json`；register/revoke 册缺失自动建册；revoke 无此径 exit 2；
list 册缺失 exit 2。退出码：0 通过 / 1 门禁失败 / 2 用法与输入错误。

- **乡校**：一声一川。它审**开发期**组织批评通道被静音（@ts-ignore/eslint-disable/it.skip/

## 12. 既知从宽代价（宁漏方向，逐条登记）

- **注释与字符串内的形同判**：词法不析语法——文档豁免后缀挡大头（.md/.txt 等），
  代码注释里的示例吞形照案（宁记方向，登记）；
- **catch 体唯注释不判**：体剥空白后非空的形一概不扫（词法不做注释剥离——URL 里的
  `//` 会误伤字符串，宁纵）；
- **降级不判**：`catch { return null }` / `.catch(() => false)` 等以默认值降级的写法
  不是湮形（决策不是湮——宁纵；空接只认 null/undefined/空体三写法）；
- **裸捕不判**：Python `except:`（无异常类型）体非空时不判——宽与吞两可，宁纵；
- **Go/Shell 不判**：`_ = err` 归 Go 惯例两可，shell 侧归直笔地盘——词法未及，登记；
- **exec 落点沙川**：命令生成的文件文面不可见，只注记不计分（agent 免咎之途是
  补一笔带 content 的写）；
- **无文之改的修复不可见**：edit 族不携全文，末文之后的修改考不到（考其末文）；
- **多行空捕的缩进判**：tab 与空格混编的体按字面前缀比（不做 tab 展开——宁纵）；
- **词法可欺但骗一次留一次形**：`try { … } catch (e) { handle(e) }` 里的 handle 若
  内部再吞，流内不可见——本层只认词面；
- **时序以流序为准**（缺 at 照判）。
