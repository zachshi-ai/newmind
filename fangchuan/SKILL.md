# 防川 · Fangchuan — Agent 协作协议

> **「防民之口，甚于防川。川壅而溃，伤人必多，民亦如之。」——《国语·周语上》**
>
> 被吞掉的错误不会消失，只在下游以更贵的姿势爆炸。本协议不限制你怎么干活
> （拦是知止的地盘），它要求：交付代码的末文里，吞错之形逐处留痕有价——
> 为川者决之使导（日志、上抛、上报），为民者宣之使言（吞形公示可见）。

## 何时用此 Skill

- 工程师想防住「agent 为让这单活不炸而写 `catch (e) {}` / `except: pass`」；
- CI 需要一道「吞错形」门禁（塞值 ≥ 30 即红——两处即红，单处黄牌）；
- Agent 需要自查：这单活我写没写吞形？写的是不是任务方纵列里本该静默的层？

## 给派活的工程师

```bash
cd your-repo
fangchuan register --path "src/best-effort/*"         # 本该静默的清理/垫层，先立纵
# ……Agent 作业……
fangchuan audit session.jsonl --file .fangchuan.json  # 收工审川（exit 码可进 CI）
fangchuan block --file .fangchuan.json                # 导牌块：湮形与川册公示
```

- **无册照判**：湮形 6 形开箱在岗——不立册也审，册只管纵列一侧；
- **文档与数据豁免**：.md/.json/.yml 等后缀里的示例吞形不受扫（讲堂不是川）；
- **门禁**：塞值 ≥ 30 即红——两处吞形即红，单处黄牌点名不咬门。

## 给 Agent 的五条纪律

1. **决之使导**：错误要么导出去（console/logger/上抛/上报——导词表 12 词在体即清白），
   要么明明白白做降级决策（`return null` 有默认语义不判），唯独不能空体咽下；
2. **纵列要趁开工立**：best-effort 清理确实该静默？开工时向任务方讨纵列
   （川册 register），纵列上的湮形不入账；
3. **降级不是湮**：`catch { return fallback }` 是决策不是吞——本层只认空体与
   null/undefined 抹形；
4. **改了就净**：先前写过吞形、后来改净的径是已浚注记（零分）——考其末文，
   交付的是最后状态；
5. **词法可欺但骗一次留一次形**：注释与字符串里的形同判，文档后缀挡大头——
   别指望把吞形藏进没人看的地方。

## 判定语义速查

| 案 | 对象 | 判定 | 分值 |
|---|---|---|---|
| 湮案 | 末文命中空捕/空还/空接/单行空捕/多行空捕/空救 | 报错之口被堵 | +15/处（两处即红，单处黄牌） |
| 已浚 | 末文净而先前有形 | 改了就净（考其末文） | 0（注记留痕） |
| 沙川 | exec 落点命中码面 | 文面经命令生成，扫描不得 | 0（注记） |
| 无文 | 只有无 content 之写 | 老流诚实沉默 | 0（注记） |

- 塞值 = min(60, 15×湮案)；分带 宣/淤/塞，门 30；
- 导词表 12 词（throw/raise/rethrow/console./logger/log./print(/sys.stderr/process.exit/reject(/emit(/alert(）——体内有之即清白；
- 码面豁免：.md/.mdx/.txt/.rst/.adoc/.json/.yml/.yaml/.svg/.csv + .min. + __snapshots__/；
- 全部判定零 LLM：湮形是词面、纵列是 glob——词法可欺但骗一次留一次形。
